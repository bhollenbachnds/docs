---
title: "Upgrading to PADS4 2024.2"
description: "Check the minimum version needed to upgrade to PADS4 2024.2 and learn why you must update the Main Server before sub servers in multi-server setups."
---

If you want to upgrade to PADS4 2024.2, your current PADS4 version must be at least PADS4 2022.3. That means you need to have PADS4 2022.3 installed and running before you update to 2024.2.

Versions 2022.2 and lower don't automatically update to 2024.2. You need to perform an intermediate upgrade to PADS4 2022.3 first.

From version 2024.2 onwards, PADS4 includes a new central user management system.

This offers a more streamlined approach to managing users and roles with user management in the PADS4 Web Portal.

Because this is a significant change, you need to consider a few additional points when you upgrade a multi-server environment, as described below.

## Upgrading multi-server installations

To implement the central user management feature, we changed the PADS4 Database. Because of this, **you first must update the PADS4 Main Server** and then the sub server. There are a few reasons for this:

- The Main Server will block connections made with pre-2024.2 server versions, because the PADS4 Database has changed, and older implementations won't understand the new user objects.
- Migration of licenses and users is only executed on the Main Server and those are then replicated to the sub servers. So, if you update a sub server first, you might no longer be able to connect to this server. This depends on whether the user exists in the authentication service database.
- A 2024.2 sub server won't connect to Main Servers that are running a pre-2024.2 version, for the same reason as Main Servers.
