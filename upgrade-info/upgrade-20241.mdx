---
title: "Upgrading to PADS4 2024.1"
description: "Upgrade to PADS4 2024.1 from version 2022.3, run an intermediate upgrade from 2022.2 or lower, and estimate Content Library migration time by size."
---

If you want to upgrade to PADS4 2024.1, your PADS4 version must be up to date. In this case, that means you have PADS4 2022.3 installed and running on your PADS4 server. <br /><br />Any version before this (PADS4 2022.2 and lower) doesn't automatically update to 2024.1. You need to perform an intermediate upgrade to PADS4 2022.3 first.

<Check>
   All PADS4 versions equal to or below 2022.2 (when upgrading to PADS4 2024.1).
</Check>

**Remarks:**

If you're coming from **a version lower than 2021.3**, allow the PADS4 server to migrate the content. This is because from version 2021.3 onward, PADS4 uses a closed Content Library system that needs time to convert the previous static content to an encrypted source.

Otherwise, the Content Library isn't accessible and the content is not properly viewed or utilized on the PADS4 server directly after an upgrade.

<Note>
  Below is an estimation of the time needed based on the size of your Content Library:<br /><br />_0-1 gigabyte: 30 minutes_<br />_1-10 gigabyte: 1 hour_<br />_10\+ gigabyte: 4 hours_
</Note>
