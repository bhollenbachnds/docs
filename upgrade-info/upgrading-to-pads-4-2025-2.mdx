---
title: "Upgrading from before 2025.2"
---

To upgrade to PADS4 2025.2, your current version must be at least 2022.3, meaning PADS4 2022.3 must be installed and running first.

Versions 2022.2 or earlier will not auto-update to 2025.2; an intermediate upgrade to 2022.3 is required.

<Warning>
  User Accounts and Security Update

  As of version 2025.1, the default users User1 and Administrator have been removed to enhance security. During setup, you must create a new user account. This user is created by the Root user, whose password is defined during the installation process.
</Warning>

### **Release Notes**

PADS4 2025.2 release notes are available \[[here](https://www.netdisplaysystems.com/downloads/ForwardLinks/PADS4relnotes.pdf)\]

## User Management and Migration

User management for PADS4 Workspace and PADS4 CMS 1.0 has been migrated to PADS4 CTRL Center, allowing all users to be managed from a single, centralized location.

This migration includes all PADS4 Workspace and CMS 1.0 users, licenses, and assigned roles, which are automatically transferred to PADS4 CTRL Center during installation. After the installation, you can review the migration process by logging in to the web portal with your Root account and navigating to Migration.

In this section, you’ll find an overview of all migration steps. By selecting an item, you can view detailed information in Migration Run Details or open the Migration Status Report for a full summary.

## Updating Azure Single Sign-on Reply URL

<Warning>
  This change have to be applied before the update to 2025.2. It can also be applied at any time before the migration as this would not affect the current installation.
</Warning>

From PADS4 version **2025.2**, the expected Reply URL on the external identity provider changes to support multi-domain usage.

To keep PADS4 SSO working as before, you must add an additional domain-specific Reply URL to the existing Azure Enterprise Application used for PADS4.

Follow these steps:

1. Go to https://entra.microsoft.com
2. Select **Entra ID**.
3. Open Enterprise applications → All applications.
4. Search for and select the application you created for PADS4.
5. In the left-hand Manage menu, select Single sign-on.
6. On the Single sign-on page, in the Basic SAML Configuration section, click Edit.
7. In the Basic SAML Configuration panel, under Reply URL (Assertion Consumer Service URL), click Add reply URL.
8. In the new row, enter the domain-related Reply URL in the first column, for example:<br /><br />https://\[PADS4Server\]/rdx/nds.services.authentication.integration/api/v1/**pads**/Saml2/Acs<br />
   <Frame>
     ![Entra ID Basic SAML Configuration Reply URL](/images/install-pads4/EntraID_Basic_SAML_Configuration_Reply-URL.png "Entra ID Basic SAML Configuration Reply URL")
   </Frame>
9. In this example, **pads** is the domain segment added to the existing Reply URL. If your domain is different from the default `pads` domain, replace `pads` in the URL with your own domain value.
10. Click Save at the top of the panel to apply the changes.

## Viewer Roles

After the migration is complete, you may not see any viewers listed when you log in, even though all licenses are available. This is because three new roles have been introduced to manage viewer access.

<Warning>
  To view or modify viewer settings, you must have one of the viewer roles assigned to your user account. For more information, see User and Roles in PADS4 CTRL Center → Administrator → User Management.
</Warning>

## Obsolete Features

The following components have been marked as obsolete and are no longer included in the installation:

- TV Element – Replaced by the Streaming element.
- Flash – Support fully discontinued due to outdated technology.
- PADS4 License Wizard – Replaced by the web-based licensing system available through the PADS4 portal.
