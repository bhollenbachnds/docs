This site is the official documentation for PADS4. It helps you install PADS4, set it up, and use it every day, whether you manage screens, book rooms, show flight information, or connect PADS4 to other systems.

PADS4 is a platform with several parts. Each part has its own documentation. Use the dropdown menu on the left to select the part you need.

## What you can do with this documentation

- Install and activate PADS4, and find out which requirements your environment must meet.
- Learn how to create content, schedule presentations, and manage Viewers.
- Set up and use Workspace to book meeting rooms, desks, and shared services.
- Configure single sign-on (SSO), multi-factor authentication (MFA), and integrations with Microsoft and other providers.
- Connect your own systems to PADS4 with the REST API.

## What each part explains

| Part | What it explains | Who it is for |
| --- | --- | --- |
| **Installation Guide** | System requirements, installation, license activation, and upgrades for the PADS4 Server and its components. | Installers and IT administrators |
| **PADS4 Super User** | The server-level `su\root` account, Diagnostics, Migration, and Domains for multi-tenant setups. | Server administrators |
| **PADS4 Ctrl Center** | The PADS4 Ctrl Center: Dashboard, Viewers, Content, Sensors, and Administration. | Administrators |
| **PADS4 Digital Signage** | Creating presentations and scheduling them to Viewers. | Designers and content editors |
| **PADS4 Workspace** | Booking of meeting rooms, desks, parking, and shared services, plus the web application, mobile application, Outlook add-in, and administration. | Employees, workplace managers, administrators |
| **PADS4 CMS 1.0** | The web-based CMS 1.0 for creating, scheduling, and distributing messages to screens. | CMS 1.0 users and administrators |
| **PADS4 FIDS** | The Flight Information Display System: installation, the FIDS Operator, server settings, and SQL Server failover. | Airport operators, administrators |
| **API Reference** | The PADS4 REST API, with the endpoints of each PADS4 service. | Developers and integrators |
| **Plug-ins** | Additional products for PADS4, such as the Reporting plug-in. | Administrators and report users |

## How the pages are organized

Most parts follow the same structure. When you know it, you find information faster.

- **Introduction**: What the part is for and how it works. Start here if the part is new to you.
- **Getting started**: The shortest path to a first result.
- **How-to articles**: Step-by-step instructions for one task, such as creating a cluster or connecting an identity provider.
- **Reference pages**: A description of every setting on a screen.
- **Administration**: Settings for users, roles, licenses, and integrations.
