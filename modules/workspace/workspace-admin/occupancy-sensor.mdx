title: "Occupancy Sensors"
---

#### Gateways

In this section the network information of the connected occupancy sensors is listed.

**Name**: Name of the occupancy sensor.

**MAC address**: The MAC address of the occupancy sensor

**IP address**: The IP or network address of the occupancy sensor.

#### Sensors

In this section the connected sensors are listed

**ID**: The ID of the sensor

**Name**: The name of the sensor

**Type**: Indicates the type of sensor

**Connected to**: Indicates to which gateway the sensor is connected to.

**Linked to room**: Indicates to which rooms the sensor is linked to.

#### LED's

Used to indicate whether a room or workspace is booked (green available / red unavailable)

**Name**: Name of the LED

**MAC Address**: MAC Address of the LED

**IP Address**: IP Address / Network address of the LED

**Last Activity**: Indicates when the LED was triggered last.

**Linked To**: Indicates to which rooms the LED is linked to.
