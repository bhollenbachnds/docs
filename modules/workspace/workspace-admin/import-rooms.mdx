---
title: "Importing rooms"
---

<Note>
  Before importing rooms, configure the **Calendar** section in **Administrator Setup**. You can import rooms from Microsoft or Google calendars.
</Note>

1. In the **Rooms** dashboard, click **Import Rooms**.
2. Select the calendar source: **Microsoft** or **Google**.
3. Select the rooms to import from the list of rooms configured in the selected environment.
4. Click **Save**.

The selected rooms are imported and displayed in the **Rooms** dashboard.
