---
title: "Modular Spaces"
---

A modular space allows you to either split up an existing room into multiple rooms or merge multiple rooms into a single room.

#### Create Modular Space

**Name**: Specify the name of the modular space

**Image**: Upload an image of the modular space from the content library

**Type**: Specify if the modular is space is either a bookable or non-bookable room.
