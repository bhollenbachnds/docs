---
title: "Users"
---

The **Room Users** tab allows administrators to manage users who can access the PADS4 Workspace user interface. The tab lists all users registered in PADS4.

## Add a room user

- **Name:** Enter the user’s full name. The value must contain between 6 and 50 characters.
- **Password:** Enter a password for the user.
- **Confirm password:** Re-enter the password. The value must exactly match the password entered in the **Password** field.
- **Profile:** Select the applicable user profile. By default, users can view and book all available rooms. User profiles can restrict access so that users can view and book only assigned rooms.

### Additional information

- **E-mail:** Enter the user’s email address.
- **Name:** Enter the user’s last name or surname.
- **First Name:** Enter the user’s first name.
- **NFC Number:** Enter the user’s NFC card number. For example, users can use an NFC access card to quickly book a room.
- **Teleworking:** Select this option if the user works from an off-site location.
- **Prevent Room Booking:** Select this option to prevent the user from booking rooms.
- **Booking request enabled:** Select this option to allow the user to send booking requests to their manager.

## Rooms

Use the **Rooms** section to specify which rooms the user can view and book.

## Delegation

Use the **Delegation** section to allow the user to make room bookings on behalf of another user.

## Teleworking

The **Teleworking** tab allows administrators to manage the number of days a user can work from home or another remote location.

Use the Teleworking tab to define the user’s remote-working allowance. You can specify the maximum number of days the user may work from home and create schedules for different time periods.

For each schedule period, define the start and end date and the permitted number of teleworking days. This allows you to apply different remote-working arrangements during specific periods, such as temporary policies, seasonal schedules, or individual agreements.

## Meeting management

- **Enable bookings overview:** Enables the **Manager** tab for the user, next to the **Delegation** tab. This allows the user to edit meetings in rooms for which they are assigned as a manager.

## Manager

Use the **Manager** section to allow the user to edit meetings in rooms that they manage.
