---
title: "Statistics"
---

The **Statistics** tab provides reports and analytical data about room and workspace usage in PADS4 Workspace. Use these reports to evaluate occupancy, booking behavior, and workspace efficiency. Statistics can display live data or historical data for a selected period and location.

## Statistical data modules

PADS4 Workspace includes the following statistical modules by default:

- **Workspace Occupancy Rate:** Displays the average occupancy of bookable workspaces.
- **Non-Bookable Room Occupancy Rate:** Displays the average occupancy of non-bookable rooms.
- **Distribution of Workspace Occupancy Bookings:** Displays the distribution of the number of workspace bookings.
- **Distribution of Workspace Occupancy Duration:** Displays the distribution of booking durations.
- **Automatic Booking Cancellation Rate:** Displays the rate at which booked rooms are cancelled automatically.
- **Automatic Booking Release Rate:** Displays the rate at which booked rooms are released automatically.

For each module, use the icons in the upper-right corner to:

- Switch between table and graph views.
- Expand the module to a full-width view.
- Return the module to its standard half-page view.

## Filter statistics

Use the options in the top ribbon to filter the data displayed on the dashboard.

- **Live Data:** Updates the dashboard as rooms and workspaces are used. Disable this option to reduce network traffic.
- **Start Date / End Date:** Define the period for which statistics are displayed.
- **Locations:** Select one or more locations for which to display statistics.
- **Apply:** Applies the selected date range and location filters to the dashboard.
- **Export:** Exports selected statistical modules to a PDF or Microsoft Excel file.

To filter and export statistics:

1. Configure the required **Start Date**, **End Date**, and **Locations**.
2. Enable or disable **Live Data**, as required.
3. Click **Apply** to refresh the dashboard.
4. Click **Export**.
5. Select the report modules to include.
6. Select PDF or Microsoft Excel as the export format.
