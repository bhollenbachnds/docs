#### Create common area

You can set up a common area (for example: cafeteria areas, recreational spaces and more)

**Name**: Specify the name of the common area

**Image**: Upload an image of the common area

**Cancellation time**: The time limit, in minutes, within which you can cancel the reservation.

**Time Zone**: Specify the time zone of the common area

**Inactive**: Check this checkbox to mark the common area as inactive, when for example the common area is unavailable for booking.

**Timeslots**: Specify on what days and times the common area is available for booking
