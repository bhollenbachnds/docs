After you install the application, tell it which PADS4 Workspace environment to use. You do this once, with the address of the PADS4 server of your organization.

## Before you begin

- Install the application on [iOS](/modules/workspace/ios-install) or [Android](/modules/workspace/android-install).
- Get the address of your PADS4 server from your administrator. It looks like `https://<your-server>.<your-domain>`.

## Connect the application

<Steps>
  <Step title="Open the application">
    Open **PADS4 Workspace** on your device.
  </Step>
  <Step title="Enter the server address">
    Enter the address of the PADS4 instance of your organization, for example `https://<your-server>.<your-domain>`.
  </Step>
  <Step title="Save the address">
    Tap **Save**.
  </Step>
</Steps>
