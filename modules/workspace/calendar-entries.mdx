Each type of entry in My calendar has its own icon and color. Use this page to find the right icon, and to understand what you see in your calendar.

## Icons and colors

| Entry | Icon to start it | Color in the calendar |
| --- | --- | --- |
| Room booking | The **\+** button in the lower-right corner | Green |
| Booking that waits for approval | The **\+** button, as for a room booking | Green (shown as Pending.) |
| Reservation request | Reservation Request in your calendar | Yellow |
| Common space reservation | The purple icon, after you select the **\+** button | Purple |
| Group workspace booking | The green icon in the lower-right corner | Green |
| Remote work declaration | The blue icon in the lower-right corner | Blue |
| Absence | The red icon, after you select the **\+** button | Red |
