title: "Set up approvals and booking requests"
description: "Turn on approval for rooms and allow booking requests in PADS4 Workspace, and give users the rights to approve bookings and manage rooms."
---

Set up approvals and booking requests so that users can follow the processes in [Booking approvals and requests](/modules/workspace/booking-workflows). You set up three things: approval for a room, booking requests for users, and managers for rooms.

## Turn on approval for a room

<Steps>
  <Step title="Open the room">
    In the admin interface, go to **Rooms**, and then open the room.
  </Step>
  <Step title="Turn on approval">
    On the **Approval** tab, specify that bookings for this room need approval.
  </Step>
  <Step title="Save the room">
    Save your changes.
  </Step>
</Steps>

## Allow booking requests for a user

1. Go to **Room Users**, and then open the user.
2. Turn on **Booking request enabled**. The user can then send booking requests to their manager.
3. Save the user.

## Give a user the rights of a manager

Managers can edit meetings in the rooms that they manage.

1. Go to **Room Users**, and then open the user.
2. Turn on **Enable bookings overview**. The **Manager** tab appears next to the **Delegation** tab.
3. On the **Manager** tab, select the rooms that the user manages.
4. Save the user.
