---
title: "Add a room user"
description: "Create a room user in the PADS4 Workspace admin interface by entering a name and password and choosing a room user profile."
---

Add a room user so that a person can sign in to PADS4 Workspace and book spaces. You enter the required details first, and the other settings afterwards.

## Before you begin

- Create a room user profile if the user needs limited access. By default, a user can view and book all available rooms. See [Create a room user profile](/modules/workspace/workspace-admin/create-a-room-user-profile).
- Collect the email address and, if the user uses an NFC card, the NFC card number.

## Add a room user

<Steps>
  <Step title="Open Room Users">
    In the Workspace admin interface, go to **Room Users**.
  </Step>
  <Step title="Add the user">
    Add a new user.
  </Step>
  <Step title="Enter the required details">
    | Field | Description |
    | --- | --- |
    | **Name** | The full name of the user. Enter 6 to 50 characters. |
    | **Password** | The password of the user. |
    | **Confirm password** | The same password again. The two values must be identical. |
    | **Profile** | The room user profile of the user. The profile can restrict which rooms the user can view and book. |
  </Step>
  <Step title="Enter additional information">
    (Optional) Enter the **E-mail** address, the last name in **Name**, the **First Name**, and the **NFC Number**. See [Room user settings](/modules/workspace/workspace-admin/room-user-settings). 
  </Step>
  <Step title="Save the user">
    Save the user. 
  </Step>
</Steps>

{/* SCREENSHOT: Workspace admin interface > Room Users, the form to add a room user. */}

<Check>
  The user appears in the list on the **Room Users** tab.
</Check>

## Next steps

- Limit the rooms, set up delegation, or give manager rights. See [Room user settings](/modules/workspace/workspace-admin/room-user-settings).
- Set the remote work allowance. See [Set the remote work allowance](/modules/workspace/workspace-admin/remote-work-allowance).
