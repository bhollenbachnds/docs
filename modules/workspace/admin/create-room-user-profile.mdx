---
title: "Create a room user profile"
description: "Create a room user profile in PADS4 Workspace, choose the rooms that its users can view and book, and edit or delete the profile later."
---

Create a profile to give a group of room users the same access to rooms.

## Before you begin

Know which rooms the group can view, and which rooms it can book. See [Room user profiles](/modules/workspace/workspace-admin/room-user-profile).

## Create a profile

<Steps>
  <Step title="Open Room User Profiles">
    In the Workspace admin interface, go to **Room User Profiles**.
  </Step>
  <Step title="Add the profile">
    Select **Add Room User Profile**.
  </Step>
  <Step title="Enter the general information">
    Enter a **Name** and a **Description**. Turn on **Teleworking** if the users primarily work from home. Turn on **Prevent Room Booking** if the users can view rooms but not book them.
  </Step>
  <Step title="Choose the rooms">
    On the **Rooms** tab, choose the rooms that the users can view and the rooms that they can book.
  </Step>
  <Step title="Save the profile">
    Save the profile.
  </Step>
</Steps>

{/* SCREENSHOT: Workspace admin interface > Room User Profiles, the form to add a profile with the Rooms tab. */}

Assign the profile to a user in the **Profile** field when you [add a room user](/modules/workspace/admin/add-user).

## Edit a profile

1. In **Room User Profiles**, select the edit option for the profile.
2. Change the fields that you need.
3. Save your changes.

## Delete a profile

1. In **Room User Profiles**, select the edit option for the profile.
2. Select **Delete**.
