---
title: "Set the remote work allowance"
description: "Turn on remote work for users in PADS4 Workspace and set how many remote work days each user can declare, for one period or for several periods."
---

Set how many days a user can work remotely. Users declare their remote work days in the Workspace web application, and PADS4 Workspace counts them against this allowance. The admin interface calls remote work **Teleworking**.

## Before you begin

- Create the room user. See [Users](/modules/workspace/workspace-admin/users).
- Decide whether you set remote work for a single user or for a group of users with a room user profile.

## Turn on teleworking

Choose the level that fits your organization.

| Level | Where | Setting | Use it for |
| --- | --- | --- | --- |
| User | **Room Users** > the user | **Teleworking** | A user who works from an off-site location. |
| Profile | **Room User Profiles** > the profile | **Teleworking** | A group of users who primarily work from home. |

## Set the allowance for a user

<Steps>
  <Step title="Open the user">
    In the admin interface, go to **Room Users**, and then open the user.
  </Step>
  <Step title="Open the Teleworking tab">
    Select the **Teleworking** tab.
  </Step>
  <Step title="Set the maximum number of days">
    Enter the maximum number of days that the user can work from home or another remote location.
  </Step>
  <Step title="Add schedule periods">
    (Optional) Create a schedule for a specific period. For each period, enter the start date, the end date, and the number of teleworking days that are allowed.
  </Step>
  <Step title="Save the user">
    Save your changes.
  </Step>
</Steps>

## Verify the allowance

Ask the user to open the remote work tool in the Workspace web application. The remaining remote work days are shown at the bottom left. See [Declare remote work](/modules/workspace/workspace-web-application/declaring-remote-work).
