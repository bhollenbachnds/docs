title: "Room users"
description: "Learn how room users and room user profiles control who can sign in to PADS4 Workspace, which rooms they can see and book, and which extra rights they have."
---

A _room user_ is a person who uses PADS4 Workspace to find and book spaces. You manage room users in the **Room Users** tab of the Workspace admin interface. The tab lists all users that are registered in PADS4.

## How access works

By default, a room user can view and book all available rooms. You can limit this in two ways:

- **A room user profile** defines the access for a group of users. Assign the profile to each user in the group. See [Room user profiles](/modules/workspace/workspace-admin/room-user-profile).
- **The settings of one user** define extra options for one person, such as a remote work allowance, delegation, or manager rights. See [Room user settings](/modules/workspace/admin/room-user-settings).

<Note>
  Room users are different from administrator accounts in CMS Admin. Administrator accounts manage the system. Room users book spaces. See [Users in CMS Admin](/modules/workspace/workspace-cms-admin/users).
</Note>
