title: "Room user profiles"
description: "Learn how room user profiles define which rooms a group of users can view and book in PADS4 Workspace, and which settings a profile contains."
---

A _room user profile_ defines access levels and permissions for a group of room users. Assign the same profile to each user in the group, instead of setting the same options for every user. You manage profiles in the **Room User Profiles** tab.

By default, a room user can view and book all available rooms. A profile can limit this to selected rooms, or allow users to view rooms without booking them.

## Profile settings

| Setting | Description |
| --- | --- |
| **Name** | The name of the profile. |
| **Description** | A short description of the purpose of the profile, or of the group of users that it is meant for. |
| **Teleworking** | Turn this on if the users with this profile primarily work from home. |
| **Prevent Room Booking** | Turn this on to let users view rooms, but not book them. |

### Rooms tab

On the **Rooms** tab, choose which rooms the users with this profile can **view** and which rooms they can **book**.

## When to use a profile

Use a profile when many users need the same access. For example, create one profile for the users of one building, and one for users who only need to view rooms. Use the settings of a single user for exceptions. See [Room user settings](/modules/workspace/workspace-admin/room-user-settings).
