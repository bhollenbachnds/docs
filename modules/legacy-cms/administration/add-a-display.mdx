### Screens overview

Here you can add screens that work with your PADS4 CMS forms & messages.

A short reminder: you might be working with a configured PADS4 system and want users to send messages to all the connected Viewers. In that case, you have to manually add the Viewers here in the PADS4 CMS Digital Signage / screens section.

Note: the Viewers cannot have special characters in the name, so make sure to rename your Viewers to generic names before implementation here in PADS4 CMS Digital Signage.

### Adding screens

On the left-hand side, you have an overview of your screens. 

Quick tip: Use your PADS4 System Management | Destinations tab or PADS4 Agent | Viewer Connections as a reference. This helps you decide which screens you want to add to the PADS4 CMS Digital Signage module.

Tile view or list view: By selecting either the tile or list view icons, you change the view you have of your added screens.

If you want to add a screen, click the yellow \+ icon beneath in the left pane.

• Click on the \+ icon underneath the Screens pane.<br />• Create a name for your viewer (copy the name of the Viewer in your Destinations tab of the PADS4 System Management application. This is case sensitive, and make sure there are no special characters involved.)<br />• Select a timezone for the Screen to operate in.<br />• You can assign the Screen to all profiles, or select specific profiles.

You can edit/delete a group by clicking on the individual Screen, and clicking on either the pencil icon or the trash can icon.

Once you have created a screen, you can assign them to a group.

### Creating groups

You can add multiple Screens to a group within PADS4 CMS. The right-hand pane shows an overview of your groups. You can select a tile or a list view of these groups (just like the screens section).

• Click on the \+ icon underneath the Groups pane.<br />• Create a name for your group<br />• The group will now appear in the Groups pane.<br />• Add a screen by dragging and dropping the screen into the group.<br />• If you double-click on the Group, it will showcase which Viewers are in the group.<br />• Optionally you can create sub-groups within groups. Head inside a group and select the \+ icon

You can edit/delete a group by clicking on the individual Group, and clicking on either the pencil icon or the trash can icon.

#### Adding a screen to a group

Simply select a screen from the left pane, and drag & drop into the selected Group. It will appear in the group. If you want to add a Screen to a sub-group, you will have to navigate to where the subgroup is located. Then drag & drop the screen into the subgroup.

It is possible to assign groups to multiple layers within groups, or add them to multiple groups.
