Make sure that the computer where you install PADS4 Server meets these requirements. The requirements apply to PADS4 2021.1 and later.

## Supported operating systems

PADS4 Server runs on these 64-bit versions of Windows:

- Windows 10
- Windows 11
- Windows Server 2016, including the Datacenter edition
- Windows Server 2019, including the Datacenter edition
- Windows Server 2022, including the Datacenter edition
- Windows Server 2025, including the Datacenter edition
