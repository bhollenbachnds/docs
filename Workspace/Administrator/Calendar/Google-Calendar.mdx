Use this section to configure the Google Calendar service when you use PADS4 CMS with the Workspace module. The following steps show you how to generate a configuration JSON file and set up the Google Workspace account.

 

**Service account configuration**

The service account is the Google Workspace account that PADS4 CMS uses to:

• Retrieve a list of rooms

• Manage reservations

Perform the following steps:

From the Google Workspace administration site: [<u>https://console.developers.google.com/cloud-resource-manager</u>](https://console.developers.google.com/cloud-resource-manager)

- Create a project for the PADS4 CMS application.
- After you create the project, select it in the console to activate the APIs.

The APIs to activate are:

• Google Calendar

• Admin SDK

- Create a service account with the following configuration.
- Create a private key for the service account.
- Download the key file in JSON format. You need it later when you configure PADS4 CMS.

- Authorize the actions that PADS4 CMS requires for the service account.

Retrieve the service account ID number.

Then go to the administration console, [https://admin.google.com](https://admin.google.com), and open the "Security" tab and "Manage API client access".

Then add your ID and the following URLs:

[https://www.googleapis.com/auth/admin.directory.resource.calendar](https://www.googleapis.com/auth/admin.directory.resource.calendar)

[https://www.googleapis.com/auth/admin.directory.resource.calendar.readonly](https://www.googleapis.com/auth/admin.directory.resource.calendar.readonly)

[https://www.googleapis.com/auth/calendar](https://www.googleapis.com/auth/calendar)

Create and configure resources in the administration console: [https://admin.google.com](https://admin.google.com)

Go to "Apps" then "GSuite".

Then select the "Calendar" application.

#### Enable Google Calendar in PADS4 CMS

When this is completed, go back to the PADS4 CMS administrator section and go to Plugins.<br /><br />Select the Calendar option.<br /><br />Set the slider in the top-right corner to "<u>ON</u>" and fill in the following information:<br /><br />Select the Google Calendar option under Authentication Type.

Service account key: _Upload your JSON file here_.

Username: _Fill in your email address._

Disable booking notifications: _Select if you want to disable notifications yes/no._

Save the options, and verify that the connection is valid by importing rooms in the Workspace module.
