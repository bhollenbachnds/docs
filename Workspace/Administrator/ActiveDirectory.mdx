title: "Active Directory "
description: "Connect an Active Directory (LDAP) server to PADS4 with your LDAP server, username, and password, then import users through the Users tab in each module."
---

<Warning>
  Since **PADS4 version 2025.2**, this plugin is managed from the **Credentials** section in PADS4 CTRL Center, providing a cohesive user management system within a single environment.
</Warning>

Use this plugin to connect an **Active Directory (LDAP)** server to your PADS4 environment.

![LDAP CMS 1 0](/images/modules/workspace/workspace-cms-admin/LDAP-CMS-1.0.png)

- Enter your **LDAP server**, **username**, and **password** to establish a secure connection.
  <Info>
    The LDAP server address requires to have the following format: **LDAP://**\<servername\>
  </Info>
- Once connected, you can import users from Active Directory directly through the **Users** tab in each module.
