---
title: "External Occupancy Sensor"
description: "Connect PADS4 to a third-party occupancy source such as KNX, SIGFOX, or PADS4 by enabling the sensor toggle and setting the source type and URL fields."
---

The External Occupancy Sensors section lets you connect PADS4 to a third-party occupancy source so room occupancy information from an outside source (KNX, SIGFOX, or PADS4) can be used within the platform.

Enable the occupancy sensor using the **ON/OFF** toggle in the upper-left corner. This switch enables or disables the entire feature.

When the switch is set to **OFF**, the **Source type** and **URL** fields are unavailable and shown in grey. Set the switch to **ON** to enable the feature and make both fields editable.

Select the occupancy sensor type used in your installation. The configuration instructions are provided below.

<Note>
  This procedure registers the external occupancy sensor configuration only. To use the sensor in PADS4, see the IoT section in Workspace Administration.
</Note>
