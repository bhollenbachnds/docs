title: "MappedIn"
---

The Mappedin Web SDK lets you render the maps of your venue, designed using Mappedin CMS, inside an HTML page on your web app's frontend. The SDK is a JavaScript package, built using plain JavaScript. For more on MappedIn, please checkout the developer documentation here.

You will need to acquire certain keys before implementing, so make sure you have made your way throughout their Knowledge Base: [https://developer.mappedin.com/](https://developer.mappedin.com/)<br />

Enable the slider in the top-right corner to  "ON" and fill in the following information

#### Login information

Public key: _Add the public key from the MappedIn API_

Private key: _Add the private key from the MappedIn API_

Venue: _Fill in your venue type_

Workspace type:  _Fill in your Workspace type._
