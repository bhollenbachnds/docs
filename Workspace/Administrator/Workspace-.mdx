### Default notification settings

This setting configures global notification preferences in PADS4 Workspace, where you can toggle notifications, set timing, and enable reminders for meeting participants.

![Workspace Defaults](/images/modules/workspace-cms-admin/WorkspaceDefaults.png)

### Event creation setting

Enable automatic Microsoft Teams online meetings by default. Available for Exchange-integrated rooms only.

### Privacy settings

This setting configures global privacy options for bookings in PADS4 Workspace, where you can control organizer name visibility and enable the "Search for colleague" feature.
