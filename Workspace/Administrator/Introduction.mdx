PADS Workspace is a module for finding and reserving rooms or other spaces through an intuitive calendar interface. It can operate as a standalone corporate booking solution. Users open the configured Workspace URL and sign in with an authorized account.

Workspace can also complement existing booking tools and calendar environments within your organization.

PADS Workspace integrates with the following platforms:

- Microsoft Graph
- Microsoft Office 365
- Microsoft Exchange Server
- Google Calendar
- iPorta
