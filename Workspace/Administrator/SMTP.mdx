---
title: "SMTP"
description: "Set up SMTP server credentials and a sender address so the platform can send email alerts and automated reports. Managed in PADS4 CTRL Center since 2025.2."
---

<Warning>
  Since **PADS4 version 2025.2,** this plugin is managed from the **SMTP** section in PADS4 CTRL Center, providing a cohesive user management system within a single environment.
</Warning>

This section allows you to set up the **SMTP (Simple Mail Transfer Protocol)** server credentials to enable the platform to send:

- **Email alerts**
- **Automated reports**

You must specify the email address that the platform uses as the sender.
