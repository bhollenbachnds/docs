The Amino H200 is an Android media player that you manage from the Amino Orchestrate console. You add PADS4 Viewer as an application in Orchestrate, and Orchestrate installs it on the player. This page explains how to set up the application and the configuration in Orchestrate, add the player, and connect PADS4 Viewer to your PADS4 Server.

## Before you begin

### Supported devices

- Amino H200 (Android 12)
- Amino H200 (Android 14)

### Minimum requirements

| Requirement | Minimum |
| --- | --- |
| PADS4 Server | PADS4 2025.1 or later |
| Firmware, Android 12 | `25.6.2540.10R` |
| Firmware, Android 14 | `25.8.2620.4R` |

### Other prerequisites

- An Amino Orchestrate account.
- The APK file of the Generic Android Viewer. See [PADS4 Generic Android Viewer](/certified-devices/generic-android-viewer/PADS4-Generic-Android-Viewer).
- The serial number of the player.

## Install PADS4 Viewer

Amino players are managed from a central console, Amino Orchestrate. You add PADS4 Viewer as an application, put it in a configuration, and then add the player to that configuration. Orchestrate installs PADS4 Viewer when the player comes online.

### Add PADS4 Viewer as an application

1. Open the Amino Orchestrate site: `https://orchestrate.amino.tv/`.
2. On the main page, go to the **Applications** section.
3. Select **Add Application**.
4. In **Application Name**, enter `PADS4 Viewer`.
5. Upload the APK file of the Generic Android Viewer.

PADS4 Viewer is now ready to deploy to a player.

### Create a configuration

1. Go to **Configurations**.
2. Select **Add Configuration**, and then enter a name.
3. Select **Add**.
4. Open the **Parameters** tab.
5. In **Target Version**, select the firmware version.
6. Select **Save Changes**.
7. Open the **Applications** tab.
8. Select **Add Action**, and then select **PADS4 Viewer**.
9. Check that PADS4 Viewer appears in the list. Set **Action** to **Install**, and select the correct **Version** if necessary.
10. Select **Save Changes**.

### Set PADS4 Viewer as the Home app

Set PADS4 Viewer as the Home app, so that the player starts it automatically.

1. In the configuration, open the **Parameters** tab.
2. Under **Application Settings**, in **Home App**, select **PADS4 Viewer**.
3. Select **Save Changes**.

### Add the player to Orchestrate

1. Go to **Devices** > **Device list**.
2. Select **Add Device**.
3. Enter the serial number of the player.
4. Under **Configuration**, select the configuration that you created.
5. Wait until the player comes online. Orchestrate then installs PADS4 Viewer.

## Connect the Viewer to the PADS4 Server

After the installation, PADS4 Viewer opens on the player. The server location has this format: `https://<host>:<port>/<domain>/`.

1. Enter the PADS4 Server location.
2. (Optional) Enter a name for the Viewer.
3. Select **Start**.

<Check>
  The Viewer shows a green LED and the name of the Viewer. This means that the connection works.
</Check>
