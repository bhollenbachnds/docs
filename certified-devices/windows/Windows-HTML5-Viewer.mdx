The Windows HTML5 Viewer offers several advantages over the legacy Windows Viewer:

- Supports sync repeat functionality
- Allows orientation changes without modifying Windows settings
- Provides a consistent experience across all HTML viewers
- Can be used as a screensaver
- Easier support for new features
- Improved performance
- Enhanced security via Kiosk mode
- Automatic updates from the PADS4 Server (no manual updates required)

<Note>
  This viewer shares the same limitations as other HTML viewers. For more information, see [HTML5 Viewer Known Limitations](https://support.pads4.com/en/support/solutions/articles/204000036395-known-limitations-for-html5-viewer).
</Note>

## Before you begin

### Minimum requirements

| Requirement | Minimum |
| --- | --- |
| Windows | Windows 10 build 1909 or later |
| PADS4 Server | PADS4 2025.1 or later |

<Warning>
  The **Switch User** option in the Launcher settings requires PADS4 Windows HTML viewer version 1.4.0 and PADS4 version 2025.2. This option lets you switch user accounts when you use Windows Kiosk mode.
</Warning>

### Other prerequisites

- The installation package. Download it from [GitHub](https://github.com/PADS4/PADS4-Viewer-Windows/releases).

## Install PADS4 Viewer

1. Run `PADS4WindowsHTMLviewer.exe` as **Administrator**.
2. Select the installation directory, or use the default.
3. (Optional) Clear **Configure Windows to launch the PADS4 HTML5 Viewer in Kiosk Mode** if one of these applies:
   - You want to use the Viewer as a screensaver.
   - You want to run the Viewer under a regular Windows user.
4. Accept the License Agreement, and then select **Install**.

## Switch to a regular user account

You can exit Kiosk mode and switch to a standard Windows account in three ways:

- In PADS4 2025.2 and later, open the **Viewer settings**, go to **Launcher settings**, and then select **Switch User** in the lower-right corner.
- Use **Remote Desktop**, if configured, to log in with a different user account.
- Hold the **Shift** key while you reboot the machine. The Windows login screen opens.

## Use the Viewer as a screensaver

1. During the installation, make sure that Kiosk mode is **not** enabled.
2. Open **Screensaver Settings** in Windows.
3. Select **Pads4viewer** as the screensaver.

<img
  height="200"
  src="/images/install-pads4/install-pads4-viewer/intall-pads4-html5-windows-viewer/screensaver.png"
/>

4. Select **Apply**, and then select **OK**.

The Viewer now starts based on the configured screensaver timer.

## Kiosk mode script reference

To review the Kiosk mode configuration of the system, see this PowerShell script:

```plaintext
C:\Program Files\PADS4\Launcher Service\configure-kioskmode
```

| HTTP and HTTPS | Yes |  |
