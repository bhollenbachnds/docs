### Installing PADS4 Client Applications

This guide explains how to install the PADS4 client applications on Windows, including PADS4 Viewer, Designer, Scheduler, and other tools.

#### Step 1: Download the installer

Download the latest PADS4 client installer from the official download page:<br />[Download PADS4 Clients](http://go.pads4.com/?fwlink=1011)

#### Step 2: Run the installer

1. **Start the installer as an administrator**
   - Locate the downloaded **PADS4 Clients.exe** file.
   - Right-click it and select **Run as administrator**.
   - Choose your language and continue.
2. **Check the version**
   - Make sure you're installing PADS4 version 2026.1 or later.
3. **Accept the license agreement**
   - Read the license agreement.
   - Select the checkbox to accept the terms, then click **Next**.

#### Step 3: Choose who to install for

- Choose whether to install the PADS4 clients for all users on this computer or only for the current user.
- Click **Next**.

#### Step 4: Select the Viewer installation

- In the dropdown menu, select **Viewer Installation**.
- Click **Next**.

#### Step 5: Install the help documentation (optional)

- Choose whether to install the online help file.
- With the help file installed, you can press **F1** in any PADS4 application to open the relevant documentation.
- We recommend installing it so the user guides are always within reach.

#### Step 6: Configure the Viewer

- Enter a **Viewer name** and specify the **PADS4 Server location**.
- Click **Next**.

#### Step 7: Set Desktop mode and User Account Control (UAC)

- **Desktop mode:** Choose whether the PADS4 clients should run in Desktop mode.
- **User Account Control (UAC):**
  - We recommend disabling UAC so the PADS4 clients can run with administrator privileges without extra prompts.
  - If the user isn't a member of the local Administrators group, you can specify an administrator account to run the Viewer.

#### Step 8: Choose shortcuts and the installation folder

- Select the shortcuts you want to create.
- Choose the folder where the PADS4 clients will be installed.
- Click **Install** to start the installation.

#### Step 9: Finish the installation

- Wait while the PADS4 clients are installed.
- When the installation is complete, you'll see the message: _"PADS4 Clients has been successfully installed."_
