title: "Maxhub ND55CMB"
---

This guide provides step-by-step instructions for installing and configuring the PADS4 Web Launcher on a Maxhub ND55CMD Android displays. It covers initial setup, APK installation, autostart configuration, and viewer setup.

### Compatible Devices:

- **Maxhub ND55CMB (Android 14)**

<Note>
  Support for the Maxhub ND55CMB has been added to our PADS4 Generic Launcher solution in **PADS4 version 2026.1**, kindly refer to the PADS4 Generic Android Viewer manual for further instructions.
</Note>

### Minimum requirements

PADS4 Version Required: **2025.2**

Device Firmware: 2026-06-09

## Prerequisites

- Download the latest PADS4WebLauncher.apk from your PADS4 server (e.g., https://[your-server]/[domain]/apps) or from [here](https://github.com/PADS4/PADS4-Viewer-Android/releases/tag/v1.3), and copy it to a USB stick.
- Ensure the PADS4 Server is set up and accessible.

### Installing PADS4 Viewer

1. Power on the screen.
2. Access **All Apps**
3. Insert the USB stick into the screen.
4. Select **Finder**.
5. Navigate to the USB drive and select **PADS4WebLauncher.apk**.
6. Click **Install** and wait for completion.
7. Once the installation is finished, select **Done**
8. **Exit** the File browser

## **Enabling Auto-Start**

1. Open **Settings** on the display.
2. Go to **Applications**.
3. Select **PADS4 Web Launcher**.
4. Select **Home app**.
5. Choose **PADS4 Web Launcher** from the list of available applications.
6. Return to the main **Settings** menu and go to **System**.
7. Select **Startup & Shutdown**.
8. Select **Startup Channel Android**.
9. Set the **Default startup item** to **PADS4 Web Launcher**.
10. Enable **Auto startup**.
11. Press **Back** to exit Settings.

## **Configuring Connection**

1. Launch the PADS4 Web Launcher.
2. Enter the **Server URL** in the format `<protocol>://<host>:<port>/<hostpath>/`
3. Fill in the **ViewerName** as required.
4. Click **Start** to connect.

The PADS4 viewer is now connected and ready for use.
