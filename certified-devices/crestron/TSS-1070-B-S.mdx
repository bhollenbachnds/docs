Crestron TSS-1070-B-S room scheduling touch panels include PADS4 Viewer in the Crestron firmware. You set the application mode of the panel to PADS4, and the panel then loads the Viewer from your PADS4 Server. This page explains how to prepare the panel, set the application mode, connect the Viewer to your PADS4 Server, and set up the Crestron occupancy sensor.

## Before you begin

### Supported devices

- Crestron TSS-1070-B-S

### Minimum requirements

| Requirement | Minimum |  |  |
| --- | --- | --- | --- |
| PADS4 Server | PADS4 2022.3 or later |  |  |
| Device firmware | `2.003.1011` |  |  |

### Other prerequisites

- A PADS4 Server that is installed and running. You need its location to connect the Viewer.
- Network access from the panel to the PADS4 Server.
- Access to the web configuration interface of the panel.
- (Optional) A Crestron POE occupancy sensor, if you want to use occupancy data. You also need PADS4 Workspace.

## Prepare the device

### Reset the device

Reset the panel if it was used before. This clears the storage and prevents software conflicts.

<Warning>
  A factory reset removes all data and settings from the panel.
</Warning>

1. Sign in to the Crestron web configuration interface.
2. Select the arrow next to the **Action** button in the upper-right corner.
3. Select **Restore**.
4. In the confirmation dialog, select **Yes**.

### Check the firmware version

PADS4 Viewer is part of the Crestron firmware. You cannot install it separately. PADS4 Viewer needs firmware version `2.003.1011` or later.

## Install PADS4 Viewer

Set the application mode of the panel to PADS4. The panel then downloads PADS4 Viewer from your PADS4 Server when you connect it.

1. Sign in to the Crestron web configuration interface.
2. Select the **Settings** tab.
3. Select **Applications**.
4. In the **Application Mode** list, select **PADS4**.
5. In the upper-right corner, select **Save Changes**.
6. In the confirmation dialog, select **Yes, Reboot Now**.

## Connect the Viewer to the PADS4 Server

The server location has this format: `http(s)://<server>/<domain>`. Replace `<server>` with the IP address or host name of your PADS4 Server. Replace `<domain>` with your PADS4 domain. The default domain is `PADS4`.

1. Enter the PADS4 Server location.
2. (Optional) Enter a name for the Viewer. If you leave the field empty, the PADS4 Server generates a name.
3. Select **Start**.
4. Set **PADS4 IIyama Touch** as the Home app, and then select **Always**.

<Check>
  The Viewer shows a green LED and the name of the Viewer. This means that the connection works.
</Check>

## Change platform settings

### Open the Viewer options

1. Touch the screen for 3 seconds, or press and hold the mouse button. The options screen opens.
2. To return to the PADS4 app, select **Launcher Settings**.

## Configure the Crestron occupancy sensor

PADS4 supports the Crestron occupancy sensor. First pair the sensor with the panel, and then find the sensor in PADS4 Workspace.

### Pair the occupancy sensor with the panel

1. Sign in to the Crestron web configuration interface of the panel.
2. Select the **Settings** tab.
3. Open **Device Pairing**.
4. In the **Device Model** list, select **POE Occupancy Sensor**.
5. Enter the IP address or the FQDN of the sensor.
6. In the upper-right corner, select **Save Changes**.
7. Check that **Pairing Status** changes to **Online**.

### Find the occupancy sensor in PADS4 Workspace

1. Sign in to PADS4 Workspace Admin.
2. Select **Occupancy Sensors**.
3. Select the **Sensors** tab.

The sensor appears in the table.

## Supported features and limitations

### General

| Feature | Support | Notes |
| --- | --- | --- |
| Offline mode | Partial | The Viewer caches the Content Library on the panel. Local file storage for content is not supported. |
| HTTP and HTTPS | Yes |  |
| Portrait mode | Yes |  |
| Cluster Viewer | n/a |  |

### Video and images

| Feature | Support | Notes |
| --- | --- | --- |
| Videos on one page | Yes | One video at a time. |
| Video streaming | No |  |
| Image formats | Yes | JPG, PNG, BMP, and GIF. |

### Content and data

| Feature | Support | Notes |
| --- | --- | --- |
| Text, scrolling text, tables, shapes, and interactive buttons | Yes |  |
| Web element | Yes | The interactive address bar is not supported. |
| Data providers, Viewer Variables, and rules | Yes |  |

### Device management

| Feature | Support | Notes |
| --- | --- | --- |
| Remote management in PADS4 CTRL Center | Yes |  |
| Restart Viewer | Yes |  |
| Reboot device | Yes |  |
| Shut down device | No |  |
| Wake-on-LAN | No |  |
| Block remote control | No |  |
| Retrieve screenshots | Yes |  |
| Retrieve logs | Yes |  |
| Proof of play | Yes | The panel stores up to 50,000 records while it is offline. |
| Install fonts | Yes |  |
| Crestron occupancy sensor | Yes | See [Configure the Crestron occupancy sensor](#configure-the-crestron-occupancy-sensor). |

Local file storage for content is not supported.
