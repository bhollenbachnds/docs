This guide explains how to **install and configure PADS4 Viewer** on **Philips CRD50 displays**.

---

## 1. First-time use

Before you install, make sure that the **PADS4 Server is set up and configured properly**.

📌 **Minimum PADS4 Server version required:** **PADS4 Foundation 2023.1**

When you turn on the device for the first time, the **Configuration Wizard** appears. If it does not appear, **reset the device** as described in **1.2 Resetting the device**.

---

### 1.1 Configuring the device

<Steps>
  <Step title="Step One">
    On the **Welcome Screen**, select your preferred **language** and select **Start**.
  </Step>
  <Step title="Step Two">
    On the **Security Settings** screen, make sure that **SICP Network Port** is **enabled**. _(You can enable or disable other settings as required.)_
  </Step>
  <Step title="Step Three">
    On the **Network Settings** screen, select and configure the **network type**.
  </Step>
  <Step title="Step Four">
    On the **Signage Display Settings** screen, select **Skip**.
  </Step>
  <Step title="Step Five">
    On the **Clone Media Files** screen, select **Skip**.
  </Step>
  <Step title="Step Six">
    Select **Finish** to complete the setup.
  </Step>
</Steps>

The device displays **CMND & Deploy**, an **app supplied by Philips** _(No configuration is required for this app)._

---

### 1.2 Resetting the device

If someone used the device before, perform a **factory reset** to clear storage and prevent software conflicts.

<Steps>
  <Step title="Step One">
    Attach a **keyboard** to the **Philips CRD50 device**.
  </Step>
  <Step title="Step Two">
    Hold the **Windows key** and enter **1 8 8 8** to open the **Android menu**.
  </Step>
  <Step title="Step Three">
    Open **Settings**.
  </Step>
  <Step title="Step Four">
    Select **System Tools → Factory Reset**.
  </Step>
  <Step title="Step Five">
    Select **Factory Reset**, and then select **OK** to confirm.
  </Step>
</Steps>

After the reset, the **Welcome Screen** appears. Follow the steps in **1.1 Configuring the device**.

---

## 2. Installing PADS4 Viewer

Follow these steps to install the **PADS4 Viewer** on **Philips CRD50**.

---

### 2.1 Checking device firmware

Make sure that the **correct firmware version** is installed for full **PADS4 Viewer** functionality.

<Steps>
  <Step title="Step One">
    Attach a **keyboard** to the device.
  </Step>
  <Step title="Step Two">
    Hold the **Windows key** and enter **1 8 8 8** to open the **Android menu**.
  </Step>
  <Step title="Step Three">
    Open **Settings**.
  </Step>
  <Step title="Step Four">
    Select **About**.
  </Step>
  <Step title="Step Five">
    Make sure that the **Build Number** is **FB04.01** _(required for PADS4)_.
  </Step>
</Steps>

---

### 2.2 Updating device firmware

To update the **firmware**, follow the **Philips instructions**:

📌 **Firmware update guide:** [Download Philips CRD50 Firmware](#)

---

### 2.3 Installing PADS4Philips from USB stick

You can find the **PADS4Philips.apk** file on the **PADS4 Server** in:

```
C:\Program Files\PADS4\Foundation\Apps
```

Alternatively, download the latest version from [**this link**](http://go.pads4.com/?fwlink=1006) and place it in the **apps directory on the PADS4 Server**.

#### Installation steps

<Steps>
  <Step title="Step One">
    Copy the **PADS4Philips.apk** file onto a **USB stick**.
  </Step>
  <Step title="Step Two">
    Insert the **USB stick** into the **Philips CRD50 device**.
  </Step>
  <Step title="Step Three">
    Attach a **keyboard** to the device.
  </Step>
  <Step title="Step Four">
    Hold the **Windows key** and enter **1 8 8 8** to open the **Android menu**.
  </Step>
  <Step title="Step Five">
    Select **Apps → File Manager**.
  </Step>
  <Step title="Step Six">
    Navigate to **mnt → usb_storage**, then open **PADS4Philips.apk**.
  </Step>
  <Step title="Step Seven">
    Select **Install**, then **Open** the app.
  </Step>
</Steps>

## 3. Supported features & limitations

| Feature | Description                                                                             |
| :-----: | --------------------------------------------------------------------------------------- |
| ✅       | **Automatic Software Updates** – PADS4 Viewer updates automatically.                    |
| ✅       | **Offline Mode** – Device continues running presentations for **7 days** while offline. |
| ✅       | **Supports HTTP & HTTPS**                                                               |
| ✅       | **Maximum 1 Video per Page**                                                            |
| ✅       | **Streaming Support** – HTTP.                                                           |
| ✅       | **Cluster Viewer Mode** – Supported.                                                    |
| ✅       | **Interactive Button, Text, Scrolling Text, Image, Table**                              |
| ✅       | **PowerPoint & PDF Elements** – _(PowerPoint requires installation on PADS4 Server)_.   |
| ✅       | **Remote Device Management** – Controlled via **PADS4 Agent**.                          |
| ❌       | **Wake-on-LAN Not Supported**                                                           |
| ❌ | **Global Volume Control Not Supported**_(Only element-level volume control works.)_ |

## 4. Troubleshooting

| **Problem**                                                               | **Solution**                                                             |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Block Remote Control, Turn Off Display, Shutdown Commands Not Working** | Make sure that **SICP over Network** is **enabled** and hosted on **port 5000**. |
| **Viewer does not start in full screen**                                  | Check **firmware version** and **update if necessary**.                  |
| **Device fails to connect over Ethernet**                                 | Updating the **firmware** may resolve this issue.                        |
| **Navigation bar remains visible**                                        | **Firmware update** required.                                            |
| **Viewer repeatedly asks for content storage permission**                 | Check that the **correct firmware version** is installed.                      |
