This page explains how to install and configure PADS4 Viewer on the Hikvision DS-D60C-B device.

## Before you begin

### Minimum requirements

| Requirement | Minimum |
| --- | --- |
| PADS4 Server | PADS4 Foundation 2023.1 |
| Firmware | V1.7.1 build 20230424 |

### Other prerequisites

- A PADS4 Server that is set up and configured.
- A USB stick.

## Prepare the device

### Reset the device

If the device was used before, do a factory reset. A factory reset clears the storage and prevents software conflicts.

1. Open the home screen of the device.
2. Open the **Settings** app.
3. In the **Settings** menu, select **System**.
4. Scroll down, and then select **Restore to Factory Settings**.
5. In the dialog, select **Confirm**.

### Update the firmware

Update the firmware to at least V1.7.1 build 20230424 before you install PADS4.

1. Copy the `update.zip` firmware file to the root directory of a USB stick.
2. Insert the USB stick into the device.
3. The device detects the USB firmware update and prompts you to install it.
4. Follow the on-screen instructions to install the firmware update.

## Install PADS4 Viewer

The `PADS4Hikvision.apk` file is available on the PADS4 Server in this folder:

```text
C:\Program Files\PADS4\Foundation\Apps
```

You can also download the latest version from [GitHub](https://github.com/PADS4/PADS4-Viewer-HikVision/releases/latest). Place the downloaded file in the PADS4 Server apps directory to make sure that the correct version is installed.

1. Copy the `PADS4Hikvision.apk` file to a USB stick.
2. Insert the USB stick into the Hikvision DS-D60C-B device.
3. Open the home screen of the device.
4. Open the **FileBrowser** app.
5. Select **USB DISK** from the list.
6. Select `PADS4Hikvision.apk`.
7. When the message **Do you want to install this application?** appears, select **Install**.
8. When the installation is complete, select **Open** to start the PADS4 Hikvision app.

## Connect the Viewer to the PADS4 Server

The server location has this format: `protocol://host:port/hostpath/`.

- **Protocol**: `http` or `https`. This depends on the SSL certificate.
- **Host**: The DNS name or IP address of the PADS4 Server.
- **Port**: Optional. Specify the port only if you use non-default ports.
- **Host path**: Configured in **System Management**. The default is `PADS4`.

1. Enter the PADS4 Server location.
2. (Optional) Enter a name for the Viewer. If you leave the field empty, PADS4 generates a name.
3. Select **Start**.
4. When prompted, grant permission to access photos, media, and files.

PADS4 downloads and installs PADS4 Viewer.

## Change device settings

### Open the Viewer settings

To open the Viewer settings, touch the screen for 3 seconds, or press and hold the left mouse button.

### Open the Android menu

If you open the Android menu while PADS4 is running, the Viewer Monitor Service detects inactivity. The device then reboots after 30 seconds.

To prevent the reboot, stop the PADS4 Hikvision app within 30 seconds.

## Update PADS4 Viewer

PADS4 Viewer and the PADS4 Hikvision app update automatically when you update the PADS4 Server.
