The Giada DN73 is a signage player that runs Android 7.1 and Android 10. You install the PADS4Giada app on the player to show PADS4 presentations. This page explains how to prepare the player, install the app, and connect it to your PADS4 Server.

## Before you begin

### Supported devices

- Giada DN73 (Android 10)
- Giada DN73 (Android 7.1)

### Minimum requirements

| Requirement | Minimum |
| --- | --- |
| PADS4 Server | PADS4 2022.1 or later |
| PADS4Giada app | PADS4Giada 1.0 |
| Android version | Android 10 <br />Android 7.1 |

### Other prerequisites

- A PADS4 Server that is installed and running.
- A USB flash drive. You use it to install the app.
- Network access from the player to the PADS4 Server.

### Open the Android menu

<Warning>
  If you open the Android menu while PADS4Giada is running, the player restarts after 30 seconds. The Viewer Monitor Service detects that the app is not active. To prevent this, stop the PADS4Giada app within 30 seconds.
</Warning>

## Prepare the device

### Reset the device

Reset the player if it was used before. This clears the storage and prevents software conflicts.

<Warning>
  A factory reset removes all data and settings from the player.
</Warning>

1. Open the Android settings.
2. Select **Backup & Reset**.
3. Select **Factory Data Reset**.
4. Select **Reset Tablet**.
5. Select **Erase Everything**.

### Turn on default superuser access

Superuser access is needed for automatic updates of the PADS4Giada app. Without it, you must update the app manually.

1. Open the **SuperSU** app.
2. Go to **Settings**.
3. Select **Default Access**.
4. In the dialog, select **Grant**.
5. Close the app.

### Reset the screen orientation

This step is optional.

1. In the Android settings, go to **Display** > **HDMI** > **Screen Rotation**.
2. Select **0**.

### Check the date and time

A correct date and time prevent certificate errors and connection problems.

1. Open the PADS4Giada app.
2. Select **System Settings**. The Android settings open.
3. Go to **Date & Time**.
4. Set the correct date and time.
5. (Optional) Turn on **Auto Sync Date & Time**, if your network supports it.

## Install PADS4 Viewer

Install the `PADS4Giada.apk` file from a USB flash drive. You find the file on your PADS4 Server in `http(s)://<server>/<domain>/apps`. 

You can also download the latest version from [GitHub](https://github.com/PADS4/PADS4-Viewer-Giada/releases/latest). If you download the file, also copy it to the `Apps` folder on the PADS4 Server, so that the correct version is installed.

1. Copy `PADS4Giada.apk` to a USB flash drive.
2. Insert the USB flash drive into the player.
3. Open the **File Explorer** app.
4. Select **USB Storage**.
5. Select the APK file.
6. If a security warning appears, select **Settings**.
7. Turn on **Unknown Sources**, and then select **OK**.
8. Go back to **File Explorer**, and select the APK file again.
9. In the confirmation dialog, select **Install**.
10. When the installation is complete, select **Open** to start the PADS4Giada app.

## Connect the Viewer to the PADS4 Server

The server location has this format: `http(s)://<server>/<domain>`. Replace `<server>` with the IP address or host name of your PADS4 Server. Replace `<domain>` with your PADS4 domain. The default domain is `PADS4`.

1. Enter the PADS4 Server location.
2. (Optional) Enter a name for the Viewer. If you leave the field empty, the PADS4 Server generates a name.
3. Select **Start**.

<Check>
  The Viewer shows a green LED and the name of the Viewer. This means that the connection works.
</Check>

## Update PADS4 Viewer

PADS4 Viewer and the PADS4Giada app update automatically when the PADS4 Server updates.
