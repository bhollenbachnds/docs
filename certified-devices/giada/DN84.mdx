The Giada DN84 is an Android 14 media player that you use as a screen. You install the PADS4 Web Launcher app on the player to show PADS4 presentations. This page explains how to install the app, set it as the Home app, and connect it to your PADS4 Server.

## Before you begin

### Supported devices

- Giada DN84 (Android 14)

### Minimum requirements

| Requirement | Minimum |
| --- | --- |
| PADS4 Server | PADS4 2025.1 or later |
| Android version | Android 14 |

### Other prerequisites

- A PADS4 Server that is installed and running.
- A USB flash drive. You use it to install the app.
- Network access from the player to the PADS4 Server.

## Install PADS4 Viewer

Install the `PADS4WebLauncher.apk` file from a USB flash drive. Get the latest version from one of these sources:

- Your PADS4 Server: `https://<your-server>/<domain>/apps`
- GitHub: [Latest release](https://github.com/PADS4/PADS4-Viewer-Android)

1. Copy `PADS4WebLauncher.apk` to a USB flash drive.
2. Turn on the screen, and open the menu with the installed applications.
3. Insert the USB flash drive into the player.
4. Open the **FileBrowser** app.
5. Go to the USB flash drive, and then select `PADS4WebLauncher.apk`.
6. In the warning message, select **Continue**.
7. Select **Install**, and wait until the installation is complete.
8. Select **Done**, and then close **FileBrowser**.

## Connect the Viewer to the PADS4 Server

The server location has this format: `http(s)://<server>/<domain>`. Replace `<server>` with the IP address or host name of your PADS4 Server. Replace `<domain>` with your PADS4 domain. The default domain is `PADS4`.

1. Enter the PADS4 Server location.
2. (Optional) Enter a name for the Viewer. If you leave the field empty, the PADS4 Server generates a name.
3. Select **Start**.
4. Set **PADS4 IIyama Touch** as the Home app, and then select **Always**.

<Check>
  The Viewer shows a green LED and the name of the Viewer. This means that the connection works.
</Check>

## Start the Viewer automatically

Set PADS4 Web Launcher as the Home app, so that the player starts PADS4 Viewer automatically.

1. Open **Settings**.
2. Go to **Apps**.
3. Select **PADS4 Web Launcher**.
4. Select **Home app**, and then select **PADS4 Web Launcher**.

PADS4 Viewer starts.
