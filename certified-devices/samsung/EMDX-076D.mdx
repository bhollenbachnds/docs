This guide provides **step-by-step instructions** for installing and configuring **PADS4 Viewer** on **Samsung EMDX** devices.

## **Before you start**

### **Supported Samsung EMDX series devices**

The following **Samsung** **EMDX Series** device is supported:

- **EMDX**

**Ensure your PADS4 Server is installed and configured before proceeding.**

## **Minimum requirements**

**PADS4 Server Version:** **2026.1 or later**<br />**Firmware Version:** **1130.7**

**Ensure your server meets the minimum version requirement before proceeding with installation.**

## **First-time setup**

When you **turn on** the Samsung EMDX for the first time, a **configuration wizard** will start.

**If the configuration wizard does not start, perform a factory reset before continuing.**

---

## **Performing a factory reset**

<Steps>
  <Step title="Step One">
    Hold the PAIRING and MODE keys on the back of the display for about 5 seconds to reset the device.

    The reset takes about 10 seconds to complete.
  </Step>
  <Step title="Step Two">
    Press the power button again to boot the display.
  </Step>
  <Step title="Step Three">
    The device is now reset and shows new QR codes that you can scan.
  </Step>
</Steps>

**The device will restart and display the welcome screen or QR codes to scan for the mobile application.**

---

## **Installing mobile application**

<Info>
  You need a mobile application to use this display because it does not support interactivity through other mediums. To download the latest version from the app store, scan the QR code on the display.
</Info>

## **Setting up the display**

<Info>
  Once you have the mobile application, you can set up the display. Before you start, enable Bluetooth and Location on your mobile phone. You can disable Location at the end of this process.
</Info>

<Steps>
  <Step title="Step One">
    Start the Samsung mobile application on your mobile device.
  </Step>
  <Step title="Step Two">
    Accept the required permissions.
  </Step>
  <Step title="Step Three">
    Scan the QR code shown at the bottom of the screen.
  </Step>
  <Step title="Step Four">
    Accept the request to connect the display via Bluetooth.
  </Step>
  <Step title="Step Five">
    To set up the Wi-Fi connection on the display, select a connection that your mobile phone is also connected to. This step requires Location.

    <Note>
      _Make sure you select a connection that_ **does not** _require account credentials (only Wi-Fi password allowed)_
    </Note>
  </Step>
  <Step title="Step Six">
    Accept the privacy agreement and select "Manual Setup".
  </Step>
  <Step title="Step Seven">
    Define a device pin and set the device orientation to **landscape.**
  </Step>
  <Step title="Step Eight">
    Configure sleep mode to **off.**
  </Step>
  <Step title="Step Nine">
    Turn **off** network standby and set device date & time to automatic.
  </Step>
  <Step title="Step Ten">
    Set the daily refresher timer and set the content player to **custom**.
  </Step>
  <Step title="Step Eleven">
    Define a name for the device. The device then appears under **devices** in the application.
  </Step>
</Steps>

## **Installing PADS4 Viewer**

<Note>
  To install the PADS4 Viewer application, you need to define the server URL where the application is hosted. This works like other Samsung displays, but instead of doing it on the display directly, you need the mobile application.
</Note>

<Steps>
  <Step title="Step One">
    Start the Samsung mobile application.
  </Step>
  <Step title="Step Two">
    Select the display you want to use.
  </Step>
  <Step title="Step Three">
    Under "Player type" at the bottom of the screen, make sure "CustomApp" is selected.
  </Step>
</Steps>

<Tip>
  If the display is sleeping, select “Wake up”. If that doesn’t work, press the power button on the display.
</Tip>

<Steps>
  <Step title="Step Four">
    **Specify your PADS4 Server URL:**

    ```text
    http://<server>/PADS4/Apps/tizen
    https://<server>/PADS4/Apps/tizen
    ```

    Replace `<server>` with the **IP address** or **domain name** of your **PADS4 Server**.\
    **Ensure "PADS4" is in CAPITAL letters, or the connection will fail due to case sensitivity.**
  </Step>
  <Step title="Step Five">
    Select "Install".
  </Step>
  <Step title="Step Six">
    After about a minute, the display shows the PADS4 logo with the viewer name and connection status at the bottom left of the screen.
  </Step>
</Steps>

## **Adjusting PADS4 Viewer settings**

**You cannot adjust viewer settings directly on the panel because of its refresh rate of about 30 seconds.**

## **Supported features & limitations**

### **General features**

| Feature | Description |
| :-: | :-- |
| ✅ | **Automatic Software Updates** – The HTML5 Viewer updates automatically. |
| ✅ | **Offline Mode** – Plays scheduled content for **7 days** while offline. |

### **Device features**

| Feature | Description |
| :-: | :-- |
| ✅ | **Portrait Mode** – Set rotation to **270°** in Viewer Settings. Do **NOT** use SSP rotate. |
| ✅ | **Cluster Viewer** – Can be used in a **cluster setup**. |
| ✅ | **Block Remote Control** – Prevent unauthorized screen control. |
| ✅ | **Wake on LAN** – Supported. |
| ❌ | **Turn Off Display** – Not supported. |

### **Video & content support**

| Feature | Description |
| :-: | :-- |
| ❌ | **4K Video Mode** – Enabled via **PADS4 CTRL Center**. |
| ❌ | **Seamless Video Playback** – **Supported** in **Landscape Mode**. |
| ❌ | **Streaming** – Supports **HTTP, HLS, RTP, UDP**. |
| ❌ | **Playback Speed Adjustment** – Not supported. |
| ❌ | **All content that requires a higher refresh rate than 30 seconds.** |

### **Device management**

| Feature | Description |
| :-: | :-- |
| ✅ | **Remote Management via PADS4 CTRL Center** |
| ✅ | **Connection State Monitoring & Alerts** |
| ✅ | **Reboot Support** – Supported. |
| ❌ | **Shutdown Support** – Not supported. |

---

## **General limitations**

| **Consideration** |  |
| :-- | :-- |
| **Refresh rate** | The refresh rate of the display is about once every 30 seconds. |
| **Dynamic content** | The display can run dynamic content, but it only shows a screenshot of that content. |
| **Dataproviders** | Only static data is supported; data can only be updated if the time is higher than the refresh rate of the display. |
