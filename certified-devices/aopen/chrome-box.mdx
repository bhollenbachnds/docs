AOPEN ChromeBox Series players run ChromeOS. You set up PADS4 Viewer with the standard ChromeOS procedure, and the player then loads it from your PADS4 Server. This page lists the supported devices and links to the installation steps.

## Before you begin

### Supported devices

- AOPEN ChromeBox Series players

### Minimum requirements

| Requirement | Minimum |
| --- | --- |
| PADS4 Server | PADS4 Foundation 2024.1 or later |
| Platform version | ChromeOS |

### Other prerequisites

- Network access from the player to the PADS4 Server.
- Access to the management tool for the player. 

## Install PADS4 Viewer

Install PADS4 Viewer with the standard ChromeOS procedure. For the steps, see [ChromeOS and ChromeOS Flex](/certified-devices/chromeOS/ChromeOS).
