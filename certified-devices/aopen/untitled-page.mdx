AOPEN DE Series computers run Windows 10 or Windows 11. You run PADS4 Viewer on the computer to show PADS4 presentations. This page lists the supported devices and links to the installation steps.

## Before you begin

### Supported devices

- AOPEN DE Series computers

### Minimum requirements

| Requirement | Minimum |
| --- | --- |
| PADS4 Server | PADS4 2021.1 or later |
| Windows | Windows 10 or Windows 11 |

### Other prerequisites

- An account with administrator rights. 
- Network access from the computer to the PADS4 Server.

## Install PADS4 Viewer

Install PADS4 Viewer with the standard Windows installation procedure. For the steps, see [Windows Viewer](/certified-devices/windows/Windows-Viewer) or [Windows HTML5 Viewer](/certified-devices/windows/Windows-HTML5-Viewer).
