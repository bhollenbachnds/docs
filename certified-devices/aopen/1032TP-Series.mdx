AOPEN 1032TP Series touch devices run Android. You install the PADS4 Viewer app on the device to show PADS4 presentations. This page explains how to install the app, connect it to your PADS4 Server, and change the device settings.

## Before you begin

### Supported devices

- AOPEN AT1032TP
- AOPEN eTILE-X1032TP

### Minimum requirements

| Requirement | Minimum |
| --- | --- |
| PADS4 Server, AOPEN AT1032TP | PADS4 2024.1 or later |
| PADS4 Server, AOPEN eTILE-X1032TP | PADS4 2025.1 or later |
| Android version | 11 |

### Other prerequisites

- A PADS4 Server that is installed and running. You need its location to connect the Viewer.
- A USB flash drive. You use it to install the app. 
- Network access from the device to the PADS4 Server.

## Install PADS4 Viewer

Install the `PADS4AOpen.apk` file from a USB flash drive. You find the file on your PADS4 Server in `http(s)://<server>/<domain>/apps`. You can also download the latest version from [GitHub](https://github.com/PADS4/PADS4-Viewer-AOpen/releases/download/v1.0/PADS4AOpen.apk).

If you download the file, also copy it to the `Apps` folder on the PADS4 Server. If the server holds a different version, the device installs that version when it connects.

<Note>
  Support for the eTILE-X1032TP started in PADS4 2025.1. If your PADS4 Server is older, replace the `PADS4AOpen.apk` file in the `Apps` folder with the latest download.
</Note>

1. Copy `PADS4AOpen.apk` to a USB flash drive.
2. Insert the USB flash drive into the device.
3. Open the **File Manager** app.
4. Browse to the USB flash drive, and then open `PADS4AOpen.apk`.
5. A message says that installation from unknown sources is not allowed. Select **Settings**, and then allow installation from this source.
6. Press **Back**, and then select **Install**.
7. When the installation is complete, open the PADS4 AOpen app.

## Connect the Viewer to the PADS4 Server

1. The server location has this format: `http(s)://<server>/<domain>`. Replace `<server>` with the IP address or host name of your PADS4 Server. Replace `<domain>` with your PADS4 domain. The default domain is `PADS4`.
   1. Enter the PADS4 Server location.
   2. (Optional) Enter a name for the Viewer. If you leave the field empty, the PADS4 Server generates a name.
   3. Select **Start**.
   4. Set **PADS4 IIyama Touch** as the Home app, and then select **Always**.
   <Check>
     The Viewer shows a green LED and the name of the Viewer. This means that the connection works.
   </Check>

You can set the screen orientation and the remote control restrictions with PADS4 Agent or in the Viewer settings.

## Change device settings

### Open the Viewer options

Press and hold the screen to open the menu. You can also change the options remotely in PADS4 CTRL Center or with PADS4 Agent.

### Open the Android settings

<Warning>
  If **Hide Status Bar** is turned on, you can leave the Android settings only by restarting the device. To restart it, disconnect the power.
</Warning>

1. Open the Viewer menu.
2. Select **Launcher Settings**.
3. Select the gear icon in the lower-right corner.

The Android settings open.

### Turn off the Android navigation bar

Turn off the navigation bar to prevent unauthorized use of the device. This step is optional.

<Warning>
  After you turn off the navigation bar, you can leave the settings only by restarting the device. To restart it, disconnect the power.
</Warning>

1. Open the Viewer menu.
2. Select **Launcher Settings**.
3. Select the gear icon in the lower-right corner.
4. Select **System Tools**.
5. Select **Disable Navigation Bar**.

### Reset the device

<Warning>
  A factory reset removes all data and settings from the device.
</Warning>

1. [Open the Android settings](#open-the-android-settings).
2. Go to **Backup & Reset**.
3. Select **Factory Data Reset**.
4. (Optional) Select **Erase SD Card**.
5. Select **Reset Tablet**.
6. Select **Erase Everything**.

## Update PADS4 Viewer

The HTML5 Viewer updates automatically. To install a newer version of the app manually, repeat the steps in [Install PADS4 Viewer](#install-pads4-viewer).

## Supported features and limitations

### General

| Feature | Support | Notes |
| --- | --- | --- |
| Automatic Viewer updates | Yes | The HTML5 Viewer updates automatically. |
| Offline mode | Yes | Playback and schedule updates continue for 7 days offline. |
| HTTP and HTTPS | Yes |  |
| Portrait mode | Yes | The device rotates the screen automatically. |
| Cluster Viewer | Yes | The device can be part of a cluster setup. |
| Content integrity check | Yes | The PADS4 Content Library checks each file with an MD5 checksum during synchronization. |

### Video and images

| Feature | Support | Notes |
| --- | --- | --- |
| Videos on one page | Yes | One video at a time. |
| Video streaming | Yes | HTTP streaming. |
| Seamless video playback | No |  |
| Video rotation, reflection, skew, and flip | No |  |
| Image formats | Yes | JPG, PNG, BMP, and GIF. |

### Content and data

| Feature | Support | Notes |
| --- | --- | --- |
| Text, scrolling text, tables, shapes, and interactive buttons | Yes | Lines and formatted text are also supported. Flash and clipping effects are not supported. |
| Web element | Yes |  |
| PowerPoint and PDF | Partial | PDF is supported and needs an Xpert license. |
| Data providers, Viewer Variables, and rules | Yes | Includes more than 70 data providers, Viewer Variables, and property bindings. |
