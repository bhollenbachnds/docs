---
title: "CMS 2.0"
---

**CMS 2.0** (`/cms`) lists scheduled content messages from PADS4's CMS 2.0 module, with names resolved for destinations, priority, and the user who created each message. Data is collected in the background on an interval (default every 5 minutes) rather than fetched live.

- **Current tab**: the latest snapshot. Shows a warning banner if the most recent collection attempt failed (falling back to the last good snapshot).
- **History tab**: pick a date range (up to 3 months back) and a specific snapshot within it from the dropdown, to see what CMS looked like at that point in time.
- Each message row can be expanded (**Show**) for details: description, priority, user, message ID, template ID.
- Table columns include Name, Start/End dates, Destinations, User, Priority, Resolution, Pages, Weight, Template weight, and Status flags (Invisible / Disabled by template, if applicable).
- Search across name, destination, priority, and user.
