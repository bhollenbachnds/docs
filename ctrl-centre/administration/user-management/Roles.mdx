PADS4 version 2025.1 introduces a new user management system.

This fundamental change moves the User Management settings from the System Management application to the PADS4 Web Portal.

This release also introduces roles to further refine user management in PADS4.

Roles let you quickly assign a certain set of licenses and permissions to a user.

<Warning>
  The new user management system is not compatible with Legacy CMS and Workspace in PADS4 version 2025.1. Support for these was added in PADS4 version 2025.2.
</Warning>

## How to use roles in PADS4

<Info>
  The System Management and License Management licenses are required to administer your users and roles.
</Info>

- To access user management, log in to your PADS4 Web Portal with your Administrator account. Go to Dashboard, and on the bottom left go to **Users**.

<img
  src="/images/ctrl-centre/administration/user-management/Users.png"
  alt="Users Pn"
  style={{ width:"50%" }}
/>

- On the left-hand side, you can switch between Users and Roles.

<img
  src="/images/ctrl-centre/administration/user-management/Users-overview.png"
  alt="Users Overview Pn"
  style={{ width:"51%" }}
/>

- In the users overview, you see the users and their corresponding information:
  - Name
  - Username
  - Roles
  - License

![Single User Summary Pn](/images/ctrl-centre/administration/user-management/single-user-summary.png)

- The Roles section shows an overview of the available roles, including the default roles explained below.

![Default Roles](/images/ctrl-centre/administration/user-management/default-roles.png)

### Search for users

Use the search function to quickly locate specific users in the system. It searches across key fields: Name, Username, Roles, and License. This is ideal for admins managing PADS4.

**How to search**

1. Enter keywords in the search box (e.g., "john.doe", "admin role", or "Cms users group").
2. Results filter dynamically as you type. You don't need to press Enter.

**Export results**

Click the **Export** button to download results as Excel. This expands the view for bulk analysis or reporting. Exported data includes all visible columns for easy import elsewhere.

## Default roles

<Note>
  PADS4 version 2025.1 has five default roles. PADS4 version 2025.2 adds five more roles, which are listed later in this article.
</Note>

### CMS Advanced users group

| Application  | Access            | Inheritance         |
| ------------ | ----------------- | ------------------- |
| Web Designer | Read/Write/Delete |                     |
| CMS          | Read              |                     |
| Content      | Read/Write/Delete | Content users group |

### CMS Manager group

| Application | Access            | Inheritance         |
| ----------- | ----------------- | ------------------- |
| CMS         | Read/Write/Delete |                     |
| Users       | Read/Write/Delete |                     |
| Content     | Read/Write/Delete | Content users group |

### CMS User group

| Application | Access            | Inheritance         |
| ----------- | ----------------- | ------------------- |
| CMS         | Read              |                     |
| Content     | Read/Write/Delete | Content users group |

### Content Managers group

| Application | Access                   | Inheritance |
| ----------- | ------------------------ | ----------- |
| Content     | Read/Write/Delete/Modify |             |

### Content User group

| Application | Access            | Inheritance |
| ----------- | ----------------- | ----------- |
| Content     | Read/Write/Delete |             |

<Note>
  With the release of PADS4 version 2025.2, the following default roles have been added.
</Note>

<Danger>
  The viewer roles require an Agent or System Management (only for online/offline status and removal of viewers) license to be effective outside of CMS 2.0. The roles only set permissions once access has been granted by the license that has been assigned to the user.

  You can choose to adjust the default viewer roles to automatically add this license to users who have this role assigned.
</Danger>

## Customizing roles

- You can edit these roles to your preferred configuration, or create your own roles. In your own roles, you can specify other roles that the role is a member of, or assign certain licenses.

<img
  src="/images/ctrl-centre/administration/user-management/new-roles.png"
  alt="New Roles Pn"
  style={{ width:"65%" }}
/>

<img
  src="/images/ctrl-centre/administration/user-management/create-role.png"
  alt="Create Role Pn"
  style={{ width:"78%" }}
/>

- With these roles or the self-created roles, you can then further specify the access that users with a certain role have to applications available in the PADS4 Web Portal.

### Content library

- Right-click the folder that you want to change or review access for and click **"Edit access"**.

<img
  src="/images/ctrl-centre/administration/user-management/content-access.png"
  alt="Content Access Pn"
  style={{ width:"71%" }}
/>

- An overview of the roles and users with their rights on this folder appears. Here you can add or remove roles and users.

![Content Access 2 Pn](/images/ctrl-centre/administration/user-management/content-access-2.png)

### Web designer categories

- Click the three dots on the right of your category and click **"Edit access"**.

<img
  src="/images/ctrl-centre/administration/user-management/Webdesigner-category-access.png"
  alt="Webdesigner Category Access Pn"
  style={{ width:"57%" }}
/>

### Web designer templates

- Hover over a template, click the three dots, and click **"Edit access"**.

![Webdesigner Template Access Pn](/images/ctrl-centre/administration/user-management/Webdesigner-template-access.png)

### Viewers & viewer groups

- In Tree view, right-click the viewer group and click **"Edit Access"**.

<img
  src="/images/ctrl-centre/administration/user-management/treeview-perm.png"
  alt="Treeview Perm"
  style={{ width:"61%" }}
/>

- In Detail view, hover over either the viewer group or viewer, click the three dots, and click **"Edit access"**.

<img
  src="/images/ctrl-centre/administration/user-management/detailviewer-perm.png"
  alt="Detailviewer Perm"
