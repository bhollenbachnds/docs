---
title: "SCIM for Custom SAML 2.0"
---

For any identity provider that supports user provisioning with the SCIM standard, apply the following configuration:

- SCIM URL – Enter the URL shown on the PADS4 identity provider as “SCIM URL” (e.g. `https://pads4.mycompany.com/rdx/nds.services.user.scim/api/v1/scim`)
- SCIM Token – PADS4 uses Bearer token authentication for SCIM. Enter the token shown on the PADS4 identity provider as “SCIM Access token”

<Warning>
  Attention: This SCIM URL must be publicly accessible because the identity provider uses it as a callback for user provisioning.
</Warning>

Ensure that your SCIM configuration pushes notifications when users are created, updated, or deleted. Apply the same setting for user groups.

For the user and group property mapping, enter at least the following required properties:

- userName
- familyName
- givenName
- preferredLanguage
- emails
