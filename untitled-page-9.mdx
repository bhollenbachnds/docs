#### Newsfeed overview

Here you can set up a welcome message & a newsfeed ticker for your users on the dashboard. This can be useful for sending out certain updates to your PADS4 CMS users.

#### Welcome message

Here you can add a welcome image & message in the upper-left corner of the dashboard.

• Add an image (branded corporate image or anything you can think of).<br />• Add a text message to be displayed for users when they log in to PADS4 CMS.

When you are done adding an image & message, click the Save button on the right.

#### Newsfeed messages

Here is an overview of different newsfeed messages. You can create multiple messages that show as a ticker in the upper-right corner of the PADS4 CMS user dashboard.

**Show X entries**: showcase 10/25/50/100 messages.<br />**Search**: use keywords to search for certain messages.

Click the 'add message' button to add a newsfeed ticker message.

• Add a text message to be displayed for users when they log in to PADS4 CMS.<br />• Add an image (branded corporate image or anything you can think of).

When you are satisfied with your messages, click the Save button on the right. You can always view the separate messages and click the pencil icon to edit/delete the messages.
