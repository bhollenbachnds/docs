> **Not to be confused with** License & activation (Section 13), which is this _plugin's own_ license, managed separately by administrators. This page is read-only and shows **PADS4's own application/device licensing**, pulled live from PADS4.

The **Licenses** (`/licenses`) page shows license usage, capacity, and expiration across every licensed PADS4 application.

- **Summary**: licensee name, product key, and configured viewer-offline-days grace period (how many days a viewer can stay offline before its license seat is released).
- **Stats**: number of license pools, how many are at capacity, how many expire within 30 days (flagged in the table too).
- **Table**: one row per application license pool — Application name, Type, License type (Included / User / Device), Usage (used/total with a bar), Available, Demo flag, Expiration.
- Filter by name/type, or toggle **At capacity only**.
- Click **View devices** on any **device**-type license row to open a modal listing exactly which players currently hold a seat on that license (name, group, brand, status, last connected).
