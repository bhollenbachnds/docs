title: "PADS4"
---

To enable PADS4, perform the steps below:

1. Set the toggle to ON.
2. Select PADS4 as Source type.
3. Enter the PADS4 endpoint URL.<br />
   <Frame>
     ![PADS4 Sensor Config](/images/Workspace/Administrator/PADS4-Sensor-config.png "PADS4 Sensor Config")
   </Frame>
4. Click Save.
