## Aperçu

Gère l'intégration avec les systèmes d'identité externes : flux de connexion SAML 2.0, diagnostics de disjoncteur pour la connectivité des fournisseurs d'identité, et gestion des files de messages pour les événements d'authentification.

| ------------------------------------- | ------------------------------------------------------------------------------------------- |
| Swagger UI                            | `https://<your-server>/rdx/NDS.Services.Authentication.Integration/swagger/index.html`      |
| Spécification OpenAPI                 | `https://<your-server>/rdx/NDS.Services.Authentication.Integration/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.Authentication.Integration`                         |
| Nombre total de points de terminaison | 16                                                                                          |

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin de service indiqué ci-dessus.
