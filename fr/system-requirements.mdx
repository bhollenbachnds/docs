- title: Configuration système requise pour le serveur PADS4
- description: Configuration minimale et recommandée en termes de CPU, RAM, disque
    et systèmes d'exploitation Windows pris en charge pour le serveur PADS4 à
    partir de la version 2021.1.
---

## Configuration minimale requise pour le serveur PADS4

* CPU: 4 cores
* RAM: 16 GB
* Taille d'installation complète : 1,32 Go
* Système d'exploitation 64 bits : Windows 10, Windows 11, Windows Server 2016, Windows Server + Datacenter edition 2019, Windows Server + Datacenter edition 2022, Windows Server + Datacenter edition 2025

## Configuration recommandée pour le serveur PADS4

* CPU: 8 cores
* RAM: 24 GB
* Taille d'installation complète : 1,32 Go
* Système d'exploitation 64 bits : Windows 10, Windows 11, Windows Server 2016, Windows Server + Datacenter edition 2019, Windows Server + Datacenter edition 2022, Windows Server + Datacenter edition 2025
