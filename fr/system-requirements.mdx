---
- title: Configuration système requise pour PADS4 Server
- description: Vérifiez les exigences minimales et recommandées en matière de CPU,
    RAM, espace disque et versions Windows dont PADS4 Server a besoin à partir
    de la version 2021.1.
---

Assurez-vous que l'ordinateur sur lequel vous installez PADS4 Server répond à ces exigences. Les exigences s'appliquent à PADS4 2021.1 et versions ultérieures.

## Systèmes d'exploitation pris en charge

PADS4 Server fonctionne sur ces versions 64 bits de Windows :

* Windows 10
* Windows 11
* Windows Server 2016, y compris l'édition Datacenter
* Windows Server 2019, y compris l'édition Datacenter
* Windows Server 2022, y compris l'édition Datacenter
* Windows Server 2025, y compris l'édition Datacenter
