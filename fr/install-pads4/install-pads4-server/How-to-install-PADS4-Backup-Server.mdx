- title: Installer un serveur de sauvegarde PADS4
---

Le processus d'installation correspond à la configuration du PADS4 Server. Voir [Installer PADS4 Server](/fr/install-pads4/install-pads4-server/Install-the-PADS4-server) et exécutez le programme d'installation.

## Configuration d'un serveur de sauvegarde

Pour configurer un serveur de sauvegarde, effectuez les étapes suivantes dans PADS4 System Management sur le serveur principal :​

1. Ouvrez **PADS4 System Management** sur le serveur principal.
2. Dans le menu de gauche, sélectionnez **Serveurs**.​
3. Dans la barre de ruban, cliquez sur **Ajouter un serveur de sauvegarde**.
4. Saisissez un **nom d'affichage** pour le sous-serveur tel qu'il doit apparaître dans PADS4.
5. Vérifiez qu'une **licence valide** est attribuée au serveur de sauvegarde.

## Configuration des ports réseau

PADS4 utilise des ports réseau spécifiques pour sa communication interne et ses services. Reportez-vous à la [**Configuration des ports réseau**](/fr/network-requirements) page pour la liste complète des ports requis et des paramètres.

Pour plus de détails sur la façon dont les données sont synchronisées entre les serveurs Principal, Secondaire et de Sauvegarde, consultez la [**Réplication avec les serveurs Secondaire et de Sauvegarde**](/fr/network-requirements) page.

## Exigences d'installation du serveur

<Warning>
  N'installez pas **PADS4 Foundation** sur un poste de travail ou un PC Viewer. Il doit fonctionner sur un **serveur dédié**.
</Warning>
