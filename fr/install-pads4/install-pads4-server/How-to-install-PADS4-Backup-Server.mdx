Le processus d'installation correspond à la configuration du serveur PADS4. Voir [Installer PADS4 Server](/fr/install-pads4/install-pads4-server/Install-the-PADS4-server) et exécuter le programme d'installation.

## Configuration d'un serveur de sauvegarde

Pour configurer un serveur de sauvegarde, effectuez les étapes suivantes dans PADS4 System Management sur le serveur principal :​

1. Ouvrir **PADS4 System Management** sur le serveur principal.
2. Dans le menu de gauche, sélectionner **Servers**.​
3. Dans la barre de ruban, cliquer sur **Add Backup Server**.
4. Saisir un **nom d'affichage** pour le sous-serveur tel qu'il doit apparaître dans PADS4.
5. Vérifier qu'une **licence valide** est attribuée au serveur de sauvegarde.

## Configuration des ports réseau

PADS4 utilise des ports réseau spécifiques pour sa communication interne et ses services. Consultez la page [**Network Ports Configuration**](/fr/network-requirements) pour la liste complète des ports et paramètres requis.

Pour plus de détails sur la façon dont les données sont synchronisées entre les serveurs principal, secondaire et de sauvegarde, consultez la page [**Replication with Sub and Backup Servers**](/fr/network-requirements).

## Exigences d'installation du serveur

<Warning>
  Ne pas installer **PADS4 Foundation** sur un poste de travail ou un PC Viewer. Il doit fonctionner sur un **serveur dédié**.
</Warning>
