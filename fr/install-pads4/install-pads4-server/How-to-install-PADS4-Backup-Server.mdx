Le processus d'installation correspond à la configuration du PADS4 Server. Voir [Install PADS4 Server](/fr/install-pads4/install-pads4-server/Install-the-PADS4-server) et exécutez le programme d'installation.

## Configurer un Backup Server

Pour configurer un Backup Server, effectuez les étapes suivantes dans PADS4 System Management sur le Main Server :​

1. Ouvrez **PADS4 System Management** sur le Main Server.
2. Dans le menu de gauche, sélectionnez **Servers**.​
3. Dans la barre de ruban, cliquez sur **Add Backup Server**.
4. Saisissez un **nom d'affichage** pour le Sub Server tel qu'il doit apparaître dans PADS4.
5. Vérifiez qu'une **licence valide** est attribuée au Backup Server.

## Configuration des ports réseau

PADS4 utilise des ports réseau spécifiques pour sa communication interne et ses services. Consultez la page [**Network Ports Configuration**](/fr/network-requirements) pour la liste complète des ports et paramètres requis.

Pour plus de détails sur la façon dont les données sont synchronisées entre les Main, Sub et Backup Servers, consultez la page [**Replication with Sub and Backup Servers**](/fr/network-requirements).

## Exigences d'installation du serveur

<Warning>
  N'installez pas **PADS4 Foundation** sur un poste de travail ou un PC Viewer. Il doit fonctionner sur une **machine serveur dédiée**.
</Warning>
