Pour activer votre **produit PADS4**, suivez les étapes ci-dessous en utilisant la **clé de licence PADS4 fournie.**

## Étape 1 : Ouvrir PADS4 CTRL Center

* Après avoir installé **PADS4**, accédez au **PADS4 Web Portal.**

<Tip>
  Si vous réactivez une installation PADS4 déjà en cours d'utilisation, vous n'avez pas besoin d'utiliser l'utilisateur su\root. Tout utilisateur disposant de la licence **System Management + License Management** peut réactiver l'installation en accédant à **Licenses** dans le menu de gauche.
</Tip>

* Connectez-vous avec l'utilisateur **su\root**.
* En haut de l'écran, sélectionnez le domaine "**pads**".

![Root Domain](/images/install-pads4/activating-pads4/root-domain.png)

* **Licenses** apparaît maintenant dans le menu de gauche.

<img src="/images/install-pads4/activating-pads4/root-licenses.png" alt="Root Licenses" title="Root Licenses" style={{ width:"100%" }} />

* Sélectionnez **Licenses**, puis sélectionnez **Activate**.

![Root License2](/images/install-pads4/activating-pads4/root-license2.png)

* Si une connexion internet n'est pas disponible, PADS4 affiche une méthode d'**activation hors ligne**.
  * Suivez les instructions affichées à l'écran.
  * Après avoir reçu le **fichier de licence**, sélectionnez **Upload License File**, puis sélectionnez le fichier.
  * Terminez le processus d'activation en suivant l'assistant.

Une fois l'activation terminée, votre **installation PADS4 est prête à l'emploi.**
