## Vue d'ensemble

Crystal est l'API REST intégrée de PADS4 pour la gestion de l'affichage dynamique et des espaces de travail (salles de réunion). Elle fournit une interface unifiée pour gérer le contenu des affichages, les catégories, les messages, les réservations de salles de réunion, les ressources et l'occupation — couvrant à la fois la couche de lecture de l'affichage et le cycle de vie complet de la réservation de salles. Crystal s'exécute sur un chemin de base distinct des services PADS4 Foundation standard.

| Champ                                 | Valeur                                                  |
| ------------------------------------- | ------------------------------------------------------- |
| Swagger UI                            | `https://<your-server>/crystal/pads/swagger/index.html` |
| Spécification OpenAPI                 | `https://<your-server>/crystal/pads/swagger/docs/v1`    |
| URL de base                           | `https://<your-server>/crystal/pads`                    |
| Nombre total de points de terminaison | 100                                                     |

***

## Authentification

Crystal utilise son **propre point de terminaison de jeton** — il ne **pas** utilise le cookie de session PADS4 standard de `/api/v1/Account/Logon`.

```bash
# Step 1 — obtain a Bearer token from Crystal
curl -X POST 'https://<your-server>/crystal/pads/api/token' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -d 'grant_type=password&username=admin&password=yourpassword'

# Response
# {"access_token": "eyJ...", "token_type": "bearer", "expires_in": 3600}

# Step 2 — use the token on all Crystal requests
curl -X GET 'https://<your-server>/crystal/pads/api/public/digitalsignage/displays' \
  -H 'Authorization: Bearer eyJ...'
```

> Tous les exemples ci-dessous supposent que le jeton est stocké dans la variable shell `$TOKEN`.

## Exemples de requêtes et de réponses

### POST `/api/token`

S'authentifier et obtenir un jeton Bearer Crystal.

**Request:**

```bash
curl -X POST 'https://<your-server>/crystal/pads/api/token' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -d 'grant_type=password&username=admin&password=yourpassword'
```

**Réponse `200 OK`:**

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 3600
}
```
