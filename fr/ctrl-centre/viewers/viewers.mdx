La **Viewers** section dans **PADS4** affiche tous les **Viewers et groupes de Viewers**. Un **Viewer** est le **endpoint** où les présentations sont affichées.

## Aperçu

* Affiche **tous les Viewers disponibles** et **groupes de Viewers**.
* **Créer un nouveau Viewer** en utilisant le **➕ New** bouton.
* **Nommage par défaut**:
  * Les Viewers de première connexion **génèrent automatiquement** un nom basé sur le type d'appareil :
    * **Samsung** appareils → *Samsung000x*
    * **LG** appareils → *LG000x*
  * Les noms peuvent être modifiés via l'option **Edit** (uniquement pour les Viewers en ligne).
* **Options d'affichage**:
  * Basculer entre **Tree View** et **Detail View**.
  * **Tree view**

![Tree View](/images/ctrl-centre/viewers/tree-view.png)

* **Detail view**

![Detail View](/images/ctrl-centre/viewers/detail-view.png)

* Utilisez l'option **Search/Filter** pour localiser des Viewers spécifiques.

![Viewer Filter](/images/ctrl-centre/viewers/viewer-filter.png)

## Créer un nouveau viewer

Suivez ces étapes pour **ajouter un nouveau Viewer** à PADS4 :

1️⃣ **Cliquez sur le** ➕ **New** bouton sur la page Viewers.

![New Viewer](/images/ctrl-centre/viewers/new-viewer.png)

2️⃣ **Sélectionnez le type de Viewer** (Seuls les types de Viewers disposant de licences disponibles seront affichés) :

![New Viewer1](/images/ctrl-centre/viewers/new-viewer1.png)

* **Viewer Group** – Un groupe contenant plusieurs Viewers (simplifie la planification).
* **Viewer** – Un Viewer autonome qui prend en charge les types **Windows et HTML5**.
* **Windows Viewer** – Un Viewer fonctionnant sur **Microsoft Windows**.
* **HTML5 Viewer** – Un Viewer fonctionnant sur des **systèmes non-Windows (compatibles HTML5)**.
* **Zone Viewer** – Un Viewer assigné à une **zone** spécifique dans une **présentation PADS4**.
* **Desktop Viewer** – Un Viewer fonctionnant sur des **PC de bureau Windows**.\
  3️⃣ **Attribuez un nom de Viewer unique** (optionnellement, ajoutez une description – ex. : emplacement du Viewer).\
  4️⃣ **Sélectionnez un groupe de Viewers** (le cas échéant).\
  5️⃣ **Attribuez une licence**:
* **Basic** – Prend en charge la plus petite gamme d'éléments de présentation.
* **Xpress** – Offre une gamme **modérée** de fonctionnalités.
* **Xpert** – Fournit un **accès complet aux fonctionnalités** pour les présentations avancées.\
  6️⃣ **(Optionnel) Définir un mot de passe** – Le Viewer aura besoin de ce mot de passe pour s'authentifier lors de la connexion au **PADS4 Server**, garantissant ainsi la sécurité.

**Une fois toutes les étapes terminées, le nouveau Viewer est prêt à être utilisé !**

## Informations sur le Viewer

* Cliquer sur une **ligne de Viewer** la développe pour afficher des **informations détaillées**.

![Viewer Detail](/images/ctrl-centre/viewers/viewer-detail.png)

* Un double-clic sur le viewer ouvre la page de détails du viewer décrite ci-dessous.
* Lorsque vous survolez l'un des viewers avec votre souris, trois points apparaissent à droite avec plus d'options :

![Viewer Menu](/images/ctrl-centre/viewers/viewer-menu.png)

* **View Details** – Inspecter et gérer le Viewer. (Plus d'informations ci-dessous.)
* **Viewer schedules** – Redirige vers le module de planification pour vérifier les planifications de ce Viewer spécifique.
* **Manage:**
  * **Reboot viewer** – Redémarrer l'appareil à distance.
  * **Restart viewer** – Redémarrer l'application viewer à distance.
  * **Retrieve Blackbox** – Collecter des données de diagnostic.
* **Edit** – Modifier les aspects suivants du viewer :
  * Nom et description du Viewer
  * Attribuer ou modifier le groupe de viewers
  * Attribuer une licence
  * Activer / désactiver l'exigence de mot de passe
* **Delete** – Supprimer le viewer du système.
* **Access** – Définir les permissions sur le viewer / groupe de viewers.
  * [Vous pouvez en savoir plus à ce sujet ici.](https://docs.pads4.com/ctrl-centre/viewers/viewer-permissions)

## Informations détaillées sur le viewer

![Viewer Details2](/images/ctrl-centre/viewers/viewer-details2.png)

* **System information** – Informations détaillées sur l'appareil, notamment les caractéristiques matérielles, l'espace de stockage, le firmware, la résolution, etc.
* **Viewer Log** – Consulter les journaux d'activité.
* **Viewer Settings** – Modifier les préférences du Viewer.
* **Viewer Screenshot** – Capturer l'affichage actuel.

## Viewer blackbox (pour le dépannage)

* Si un **problème de Viewer survient**, **NDS Support** peut demander la **Blackbox** pour le dépannage.
* Le **Blackbox** contains:
  * **Journaux**
  * **Informations système et mémoire**
  * **Autres données de diagnostic**
* **Comment fournir le Blackbox**:
  * Soumettez-le via le portail de support PADS4 pour le support NDS.
  * Fournissez-le à votre **partenaire** pour une analyse approfondie.
  * Utilisez **PADS4 Agent** pour analyser les données.
