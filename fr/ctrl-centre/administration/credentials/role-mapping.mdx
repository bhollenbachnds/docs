---
- title: Mappage de rôles
- description: Mappez les groupes du fournisseur d'identité externe aux rôles
    PADS4 et modifiez les attributs de revendications afin que les utilisateurs
    SSO reçoivent les bonnes autorisations lorsqu'ils se connectent à PADS4.
---

<Warning>
  Cet article nécessite au moins la version 2025.2 de PADS4.
</Warning>

Après avoir créé votre fournisseur d'identité, gérez ses mappages de rôles.

Lorsqu'un utilisateur se connecte, PADS4 lui attribue des rôles PADS4 en fonction des mappages du groupe du fournisseur d'identité aux rôles PADS4 que vous configurez.

## 1. Configurer les mappages

Pour configurer ces mappages :

* Sur votre fournisseur d'identité nouvellement créé, cliquez sur **Identity mappings**.

![Role Mapping1](/images/ctrl-centre/administration/credentials/role-mapping1.png)

* Sur l'onglet **Role mappings**, cliquez sur **New** pour créer un nouveau mappage de rôle.

![Role Mapping2](/images/ctrl-centre/administration/credentials/role-mapping2.png)

* Sur le formulaire de mappage de rôle, remplissez deux champs :
  * Le groupe du fournisseur SSO. Cela correspond à la revendication de groupe d'utilisateurs que vous avez configurée sur le fournisseur d'identité externe.
  * Les rôles PADS4. Ceux-ci déterminent les rôles attribués à un utilisateur en fonction du groupe du fournisseur d'identité externe auquel il appartient.

![Role Mapping3](/images/ctrl-centre/administration/credentials/role-mapping3.png)

* Sélectionnez un groupe de fournisseur SSO pour votre mappage de rôle.
  * Si le groupe de fournisseur SSO que vous attendez n'existe pas encore, cliquez sur **New SSO Group** pour ajouter un autre groupe à la liste.

![Role Mapping4](/images/ctrl-centre/administration/credentials/role-mapping4.png)

* Le **SSO Group Name** vous aide uniquement à mémoriser l'identité du groupe que vous avez créé.
* Le **SSO Group id** doit correspondre à la valeur de revendication de groupe que vous avez configurée dans la configuration des revendications du fournisseur d'identité externe.
  * *Par défaut, la valeur de revendication de groupe est :*
    * *L'identifiant du groupe d'utilisateurs pour Azure*
    * *Le nom du groupe d'utilisateurs pour Okta*

Après avoir renseigné le groupe SSO, cliquez sur **Create** pour enregistrer le groupe. Sélectionnez ensuite le groupe dans votre formulaire de création de mappage de rôle.

![Role Mapping5](/images/ctrl-centre/administration/credentials/role-mapping5.png)

* Sélectionnez des rôles dans PADS4.

Sélectionnez les rôles que PADS4 attribue à l'utilisateur si celui-ci est membre du groupe SSO sélectionné.

Si un rôle est manquant, cliquez sur **New role** pour créer un nouveau rôle, puis sélectionnez-le.

![Role Mapping6](/images/ctrl-centre/administration/credentials/role-mapping6.png)

* Cliquez sur **Create** pour enregistrer le mappage de rôle.
* Répétez ce processus pour chaque groupe d'utilisateurs du fournisseur d'identité externe auquel vous souhaitez autoriser l'accès à l'application.

<Warning>
  Si un utilisateur de votre fournisseur d'identité externe appartient à un groupe qui ne figure pas dans le tableau de mappage de rôles, cet utilisateur n'a aucun droit sur l'application par défaut.
</Warning>

## 2. Mettre à jour les revendications du fournisseur d'identité (facultatif)

Vous souhaiterez peut-être modifier le mappage des revendications sur le fournisseur d'identité PADS4 que vous avez créé. Faites-le si vous avez créé votre fournisseur d'identité à partir d'un fournisseur d'identité externe SAML 2.0 personnalisé, ou si vous souhaitez étendre ou mettre à jour vos attributs de revendications.

Pour mettre à jour ces revendications :

* Sur votre fournisseur d'identité nouvellement créé, cliquez sur **Identity mappings**.

![Role Mapping7](/images/ctrl-centre/administration/credentials/role-mapping7.png)

* Passez à l'onglet **Claims**.

<Note>
  Si vous avez créé votre fournisseur d'identité à partir d'Azure ou d'Okta, cet onglet peut déjà contenir des mappages de revendications par défaut que vous pouvez modifier si nécessaire.
</Note>

![Role Mapping8](/images/ctrl-centre/administration/credentials/role-mapping8.png)

* Créez une nouvelle revendication ou mettez à jour une revendication existante. Si vous créez une nouvelle revendication, renseignez les informations suivantes :
  * Le **claim name**. Cela correspond au nom de revendication que PADS4 récupère depuis la réponse SAML.
  * Le **local attribute**. Cela détermine la propriété que PADS4 renseigne avec la valeur de revendication lors de la création de l'utilisateur PADS4.

![Role Mapping9](/images/ctrl-centre/administration/credentials/role-mapping9.png)

* Vous pouvez uniquement choisir l'attribut local dans la liste des propriétés d'utilisateur PADS4 ci-dessous.

| Attribut local   | Description                                                                                                                       |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **GroupIds**     | Correspond aux identifiants de groupe récupérés pour la logique d'association de mappage de rôles                                 |
| **FirstName**    | Correspond à la propriété prénom de l'utilisateur PADS4                                                                           |
| **SID**          | Correspond à la propriété nom de famille de l'utilisateur PADS4                                                                   |
| **EmailAddress** | Correspond à une clé unique qui est le lien entre l'utilisateur dans le fournisseur d'identité externe et l'utilisateur dans PADS |
| **Name**         | Correspond à la propriété e-mail de l'utilisateur PADS4                                                                           |
| **DisplayName**  | Correspond à la propriété de connexion de l'utilisateur PADS4                                                                     |
| **NFC**          | Correspond à la propriété NFC de l'utilisateur PADS4                                                                              |
