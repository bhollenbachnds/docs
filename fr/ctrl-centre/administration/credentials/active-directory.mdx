PADS4 permet l'intégration avec **Active Directory (AD)** pour simplifier **l'authentification et la gestion des utilisateurs**. Cela s'effectue via l'interface **Credentials** dans **PADS4 CTRL Center**.

<Note>
  Pour **Active Directory Federation Services (AD FS)**, créer un **fournisseur d'identité SAML 2.0 personnalisé** dans PADS4. Pour des instructions de configuration détaillées, voir **SAML 2.0 personnalisé**.
</Note>

Suivez les étapes ci-dessous pour connecter votre instance Active Directory :

## **1. Accès au PADS4 CTRL Center**

Pour commencer :

* Ouvrir votre **navigateur web**.
* Accéder à l' **URL du serveur PADS4** (un nom DNS ou une adresse IP).
* Se connecter avec un **compte Administrateur**.

Une fois connecté :

* Cliquer sur **Dashboard**.
* Utiliser le bouton **Toggle Sidebar** en **haut à droite** de l'écran.
* Accéder à **Credentials**.
* Puis sélectionner **Providers**.

## **2. Ajout d'une connexion Active Directory**

Pour ajouter Active Directory :

1. Cliquer sur **+ Nouveau**
2. Sélectionner **Identity**
3. Sélectionner **Active Directory**

Vous serez invité à renseigner les détails de configuration requis :

* **Host Name** – Le nom de domaine ou l'adresse IP de votre serveur AD.
* **Port** – Généralement `389` pour LDAP ou `636` pour LDAPS.
* **Use SSL** – Activez ce bouton si vous utilisez **Secure LDAP (LDAPS)**.
* **Nom d'utilisateur** – Un compte AD avec des autorisations de lecture (par ex., `admin@domain.local`).
* **Mot de passe** – Le mot de passe associé au compte ci-dessus.

Une fois terminé, cliquez sur **Créer** pour finaliser la connexion.

## **3. Gestion des utilisateurs via Active Directory**

Après une connexion réussie :

* Vous pouvez maintenant **importer et gérer des utilisateurs** depuis votre Active Directory dans PADS4.
* Cela permet un contrôle centralisé des utilisateurs et une **attribution des rôles et authentification transparentes**.

Pour des fonctionnalités de gestion plus avancées, consultez la **documentation de gestion des utilisateurs PADS4**.
