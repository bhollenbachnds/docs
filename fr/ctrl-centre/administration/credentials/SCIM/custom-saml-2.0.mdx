---
- title: SCIM pour SAML 2.0 personnalisé
- description: Configurez le provisionnement des utilisateurs SCIM entre un
    fournisseur d'identité SAML 2.0 personnalisé et PADS4 pour synchroniser les
    utilisateurs et les groupes à l'aide du token Bearer standard SCIM.
---

Pour tout fournisseur d'identité prenant en charge le provisionnement des utilisateurs avec la norme SCIM, appliquez la configuration suivante :

* URL SCIM – Entrez l'URL affichée sur le fournisseur d'identité PADS4 en tant que « URL SCIM » (par ex. `https://pads4.mycompany.com/rdx/nds.services.user.scim/api/v1/scim`)
* Token SCIM – PADS4 utilise l'authentification par token Bearer pour SCIM. Entrez le token affiché sur le fournisseur d'identité PADS4 en tant que « Token d'accès SCIM »

<Warning>
  Attention: This SCIM URL must be publicly accessible because the identity provider uses it as a callback for user provisioning.
</Warning>

Assurez-vous que votre configuration SCIM envoie des notifications lorsque des utilisateurs sont créés, mis à jour ou supprimés. Appliquez le même paramètre pour les groupes d'utilisateurs.

Pour le mappage des propriétés des utilisateurs et des groupes, entrez au moins les propriétés requises suivantes :

* userName
* familyName
* givenName
* preferredLanguage
* emails
