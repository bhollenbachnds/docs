- description: Configurez le provisionnement d'utilisateurs SCIM entre Microsoft
    Entra ID et PADS4 pour créer, mettre à jour et désactiver automatiquement

<Warning>
  Cet article nécessite que vous disposiez au moins de la version PADS4 2025.2.
</Warning>

L'approvisionnement des utilisateurs est le processus de création, de mise à jour et de suppression automatiques des comptes utilisateurs. Il garantit que les utilisateurs obtiennent les accès appropriés lorsqu'ils rejoignent l'organisation, changent de rôle ou la quittent.

Pour activer l'approvisionnement des utilisateurs, PADS4 utilise la norme SCIM (System for Cross-domain Identity Management). SCIM fournit un moyen cohérent et automatisé de créer, mettre à jour et désactiver des utilisateurs.

Pour configurer l'approvisionnement des utilisateurs, créez un fournisseur d'identité en suivant les instructions de configuration SSO dans ce document. Activez ensuite l'option SCIM sur celui-ci et configurez la configuration SCIM sur le fournisseur d'identité externe.

## 1. Activer SCIM sur le fournisseur d'identité PADS4

Lors de la configuration de votre fournisseur d'identité PADS4, vous pouvez activer l'option SCIM Provisioning.

Pour l'activer lors de la création du fournisseur d'identité :

* Cliquez sur l'étape "SCIM Provisioning"
* Cliquez sur "Enable SCIM Provisioning"

![Scim Ms1](/images/ctrl-centre/administration/credentials/SCIM/scim-ms1.png)

Après l'avoir activé, conservez les données suivantes :

* URL SCIM
* Jeton d'accès SCIM

Vous réutiliserez ces valeurs ultérieurement lors de la configuration de SCIM Provisioning sur le fournisseur d'identité externe.

## 2. Configurer SCIM sur le fournisseur d'identité externe

Maintenant que SCIM Provisioning est activé sur PADS4, configurez la configuration d'approvisionnement des utilisateurs SCIM sur le fournisseur d'identité externe.

### Fournisseur d'identité Microsoft Entra

Sur Microsoft Entra, vous pouvez activer la fonctionnalité d'approvisionnement des utilisateurs sur la même application que vous avez précédemment créée pour SSO.

* Ouvrez l'application d'entreprise que vous avez précédemment créée
* Dans le menu de gauche, cliquez sur "Provisioning"

![Scim Ms2](/images/ctrl-centre/administration/credentials/SCIM/scim-ms2.png)

* Sur la page d'aperçu qui s'ouvre, cliquez sur "New Configuration"

![Scim Ms3](/images/ctrl-centre/administration/credentials/SCIM/scim-ms3.png)

#### Créez la configuration d'approvisionnement

* Sur la page de nouvelle configuration, entrez les informations suivantes :
  * **Méthode d'authentification** – PADS4 utilise l'authentification Bearer pour SCIM, sélectionnez donc "Bearer authentication"
  * **URL du locataire** – Entrez l'URL affichée sur le fournisseur d'identité PADS4 en tant que "SCIM URL" (ex. `https://pads4.mycompany.com/rdx/nds.services.user.scim/api/v1/scim`)
  * **Jeton secret** – Entrez le jeton affiché sur le fournisseur d'identité PADS4 en tant que "SCIM Access token"

<Warning>
  Attention: This Tenant URL must be publicly accessible because Azure uses it as a callback for user provisioning.
</Warning>

* Cliquez sur "Test connection" pour vérifier que la connexion est correcte
* Si la connexion est correcte, cliquez sur le bouton "Create"

![Scim Ms4](/images/ctrl-centre/administration/credentials/SCIM/scim-ms4.png)

#### Configurer le mappage des utilisateurs et des groupes

Maintenant que la configuration de l'approvisionnement des utilisateurs est terminée, configurez le mappage des utilisateurs et des groupes.

* Dans le menu de la page Provisioning, cliquez sur "**Attribute mapping**"

![Scim Ms5](/images/ctrl-centre/administration/credentials/SCIM/scim-ms5.png)

* Configurez le mappage des groupes

<Note>
  Microsoft Entra configure le mappage des groupes comme prévu par défaut. Assurez-vous que les paramètres suivants sont appliqués.
</Note>

![Scim Ms6](/images/ctrl-centre/administration/credentials/SCIM/scim-ms6.png)

* Configurez le mappage des utilisateurs
  * Par défaut, le mappage des utilisateurs est configuré comme indiqué ci-dessous.

![Scim Ms7](/images/ctrl-centre/administration/credentials/SCIM/scim-ms7.png)

* À partir de la configuration initiale, conservez les attributs suivants
  * Vous pouvez supprimer tous les attributs mappés qui n'existent pas dans cette liste.

![Scim Ms8](/images/ctrl-centre/administration/credentials/SCIM/scim-ms8.png)

* Ajoutez le nouvel attribut personnalisé **externalId**
  * Après avoir supprimé les attributs inexistants, cliquez sur le bouton "Add New Mapping" et entrez les informations suivantes pour créer l'attribut **externalId**

![Scim Ms9](/images/ctrl-centre/administration/credentials/SCIM/scim-ms9.png)

* **(Facultatif)** Ajouter des attributs facultatifs

Vous pouvez également ajouter des attributs facultatifs définis par PADS4.

Pour les utiliser, cliquez à nouveau sur "Add New Mapping" pour chaque attribut et configurez-le.

Actuellement, les attributs facultatifs disponibles sont :

| Attribut cible | Commentaire                                                                  |
| -------------- | ---------------------------------------------------------------------------- |
| NFC            | Synchronise toute valeur saisie dans la propriété NFC de l'utilisateur PADS4 |

* Cliquez sur « Enregistrer » pour sauvegarder la configuration du mappage utilisateur

#### Attribuer le groupe autorisé à accéder à l'application

Sur Microsoft Entra, définissez quels membres du groupe se synchronisent avec l'application.

Vous configurez cela de la même manière que la configuration de l'authentification unique (SSO). Les groupes d'utilisateurs que vous avez déjà définis pour le SSO s'appliquent automatiquement à cette configuration.

Pour étendre cette liste de groupes d'utilisateurs, suivez les instructions dans la **Attribuer des groupes d'utilisateurs à l'application** section de l'article SSO correspondant.

#### Démarrer le service de provisionnement

Après avoir terminé la configuration du provisionnement sur **Microsoft Entra (Azure)** et **PADS4** et attribué les groupes à l'application, vous pouvez démarrer le **service de provisionnement**.

Pour le démarrer, accédez à l'onglet Provisionnement dans le menu de gauche et cliquez sur le bouton « **Démarrer le provisionnement** ».

![Scim Ms10](/images/ctrl-centre/administration/credentials/SCIM/scim-ms10.png)
