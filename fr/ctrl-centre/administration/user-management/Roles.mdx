PADS4 version 2025.1 introduit un nouveau système de gestion des utilisateurs.

Ce changement fondamental déplace les paramètres de gestion des utilisateurs de l'application System Management vers le PADS4 Web Portal.

Cette version introduit également des rôles pour affiner davantage la gestion des utilisateurs dans PADS4.

Les rôles vous permettent d'attribuer rapidement un ensemble de licences et d'autorisations à un utilisateur.

<Warning>
  Le nouveau système de gestion des utilisateurs n'est pas compatible avec Legacy CMS et Workspace dans PADS4 version 2025.1. La prise en charge de ceux-ci a été ajoutée dans PADS4 version 2025.2.
</Warning>

## Comment utiliser les rôles dans PADS4

<Info>
  Les licences System Management et License Management sont requises pour administrer vos utilisateurs et vos rôles.
</Info>

* Pour accéder à la gestion des utilisateurs, connectez-vous à votre PADS4 Web Portal avec votre compte Administrateur. Accédez au Dashboard, puis en bas à gauche, allez dans **Users**.

<img src="/images/ctrl-centre/administration/user-management/Users.png" alt="Users Pn" style={{ width:"50%" }} />

* Sur le côté gauche, vous pouvez basculer entre Users et Roles.

<img src="/images/ctrl-centre/administration/user-management/Users-overview.png" alt="Users Overview Pn" style={{ width:"51%" }} />

* Dans l'aperçu des utilisateurs, vous voyez les utilisateurs et leurs informations correspondantes :
  * Name
  * Username
  * Roles
  * License

![Single User Summary Pn](/images/ctrl-centre/administration/user-management/single-user-summary.png)

* La section Roles affiche un aperçu des rôles disponibles, y compris les rôles par défaut expliqués ci-dessous.

![Default Roles](/images/ctrl-centre/administration/user-management/default-roles.png)

### Rechercher des utilisateurs

Utilisez la fonction de recherche pour localiser rapidement des utilisateurs spécifiques dans le système. Elle effectue des recherches dans les champs clés : Name, Username, Roles et License. C'est idéal pour les administrateurs gérant PADS4.

**Comment rechercher**

1. Saisissez des mots-clés dans la zone de recherche (par ex., "john.doe", "admin role" ou "Cms users group").
2. Les résultats se filtrent dynamiquement au fur et à mesure que vous tapez. Vous n'avez pas besoin d'appuyer sur Entrée.

**Exporter les résultats**

Cliquez sur le bouton **Export** pour télécharger les résultats au format Excel. Cela élargit la vue pour une analyse en masse ou des rapports. Les données exportées incluent toutes les colonnes visibles pour une importation facile ailleurs.

<Danger>
  Les rôles de visionneuse nécessitent une licence Agent ou Gestion du système (uniquement pour le statut en ligne/hors ligne et la suppression des visionneuses) pour être effectifs en dehors de CMS 2.0. </Danger>

## Personnalisation des rôles

* Vous pouvez modifier ces rôles selon votre configuration préférée, ou créer vos propres rôles. Dans vos propres rôles, vous pouvez spécifier d'autres rôles dont le rôle est membre, ou attribuer certaines licences.

<img src="/images/ctrl-centre/administration/user-management/new-roles.png" alt="New Roles Pn" style={{ width:"65%" }} />

<img src="/images/ctrl-centre/administration/user-management/create-role.png" alt="Create Role Pn" style={{ width:"78%" }} />

* Avec ces rôles ou les rôles créés par vous-même, vous pouvez ensuite préciser davantage l'accès que les utilisateurs ayant un certain rôle ont aux applications disponibles dans le PADS4 Web Portal.

### Bibliothèque de contenu

* Faites un clic droit sur le dossier dont vous souhaitez modifier ou consulter l'accès, puis cliquez sur **"Modifier l'accès"**.

<img src="/images/ctrl-centre/administration/user-management/content-access.png" alt="Content Access Pn" style={{ width:"71%" }} />

* Un aperçu des rôles et des utilisateurs avec leurs droits sur ce dossier apparaît. Ici, vous pouvez ajouter ou supprimer des rôles et des utilisateurs.

![Content Access 2 Pn](/images/ctrl-centre/administration/user-management/content-access-2.png)

### Catégories du concepteur web

* Cliquez sur les trois points à droite de votre catégorie, puis cliquez sur **"Modifier l'accès"**.

<img src="/images/ctrl-centre/administration/user-management/Webdesigner-category-access.png" alt="Webdesigner Category Access Pn" style={{ width:"57%" }} />

### Modèles du concepteur web

* Survolez un modèle, cliquez sur les trois points, puis cliquez sur **"Modifier l'accès"**.

![Webdesigner Template Access Pn](/images/ctrl-centre/administration/user-management/Webdesigner-template-access.png)

### Visionneuses et groupes de visionneuses

* Dans la vue en arborescence, faites un clic droit sur le groupe de visionneuses et cliquez sur **"Modifier l'accès"**.

<img src="/images/ctrl-centre/administration/user-management/treeview-perm.png" alt="Treeview Perm" style={{ width:"61%" }} />

* Dans la vue détaillée, survolez le groupe de visionneuses ou la visionneuse, cliquez sur les trois points, puis cliquez sur **"Modifier l'accès"**.

<img src="/images/ctrl-centre/administration/user-management/detailviewer-perm.png" alt="Detailviewer Perm" style={{ width:"65%" }} />
