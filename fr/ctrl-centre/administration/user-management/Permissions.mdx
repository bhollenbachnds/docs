La page Permissions donne un aperçu complet de toutes les permissions configurées pour un utilisateur ou un rôle dans les modules suivants :

* Contenu
* Viewers
* CMS 2.0

## Aperçu des permissions

Une fois que vous avez ouvert la page Permissions, vous pouvez choisir les permissions que vous souhaitez examiner.

Vous pouvez choisir n'importe quel utilisateur spécifique ou n'importe quel rôle spécifique.

Type: **Utilisateur**

![Po Type User](/images/digital-signage/cms/po-type-user.png)

Type: **Rôle**

![Po Type Role](/images/digital-signage/cms/po-type-role.png)

Après avoir sélectionné et soumis votre choix, la page se rafraîchit et affiche les permissions configurées pour cet utilisateur ou ce rôle, comme indiqué ci-dessous :

* **Contenu** : Toutes les permissions pour tous les dossiers de contenu et les fichiers individuels sont affichées ici.

![Po Content](/images/digital-signage/cms/po-content.png)

* **Viewer** : Toutes les permissions pour tous les groupes de viewers et les viewers individuels sont affichées ici.

![Po Viewers](/images/digital-signage/cms/po-viewers.png)

* **CMS** : Toutes les permissions pour toutes les catégories et modèles CMS 2.0 sont affichées ici.

![Po Cms](/images/digital-signage/cms/po-cms.png)
