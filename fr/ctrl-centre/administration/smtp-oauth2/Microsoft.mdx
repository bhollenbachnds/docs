<Warning>
  Cet article nécessite que vous disposiez d'au moins la version PADS4 2025.2.
</Warning>

Ce document fournit des instructions étape par étape pour créer des identifiants OAuth2 pour l'authentification SMTP en utilisant les plateformes Google et Microsoft. Ce document suppose que le lecteur a une connaissance de base du portail Microsoft Azure.

## **1. Enregistrer une application**

* Aller sur [https://portal.azure.com/](https://portal.azure.com/) et se connecter avec un compte disposant de privilèges administratifs pour Microsoft Entra ID
* Dans le menu de gauche, sélectionner **App registrations**
* Configurer l'application :

![MS Smtp1](/images/ctrl-centre/administration/smtp-oauth2/MS-smtp1.png)

* Utiliser les informations suivantes :
  * **Name:** Entrer un nom descriptif ( ex. Gateway SMTP App )
  * **Types de comptes pris en charge :** Comptes dans cet annuaire organisationnel uniquement
  * **URI de redirection :** L'URI de redirection spécifie où le serveur d'autorisation doit renvoyer l'utilisateur après une authentification réussie pour retourner un jeton d'accès à son compte de messagerie.
    * **Type** : Web
    * **URL:** http\://\<host>:\<port>/credentials/generic/authorize/callback
      * **Host** : Nom DNS ou adresse IP de votre portail Web PADS4
      * **Port:** Facultatif, si votre instance PADS4 n'utilise pas les ports par défaut pour HTTP ou HTTPS.
* Une fois les informations renseignées, cliquer sur "**Register**".
* Sur la page de présentation de l'application, copier le **Application(client) ID** et le **Directory (tenant) ID**. Ces informations sont requises pour la configuration de votre passerelle.

![MS Smtp2](/images/ctrl-centre/administration/smtp-oauth2/MS-smtp2.png)

## **2. Créer un secret client**

* Aller dans **Certificates & secrets** > **Client Secrets** > **New client secret**.
* Ajouter une description (ex. : "SMTP Secret") et sélectionner une période d'expiration (ex. : 24 mois).
* Cliquer sur**Add**, **puis copier immédiatement** la **valeur** du secret client. **Remarque** : **Cette valeur n'est affichée qu'une seule fois**, et vous ne pourrez pas la récupérer après avoir quitté cette page. Si vous la perdez, vous devrez en générer une nouvelle. Il s'agit de votre "**ClientSecret**".
* Conservez-la en lieu sûr, car elle donne accès à votre application

## **3. Configurer les autorisations API**

* Dans le menu de navigation de gauche de la page de présentation de votre application, cliquer sur **API permissions > +Add** une autorisation
* Sélectionner Microsoft Graph

![MS Smtp3](/images/ctrl-centre/administration/smtp-oauth2/MS-smtp3.png)

* Choisir les autorisations **Delegated > Rechercher** offline access

![MS Smpt4](/images/ctrl-centre/administration/smtp-oauth2/MS-smpt4.png)

* Ajouter l'autorisation **offline\_access**.

![MS Smtp5](/images/ctrl-centre/administration/smtp-oauth2/MS-smtp5.png)

* Rechercher l'autorisation **SMTP.Send** et ajouter également cette autorisation.

![MS Smtp6](/images/ctrl-centre/administration/smtp-oauth2/MS-smtp6.png)

## **5. Configuration dans PADS4**

Pour commencer :

* Ouvrir votre **navigateur web**.
* Accéder à l'**URL du serveur PADS4** (nom DNS ou adresse IP).
* Se connecter avec un **compte Administrateur**.

Une fois connecté :

* Cliquer sur **Dashboard**.
* Utiliser le bouton **Toggle Sidebar** en **haut à gauche** de l'écran.
* Accéder à **Credentials**.
* Puis sélectionner **Providers**.
* Cliquer sur **New**

![SMTP Oauth2white](/images/ctrl-centre/administration/smtp-oauth2/SMTP-Oauth2White.png)

* Sélectionner **SMTPOAuth2**

![MS Smtp7](/images/ctrl-centre/administration/smtp-oauth2/MS-smtp7.png)

* Remplir les informations comme suit :
  * **Nom de l'application :** Représente le nom de votre fournisseur dans PADS4 (peut être n'importe quelle valeur)
  * **Fournisseur SMTP :** Microsoft
  * **App (client) ID :** ID d'application provenant d'Azure/Entra ID décrit à la fin de l'étape 1
  * **Client Secret :** Récupéré depuis Azure/Entra ID décrit à la fin de l'étape 1
  * **Tenant ID :** ID de répertoire provenant d'Azure/Entra ID décrit à la fin de l'étape 1
* Cliquer sur **create**
* Aller maintenant sur la page de présentation et sélectionner le fournisseur SMTP que vous venez de configurer.
* Cliquer sur connect, choisir votre compte utilisateur et accorder l'accès demandé.

## Comment utiliser cette configuration dans la configuration SMTP.

Une fois connecté :

* Cliquer sur **Home**.
* Utiliser le **Basculer la barre latérale** bouton en haut à **gauche** de l'écran.
* Accéder à **Config**.
* Puis appuyer sur **Edit**

![Smtp Oauth](/images/ctrl-centre/administration/config/smtp-oauth.png)

* Activer **Use OAuth**
* Sélectionnez votre fournisseur OAuth et votre nom d'utilisateur que vous venez de configurer.
* Remplissez le reste des détails de votre serveur SMTP et de votre adresse
* Vous pouvez ensuite tester la connexion en bas à gauche, ce qui affichera une coche verte si la connexion est correctement configurée.

![Smtp Test Connection](/images/ctrl-centre/administration/config/smtp-test-connection.png)
