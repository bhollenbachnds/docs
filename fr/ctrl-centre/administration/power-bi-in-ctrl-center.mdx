Une fois l'enregistrement de l'application Azure et la configuration Power BI en place, finalisez l'intégration dans PADS4 CTRL Center. Vous enregistrerez l'application, puis générerez un jeton pour chaque rapport ou tableau de bord que vous souhaitez intégrer dans une présentation.

## Avant de commencer

Assurez-vous d'avoir complété :

* [Azure Set-up](/fr/ctrl-centre/administration/azure-set-up-1) — ID client, ID locataire et secret client.
* [PowerBI Services Admin Set-up](/fr/ctrl-centre/administration/power-bi-admin-set-up) — principal de service ajouté à l'espace de travail.
* [PowerBI Set-up](/fr/ctrl-centre/administration/power-bi-set-up) — ID de l'espace de travail et ID du rapport ou du tableau de bord.

## Étape 1 : Enregistrer l'application Power BI dans le gestionnaire d'informations d'identification

1. Connectez-vous à **PADS4 CTRL Center**.
2. Sous **Administration**, ouvrez **Credentials**.
3. Ouvrez l'onglet **Providers** et sélectionnez **New** > **Microsoft Power BI**.
4. Saisissez les valeurs collectées depuis Azure :
   * **App name** — un nom de référence affiché dans CTRL Center.
   * **Application (Client) ID**
   * **Directory (Tenant) ID**
   * **Client secret**
5. Enregistrez l'inscription.

<img height="200" src="/images/ctrl-centre/credentials/powerbi/PowerBIAppReg.png" alt="Registering the Power BI app in PADS4 Credential Manager" />

## Étape 2 : Connecter un rapport ou un tableau de bord

Pour chaque élément Power BI que vous souhaitez intégrer, générez un token à partir de l'application enregistrée.

1. Dans **Credential Manager**, accédez à **Overview**.
2. Trouvez l'enregistrement d'application que vous venez d'ajouter et sélectionnez **Connect**.
   <img height="200" src="/images/ctrl-centre/credentials/powerbi/PADS4PowerBIappOverview.png" alt="Credential Manager overview with the Connect action" />
3. Saisissez les détails de l'élément :

   * **Workspace ID**
   * **Type** — **Report** ou **Dashboard**.
   * **Report ID** ou **Dashboard ID**

   <img height="200" src="/images/ctrl-centre/credentials/powerbi/PowerBiRegScreen.png" alt="Registering a Power BI report or dashboard in CTRL Center" />
4. Sélectionnez **Create**.

PADS4 génère un **Token ID** pour le rapport ou le tableau de bord. Utilisez ce token dans les **éléments Web** de PADS4 pour intégrer l'élément dans une présentation.

<img height="200" src="/images/ctrl-centre/credentials/powerbi/PowerBIReference.png" alt="Generated Token ID for a Power BI item" />

<Tip>
  Générez un token distinct pour chaque rapport ou tableau de bord que vous souhaitez intégrer. Vous pouvez réutiliser le même enregistrement d'application pour autant d'éléments que nécessaire.
</Tip>
