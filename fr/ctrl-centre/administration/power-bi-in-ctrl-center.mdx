Une fois l'enregistrement de l'application Azure et la configuration Power BI en place, finalisez l'intégration dans PADS4 CTRL Center. Vous enregistrerez l'application, puis générerez un token pour chaque rapport ou tableau de bord que vous souhaitez intégrer dans une présentation.

## Avant de commencer

Assurez-vous d'avoir complété :

* [Configuration Azure](/fr/ctrl-centre/administration/azure-set-up-1) — client ID, tenant ID et client secret.
* [Configuration de l'administration des services PowerBI](/fr/ctrl-centre/administration/power-bi-admin-set-up) — principal de service ajouté à l'espace de travail.
* [Configuration PowerBI](/fr/ctrl-centre/administration/power-bi-set-up) — ID de l'espace de travail et ID du rapport ou du tableau de bord.

## Étape 1 : Enregistrer l'application Power BI dans le gestionnaire de Credentials

1. Connectez-vous à **PADS4 CTRL Center**.
2. Sous **Administration**, ouvrez **Credentials**.
3. Ouvrez l'onglet **Providers** et sélectionnez **New** > **Microsoft Power BI**.
4. Entrez les valeurs que vous avez collectées depuis Azure :
   * **Nom de l'application** — un nom de référence affiché dans CTRL Center.
   * **ID d'application (client)**
   * **ID de répertoire (locataire)**
   * **Secret client**
5. Enregistrez l'inscription.

<img height="200" src="/images/ctrl-centre/credentials/powerbi/PowerBIAppReg.png" alt="Registering the Power BI app in PADS4 Credential Manager" />

## Étape 2 : Connecter un rapport ou un tableau de bord

Pour chaque élément Power BI que vous souhaitez intégrer, générez un jeton à partir de l'application inscrite.

1. Dans **Credential Manager**, accédez à **Overview**.
2. Trouvez l'inscription d'application que vous venez d'ajouter et sélectionnez **Connect**.
   <img height="200" src="/images/ctrl-centre/credentials/powerbi/PADS4PowerBIappOverview.png" alt="Credential Manager overview with the Connect action" />
3. Entrez les détails de l'élément :

   * **ID d'espace de travail**
   * **Type** — **Rapport** ou **Tableau de bord**.
   * **ID de rapport** ou **ID de tableau de bord**

   <img height="200" src="/images/ctrl-centre/credentials/powerbi/PowerBiRegScreen.png" alt="Registering a Power BI report or dashboard in CTRL Center" />
4. Sélectionnez **Create**.

PADS4 génère un **ID de jeton** pour le rapport ou le tableau de bord. Utilisez ce jeton dans les éléments **Web** de PADS4 pour intégrer l'élément dans une présentation.

<img height="200" src="/images/ctrl-centre/credentials/powerbi/PowerBIReference.png" alt="Generated Token ID for a Power BI item" />

<Tip>
  Générez un jeton distinct pour chaque rapport ou tableau de bord que vous souhaitez intégrer. Vous pouvez réutiliser la même inscription d'application pour autant d'éléments que nécessaire.
</Tip>
