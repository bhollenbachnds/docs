PADS4 vous permet d'intégrer **des caméras, des logiciels de gestion de caméras et d'autres dispositifs capteurs** pour collecter et traiter des données en temps réel. Ces capteurs fournissent des capacités de **mesure d'audience**, **reconnaissance faciale**, **comptage de personnes** et **surveillance environnementale**.

Pour une liste de **capteurs certifiés**, consultez la **Page des capteurs certifiés**.

## **Aperçu**

La **Vue d'ensemble des capteurs** affiche tous les capteurs ajoutés. Un **point vert** indique que PADS4 a une **connexion active** au capteur.

### **Ajout d'un nouveau capteur**

Pour ajouter un nouveau capteur, suivez ces étapes :

1. **Accédez à la page Vue d'ensemble des capteurs** dans PADS4.
2. **Cliquez sur le bouton "Nouveau"** dans l'en-tête.
3. **Sélectionnez le type de capteur** – Caméra ou Logiciel de gestion de caméras.
4. **Spécifiez le modèle/type** de l'appareil.
5. **Ajoutez éventuellement une description et un emplacement** pour aider à identifier le capteur.
6. **Entrez les identifiants et le nom d'hôte** où se trouve le capteur.
7. **Enregistrez la configuration** – PADS4 tentera d'établir une connexion.

## **Regroupement des capteurs en zones**

Une **Zone** est un regroupement logique de capteurs. Cela permet une **collecte et analyse de données agrégées**.

### **Comptage de personnes**

* Si plusieurs **caméras de comptage de personnes** se trouvent dans une Area, leurs données sont **combinées**.
* Utile pour **suivre l'occupation totale** lorsqu'il y a plusieurs points d'entrée.

### **Créer une nouvelle area**

1. **Accédez à la page Areas** dans PADS4.
2. **Cliquez sur "New"** dans l'en-tête.
3. **Saisissez un nom d'Area** et (facultatif) une description.
4. **Sélectionnez les Sensors** qui appartiennent à cette area.
5. **Assignez des Rules** pour automatiser la détection des incidents.
6. **Enregistrez la configuration**.

## **Définir des règles d'incident**

Les Rules définissent **quelles conditions déclenchent un incident**, permettant des réponses automatisées.

### **Rules disponibles**

| **Rule**                 | **Description**                                                                                                                           |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **No Facemask**          | Détecte si une personne **ne porte pas de masque** et déclenche un incident.                                                              |
| **Maximum People Count** | Définit une **occupation maximale** pour une area. Si elle est dépassée, un incident est créé.                                            |
| **Maximum Temperature**  | Surveille la température corporelle. Si elle **dépasse un seuil défini** (par ex., 36,5°C), un incident est déclenché.                    |
| **Milestone Alarms**     | Utilise les **Milestone VMS** alarmes pour détecter des problèmes de sécurité ou de sûreté. Les alarmes peuvent déclencher des incidents. |

> **Note:** Le paramètre de température doit correspondre à l'unité configurée de la caméra (**Celsius ou Fahrenheit**).

## **Gérer les incidents**

Les incidents sont générés lorsque **des rules sont déclenchées**. Vous pouvez gérer les incidents dans le **PADS4 CTRL Center**.

Pour plus de détails, consultez la **page How to Use Incidents**.

## **Utiliser les données des sensors dans PADS4 Designer**

PADS4 Designer vous permet d'intégrer **des données de sensors** dans des présentations.

### **Options d'utilisation des données**

* **Événements de caméra en temps réel** pour des présentations interactives.
* **Données d'area agrégées** pour l'analyse d'audience.
* **Alertes d'incidents** affichées sur la signalétique pour une réponse immédiate.

## **Conclusion**

L'**intégration des sensors** de PADS4 permet **la surveillance en temps réel, des alertes automatisées basées sur des rules, et une signalétique numérique interactive**. En **configurant les sensors et en définissant des rules**, les entreprises peuvent améliorer **la sécurité, l'engagement de l'audience et l'efficacité opérationnelle**.
