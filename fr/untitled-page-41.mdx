## Aperçu

Contrôle les applications de visualisation PADS4 : commandes à distance (redémarrage, rechargement, capture d'écran), surveillance de l'état, récupération des journaux, gestion des mises à jour logicielles et configuration du visualiseur. Le service principal pour gérer ce qui s'exécute sur le matériel d'affichage.

| Champ                                 | Valeur                                                                  |
| ------------------------------------- | ----------------------------------------------------------------------- |
| Swagger UI                            | `https://<your-server>/rdx/NDS.Services.Viewer/swagger/index.html`      |
| OpenAPI spec                          | `https://<your-server>/rdx/NDS.Services.Viewer/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.Viewer`                         |
| Nombre total de points de terminaison | 65                                                                      |

***

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin de service indiqué ci-dessus.
