## Aperçu

Capture des pages web sous forme d'images ou de captures d'écran pour une utilisation en tant que contenu PADS4. Prend en charge les tailles de fenêtre d'affichage personnalisées, les conditions d'attente et l'injection CSS pour des captures web-vers-image personnalisées.

| Spécification OpenAPI                 | `https://<your-server>/rdx/NDS.Services.Web.ToImage/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.Web.ToImage`                         |
| Nombre total de points de terminaison | 15                                                                           |

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin du service indiqué ci-dessus.
