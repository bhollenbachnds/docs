### Installation des applications client PADS4

Ce guide explique comment installer les applications client PADS4 sur Windows, notamment PADS4 Viewer, Designer, Scheduler et d'autres outils.

#### Étape 1 : Télécharger le programme d'installation

Téléchargez le dernier programme d'installation du client PADS4 depuis la page de téléchargement officielle :<br />[Télécharger les clients PADS4](http://go.pads4.com/?fwlink=1011)

#### Étape 2 : Exécuter le programme d'installation

1. **Démarrer le programme d'installation en tant qu'administrateur**
   * Localiser le fichier **PADS4 Clients.exe** téléchargé.
   * Faire un clic droit dessus et sélectionner **Run as administrator**.
   * Choisir votre langue et continuer.
2. **Vérifier la version**
   * Assurez-vous d'installer PADS4 version 2026.1 ou ultérieure.
3. **Accepter le contrat de licence**
   * Lire le contrat de licence.
   * Cocher la case pour accepter les conditions, puis cliquer sur **Next**.

#### Étape 3 : Choisir pour qui installer

* Choisir d'installer les clients PADS4 pour tous les utilisateurs de cet ordinateur ou uniquement pour l'utilisateur actuel.
* Cliquer sur **Next**.

#### Étape 4 : Sélectionner l'installation du Viewer

* Dans le menu déroulant, sélectionner **Viewer Installation**.
* Cliquer sur **Next**.

#### Étape 5 : Installer la documentation d'aide (facultatif)

* Choisir d'installer ou non le fichier d'aide en ligne.
* Une fois le fichier d'aide installé, vous pouvez appuyer sur **F1** dans n'importe quelle application PADS4 pour ouvrir la documentation correspondante.
* Nous recommandons de l'installer afin que les guides utilisateur soient toujours à portée de main.

#### Étape 6 : Configurer le Viewer

* Saisir un **nom de Viewer** et spécifier l'**emplacement du serveur PADS4**.
* Cliquer sur **Next**.

#### Étape 7 : Configurer le mode Bureau et le Contrôle de compte d'utilisateur (UAC)

* **Mode Bureau :** Choisissez si les clients PADS4 doivent s'exécuter en mode Desktop.
* **Contrôle de compte d'utilisateur (UAC) :**
  * Nous recommandons de désactiver l'UAC afin que les clients PADS4 puissent s'exécuter avec des privilèges d'administrateur sans invites supplémentaires.
  * Si l'utilisateur n'est pas membre du groupe Administrateurs local, vous pouvez spécifier un compte administrateur pour exécuter le Viewer.

#### Étape 8 : Choisir les raccourcis et le dossier d'installation

* Sélectionnez les raccourcis que vous souhaitez créer.
* Choisissez le dossier dans lequel vous souhaitez installer les clients PADS4.
* Cliquez sur **Install** pour démarrer l'installation.

#### Étape 9 : Terminer l'installation

* Patientez pendant que le programme d'installation installe les clients PADS4.
* Une fois l'installation terminée, le message suivant s'affiche : *"PADS4 Clients has been successfully installed."*
