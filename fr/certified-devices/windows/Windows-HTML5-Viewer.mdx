Le Windows HTML5 Viewer offre plusieurs avantages par rapport au Windows Viewer hérité :

* Prend en charge la fonctionnalité de répétition synchronisée
* Permet les changements d'orientation sans modifier les paramètres Windows
* Offre une expérience cohérente sur tous les viewers HTML
* Peut être utilisé comme économiseur d'écran
* Prise en charge facilitée des nouvelles fonctionnalités
* Performances améliorées
* Sécurité renforcée via le mode Kiosk
* Mises à jour automatiques depuis le serveur PADS4 (aucune mise à jour manuelle requise)

<Note>
  Ce viewer partage les mêmes limitations que les autres viewers HTML. Pour plus d'informations, voir [Limitations connues du HTML5 Viewer](https://support.pads4.com/en/support/solutions/articles/204000036395-known-limitations-for-html5-viewer).
</Note>

## Avant de commencer

### Configuration minimale requise

| Exigence     | Minimum                                     |
| ------------ | ------------------------------------------- |
| Windows      | Windows 10 build 1909 ou version ultérieure |
| PADS4 Server | PADS4 2025.1 ou version ultérieure          |

<Warning>
  L'**Switch User** option dans les paramètres du Launcher nécessite PADS4 Windows HTML viewer version 1.4.0 et PADS4 version 2025.2. Cette option vous permet de changer de compte utilisateur lorsque vous utilisez le mode Kiosk de Windows.
</Warning>

### Autres prérequis

* Le package d'installation. Téléchargez-le depuis [GitHub](https://github.com/PADS4/PADS4-Viewer-Windows/releases).

## Installer PADS4 Viewer

1. Exécuter `PADS4WindowsHTMLviewer.exe` en tant que **Administrateur**.
2. Sélectionnez le répertoire d'installation ou utilisez celui par défaut.
3. (Facultatif) Décochez **Configure Windows to launch the PADS4 HTML5 Viewer in Kiosk Mode** si l'une de ces conditions s'applique :
   * Vous souhaitez utiliser le Viewer comme économiseur d'écran.
   * Vous souhaitez exécuter le Viewer sous un utilisateur Windows standard.
4. Acceptez le Contrat de licence, puis sélectionnez **Install**.

<img height="200" src="/images/install-pads4/install-pads4-viewer/intall-pads4-html5-windows-viewer/installer.png" />

<img height="200" src="/images/install-pads4/install-pads4-viewer/intall-pads4-html5-windows-viewer/installer-progress.png" />

5. Une fois l'installation terminée, sélectionnez **Reboot** pour redémarrer la machine.

<img height="200" src="/images/install-pads4/install-pads4-viewer/intall-pads4-html5-windows-viewer/installation-succesful.png" />

## Connecter le Viewer au PADS4 Server

Après le redémarrage, le Viewer démarre en mode Kiosk.

1. Entrez votre **PADS4 Server Address** et **Viewer Name**.

<img height="200" src="/images/install-pads4/install-pads4-viewer/intall-pads4-html5-windows-viewer/server-config.png" />

2. Sélectionnez **Start** pour connecter le Viewer.

<img height="200" src="/images/install-pads4/install-pads4-viewer/intall-pads4-html5-windows-viewer/viewer-started.png" />

Pour ouvrir les paramètres du Viewer ou revenir aux paramètres du Launcher, faites un clic droit n'importe où sur l'écran.

<img height="200" src="/images/install-pads4/install-pads4-viewer/intall-pads4-html5-windows-viewer/viewer-settings.png" />

## Passer à un compte utilisateur standard

Vous pouvez quitter le mode Kiosk et passer à un compte Windows standard de trois façons :

* Dans PADS4 2025.2 et versions ultérieures, ouvrez les **Viewer settings**, accédez à **Launcher settings**, puis sélectionnez **Switch User** dans le coin inférieur droit.
* Utilisez **Remote Desktop**, si configuré, pour vous connecter avec un autre compte utilisateur.
* Maintenez la touche **Shift** enfoncée pendant le redémarrage de la machine. L'écran de connexion Windows s'ouvre.

## Utiliser le Viewer comme économiseur d'écran

1. Lors de l'installation, assurez-vous que le mode Kiosk est **désactivé**.
2. Ouvrez **Screensaver Settings** dans Windows.
3. Sélectionnez **Pads4viewer** comme économiseur d'écran.

<img height="200" src="/images/install-pads4/install-pads4-viewer/intall-pads4-html5-windows-viewer/screensaver.png" />

4. Sélectionnez **Apply**, puis sélectionnez **OK**.

Le Viewer démarre désormais en fonction du minuteur d'économiseur d'écran configuré.

## Référence du script du mode Kiosk

Pour examiner la configuration du mode Kiosk du système, consultez ce script PowerShell :

```plaintext
C:\Program Files\PADS4\Launcher Service\configure-kioskmode
```

## Fonctionnalités prises en charge et limitations

| Fonctionnalité                                           | Support | Notes                                                            |
| -------------------------------------------------------- | ------- | ---------------------------------------------------------------- |
| Mises à jour automatiques du Viewer                      | Oui     | Se met à jour automatiquement depuis le PADS4 Server.            |
| Mode hors ligne                                          | Oui     | Exécute des présentations jusqu'à 7 jours sans connexion réseau. |
| HTTP et HTTPS                                            | Oui     |                                                                  |
| Vidéos sur une page                                      | Oui     | Maximum de 4 vidéos sur une page.                                |
| Rotation vidéo, vidéos sans interruption et retournement | Non     |                                                                  |
| Streaming vidéo                                          | Oui     | Streaming via HTTP et HTTPS.                                     |
| Cluster Viewer                                           | Oui     |                                                                  |
| Éléments interactifs                                     | Oui     | Boutons, texte, texte défilant, images et tableaux.              |
| PowerPoint et PDF                                        | Oui     | PowerPoint doit être installé sur le PADS4 Server.               |
| Gestion des appareils à distance                         | Oui     | Géré avec PADS4 Agent.                                           |
| Wake-on-LAN                                              | Oui     | Vous pouvez allumer des appareils à distance.                    |
| Éteindre l'écran                                         | Non     |                                                                  |
