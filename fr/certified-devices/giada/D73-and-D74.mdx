Le Giada DN73 est un lecteur de signalétique qui fonctionne sous Android 7.1 et Android 10. Vous installez l'application PADS4Giada sur le lecteur pour afficher les présentations PADS4. Cette page explique comment préparer le lecteur, installer l'application et le connecter à votre serveur PADS4.

## Avant de commencer

### Appareils pris en charge

* Giada DN73 (Android 10)
* Giada DN73 (Android 7.1)

### Configuration minimale requise

| Exigence               | Minimum                            |
| ---------------------- | ---------------------------------- |
| Serveur PADS4          | PADS4 2022.1 ou version ultérieure |
| Application PADS4Giada | PADS4Giada 1.0                     |
| Version Android        | Android 10 <br />Android 7.1       |

### Autres prérequis

* Un serveur PADS4 installé et en cours d'exécution.
* Une clé USB. Vous l'utilisez pour installer l'application.
* Accès réseau du lecteur au serveur PADS4.

### Ouvrir le menu Android

<Warning>
  Si vous ouvrez le menu Android pendant que PADS4Giada est en cours d'exécution, le lecteur redémarre après 30 secondes. Le Viewer Monitor Service détecte que l'application n'est pas active. Pour éviter cela, arrêtez l'application PADS4Giada dans les 30 secondes.
</Warning>

## Préparer l'appareil

### Réinitialiser l'appareil

Réinitialisez le lecteur s'il a déjà été utilisé. Cela efface le stockage et évite les conflits logiciels.

<Warning>
  Une réinitialisation d'usine supprime toutes les données et paramètres du lecteur.
</Warning>

1. Ouvrez les paramètres Android.
2. Sélectionnez **Backup & Reset**.
3. Sélectionnez **Factory Data Reset**.
4. Sélectionnez **Reset Tablet**.
5. Sélectionnez **Erase Everything**.

### Activer l'accès superutilisateur par défaut

L'accès superutilisateur est nécessaire pour les mises à jour automatiques de l'application PADS4Giada. Sans cela, vous devez mettre à jour l'application manuellement.

1. Ouvrez l'application **SuperSU**.
2. Accédez à **Settings**.
3. Sélectionnez **Default Access**.
4. Dans la boîte de dialogue, sélectionnez **Grant**.
5. Fermez l'application.

### Réinitialiser l'orientation de l'écran

Cette étape est facultative.

1. Dans les paramètres Android, accédez à **Display** > **HDMI** > **Screen Rotation**.
2. Sélectionnez **0**.

### Vérifier la date et l'heure

Une date et une heure correctes évitent les erreurs de certificat et les problèmes de connexion.

1. Ouvrez l'application PADS4Giada.
2. Sélectionnez **System Settings**. Les paramètres Android s'ouvrent.
3. Accédez à **Date & Time**.
4. Définissez la date et l'heure correctes.
5. (Facultatif) Activez **Auto Sync Date & Time**, si votre réseau le prend en charge.

## Installer PADS4 Viewer

Installez le fichier `PADS4Giada.apk` depuis une clé USB. Vous trouverez le fichier sur votre serveur PADS4 dans `http(s)://<server>/<domain>/apps`.

Vous pouvez également télécharger la dernière version depuis [GitHub](https://github.com/PADS4/PADS4-Viewer-Giada/releases/latest). Si vous téléchargez le fichier, copiez-le également dans le dossier `Apps` sur le serveur PADS4, afin que la version correcte soit installée.

1. Copiez `PADS4Giada.apk` sur une clé USB.
2. Insérez la clé USB dans le lecteur.
3. Ouvrez l'application **File Explorer**.
4. Sélectionnez **USB Storage**.
5. Sélectionnez le fichier APK.
6. Si un avertissement de sécurité apparaît, sélectionnez **Settings**.
7. Activez **Unknown Sources**, puis sélectionnez **OK**.
8. Revenez à **File Explorer**, et sélectionnez à nouveau le fichier APK.
9. Dans la boîte de dialogue de confirmation, sélectionnez **Install**.
10. Une fois l'installation terminée, sélectionnez **Open** pour démarrer l'application PADS4Giada.

## Connecter le Viewer au serveur PADS4

L'emplacement du serveur a ce format : `http(s)://<server>/<domain>`. Remplacez `<server>` par l'adresse IP ou le nom d'hôte de votre serveur PADS4. Remplacez `<domain>` par votre domaine PADS4. Le domaine par défaut est `PADS4`.

1. Entrez l'emplacement du serveur PADS4.
2. (Facultatif) Entrez un nom pour le Viewer. Si vous laissez le champ vide, le serveur PADS4 génère un nom.
3. Sélectionnez **Start**.

<Check>
  Le Viewer affiche une LED verte et le nom du Viewer. Cela signifie que la connexion fonctionne.
</Check>

## Mettre à jour PADS4 Viewer

PADS4 Viewer et l'application PADS4Giada se mettent à jour automatiquement lorsque le serveur PADS4 se met à jour.
