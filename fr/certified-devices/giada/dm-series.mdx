Les players Giada DM Series fonctionnent sous Windows 10 ou Windows 11. Vous exécutez PADS4 Viewer sur le player pour afficher les présentations PADS4. Cette page répertorie les appareils pris en charge et renvoie vers les étapes d'installation.

## Avant de commencer

### Appareils pris en charge

* Giada DM Series

### Configuration minimale requise

| Exigence     | Minimum                            |
| ------------ | ---------------------------------- |
| PADS4 Server | PADS4 2022.1 ou version ultérieure |
| Windows      | Windows 10 ou Windows 11           |

### Autres prérequis

* Un compte avec des droits d'administrateur.
* Accès réseau depuis le player vers le PADS4 Server.

## Installer PADS4 Viewer

Installez PADS4 Viewer en suivant la procédure d'installation Windows standard. Pour les étapes, consultez [Windows Viewer](/fr/certified-devices/windows/Windows-Viewer) ou [Windows HTML5 Viewer](/fr/certified-devices/windows/Windows-HTML5-Viewer).
