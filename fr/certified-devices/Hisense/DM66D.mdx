Ce guide fournit des instructions étape par étape pour installer et configurer le PADS4 Web Launcher sur les écrans Android Hisense DM66D. Il couvre la configuration initiale, l'installation de l'APK, la configuration du démarrage automatique et la configuration du viewer.

## Compatibilité

* Appareils pris en charge : Hisense DM66D (Android 11)

<Note>
  La prise en charge du Hisense DM66D a été ajoutée à notre solution PADS4 Generic Launcher dans **PADS4 version 2025.2**, veuillez vous référer au manuel PADS4 Generic Android Viewer pour de plus amples instructions.
</Note>

### Exigences minimales

Version PADS4 requise : **2025.2**

## Prérequis

* Téléchargez le dernier PADS4WebLauncher.apk depuis votre serveur PADS4 (par ex., https\://\[your-server]/\[domain]/apps) ou depuis [ici](https://github.com/PADS4/PADS4-Viewer-Android/releases/tag/v1.3), et copiez-le sur une clé USB.
* Assurez-vous que le PADS4 Server est configuré et accessible.

### Installation de PADS4 Viewer

1. Allumez l'écran.
2. Accédez au menu des applications et sélectionnez **More Apps**
3. Insérez la clé USB dans l'écran.
4. Sélectionnez **File Browser**.
5. Naviguez vers le lecteur USB et sélectionnez **PADS4WebLauncher.apk**.
6. Cliquez sur **Install** et attendre la fin.
7. Une fois l'installation terminée, sélectionner **Annuler**
8. **Quitter** le navigateur de fichiers

## **Activation du démarrage automatique**

1. Aller à **Paramètres** à l'écran.
2. Naviguer vers **Signal Management**
3. Sélectionner **Homepage setting**.
4. Sélectionner **PADS4 Web Launcher** dans la liste.
5. Cliquer sur **Retour** pour fermer le Paramètre

## **Configuration de la connexion**

1. Lancer le PADS4 Web Launcher.
2. Saisir l' **URL du serveur** au format `<protocol>://<host>:<port>/<hostpath>/`
3. Remplir le **ViewerName** selon les besoins.
4. Cliquer sur **Démarrer** pour se connecter.

Le viewer PADS4 est maintenant connecté et prêt à l'emploi.
