---
- title: Hisense DM66GE
---

Ce guide fournit des instructions étape par étape pour installer et configurer le PADS4 Web Launcher sur les écrans Android Hisense DM66GE. Il couvre la configuration initiale, l'installation de l'APK, la configuration du démarrage automatique et la configuration du viewer.

### Appareils compatibles :

* **DM66GE (Android 14)**

<Note>
  La prise en charge du Hisense DM66GE a été ajoutée à notre solution PADS4 Generic Launcher dans **PADS4 version 2025.2**, veuillez vous référer au manuel PADS4 Generic Android Viewer pour de plus amples instructions.
</Note>

### Configuration minimale requise

Version PADS4 requise : **2025.2**

Firmware de l'appareil : **V01.00.01F.Q0302**

## Prérequis

* Téléchargez le dernier PADS4WebLauncher.apk depuis votre serveur PADS4 (par ex., https\://\[your-server]/\[domain]/apps) ou depuis [ici](https://github.com/PADS4/PADS4-Viewer-Android/releases/tag/v1.3), et copiez-le sur une clé USB.
* Assurez-vous que le serveur PADS4 est configuré et accessible.

### Installation du PADS4 Viewer

1. Allumez l'écran.
2. Accédez au menu des applications et sélectionnez **More Apps**
3. Insérez la clé USB dans l'écran.
4. Sélectionnez **File Browser**.
5. Naviguez jusqu'au lecteur USB et sélectionnez **PADS4WebLauncher.apk**.
6. Cliquez sur **Install** et attendez la fin de l'installation.
7. Une fois l'installation terminée, sélectionnez **Cancel**
8. **Exit** le navigateur de fichiers

## **Activation du démarrage automatique**

1. Accédez aux **Settings** de l'écran.
2. Naviguez vers **Signal Management**
3. Sélectionnez **Homepage setting**.
4. Sélectionnez **PADS4 Web Launcher** dans la liste.
5. Cliquez sur **Back** pour fermer les paramètres

## **Configuration de la connexion**

1. Lancez le PADS4 Web Launcher.
2. Entrez l' **Server URL** au format `<protocol>://<host>:<port>/<hostpath>/`
3. Renseignez le **ViewerName** selon les besoins.
4. Cliquez sur **Start** pour vous connecter.

Le PADS4 viewer est maintenant connecté et prêt à l'emploi.
