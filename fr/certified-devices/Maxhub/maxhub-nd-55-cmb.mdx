- title: Maxhub ND55CMB
---

Ce guide fournit des instructions étape par étape pour installer et configurer le PADS4 Web Launcher sur les écrans Android Maxhub ND55CMD. Il couvre la configuration initiale, l'installation de l'APK, la configuration du démarrage automatique et la configuration du viewer.

### Appareils compatibles :

* **Maxhub ND55CMB (Android 14)**

<Note>
  La prise en charge du Maxhub ND55CMB a été ajoutée à notre solution PADS4 Generic Launcher dans **PADS4 version 2026.1**, veuillez vous référer au manuel PADS4 Generic Android Viewer pour plus d'instructions.
</Note>

### Configuration minimale requise

Version PADS4 requise : **2025.2**

Firmware de l'appareil : 2026-06-09

## Prérequis

* Téléchargez le dernier PADS4WebLauncher.apk depuis votre serveur PADS4 (par ex., https\://\[your-server]/\[domain]/apps) ou depuis [ici](https://github.com/PADS4/PADS4-Viewer-Android/releases/tag/v1.3), et copiez-le sur une clé USB.
* Assurez-vous que le serveur PADS4 est configuré et accessible.

### Installation du PADS4 Viewer

1. Allumez l'écran.
2. Accédez à **All Apps**
3. Insérez la clé USB dans l'écran.
4. Sélectionnez **Finder**.
5. Naviguez jusqu'au lecteur USB et sélectionnez **PADS4WebLauncher.apk**.
6. Cliquez sur **Install** et attendez la fin de l'installation.
7. Une fois l'installation terminée, sélectionnez **Done**
8. **Exit** le navigateur de fichiers

## **Activation du démarrage automatique**

1. Ouvrez **Settings** sur l'écran.
2. Allez dans **Applications**.
3. Sélectionnez **PADS4 Web Launcher**.
4. Sélectionnez **Home app**.
5. Choisissez **PADS4 Web Launcher** dans la liste des applications disponibles.
6. Retournez au menu principal **Settings** et allez dans **System**.
7. Sélectionnez **Startup & Shutdown**.
8. Sélectionnez **Startup Channel Android**.
9. Définissez le **Default startup item** sur **PADS4 Web Launcher**.
10. Activez **Auto startup**.
11. Appuyez sur **Back** pour quitter les paramètres.

## **Configuration de la connexion**

1. Lancez le PADS4 Web Launcher.
2. Entrez l' **Server URL** au format `<protocol>://<host>:<port>/<hostpath>/`
3. Renseignez le **ViewerName** selon les besoins.
4. Cliquez sur **Start** pour vous connecter.

Le viewer PADS4 est maintenant connecté et prêt à l'emploi.
