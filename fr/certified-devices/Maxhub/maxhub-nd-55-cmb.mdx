---
- title: Maxhub ND55CMB
---

Ce guide fournit des instructions étape par étape pour installer et configurer le PADS4 Web Launcher sur des écrans Android Maxhub ND55CMD. Il couvre la configuration initiale, l'installation de l'APK, la configuration du démarrage automatique et la configuration du viewer.

### Appareils compatibles :

* **Maxhub ND55CMB (Android 14)**

<Note>
  La prise en charge du Maxhub ND55CMB a été ajoutée à notre solution PADS4 Generic Launcher dans **PADS4 version 2025.2**, veuillez vous référer au manuel PADS4 Generic Android Viewer pour de plus amples instructions.
</Note>

### Exigences minimales

Version PADS4 requise : **2025.2**

Firmware de l'appareil : 2026-06-09

## Prérequis

* Téléchargez le dernier PADS4WebLauncher.apk depuis votre serveur PADS4 (par ex., https\://\[your-server]/\[domain]/apps) ou depuis [ici](https://github.com/PADS4/PADS4-Viewer-Android/releases/tag/v1.3), et copiez-le sur une clé USB.
* Assurez-vous que le serveur PADS4 est configuré et accessible.

### Installation de PADS4 Viewer

1. Allumez l'écran.
2. Accéder à **All Apps**
3. Insérez la clé USB dans l'écran.
4. Sélectionner **Finder**.
5. Accédez au lecteur USB et sélectionnez **PADS4WebLauncher.apk**.
6. Cliquez sur **Install** et attendez la fin de l'opération.
7. Une fois l'installation terminée, sélectionnez **Done**
8. **Exit** le navigateur de fichiers

## **Activation du démarrage automatique**

1. Aller dans **Settings** sur l'écran.
2. Accéder à **Application**
3. **Sélectionner PADS4 Web Laucher**
4. Sélectionner **Home App**
5. Sélectionner **PADS4 Web Launcher** dans la liste.
6. Cliquer sur **Back** pour fermer les paramètres

## **Configuration de la connexion**

1. Lancez le PADS4 Web Launcher.
2. Entrez l' **URL du serveur** au format `<protocol>://<host>:<port>/<hostpath>/`
3. Renseignez le **ViewerName** selon les besoins.
4. Cliquez sur **Start** pour vous connecter.

Le viewer PADS4 est maintenant connecté et prêt à l'emploi.
