Ce guide fournit **des instructions étape par étape** pour installer et configurer **PADS4 Viewer** sur **Sony BZxx Series Displays**.

## **Modèles Sony BZxx pris en charge**

Les **Sony BZxx Series** affichages suivants sont pris en charge :

* **xxBZ35P (Android 14)**

**Assurez-vous que votre serveur PADS4 est installé et configuré avant de continuer.**

## **Configuration minimale requise**

Version du serveur PADS4 : 2026.1 ou ultérieure<br />Version du firmware : 4.250422

**Assurez-vous que le firmware de votre appareil répond à la configuration minimale requise avant de procéder à l'installation.**

## **Configuration initiale**

**Avant d'installer PADS4, vous devez vérifier la version du firmware.**

**Comment vérifier la version actuelle du firmware :**<br />1️. **Aller à** `Settings -> About -> Android TV OS Build`<br />2️. **Vérifiez le numéro de version avant « release keys »**<br />3️. **Si une connexion Internet est disponible**, recherchez les mises à jour du firmware sous `About`<br />4️. **Si aucune connexion Internet n'est disponible**, téléchargez le dernier firmware depuis **la page firmware de Sony**

## **Installation de PADS4Sony depuis une clé USB**

**Vous allez installer PADS4Sony depuis une clé USB.**

**Étapes pour installer PADS4Sony :**

1. Téléchargez le **PADS4Sony** `.pkg` fichier depuis la [page des versions PADS4 sur GitHub](https://github.com/PADS4/PADS4-Viewer-Sony/releases/latest).
2. Copiez le `.pkg` fichier sur une clé USB, puis insérez la clé dans l'écran Sony.
3. Effectuez une réinitialisation d'usine sur l'écran :
   * Allez dans **Settings > System > About > Reset > Factory data reset**.
   * Sélectionnez **Erase everything**.
     Ignorez cette étape lors de la configuration d'un nouvel écran.
4. L'écran démarrera le processus de réinitialisation d'usine dans environ 15 secondes, puis redémarrera.
5. Lorsque l'écran de configuration initiale apparaît, affichant la page de sélection de la langue, **ne commencez pas le processus de configuration**.
6. L'écran devrait détecter automatiquement le `.pkg` fichier sur la clé USB et afficher l'écran d'installation du package.
7. Sélectionnez **Install** et suivez les instructions à l'écran.
8. Une fois l'installation terminée, l'écran ouvre l'écran d'activation.
9. Faites défiler jusqu'en bas de l'écran et sélectionnez **Activate this device admin app**.
10. Lorsque le message **"Install is complete"** apparaît, retirez la clé USB et sélectionnez **OK**.
11. L'écran revient à l'écran de configuration initiale. Terminez la configuration, mais ignorez l'étape de connexion au compte Google.

**Autorisez toutes les demandes de permission pendant ou avant l'installation.**

## **Connexion au serveur PADS4**

Vous devez configurer l'URL du serveur PADS4 pour établir une connexion.

Format de l'URL du serveur PADS4 :

```text
<protocol>://<host>:<port>/<hostpath>/
```

**Protocol:** `http` ou `https` (selon le certificat SSL)<br />**Host:** `DNS name` ou `IP address` du serveur PADS4<br />**Port:** **Optionnel** (à utiliser uniquement si le serveur PADS4 n'est pas sur les ports HTTP/HTTPS par défaut)<br />**Hostpath par défaut :** `PADS4`

### **Étapes pour se connecter au serveur PADS4**

1. Saisissez le **PADS4 Server Location**.
2. Optionnellement, saisissez un **Viewer Name**. Si ce champ est laissé vide, le serveur PADS4 générera automatiquement un nom pour le Viewer.
3. Sélectionnez **Start**.
4. Attendez que le téléchargement du Viewer se termine. Le PADS4 Viewer démarrera automatiquement une fois le téléchargement terminé.
5. Lorsque vous y êtes invité, accordez la permission de stocker définitivement du contenu sur l'appareil.

**Le PADS4 Viewer va maintenant démarrer et se connecter au serveur PADS4.**

## **Ajustement des paramètres du PADS4 Viewer**

**Vous pouvez ajuster les paramètres du PADS4 Viewer directement sur l'écran.**

**Étapes pour accéder aux paramètres :**<br />1️. **Connectez une souris à l'appareil.**<br />2️. **Faites un clic droit avec la souris** pour ouvrir le **menu Viewer Settings**.<br />3️. **Effectuez des ajustements** concernant l'orientation de l'écran, les paramètres d'affichage, etc.

**Vous pouvez également revenir à la configuration PADS4Sony en cliquant sur le bouton « Launcher Settings ».**

## **Mise à jour de l'application PADS4Sony**

**L'application PADS4Sony se met à jour automatiquement lorsque le serveur PADS4 est mis à jour.**

**Comment mettre à jour manuellement l'application :**<br />1️. **Vérifiez la version du serveur PADS4.**<br />2️. **Si une nouvelle version est disponible, redémarrez l'écran Sony.**<br />3️. **L'application PADS4Sony se mettra à jour automatiquement.**

## **Accès au menu Android pendant que PADS4 est en cours d'exécution**

**Pour accéder aux paramètres rapides :**

1️⃣. **Appuyez sur le bouton « Options »** de la télécommande.<br />2️. Ajustez divers **paramètres rapides** depuis ce menu.

**Pour accéder au menu des paramètres complets :**<br />1️. **Appuyez sur le bouton « Home »** de la télécommande.<br />2️. L'**application PADS4 se fermera**.<br />3️. **Pour redémarrer PADS4, allez dans** : `Settings -> System -> Restart`.

**L'application PADS4 démarrera maintenant automatiquement.**
