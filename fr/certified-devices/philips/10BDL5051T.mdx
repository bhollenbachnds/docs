Ce guide fournit des instructions étape par étape pour **installer et configurer le PADS4 Viewer** sur **les écrans Philips T-line (10BDL5051T)**.

## **1. Première utilisation**

Avant l'installation, s'assurer que le **PADS4 Server est configuré et paramétré correctement**.

📌 **Version minimale requise du PADS4 Server :** **PADS4 Foundation 2026.1**

Lors de la première mise en marche de l'appareil, l'**Assistant de configuration** apparaîtra. Si ce n'est pas le cas, **réinitialiser l'appareil** comme décrit dans **1.2 Réinitialisation de l'appareil**.

***

### **1.1 Configuration de l'appareil**

<Steps>
  <Step title="Étape Un">
    Sur l'**Écran d'accueil**, sélectionner la **langue** préférée et cliquer sur **Start**.
  </Step>

  <Step title="Étape Deux">
    Sur l'écran **Security Settings**, s'assurer que le **SICP Network Port** est **activé**. *(Les autres paramètres peuvent être activés ou désactivés selon les besoins.)*
  </Step>

  <Step title="Étape Trois">
    Sur l'écran **Signage Display Settings**, appuyer sur **Skip**.
  </Step>

  <Step title="Étape Quatre">
    Sur l'écran **Network Settings**, sélectionner et configurer le **type de réseau**.
  </Step>

  <Step title="Étape Cinq">
    Sur l'écran **Clone Media Files**, appuyer sur **Skip**.
  </Step>

  <Step title="Étape Six">
    Appuyer sur **Finish** pour terminer la configuration.
  </Step>
</Steps>

L'appareil affichera **Philips Media Player App**.

***

### **1.2 Réinitialisation de l'appareil**

Si l'appareil a déjà été utilisé, effectuer une **réinitialisation d'usine** pour effacer le stockage et éviter les conflits logiciels.

<Steps>
  <Step title="Étape Un">
    Ouvrir le **Menu Android** en appuyant sur **Home** puis sur le bouton **Volume Down** situé derrière l'**écran**.
  </Step>

  <Step title="Étape Deux">
    Saisir le **Mot de passe administrateur** *(Par défaut : 1234)*.
  </Step>

  <Step title="Étape Trois">
    Ouvrir **Settings**.
  </Step>

  <Step title="Étape Quatre">
    Sélectionner **Signage Display → System Tools → Factory Reset**.
  </Step>

  <Step title="Étape Cinq">
    Cliquer sur **Factory Reset** et confirmer en appuyant sur **OK**.
  </Step>
</Steps>

Après la réinitialisation, l'**Écran d'accueil** apparaîtra. Suivre les étapes de **1.1 Configuration de l'appareil**.

***

## **2. Installation du PADS4 Viewer**

Suivre ces étapes pour installer le **PADS4 Viewer** sur **Philips T-line (10BDL5051T)**.

***

### **2.1 Vérification du Firmware de l'Appareil**

Assurez-vous que la **version correcte du firmware** est installée pour une **PADS4 Viewer** fonctionnalité complète.

<Steps>
  <Step title="Étape Un">
    Ouvrez le **Android Menu** en appuyant sur **Home + Volume Down**.
  </Step>

  <Step title="Étape Deux">
    Entrez le **Mot de Passe Administrateur** *(Par défaut : 1234)*.
  </Step>

  <Step title="Étape Trois">
    Ouvrez **Paramètres**.
  </Step>

  <Step title="Étape Quatre">
    Sélectionnez **À propos**.
  </Step>

  <Step title="Étape Cinq">
    Assurez-vous que le **Numéro de Build** est **FB01.14T** *(requis pour PADS4)*.
  </Step>
</Steps>

***

### **2.2 Mise à Jour du Firmware de l'Appareil**

Pour mettre à jour le **firmware**, suivez les **instructions Philips**:

📌 **Guide de mise à jour du firmware :** [Télécharger les Instructions du Firmware](https://www.dropbox.com/scl/fi/43ae7dpth1vp0vzb6urts/firmware-10BDL5051T-FB01.14.pdf?rlkey=0ehbdfymts22nbgty81nb9417\&st=sjcxb4we\&dl=0)<br />📌 **Centre de Téléchargement Philips :** [Centre de Téléchargement](https://www.dropbox.com/s/fje9ge0ao8at6rq/One_Link.xlsm?dl=0)

***

### **2.3 Installation de PADS4Philips depuis une Clé USB**

Le **PADS4Philips.apk** fichier se trouve sur le **PADS4 Server** in:

```text
C:\Program Files\PADS4\Foundation\Apps
```

Vous pouvez également télécharger la dernière version depuis [**ce lien**](http://go.pads4.com/?fwlink=1006) et le placer dans le **répertoire apps sur le PADS4 Server**.

#### **Étapes d'Installation**

<Steps>
  <Step title="Étape Un">
    Copiez le **PADS4Philips.apk** fichier sur une **clé USB**.
  </Step>

  <Step title="Étape Deux">
    Insérez la **clé USB** dans le **Philips T-line**.
  </Step>

  <Step title="Étape Trois">
    Ouvrez le **Android Menu** en appuyant sur **Home + Volume Down**.
  </Step>

  <Step title="Étape Quatre">
    Entrez le **Mot de Passe Administrateur** *(Par défaut : 1234)*.
  </Step>

  <Step title="Étape Cinq">
    Sélectionnez **Stockage → Lecteur USB** et ouvrez **PADS4Philips.apk**.
  </Step>

  <Step title="Étape Six">
    Sélectionnez **Installer** puis **Ouvrir** l'application.
  </Step>
</Steps>

## **3. Fonctionnalités Prises en Charge & Limitations**

| Fonctionnalité | Description                                                                                            |
| :------------: | ------------------------------------------------------------------------------------------------------ |
|        ✅       | **Mises à Jour Automatiques du Logiciel** – PADS4 Viewer se met à jour automatiquement.                |
|        ✅       | **Mode Hors Ligne** – L'appareil continue à exécuter les présentations pendant **7 jours** hors ligne. |
|        ✅       | **Prise en Charge HTTP & HTTPS**                                                                       |
|        ✅       | **Maximum 2 Vidéos par Page**                                                                          |
|        ✅       | **Prise en Charge du Streaming** – HTTP.                                                               |
|        ✅       | **Mode Cluster Viewer** – Pris en charge.                                                              |
|        ✅       | **Bouton Interactif, Texte, Texte Défilant, Image, Tableau**                                           |
|        ✅       | **Éléments PowerPoint & PDF** – *(PowerPoint nécessite une installation sur le PADS4 Server)*.         |
|        ✅       | **Gestion à Distance de l'Appareil** – Contrôlé via **PADS4 Agent**.                                   |
|        ❌       | **Wake-on-LAN & Arrêt Non Pris en Charge**                                                             |

## **4. Dépannage**

| **Problème**                                                                         | **Solution**                                                                           |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| **Bloquer la Télécommande, Éteindre l'Écran, Commandes d'Arrêt Ne Fonctionnent Pas** | Assurez-vous que **SICP over Network** est **activé** et hébergé sur le **port 5000**. |
| **Le Viewer ne démarre pas en plein écran**                                          | Vérifiez la **version du firmware** et **mettez à jour si nécessaire**.                |
| **L'appareil ne parvient pas à se connecter via Ethernet**                           | La mise à jour du **firmware** peut résoudre ce problème.                              |
| **La barre de navigation reste visible**                                             | **Mise à jour du firmware** requise.                                                   |
| **Le Viewer demande répétitivement la permission de stockage de contenu**            | Vérifiez si la **version correcte du firmware** est installée.                         |
