Ce guide fournit des instructions étape par étape pour **installing and configuring PADS4 Viewer** sur les **Philips D-line (4650D) displays**.

***

## **1. Première utilisation**

Avant l'installation, assurez-vous que le **PADS4 Server is set up and configured properly**.

<Note> La version minimale **PADS4 Server version** requise est **PADS4 Foundation 2023.1**.</Note>

Lors de la première mise en marche de l'appareil, l'**Configuration Wizard** apparaîtra. Si ce n'est pas le cas, **reset the device** comme décrit dans **1.2 Resetting the Device**.

***

### **1.1 Configuration de l'appareil**

<Steps>
  <Step title="Première étape">
    Sur l'**Welcome Screen**, sélectionnez votre **language** préféré et cliquez sur **Start**.
  </Step>

  <Step title="Deuxième étape">
    Sur l'écran **Security Settings**, assurez-vous que **SICP Network Port** est **enabled**. *(Les autres paramètres peuvent être activés ou désactivés selon les besoins.)*
  </Step>

  <Step title="Troisième étape">
    Sur l'écran **Network Settings**, sélectionnez et configurez le **network type**.
  </Step>

  <Step title="Quatrième étape">
    Sur l'écran **Signage Display Settings**, appuyez sur **Skip**.
  </Step>

  <Step title="Cinquième étape">
    Sur l'écran **Clone Media Files**, appuyez sur **Skip**.
  </Step>

  <Step title="Sixième étape">
    Appuyez sur **Finish** pour terminer la configuration.
  </Step>
</Steps>

L'appareil affichera **CMND & Deploy**, une application fournie par **Philips**. **No configuration is required** pour cette application.

***

### **1.2 Réinitialisation de l'appareil**

Si l'appareil a déjà été utilisé, effectuez une **factory reset** pour effacer le stockage et éviter les conflits logiciels.

<Steps>
  <Step title="Première étape">
    Ouvrez le **Android Menu** en appuyant sur **Home**, suivi de **1 8 8 8** sur la **Philips remote control**.
  </Step>

  <Step title="Deuxième étape">
    Ouvrez **Settings**.
  </Step>

  <Step title="Troisième étape">
    Sélectionnez **System Tools → Factory Reset**.
  </Step>

  <Step title="Quatrième étape">
    Cliquez sur **Factory Reset** et confirmez en appuyant sur **OK**.
  </Step>
</Steps>

Après la réinitialisation, l'**Welcome Screen** apparaîtra. Suivez les étapes dans **1.1 Configuring the Device**.

***

## **2. Installation de PADS4 Viewer**

Suivez ces étapes pour installer le **PADS4 Viewer** sur **Philips D-line (4650D)**.

***

### **2.1 Vérification du firmware de l'appareil**

Assurez-vous que la **version du firmware correcte** est installée pour une fonctionnalité complète de **PADS4 Viewer**.

<Steps>
  <Step title="Première étape">
    Ouvrez le **Android Menu** en appuyant sur **Home 1 8 8 8**.
  </Step>

  <Step title="Deuxième étape">
    Ouvrez **Settings**.
  </Step>

  <Step title="Troisième étape">
    Sélectionnez **About**.
  </Step>

  <Step title="Quatrième étape">
    Assurez-vous que le **Build Number** est **FB01.09** *(requis pour PADS4)*.
  </Step>
</Steps>

***

### **2.2 Mise à jour du firmware de l'appareil**

Pour mettre à jour le **firmware**, suivez les **instructions Philips**:

📌 **Téléchargez le firmware + instructions depuis :**\
🔗 [PPDS Philips Download Center](https://www.ppds.com/download-center)

***

### **2.3 Installation de PADS4Philips depuis une clé USB**

Le fichier **PADS4Philips.apk** peut être trouvé sur le **PADS4 Server** in:

```
C:\Program Files\PADS4\Foundation\Apps  
```

Alternativement, téléchargez la dernière version depuis **[ce lien](http://go.pads4.com/?fwlink=1006)** et placez-la dans le **répertoire apps sur le PADS4 Server**.

#### **Étapes d'installation**

<Steps>
  <Step title="Première étape">
    Copiez le fichier **PADS4Philips.apk** sur une **clé USB**.
  </Step>

  <Step title="Deuxième étape">
    Insérez la **clé USB** dans l'**appareil Philips D-line**.
  </Step>

  <Step title="Troisième étape">
    Ouvrez le **Android Menu** en appuyant sur **Home 1 8 8 8**.
  </Step>

  <Step title="Quatrième étape">
    Sélectionnez **Apps → File Manager**.
  </Step>

  <Step title="Cinquième étape">
    Ouvrez **mnt → usb\_storage** et sélectionnez **PADS4Philips.apk**.
  </Step>

  <Step title="Sixième étape">
    Sélectionnez **Install** puis **Open** l'application.
  </Step>
</Steps>

## **3. Fonctionnalités prises en charge et limitations**

| Fonctionnalité | Description                                                                                                    |
| :------------: | -------------------------------------------------------------------------------------------------------------- |
|        ✅       | **Mises à jour automatiques du logiciel** – PADS4 Viewer se met à jour automatiquement.                        |
|        ✅       | **Mode hors ligne** – L'appareil continue d'exécuter les présentations pendant **7 jours** en mode hors ligne. |
|        ✅       | **Prend en charge HTTP & HTTPS**                                                                               |
|        ✅       | **Maximum 1 vidéo par page**                                                                                   |
|        ❌       | **Rotation vidéo, vidéos sans couture, réflexion, inclinaison, retournement** – Non pris en charge.            |
|        ✅       | **Support de streaming** – HTTP.                                                                               |
|        ✅       | **Mode Cluster Viewer** – Pris en charge.                                                                      |
|        ✅       | **Bouton interactif, texte, texte défilant, image, tableau**                                                   |
|        ✅       | **Éléments PowerPoint & PDF** – *(PowerPoint nécessite une installation sur le PADS4 Server)*.                 |
|        ✅       | **Gestion à distance des appareils** – Contrôlée via **PADS4 Agent**.                                          |
|        ✅       | **Wake-on-LAN** – Démarrer l'appareil à distance.                                                              |
|        ❌       | **Éteindre l'écran** – Non pris en charge.                                                                     |

## **4. Dépannage**

| **Problème**                                                                             | **Solution**                                                                           |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **Les commandes Bloquer la télécommande, Éteindre l'écran, Arrêter ne fonctionnent pas** | Assurez-vous que **SICP over Network** est **activé** et hébergé sur le **port 5000**. |
| **Le Viewer ne démarre pas en plein écran**                                              | Vérifiez la **version du firmware** et **mettez-la à jour si nécessaire**.             |
| **L'appareil ne parvient pas à se connecter via Ethernet**                               | La mise à jour du **firmware** peut résoudre ce problème.                              |
| **La barre de navigation reste visible**                                                 | **Mise à jour du firmware** requise.                                                   |
| **Le Viewer demande répétitivement l'autorisation de stockage de contenu**               | Vérifiez si la **version du firmware correcte** est installée.                         |
