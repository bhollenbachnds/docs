Ce guide fournit des instructions étape par étape pour **l'installation et la configuration de PADS4 Viewer** sur **les écrans Philips Q-line (3550Q)**.

***

## **1. Première utilisation**

Avant l'installation, assurez-vous que le **PADS4 Server est correctement configuré**.

📌 **Version minimale requise pour PADS4 Server :** **PADS4 Foundation 2021.2**

Lors de la première mise en marche de l'appareil, l'**Assistant de configuration** apparaîtra. Si ce n'est pas le cas, **réinitialisez l'appareil** comme décrit dans **1.2 Réinitialisation de l'appareil**.

***

### **1.1 Configuration de l'appareil**

<Steps>
  <Step title="Première étape">
    Sur l'**Écran d'accueil**, sélectionnez votre **langue** préférée et cliquez sur **Démarrer**.
  </Step>

  <Step title="Deuxième étape">
    Sur l'écran **Paramètres de sécurité**, assurez-vous que le **Port réseau SICP** est **activé**. *(Les autres paramètres peuvent être activés ou désactivés selon les besoins.)*
  </Step>

  <Step title="Troisième étape">
    Sur l'écran **Paramètres réseau**, sélectionnez et configurez le **type de réseau**.
  </Step>

  <Step title="Quatrième étape">
    Sur l'écran **Paramètres d'affichage de signalisation**, appuyez sur **Ignorer**.
  </Step>

  <Step title="Cinquième étape">
    Sur l'écran **Cloner les fichiers multimédias**, appuyez sur **Ignorer**.
  </Step>

  <Step title="Sixième étape">
    Appuyez sur **Terminer** pour compléter la configuration.
  </Step>
</Steps>

L'appareil affichera **CMND & Deploy**, une application fournie par **Philips**. **Aucune configuration n'est requise** pour cette application.

***

### **1.2 Réinitialisation de l'appareil**

Si l'appareil a déjà été utilisé, effectuez une **réinitialisation d'usine** pour effacer le stockage et éviter les conflits logiciels.

<Steps>
  <Step title="Première étape">
    Ouvrez le **Menu Android** en appuyant sur **Accueil**, suivi de **1 8 8 8** sur la **télécommande Philips**.
  </Step>

  <Step title="Deuxième étape">
    Ouvrez **Paramètres**.
  </Step>

  <Step title="Troisième étape">
    Sélectionnez **Outils système → Réinitialisation d'usine**.
  </Step>

  <Step title="Quatrième étape">
    Cliquez sur **Réinitialisation d'usine** et confirmez en appuyant sur **OK**.
  </Step>
</Steps>

Après la réinitialisation, l'**Écran d'accueil** apparaîtra. Suivez les étapes dans **1.1 Configuration de l'appareil**.

***

## **2. Installation de PADS4 Viewer**

Suivez ces étapes pour installer **PADS4 Viewer** sur **Philips Q-line (3550Q)**.

***

### **2.1 Vérification du firmware de l'appareil**

Assurez-vous que la **version correcte du firmware** est installée pour une fonctionnalité complète de **PADS4 Viewer**.

<Steps>
  <Step title="Première étape">
    Ouvrez le **Menu Android** en appuyant sur **Accueil 1 8 8 8**.
  </Step>

  <Step title="Deuxième étape">
    Ouvrez **Paramètres**.
  </Step>

  <Step title="Troisième étape">
    Sélectionnez **À propos**.
  </Step>

  <Step title="Quatrième étape">
    Assurez-vous que le **Numéro de build** est **FB01.10** *(requis pour PADS4)*.
  </Step>
</Steps>

***

### **2.2 Mise à jour du firmware de l'appareil**

Pour mettre à jour le **firmware**, suivez les **instructions de Philips** :

📌 **Guide de mise à jour du firmware :** [Download Firmware Instructions](https://www.dropbox.com/s/8sj2pfo7uv01dd9/xxBDL3550Q%20Latest%20FW.pdf?dl=0)\
📌 **Centre de téléchargement Philips :** [Download Center](https://www.dropbox.com/s/fje9ge0ao8at6rq/One_Link.xlsm?dl=0)

***

### **2.3 Installation de PADS4Philips à partir d'une clé USB**

Le fichier **PADS4Philips.apk** peut être trouvé sur le **PADS4 Server** in:

```
C:\Program Files\PADS4\Foundation\Apps
```

Alternativement, téléchargez la dernière version depuis [**ce lien**](http://go.pads4.com/?fwlink=1006) et placez-le dans le **répertoire apps sur le PADS4 Server**.

#### **Étapes d'installation**

<Steps>
  <Step title="Première étape">
    Copiez le fichier **PADS4Philips.apk** sur une **clé USB**.
  </Step>

  <Step title="Deuxième étape">
    Insérez la **clé USB** dans l'**appareil Philips Q-line**.
  </Step>

  <Step title="Troisième étape">
    Ouvrez le **Menu Android** en appuyant sur **Accueil 1 8 8 8**.
  </Step>

  <Step title="Quatrième étape">
    Sélectionner **Storage → USB Drive** et ouvrir **PADS4Philips.apk**.
  </Step>

  <Step title="Étape Cinq">
    Sélectionner **Install** puis **Open** l'application.
  </Step>
</Steps>

## **3. Fonctionnalités prises en charge et limitations**

| Fonctionnalité | Description                                                                                                |
| :------------: | ---------------------------------------------------------------------------------------------------------- |
|        ✅       | **Automatic Software Updates** – PADS4 Viewer se met à jour automatiquement.                               |
|        ✅       | **Offline Mode** – L'appareil continue d'exécuter les présentations pendant **7 days** en mode hors ligne. |
|        ✅       | **Supports HTTP & HTTPS**                                                                                  |
|        ✅       | **Maximum 1 Video per Page**                                                                               |
|        ❌       | **Video Rotation, Seamless Videos, Reflection, Skew, Flip** – Non pris en charge.                          |
|        ✅       | **Streaming Support** – HTTP.                                                                              |
|        ✅       | **Cluster Viewer Mode** – Pris en charge.                                                                  |
|        ✅       | **Interactive Button, Text, Scrolling Text, Image, Table**                                                 |
|        ✅       | **PowerPoint & PDF Elements** – *(PowerPoint requires installation on PADS4 Server)*.                      |
|        ✅       | **Remote Device Management** – Contrôlé via **PADS4 Agent**.                                               |
|        ✅       | **Wake-on-LAN** – Démarrage à distance de l'appareil.                                                      |
|        ❌       | **Turn Off Display** – Non pris en charge.                                                                 |

***

## **4. Dépannage**

| **Problème**                                                              | **Solution**                                                                                 |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **Block Remote Control, Turn Off Display, Shutdown Commands Not Working** | Assurez-vous que **SICP over Network** est **enabled** et hébergé sur le **port 5000**.      |
| **Viewer does not start in full screen**                                  | Vérifiez la **firmware version** et **update if necessary**.                                 |
| **Device fails to connect over Ethernet**                                 | La mise à jour du **firmware** peut résoudre ce problème.                                    |
| **Navigation bar remains visible**                                        | **Firmware update** nécessaire.                                                              |
| **Viewer repeatedly asks for content storage permission**                 | Vérifiez si la **correct firmware version** est installée.                                   |
| **Device not starting on WOL command**                                    | Assurez-vous que **WOL is enabled** et qu'un **power save mode** compatible est sélectionné. |
| **Used valid certificate is not accepted by PADS4Philips app**            | Vérifiez si la **date and time** sont correctement configurées.                              |
