Cette page explique comment installer et configurer PADS4 Viewer sur l'appareil Hikvision DS-D6032FN.

## Avant de commencer

### Configuration minimale requise

| Exigence     | Minimum                 |
| ------------ | ----------------------- |
| PADS4 Server | PADS4 Foundation 2023.1 |
| Firmware     | V1.7.1 build 20230424   |

### Autres prérequis

* Un PADS4 Server configuré et opérationnel.
* Une clé USB.

## Préparer l'appareil

### Réinitialiser l'appareil

Si l'appareil a déjà été utilisé, effectuez une réinitialisation d'usine. Une réinitialisation d'usine efface le stockage et évite les conflits logiciels.

1. Ouvrez l'écran d'accueil de l'appareil.
2. Ouvrez l'application **Settings**.
3. Dans le menu **Settings**, sélectionnez **System**.
4. Faites défiler vers le bas, puis sélectionnez **Restore to Factory Settings**.
5. Dans la boîte de dialogue, sélectionnez **Confirm**.

### Mettre à jour le firmware

Mettez à jour le firmware vers au moins V1.7.1 build 20230424 avant d'installer PADS4.

1. Copiez le `update.zip` fichier firmware dans le répertoire racine d'une clé USB.
2. Insérez la clé USB dans l'appareil.
3. L'appareil détecte la mise à jour du firmware via USB et vous invite à l'installer.
4. Suivez les instructions à l'écran pour installer la mise à jour du firmware.

## Installer PADS4 Viewer

Le `PADS4Hikvision.apk` fichier est disponible sur le PADS4 Server dans ce dossier :

```text
C:\Program Files\PADS4\Foundation\Apps
```

Vous pouvez également télécharger la dernière version depuis [GitHub](https://github.com/PADS4/PADS4-Viewer-HikVision/releases/latest). Placez le fichier téléchargé dans le répertoire des applications du PADS4 Server pour vous assurer que la version correcte est installée.

1. Copiez le `PADS4Hikvision.apk` fichier sur une clé USB.
2. Insérez la clé USB dans l'appareil Hikvision DS-D6032FN.
3. Ouvrez l'écran d'accueil de l'appareil.
4. Ouvrez l'application **FileBrowser**.
5. Sélectionnez **USB DISK** dans la liste.
6. Sélectionnez `PADS4Hikvision.apk`.
7. Lorsque le message **Do you want to install this application?** s'affiche, sélectionnez **Install**.
8. Une fois l'installation terminée, sélectionnez **Open** pour démarrer l'application PADS4 Hikvision.

## Connecter le Viewer au PADS4 Server

L'emplacement du serveur a ce format : `protocol://host:port/hostpath/`.

* **Protocole** : `http` ou `https`. Cela dépend du certificat SSL.
* **Hôte** : Le nom DNS ou l'adresse IP du PADS4 Server.
* **Port**: Facultatif. Spécifiez le port uniquement si vous utilisez des ports non standard.
* **Chemin d'hôte**: Configuré dans **System Management**. La valeur par défaut est `PADS4`.

1. Entrez l'emplacement du serveur PADS4.
2. (Facultatif) Entrez un nom pour le Viewer. Si vous laissez le champ vide, PADS4 génère un nom.
3. Sélectionnez **Start**.
4. Lorsque vous y êtes invité, accordez l'autorisation d'accéder aux photos, aux médias et aux fichiers.

PADS4 télécharge et installe PADS4 Viewer.

## Modifier les paramètres de l'appareil

### Ouvrir les paramètres du Viewer

Pour ouvrir les paramètres du Viewer, touchez l'écran pendant 3 secondes, ou appuyez et maintenez le bouton gauche de la souris.

### Ouvrir le menu Android

Si vous ouvrez le menu Android pendant que PADS4 est en cours d'exécution, le Viewer Monitor Service détecte une inactivité. L'appareil redémarre alors après 30 secondes.

Pour éviter le redémarrage, arrêtez l'application PADS4 Hikvision dans les 30 secondes.

## Mettre à jour PADS4 Viewer

PADS4 Viewer et l'application PADS4 Hikvision se mettent à jour automatiquement lorsque vous mettez à jour le serveur PADS4.

## Fonctionnalités prises en charge et limitations

### Général

| Fonctionnalité                         | Prise en charge | Remarques                                                                            |
| -------------------------------------- | --------------- | ------------------------------------------------------------------------------------ |
| Mises à jour automatiques du Viewer    | Oui             | Le Viewer se met à jour automatiquement lorsque vous mettez à jour le serveur PADS4. |
| Mode hors ligne                        | Oui             | L'appareil continue d'exécuter les présentations pendant 7 jours en mode hors ligne. |
| HTTP et HTTPS                          | Oui             |                                                                                      |
| Mode portrait                          | Oui             | L'appareil fait pivoter l'écran automatiquement.                                     |
| Cluster Viewer                         | Oui             | Prend en charge le mode Cluster.                                                     |
| Vérification de l'intégrité du contenu | Oui             | Vérification de l'intégrité des fichiers MD5.                                        |
| Contrôle du volume principal           | Non             | Vous pouvez ajuster le volume uniquement au niveau de l'élément.                     |

### Vidéo et images

| Fonctionnalité                                                                | Prise en charge | Remarques                          |
| ----------------------------------------------------------------------------- | --------------- | ---------------------------------- |
| Vidéos sur une page                                                           | Oui             | Maximum de 2 vidéos simultanément. |
| Streaming vidéo                                                               | Non             |                                    |
| Rotation vidéo, vidéos sans interruption, reflet, inclinaison et retournement | Oui             |                                    |

### Contenu et données

| Fonctionnalité                                                                   | Prise en charge | Remarques                                                                                             |
| -------------------------------------------------------------------------------- | --------------- | ----------------------------------------------------------------------------------------------------- |
| Images, texte, lignes, formes, texte défilant, tableaux, boutons et éléments web | Oui             |                                                                                                       |
| PowerPoint et PDF                                                                | Oui             | PowerPoint doit être installé sur le serveur PADS4.                                                   |
| Éléments Flash                                                                   | Non             |                                                                                                       |
| Fournisseurs de données                                                          | Oui             | Inclut plus de 70 fournisseurs de données PADS4 pour récupérer et intégrer des données en temps réel. |
| Variables du Viewer                                                              | Oui             | Simplifiez la gestion du contenu sans modifier les présentations.                                     |
| Liaisons de propriétés                                                           | Oui             | Définissez les propriétés des éléments de manière dynamique à partir de sources de données externes.  |

### Gestion des appareils

| Fonctionnalité                              | Prise en charge | Remarques                                                                                           |
| ------------------------------------------- | --------------- | --------------------------------------------------------------------------------------------------- |
| Gestion à distance dans PADS4 CTRL Center   | Oui             | Géré avec PADS4 CTRL Center et PADS4 Agent.                                                         |
| Redémarrer l'appareil et relancer le Viewer | Oui             |                                                                                                     |
| Bloquer la télécommande                     | Oui             | Empêche l'interaction avec l'écran via la télécommande.                                             |
| Éteindre l'écran                            | Oui             | L'écran s'éteint lorsqu'aucune présentation n'est planifiée. Cela réduit la consommation d'énergie. |
| Récupérer des captures d'écran              | Oui             |                                                                                                     |
| Preuve de diffusion                         | Oui             | Suit l'historique de lecture du contenu.                                                            |
| Blackbox                                    | Oui             | Fournit des journaux système pour le dépannage et le support.                                       |
