Les ordinateurs AOPEN eTILE Series fonctionnent sous Windows 10 ou Windows 11. Vous exécutez PADS4 Viewer sur l'ordinateur pour afficher les présentations PADS4. Cette page répertorie les appareils pris en charge et les liens vers les étapes d'installation.

## Avant de commencer

### Appareils pris en charge

* Ordinateurs AOPEN eTILE Series

### Configuration minimale requise

| Exigence     | Minimum                            |
| ------------ | ---------------------------------- |
| PADS4 Server | PADS4 2022.1 ou version ultérieure |
| Windows      | Windows 10 ou Windows 11           |

### Autres prérequis

* Un compte avec des droits d'administrateur.
* Accès réseau depuis l'ordinateur vers le PADS4 Server.

## Installer PADS4 Viewer

Installez PADS4 Viewer avec la procédure d'installation Windows standard. Pour les étapes, voir [Windows Viewer](/fr/certified-devices/windows/Windows-Viewer) ou [Windows HTML5 Viewer](/fr/certified-devices/windows/Windows-HTML5-Viewer).

Les ordinateurs eTILE Series sont équipés d'un écran tactile.
