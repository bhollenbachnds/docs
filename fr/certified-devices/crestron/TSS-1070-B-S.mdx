Les panneaux tactiles de planification de salle Crestron TSS-1070-B-S incluent PADS4 Viewer dans le firmware Crestron. Vous définissez le mode d'application du panneau sur PADS4, et le panneau charge ensuite le Viewer depuis votre PADS4 Server. Cette page explique comment préparer le panneau, définir le mode d'application, connecter le Viewer à votre PADS4 Server et configurer le capteur d'occupation Crestron.

## Avant de commencer

### Appareils pris en charge

* Crestron TSS-1070-B-S

### Configuration minimale requise

| Exigence               | Minimum                            |
| ---------------------- | ---------------------------------- |
| PADS4 Server           | PADS4 2022.3 ou version ultérieure |
| Firmware de l'appareil | `2.003.1011`                       |

### Autres prérequis

* Un PADS4 Server installé et en cours d'exécution. Vous avez besoin de son emplacement pour connecter le Viewer.
* Accès réseau depuis le panneau vers le PADS4 Server.
* Accès à l'interface de configuration web du panneau.
* (Facultatif) Un capteur d'occupation Crestron POE, si vous souhaitez utiliser les données d'occupation. Vous avez également besoin de PADS4 Workspace.

## Préparer l'appareil

### Réinitialiser l'appareil

Réinitialisez le panneau s'il a déjà été utilisé. Cela efface le stockage et évite les conflits logiciels.

<Warning>
  Une réinitialisation d'usine supprime toutes les données et paramètres du panneau.
</Warning>

1. Connectez-vous à l'interface de configuration web Crestron.
2. Sélectionnez la flèche à côté du bouton **Action** dans le coin supérieur droit.
3. Sélectionnez **Restore**.
4. Dans la boîte de dialogue de confirmation, sélectionnez **Yes**.

### Vérifier la version du firmware

PADS4 Viewer fait partie du firmware Crestron. Vous ne pouvez pas l'installer séparément. PADS4 Viewer nécessite la version de firmware `2.003.1011` ou version ultérieure.

## Installer PADS4 Viewer

Définissez le mode d'application du panneau sur PADS4. Le panneau télécharge ensuite PADS4 Viewer depuis votre PADS4 Server lorsque vous le connectez.

1. Connectez-vous à l'interface de configuration web Crestron.
2. Sélectionnez l'onglet **Settings**.
3. Sélectionnez **Applications**.
4. Dans la liste **Application Mode**, sélectionnez **PADS4**.
5. Dans le coin supérieur droit, sélectionnez **Save Changes**.
6. Dans la boîte de dialogue de confirmation, sélectionnez **Yes, Reboot Now**.

## Connecter le Viewer au PADS4 Server

L'emplacement du serveur a ce format : `http(s)://<server>/<domain>`. Remplacez `<server>` par l'adresse IP ou le nom d'hôte de votre PADS4 Server. Remplacez `<domain>` par votre domaine PADS4. Le domaine par défaut est `PADS4`.

1. Entrez l'emplacement du PADS4 Server.
2. (Facultatif) Entrez un nom pour le Viewer. Si vous laissez le champ vide, le PADS4 Server génère un nom.
3. Sélectionnez **Start**.
4. Définissez **PADS4 IIyama Touch** comme application d'accueil, puis sélectionnez **Always**.

<Check>
  Le Viewer affiche une LED verte et le nom du Viewer. Cela signifie que la connexion fonctionne.
</Check>

## Modifier les paramètres de la plateforme

### Ouvrir les options du Viewer

1. Touchez l'écran pendant 3 secondes, ou appuyez et maintenez le bouton de la souris. L'écran des options s'ouvre.
2. Pour revenir à l'application PADS4, sélectionnez **Launcher Settings**.

## Configurer le capteur d'occupation Crestron

PADS4 prend en charge le capteur d'occupation Crestron. Commencez par associer le capteur au panneau, puis trouvez le capteur dans PADS4 Workspace.

### Associer le capteur d'occupation au panneau

1. Connectez-vous à l'interface de configuration web Crestron du panneau.
2. Sélectionnez l'onglet **Settings**.
3. Ouvrez **Device Pairing**.
4. Dans la liste **Device Model**, sélectionnez **POE Occupancy Sensor**.
5. Entrez l'adresse IP ou le FQDN du capteur.
6. Dans le coin supérieur droit, sélectionnez **Save Changes**.
7. Vérifiez que **Pairing Status** passe à **Online**.

### Trouver le capteur d'occupation dans PADS4 Workspace

1. Connectez-vous à PADS4 Workspace Admin.
2. Sélectionnez **Occupancy Sensors**.
3. Sélectionnez l'onglet **Sensors**.

Le capteur apparaît dans le tableau.

## Fonctionnalités prises en charge et limitations

### Général

| Fonctionnalité  | Prise en charge | Remarques                                                                                                                                  |
| --------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Mode hors ligne | Partiel         | Le Viewer met en cache la bibliothèque de contenu sur le panneau. Le stockage de fichiers locaux pour le contenu n'est pas pris en charge. |
| HTTP et HTTPS   | Oui             |                                                                                                                                            |
| Mode portrait   | Oui             |                                                                                                                                            |
| Cluster Viewer  | n/a             |                                                                                                                                            |

### Vidéo et images

| Fonctionnalité      | Support | Notes                 |
| ------------------- | ------- | --------------------- |
| Vidéos sur une page | Oui     | Une vidéo à la fois.  |
| Streaming vidéo     | Non     |                       |
| Formats d'image     | Oui     | JPG, PNG, BMP et GIF. |

### Contenu et données

| Fonctionnalité                                                 | Support | Notes                                                     |
| -------------------------------------------------------------- | ------- | --------------------------------------------------------- |
| Texte, texte défilant, tableaux, formes et boutons interactifs | Oui     |                                                           |
| Élément web                                                    | Oui     | La barre d'adresse interactive n'est pas prise en charge. |
| Fournisseurs de données, Variables Viewer et règles            | Oui     |                                                           |

### Gestion des appareils

| Fonctionnalité                            | Support | Notes                                                                                        |
| ----------------------------------------- | ------- | -------------------------------------------------------------------------------------------- |
| Gestion à distance dans PADS4 CTRL Center | Oui     |                                                                                              |
| Redémarrer le Viewer                      | Oui     |                                                                                              |
| Redémarrer l'appareil                     | Oui     |                                                                                              |
| Éteindre l'appareil                       | Non     |                                                                                              |
| Wake-on-LAN                               | Non     |                                                                                              |
| Bloquer la télécommande                   | Non     |                                                                                              |
| Récupérer les captures d'écran            | Oui     |                                                                                              |
| Récupérer les journaux                    | Oui     |                                                                                              |
| Preuve de diffusion                       | Oui     | Le panneau stocke jusqu'à 50 000 enregistrements lorsqu'il est hors ligne.                   |
| Installer des polices                     | Oui     |                                                                                              |
| Capteur de présence Crestron              | Oui     | Voir [Configurer le capteur de présence Crestron](#configure-the-crestron-occupancy-sensor). |

Le stockage local de fichiers pour le contenu n'est pas pris en charge.
