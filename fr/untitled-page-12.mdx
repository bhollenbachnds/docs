## Aperçu

Gère la configuration du routage de domaine pour le proxy inverse PADS4 Nginx. Contrôle quels noms d'hôte sont acheminés vers quels environnements de tenant PADS4 dans les déploiements multi-tenant.

| Champ               | Valeur                                                                |
| ------------------- | --------------------------------------------------------------------- |
| Swagger UI          | `https://<your-server>/rdx/NDS.Nginx.Domains/swagger/index.html`      |
| OpenAPI spec        | `https://<your-server>/rdx/NDS.Nginx.Domains/swagger/v1/swagger.json` |
| URL de base         | `https://<your-server>/rdx/NDS.Nginx.Domains`                         |
| Total des endpoints | 20                                                                    |

***

## Authentification

Tous les endpoints utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin de service indiqué ci-dessus.
