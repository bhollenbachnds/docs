Vous pouvez utiliser des capteurs Sigfox pour réserver automatiquement une salle lorsqu'ils détectent des personnes dans la salle de réunion. Cet article explique comment connecter ces capteurs à PADS4 afin qu'ils puissent être utilisés avec les salles de réunion.

Les capteurs Sigfox et les identifiants sont fournis et gérés par NDS et sont prêts à l'emploi. Suivez ces étapes pour ajouter les capteurs à PADS4 :

1. Activez le module et renseignez les informations. NDS fournit les identifiants de connexion.
   <Frame>
     ![Sig Fox Conf](/images/Workspace/Administrator/SigFox-conf.png "Sig Fox Conf")
   </Frame>
2. Accédez à PADS4 Workspace Admin
3. Accédez à Occupancy Sensors
4. Le capteur d'occupation Sigfox sera répertorié ici et vous permettra de modifier le nom du capteur et de l'affecter à une salle de réunion. Notez que l'affichage des capteurs peut prendre quelques minutes.<br />
   <Frame>
     ![Sig Fox Sensors](/images/SigFox-Sensors.png "Sig Fox Sensors")
   </Frame>

Remarks:

* Activez les capteurs d'occupation pour le profil de salle dont la salle de réunion est membre. Vous pouvez configurer cela dans la section Room Profiles de PADS4 Workspace Admin.
