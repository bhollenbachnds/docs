Pour activer Sigfox, effectuez les étapes ci-dessous :

1. Réglez le bouton sur ON.
2. Sélectionnez SIGFOX comme type de source.
3. Entrez l'URL du point de terminaison SIGFOX (par défaut : [https://sigfox.crystalunivers.com](https://sigfox.crystalunivers.com)).
4. Renseignez le Login, le mot de passe et la référence d'installation.<br />
   <Frame>
     ![Sig Fox Conf](/images/Workspace/Administrator/SigFox-conf.png "Sig Fox Conf")
   </Frame>
5. Cliquez sur Enregistrer
