**Éléments Flash player** sont utilisés pour inclure du **contenu Flash** dans votre présentation.\
Ces éléments offrent plusieurs options pour contrôler la façon dont le contenu Flash doit être lu.\
De plus, les éléments Flash peuvent être **connectés à des sources de données externes**, permettant **des mises à jour en temps réel** des fichiers Flash à lire.

***

### **Vue d'ensemble des propriétés**

| **Section de propriété**                     | **Description**                                                                                                            |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **Options d'alternance**                     | Définir comment l'élément bascule entre les éléments de la liste de lecture.                                               |
| **Couleur d'arrière-plan**                   | Définir la couleur d'arrière-plan de l'élément Flash.                                                                      |
| **Fournisseur de données**                   | Connectez l'élément à une **source de données en temps réel** pour alimenter dynamiquement le contenu Flash.               |
| **Conversion de texte de source de données** | Définissez la manière dont le texte multiligne est géré lors de l'utilisation de sources de données.                       |
| **Identification**                           | Identifiez de manière unique l'élément au sein de la page.                                                                 |
| **Interactivité**                            | Activez ou désactivez **l'interaction utilisateur** avec le contenu Flash.                                                 |
| **Liste de lecture**                         | Définissez les fichiers Flash qui seront affichés par l'élément.                                                           |
| **Options de liste de lecture**              | Déterminez la manière dont les éléments de la liste de lecture sont lus (par exemple, en boucle, dans un ordre aléatoire). |
| **Position**                                 | Définissez la position de l'élément dans la mise en page.                                                                  |
| **Preuve de lecture**                        | Activez la journalisation pour **prouver la lecture** du contenu Flash à des fins d'audit.                                 |
| **Liaisons de propriétés**                   | Liez les propriétés de l'élément à des sources de données externes pour un contrôle dynamique.                             |
| **Règles**                                   | Définissez des règles spécifiques à l'élément pour ajuster automatiquement le comportement en fonction des conditions.     |
| **Taille**                                   | Définissez la largeur et la hauteur de l'élément Flash.                                                                    |
| **Visibilité**                               | Contrôlez si l'élément et son contenu sont visibles pendant la lecture.                                                    |
| **Niveau de zoom**                           | Définissez les options de zoom et de rognage pour l'affichage du contenu Flash.                                            |

***

### **Remarque**

* Cette section **uniquement** décrit les **propriétés spécifiques à Flash**.
* Pour les **propriétés communes** qui s'appliquent à tous les éléments de page (tels que la position, la taille, la visibilité, les règles, etc.), consultez la section **Propriétés des éléments de page**.
