**Flash player elements** sont utilisés pour inclure **Flash content** dans votre présentation.\
Ces éléments offrent plusieurs options pour contrôler la façon dont le Flash content doit être lu.\
De plus, les Flash elements peuvent être **connectés à des sources de données externes**, permettant **des mises à jour en temps réel** des Flash files à lire.

***

### **Aperçu des propriétés**

| **Section de propriété**                     | **Description**                                                                                                     |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Options alternatives**                     | Définir comment l'élément bascule entre les éléments de la playlist.                                                |
| **Couleur d'arrière-plan**                   | Définir la couleur d'arrière-plan du Flash element.                                                                 |
| **Data provider**                            | Connecter l'élément à une **source de données en temps réel** pour alimenter le Flash content de manière dynamique. |
| **Conversion de texte de source de données** | Définir comment le texte multiligne est géré lors de l'utilisation de sources de données.                           |
| **Identification**                           | Identifier de manière unique l'élément au sein de la page.                                                          |
| **Interactivité**                            | Activer ou désactiver **l'interaction utilisateur** avec le Flash content.                                          |
| **Play list**                                | Définir les Flash files qui seront affichés par l'élément.                                                          |
| **Options de play list**                     | Déterminer comment les éléments de la playlist sont lus (par exemple, en boucle, dans un ordre aléatoire).          |
| **Position**                                 | Définir la position de l'élément dans la mise en page.                                                              |
| **Proof of play**                            | Activer la journalisation pour **prouver la lecture** du Flash content à des fins d'audit.                          |
| **Property bindings**                        | Lier les propriétés de l'élément à des sources de données externes pour un contrôle dynamique.                      |
| **Règles**                                   | Définir des règles spécifiques à l'élément pour ajuster automatiquement le comportement en fonction des conditions. |
| **Taille**                                   | Définir la largeur et la hauteur du Flash element.                                                                  |
| **Visibilité**                               | Contrôler si l'élément et son contenu sont visibles pendant la lecture.                                             |
| **Niveau de zoom**                           | Définir les options de zoom et de rognage pour l'affichage du Flash content.                                        |

***

### **Remarque**

* Cette section **uniquement** décrit les **propriétés spécifiques à Flash**.
* Pour les **propriétés communes** qui s'appliquent à tous les éléments de page (tels que la position, la taille, la visibilité, les règles, etc.), consultez la section **Page Element Properties**.
