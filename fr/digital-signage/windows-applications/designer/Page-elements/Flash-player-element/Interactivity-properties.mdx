Ces propriétés contrôlent si les utilisateurs peuvent **interagir** avec le contenu Flash affiché dans l'élément lecteur Flash.

### **Interactivité utilisateur**

* **Allow User Interactivity** :
  * **Activez** cette option pour permettre aux utilisateurs d'interagir avec le contenu Flash.
  * Cela peut inclure un clic sur **des hyperliens**, **des boutons**, ou d'autres composants interactifs faisant partie du fichier Flash.
  * **Désactiver** cette option si vous souhaitez que le contenu Flash soit lu sans autoriser aucune saisie ou interaction de l'utilisateur.
