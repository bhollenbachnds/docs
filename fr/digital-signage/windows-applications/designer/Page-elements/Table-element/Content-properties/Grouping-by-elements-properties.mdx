Le **regroupement par propriétés** vous permet d'organiser les lignes du tableau en **masquant les valeurs en double** dans les colonnes sélectionnées. Lorsque **deux lignes consécutives ou plus** contiennent la même valeur pour un **élément groupé**, cette valeur est **affichée uniquement dans la première ligne**.

⚠ **Important:** Cette fonctionnalité **ne** regroupe pas réellement les données dans le tableau comme le fait **"Scroll Data, Grouped By"** option. Au lieu de cela, il se contente simplement **masque les valeurs en double** pour améliorer la lisibilité.

***

## **Définir les éléments Regrouper par dans un tableau**

1. Ouvrez la **Table Properties** fenêtre.
2. Accédez à la **Row Properties** section.
3. Cliquez sur **Edit** pour modifier la **Row Definition**.
4. Dans le **Home tab** de la barre de ruban, cliquez sur **Group By**.
5. Sélectionnez les **éléments** par lesquels vous souhaitez regrouper.
6. (Facultatif) Utilisez **Move Up** ou **Move Down** pour ajuster la **priorité de regroupement**.
7. Cliquez sur **OK** pour enregistrer les **paramètres de regroupement**.
8. Dans le **File menu**, cliquez sur **Close**.
9. Cliquez sur **Yes** pour confirmer les modifications.
10. Cliquez sur **OK** ou **Apply** pour mettre à jour la présentation.

***

## **Options de regroupement supplémentaires**

* Si vous avez besoin d'**afficher les données regroupées ensemble** au lieu de simplement **masquer les valeurs en double**, utilisez l'option **"Scroll Data, Grouped By"** dans **Scroll Options**.

***

## **Remarques & Bonnes pratiques**

* **Tous les éléments** de la définition de ligne **peuvent être utilisés pour le regroupement**, mais **les éléments texte et les éléments image** sont les plus **couramment utilisés**.
* **Lorsque plusieurs éléments sont regroupés**, le système les traite dans un **ordre de priorité** :
  * Il vérifie d'abord **le premier élément de regroupement**.
  * Si sa valeur **correspond à la ligne précédente**, elle est **masquée**.
  * Le système vérifie ensuite l'**élément de regroupement suivant**, en continuant jusqu'à ce que :
    * Une **valeur différente soit trouvée**, ou
    * Tous les **éléments de regroupement** sélectionnés aient été traités.
* **Il n'y a pas de limite** au nombre d'**éléments de regroupement** que vous pouvez définir.
