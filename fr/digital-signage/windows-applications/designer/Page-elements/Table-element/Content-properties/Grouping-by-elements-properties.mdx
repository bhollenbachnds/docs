Le **regroupement par propriétés** vous permet d'organiser les lignes du tableau en **masquant les valeurs en double** dans les colonnes sélectionnées. Lorsque **deux lignes consécutives ou plus** contiennent la même valeur pour un **élément groupé**, cette valeur n'est **affichée que dans la première ligne**.

⚠ **Important:** Cette fonctionnalité **ne** regroupe pas réellement les données dans le tableau comme l'option **"Scroll Data, Grouped By"**. Au lieu de cela, elle **masque simplement les valeurs en double** pour améliorer la lisibilité.

***

## **Définition des éléments de regroupement dans un tableau**

1. Ouvrez la fenêtre **Table Properties**.
2. Accédez à la section **Row Properties**.
3. Cliquez sur **Edit** pour modifier la **Row Definition**.
4. Dans l'onglet **Home tab** de la barre de ruban, cliquez sur **Group By**.
5. Sélectionnez les **éléments** sur lequel vous souhaitez grouper.
6. (Facultatif) Utilisez **Monter** ou **Descendre** pour ajuster la **priorité de groupement**.
7. Cliquez sur **OK** pour enregistrer les **paramètres de groupe**.
8. Dans le **menu Fichier**, cliquez sur **Fermer**.
9. Cliquez sur **Oui** pour confirmer les modifications.
10. Cliquez sur **OK** ou **Appliquer** pour mettre à jour la présentation.

***

## **Options de groupement supplémentaires**

* Si vous avez besoin d'**afficher les données regroupées** plutôt que de simplement **masquer les valeurs en double**, utilisez l'option **"Scroll Data, Grouped By"** dans **Scroll Options**.

***

## **Remarques & bonnes pratiques**

* **Tous les éléments** de la définition de ligne **peuvent être utilisés pour le groupement**, mais **les éléments texte et les éléments image** sont les plus **couramment utilisés**.
* **Lorsque plusieurs éléments sont groupés**, le système les traite dans l'**ordre de priorité** :
  * Il vérifie d'abord **le premier élément de groupement**.
  * Si sa valeur **correspond à la ligne précédente**, elle est **masquée**.
  * Le système vérifie ensuite l'**élément de groupement suivant**, en continuant jusqu'à ce que :
    * Une **valeur différente soit trouvée**, ou
    * Tous les **éléments de groupement** sélectionnés aient été traités.
* **Il n'y a pas de limite** au nombre d'**éléments de groupement** que vous pouvez définir.
