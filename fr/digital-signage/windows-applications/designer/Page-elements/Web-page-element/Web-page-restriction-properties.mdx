Ces propriétés vous permettent de&#x20;
&#x20; **limiter l'accès** à des pages web spécifiques lors de l'utilisation d'un&#x20;
&#x20; **élément de page web interactive**. Cela empêche les utilisateurs de naviguer librement sur&#x20;
&#x20; **Internet** et les restreint à&#x20;
&#x20; **du contenu approuvé**.

## **Paramètres de restrictions des pages web**

### **Empêcher les affichages indésirables de pages web**

* **Activer ou désactiver** les restrictions de pages web.
* Lorsqu'elles sont activées, seuls&#x20;
  &#x20; **les sites web approuvés** seront accessibles.

### **Pages web autorisées**

* Définir une&#x20;
  &#x20; **liste de sites web autorisés** pour les utilisateurs.

***

## **Gestion des sites web autorisés**

### **Pour ajouter un site web :**

1. Cliquez sur&#x20;
   &#x20; **Ajouter**.
2. Saisissez l'
   &#x20; **URL** du site web à autoriser.
3. Cliquez sur&#x20;
   &#x20; **OK**.

### **Pour modifier un site web :**

1. Sélectionnez le&#x20;
   &#x20; **site web existant** dans la liste.
2. Cliquez sur&#x20;
   &#x20; **Modifier**.
3. Effectuez les modifications nécessaires et&#x20;
   &#x20; **cliquez sur OK**.

### **Pour supprimer un site web :**

1. Sélectionnez le&#x20;
   &#x20; **site web** dans la liste.
2. Cliquez sur&#x20;
   &#x20; **Supprimer** pour supprimer l'entrée.

***

## **Bonnes pratiques et conseils**

* **Utiliser des URL génériques**:
  * Example: Adding **"nds.eu"** autorise toutes les pages sous ce domaine (par ex.,&#x20;
    &#x20; **nds.eu/products, nds.eu/about**).
  * Ajouter&#x20;
    &#x20; **"nds.eu/products"** n'autorise l'accès qu'à la page&#x20;
    &#x20; **products**.

* **Supprimer "[www](http://www)." dans les URL**:
  * Certains sites web&#x20;
    &#x20; **redirigent automatiquement** (par ex., de&#x20;
    &#x20; **[www.example.com](http://www.example.com)** vers&#x20;
    &#x20; **example.com**).
  * Saisir uniquement&#x20;
    &#x20; **"example.com"** garantit que l'accès n'est pas bloqué en raison de&#x20;
    &#x20; **redirections non concordantes**.
