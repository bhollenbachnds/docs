Cette section décrit les **propriétés communes** disponibles pour tous les éléments de page dans PADS4 Designer.\
Pour les **propriétés spécifiques aux éléments**, référez-vous à la section dédiée de chaque type d'élément de page.

***

### **Propriétés communes et leurs descriptions**

| **Section de propriété**      | **Description**                                                                                                                                     |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Alignment**                 | Définissez l'alignement horizontal et vertical de votre contenu dans l'élément.                                                                     |
| **Alternate options**         | Définissez comment votre élément bascule entre les éléments de la liste de lecture.                                                                 |
| **Background color**          | Définissez une couleur d'arrière-plan pour votre élément.                                                                                           |
| **Background Picture**        | Définissez une image d'arrière-plan pour l'élément (ou la page entière).                                                                            |
| **Blinking**                  | Ajoutez des effets de clignotement à l'élément pour attirer l'attention.                                                                            |
| **Border**                    | Configurez la largeur, le style et la couleur de la bordure autour de votre élément.                                                                |
| **Brightness/contrast**       | Ajustez les niveaux de luminosité et de contraste du contenu de l'élément.                                                                          |
| **Data provider**             | Connectez-vous à une source de données externe pour fournir du contenu en temps réel à l'élément.                                                   |
| **Data scrolling**            | Définissez si et comment l'élément doit faire défiler les lignes de données pendant la lecture.                                                     |
| **Default duration**          | Définissez la durée par défaut (en secondes) pour les éléments de la liste de lecture de l'élément (le cas échéant).                                |
| **Default transition effect** | Définissez une animation de transition par défaut lors du changement de contenu.                                                                    |
| **Flip**                      | Retournez le contenu de l'élément horizontalement ou verticalement.                                                                                 |
| **Font**                      | Spécifiez le style et la taille de police pour l'affichage du contenu textuel.                                                                      |
| **Identification**            | Attribuez un nom ou un identifiant unique à l'élément dans la page.                                                                                 |
| **Play list options**         | Contrôlez la façon dont les éléments de la liste de lecture sont cyclés ou lus en séquence.                                                         |
| **Position**                  | Définissez la position exacte (haut, gauche) de l'élément sur la page.                                                                              |
| **Proof of play**             | Activez la journalisation pour la preuve de lecture afin de suivre quand et à quelle fréquence l'élément est affiché.                               |
| **Property bindings**         | Liez les propriétés de l'élément à des sources de données externes pour un comportement dynamique.                                                  |
| **Reflection**                | Ajoutez un effet de reflet au contenu de l'élément.                                                                                                 |
| **Rotation**                  | Faites pivoter l'élément selon un angle spécifié.                                                                                                   |
| **Rules**                     | Définissez un comportement automatique via des règles, basé sur des conditions prédéfinies (par exemple, masquer/afficher en fonction des données). |
| **Shadow**                    | Ajoutez un effet d'ombre au contenu de l'élément.                                                                                                   |
| **Size**                      | Définissez la largeur et la hauteur de l'élément.                                                                                                   |
| **Skew**                      | Inclinez le contenu de l'élément selon des angles spécifiques.                                                                                      |
| **Text alignment**            | Définissez l'alignement horizontal et vertical du texte dans l'élément.                                                                             |
| **Transition effect**         | Définissez une animation d'entrée ou un effet visuel lorsque l'élément apparaît.                                                                    |
| **Transparency**              | Définissez le niveau de transparence (opacité) de l'élément.                                                                                        |
| **Visibility**                | Contrôlez si l'élément (ou son contenu) est affiché ou masqué pendant la lecture.                                                                   |

***

### **Notes:**

* Ces propriétés permettent un **contrôle précis** sur l'apparence et le comportement des éléments de page.
* **Property bindings** et **connexions aux fournisseurs de données** permettent des mises à jour dynamiques en temps réel.
* Pour les éléments utilisant des listes de lecture (images, vidéos), **playlist options** et **default duration** définissent la façon dont les éléments se succèdent.
