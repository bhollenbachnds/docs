Les liaisons de propriétés vous permettent de lier dynamiquement **les propriétés d'éléments à des valeurs provenant d'un Data Provider**. Vous trouverez ci-dessous une liste des propriétés prises en charge, ainsi que leurs types de valeurs et formats attendus.

***

### **Nom de la propriété, Type et Valeurs possibles**

| **Nom de la propriété** | **Type**             | **Valeurs possibles**                                                                                         |
| ----------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Visible**             | Booléen              | `true` (ou `t`, `1`, `-1`, `yes`), `false` (ou `f`, `0`, `no`)                                                |
| **Left**                | Entier               | Valeur numérique (positive ou négative)                                                                       |
| **Top**                 | Entier               | Valeur numérique (positive ou négative)                                                                       |
| **Width**               | Entier               | Valeur numérique (supérieure ou égale à 0)                                                                    |
| **Height**              | Entier               | Valeur numérique (supérieure ou égale à 0)                                                                    |
| **Background Color**    | Couleur              | `#FF00FF` (hex RGB), `#AAFF00FF` (hex ARGB), `12002010` (valeur System.Drawing.Color), `red` (couleur nommée) |
| **Foreground Color**    | Couleur              | Mêmes formats que Background Color                                                                            |
| **Font Name**           | Chaîne de caractères | Nom de police, par ex., `Arial`, `Courier`                                                                    |
| **Font Bold**           | Booléen              | `true` (ou `t`, `1`, `-1`, `yes`), `false` (ou `f`, `0`, `no`)                                                |
| **Font Size**           | Entier               | Valeur numérique (supérieure ou égale à 1)                                                                    |
| **Angle**               | Entier               | Valeur numérique (0 à 359 degrés)                                                                             |
| **Volume Level**        | Entier               | Valeur numérique (0 à 100)                                                                                    |
| **Fill Color**          | Couleur              | Mêmes formats que Background Color                                                                            |
| **Right to Left**       | Booléen              | `true` (ou `t`, `1`, `-1`, `yes`), `false` (ou `f`, `0`, `no`)                                                |

***

### **Notes:**

* **Les valeurs booléennes** peuvent être exprimées de plusieurs façons pour plus de flexibilité (par ex., `true`, `yes`, `1`).
* **Les valeurs de couleur** acceptent une variété de formats :
  * Hexadécimal RGB (par ex., `#FF00FF`)
  * Hexadécimal ARGB (par ex., `#AAFF00FF`)
  * Valeur entière représentant une couleur système (par ex., `12002010`)
  * Couleur système nommée (par ex., `red`)
* **Les noms de polices** doivent correspondre aux polices disponibles sur le système.
* **Volume Level** va de `0` (muet) à `100` (volume maximum).
* **Angle** spécifie la rotation en degrés.
