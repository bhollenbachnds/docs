Ces propriétés déterminent **l'alignement horizontal et vertical** du texte à l'intérieur de votre élément.

### **Alignement**

* **Horizontal**\
  Options: **Gauche**, **Centré**, **Droite**, **Justifié**

* **Vertical**\
  Options: **Haut**, **Centré**, **Bas**

***

### **Remarques**

* **Les options d'alignement** peuvent être **indisponibles** (invisibles) dans certaines situations selon le type et la configuration de l'élément.

* Si **le dimensionnement automatique** est activé pour l'élément, les paramètres d'alignement influencent la façon dont le redimensionnement s'effectue :
  * **Comportement par défaut** : l'élément se redimensionne du côté droit.
  * Si **l'alignement horizontal** est défini sur **Droite**, l'élément se redimensionnera depuis la **gauche** côté.
  * Si **Alignement horizontal** est défini sur **Milieu**, l'élément sera redimensionné de manière égale des deux côtés.
  * **Alignement vertical** se comporte de manière similaire, affectant le redimensionnement haut/bas.

* Pour **Éléments de texte défilant**, le comportement de l'alignement dépend de la **direction de défilement** :
  * Si **Droite à gauche** ou **Gauche à droite** est choisi, **Alignement horizontal** est ignoré.
  * Si **Haut vers le bas** ou **Bas vers le haut** est choisi, **Alignement vertical** est ignoré.
