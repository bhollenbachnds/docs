Lorsqu'un élément est connecté à une **source de données**, **les propriétés de défilement des données** contrôlent la façon dont l'élément fait défiler les **données en temps réel**. Cela vous permet d'afficher **plusieurs enregistrements** lorsque plus de données sont disponibles qu'il n'en peut être affiché à la fois.

***

### Défilement des données

* **Utiliser le défilement des données**\
  Activer ou désactiver le défilement des données en temps réel pour l'élément.

***

### Taille du pas de défilement

* **Taille du pas de défilement**\
  Définit **le nombre de lignes** à avancer à chaque fois qu'une action de défilement se produit.\
  Example:
  * Si défini sur `3`, et que l'élément commence à la ligne `2`, les prochaines lignes affichées seront `5`, `8`, `11`, etc.

**Important** :\
Lorsque **plusieurs éléments** sont utilisés dans une ligne d'un élément tableau, **tous les éléments doivent partager le même Scrolling Step Size** pour garantir un défilement synchronisé.

***

### Scroll Mode

Définit **comment et quand** le défilement a lieu. Vous pouvez choisir parmi les options suivantes :

| Option                                           | Description                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Scroll by Using General Page Scroll Interval** | L'**intervalle d'actualisation des données de page** contrôle la vitesse de défilement. <br />Utilisez cette option pour garantir que **tous les éléments** de la page défilent **en synchronisation** et à la même vitesse. <br />*(Remarque : Si l'élément fait partie d'une **ligne de tableau**, c'est la seule option disponible.)* |
| **Scroll by using Play List Options**            | Les **options de liste de lecture** de l'élément contrôlent la vitesse de défilement, vous permettant de **personnaliser la fréquence de défilement** pour chaque élément de la liste de lecture.                                                                                                                                        |
| **Scroll in Sync with...**                       | L'élément va **défiler en synchronisation** avec un autre élément. <br />Spécifiez l'élément principal dans la propriété **Element**. <br />Utilisez cette option pour **lier le défilement** entre plusieurs éléments.                                                                                                                  |

***

### 💡 **Conseil**

L'utilisation de **Scroll in Sync with...** vous permet de **synchroniser** le défilement d'un élément avec un autre.\
**Exemple** : Si vous avez un élément vidéo qui lit une série de clips et que vous souhaitez que les données associées (par ex., sous-titres, statistiques) défilent au même rythme, vous pouvez les synchroniser. Lorsque la vidéo avance, l'autre élément défilera également automatiquement.

***

### Remarques

* Le défilement des données est **uniquement disponible** si l'élément est connecté à une **source de données**.
* **Les données affichées** sont toujours déterminées par la combinaison de :
  * **Propriété Row** (ligne de départ)
  * **Scrolling Step Size** (nombre de lignes à ignorer à chaque cycle)
* Exemple de flux de défilement :
  * Si **Row = 2** et **Scroll Step Size = 3**, la séquence de défilement sera :\
    `Row 2` → `Row 5` → `Row 8` → `Row 11` → ... jusqu'à ce que la fin de la source de données soit atteinte, puis elle **revient au début** à la ligne `2`.
