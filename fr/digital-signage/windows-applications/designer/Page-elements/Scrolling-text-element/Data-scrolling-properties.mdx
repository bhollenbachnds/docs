Lorsqu'un **scrolling text element** est connecté à une **data source**, ces propriétés définissent comment les **real-time data** défilent. **Data scrolling** parcourt les lignes de données en boucle, tandis que le **visual scrolling** détermine comment le texte se déplace sur l'écran.

***

## **Paramètres de défilement des données**

### **Use Data Scrolling**

* Active ou désactive le **scrolling through real-time data** dans l'élément.

### **Scrolling Step Size**

* Définit combien de **lignes** l'élément avance à chaque actualisation des données.
* Example:
  * Si **Row = 2** et **Scrolling Step Size = 3**, l'élément affichera **Row 2, Row 5, Row 8**, et ainsi de suite.
  * Une fois toutes les lignes disponibles affichées, l'élément **revient au début** à la Row 2.

**Important:**

* Lorsque plusieurs éléments avec **data scrolling** sont placés dans une **table row**, ils **doivent** avoir le **même Scrolling Step Size** pour rester synchronisés.

***

## **Défilement de données alternatif (pour les éléments de tableau uniquement)**

Lorsqu'un **scrolling text element** fait partie d'une **table row**, des options supplémentaires sont disponibles :

### **Number of Rows**

* Limite le défilement aux **N premières lignes** de la source de données.
* Utile pour afficher uniquement les **actualités les plus récentes** d'un **flux RSS** ou d'une base de données.

**Tip:**

* Si vous avez besoin d'afficher uniquement les **principales actualités**, utilisez **Number of Rows** pour limiter le défilement aux dernières entrées.

***

## **Notes supplémentaires**

* **Data scrolling** les propriétés ne sont disponibles que si l'élément est **connecté à une source de données**.
* Les données affichées sont déterminées par :
  * **Propriété Row** (position de départ).
  * **Scroll Step Size** (nombre de lignes à ignorer par actualisation).
* Le processus de défilement **boucle** à travers toutes les lignes disponibles et **redémarre** lorsqu'il atteint la fin.
