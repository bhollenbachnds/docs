Lorsqu'un **élément de texte défilant** est connecté à une **source de données**, ces propriétés définissent comment les **données en temps réel** défilent. **Défilement des données** parcourt les lignes de données en boucle, tandis que le **défilement visuel** détermine comment le texte se déplace sur l'écran.

***

## **Paramètres de défilement des données**

### **Utiliser le défilement des données**

* Active ou désactive le **défilement à travers les données en temps réel** dans l'élément.

### **Taille du pas de défilement**

* Définit combien de **lignes** l'élément avance à chaque actualisation des données.
* Example:
  * Si **Row = 2** et **Scrolling Step Size = 3**, l'élément affichera **Row 2, Row 5, Row 8**, et ainsi de suite.
  * Une fois toutes les lignes disponibles affichées, l'élément **revient au début** à la Row 2.

**Important:**

* Lorsque plusieurs éléments avec **défilement des données** sont placés dans une **ligne de tableau**, ils **doivent** avoir la **même taille de pas de défilement** pour rester synchronisés.

***

## **Défilement alternatif des données (pour les éléments de tableau uniquement)**

Lorsqu'un **élément de texte défilant** fait partie d'une **ligne de tableau**, des options supplémentaires sont disponibles :

### **Nombre de lignes**

* Limite le défilement aux **N premières lignes** de la source de données.
* Utile pour afficher uniquement les **actualités les plus récentes** d'un **flux RSS** ou d'une base de données.

**Tip:**

* Si vous avez besoin d'afficher uniquement les **principales actualités**, utilisez **Nombre de lignes** pour limiter le défilement aux dernières entrées.

***

## **Notes supplémentaires**

* **Le défilement des données** Les propriétés ne sont disponibles que si l'élément est **connecté à une source de données**.
* Les données affichées sont déterminées par :
  * **Propriété Row** (position de départ).
  * **Taille du pas de défilement** (combien de lignes ignorer par actualisation).
* Le processus de défilement **boucle** à travers toutes les lignes disponibles et **redémarre** en atteignant la fin.
