L'élément **Rich Text** permet l'affichage de texte formaté, notamment en gras, en italique et souligné, ainsi que des styles avancés tels que **les ombres, les rotations et la transparence**. Cet élément peut s'intégrer à des **sources de données externes** pour des mises à jour de contenu en temps réel et prend en charge le collage direct de texte depuis **Microsoft Word**.

***

### **Aperçu des propriétés**

| **Section de propriété**        | **Description**                                                                                                                                                  |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Alternate Options**           | Définit la façon dont l'élément bascule entre les éléments de la playlist.                                                                                       |
| **Background Color**            | Définit la couleur d'arrière-plan de l'élément.                                                                                                                  |
| **Blinking**                    | Configure un effet de clignotement pour l'élément.                                                                                                               |
| **Border**                      | Ajuste les paramètres de bordure de l'élément.                                                                                                                   |
| **Data Provider**               | Connecte l'élément à une source de données externe pour du contenu en temps réel.                                                                                |
| **Data Scrolling**              | Définit la façon dont l'élément fait défiler les données en temps réel.                                                                                          |
| **Data Source Text Conversion** | Spécifie la façon dont le texte multiligne provenant de sources externes est traité.                                                                             |
| **Default Duration**            | Définit la durée d'affichage des éléments de la playlist.                                                                                                        |
| **Default Transition Effect**   | Définit l'effet de transition par défaut pour les changements de contenu.                                                                                        |
| **Flip**                        | Retourne le contenu horizontalement ou verticalement.                                                                                                            |
| **Font**                        | Configure les styles de police, les tailles et les couleurs pour l'affichage du texte.                                                                           |
| **Identification**              | Attribue un identifiant unique à l'élément dans la page.                                                                                                         |
| **Play List**                   | Gère une liste d'éléments de texte enrichi à afficher.                                                                                                           |
| **Play List Options**           | Définit la façon dont les éléments de la playlist sont lus.                                                                                                      |
| **Advanced Editor**             | Fournit des options supplémentaires telles que **les connexions aux fournisseurs de données, les variables du viewer et l'automatisation basée sur des règles**. |
| **Position**                    | Spécifie l'emplacement de l'élément sur la page.                                                                                                                 |
| **Proof of Play**               | Enregistre les données de lecture à des fins d'analyse et de vérification.                                                                                       |
| **Property Bindings**           | Permet aux sources de données externes de mettre à jour des propriétés spécifiques en temps réel.                                                                |
| **Reflection**                  | Affiche le texte avec un effet de reflet.                                                                                                                        |
| **Rotation**                    | Fait pivoter l'élément selon un angle spécifié.                                                                                                                  |
| **Règles**                      | Automatise le comportement de l'élément en fonction de conditions prédéfinies.                                                                                   |
| **Ombre**                       | Applique des effets d'ombre au texte.                                                                                                                            |
| **Taille**                      | Définit la largeur et la hauteur de l'élément.                                                                                                                   |
| **Inclinaison**                 | Incline le texte selon un angle.                                                                                                                                 |
| **Alignement du texte**         | Définit l'alignement horizontal et vertical du texte.                                                                                                            |
| **Transparence**                | Ajuste le niveau de transparence de l'élément.                                                                                                                   |
| **Visibilité**                  | Détermine si et quand l'élément doit être visible.                                                                                                               |

***

### **Remarques**

* Cette section couvre uniquement **les propriétés spécifiques au Rich Text**. Pour les **propriétés générales des éléments**, référez-vous à la **Propriétés des éléments de page** section.
* **Les mises à jour de contenu en temps réel** sont prises en charge via **l'intégration de fournisseur de données**.
* L'**Advanced Editor** permet aux utilisateurs d'appliquer des **mises en forme de texte complexes, des mises à jour de texte pilotées par les données et des comportements basés sur des règles**.
