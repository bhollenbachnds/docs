Le **PDF Document Reader** vous permet de **intégrer et afficher des fichiers PDF** dans votre présentation. Les PDF peuvent être affichés en **taille originale** ou **redimensionnés** pour s'adapter à votre mise en page. De plus, les pages peuvent être **défilées automatiquement** avec une durée définie.

***

## **Fonctionnalités clés et limitations**

* **Prend en charge la plupart des formats PDF** (sauf les **modèles 3D**).
* **Prise en charge du contenu dynamique** en se connectant à une **source de données externe**.
* **Effets et transitions** peuvent être appliqués pour des changements visuels plus fluides.

***

## **Aperçu des propriétés**

| **Section de propriété**        | **Description**                                                                             |
| ------------------------------- | ------------------------------------------------------------------------------------------- |
| **Alignment**                   | Ajustez **l'alignement horizontal et vertical** du contenu.                                 |
| **Alternate Options**           | Configurez la façon dont l'élément bascule entre les **éléments de la playlist**.           |
| **Background Color**            | Définissez une **couleur d'arrière-plan** pour l'élément PDF.                               |
| **Border**                      | Définissez une **bordure** autour de l'élément.                                             |
| **Data Provider**               | Connectez-vous à une **source de données externe** pour des mises à jour PDF en temps réel. |
| **Data Source Text Conversion** | Gérez la façon dont l'**élément gère le texte multiligne**.                                 |
| **Default Duration**            | Définissez une **durée d'affichage par défaut** pour les éléments de la playlist.           |
| **Default Transition Effect**   | Appliquez des **effets de transition entrants** au contenu.                                 |
| **Flip**                        | Retournez le **contenu horizontalement ou verticalement**.                                  |
| **Identification**              | Attribuez un **identifiant unique** à l'élément.                                            |
| **Play List**                   | Définissez **quels fichiers PDF** seront affichés.                                          |
| **Play List Options**           | Définissez **comment les éléments de la playlist** sont lus.                                |
| **Position**                    | Ajustez le **positionnement** sur la page.                                                  |
| **Proof of Play**               | Enregistrez la **preuve de diffusion** pour les rapports.                                   |
| **Property Bindings**           | Liez les propriétés à une **source de données externe**.                                    |
| **Reflection**                  | Ajoutez un **effet de reflet** au contenu.                                                  |
| **Rotation**                    | Faites pivoter l'**élément PDF selon un angle**.                                            |
| **Rules**                       | Définissez des **règles pour la visibilité automatisée**.                                   |
| **Size**                        | Définissez la **largeur et hauteur** de l'élément.                                          |
| **Inclinaison**                 | Appliquer **effets d'inclinaison** au contenu.                                              |
| **Transparence**                | Ajuster le **niveau de transparence** de l'élément.                                         |
| **Visibilité**                  | Contrôler si l'**élément est visible pendant la lecture**.                                  |

***

## **Notes supplémentaires**

* **Les PDFs peuvent être mis à jour dynamiquement** à l'aide d'une source de données externe.
* **Lecture et défilement** peuvent être automatisés à l'aide des **options de playlist**.
* **Transitions et effets de contenu** peuvent améliorer l'expérience d'affichage.

En utilisant le **PDF Document Reader**, vous pouvez intégrer de manière transparente **du contenu basé sur des documents** dans votre présentation avec **des mises à jour dynamiques et des transitions fluides**.
