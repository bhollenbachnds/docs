---
- title: Propriétés des étiquettes de séries de données
- description: Configurez les étiquettes de points de données pour une série de
    données de graphique, notamment la visibilité, la police et les couleurs, la
    position, le contenu des étiquettes et les paramètres de bordure dans
    l'assistant.
---

Les **propriétés des étiquettes** dans le **Data Series Wizard** définissent comment les **étiquettes des éléments de données** sont affichées dans votre graphique, notamment la **visibilité, le style, le contenu et le positionnement**.

***

## **Étiquettes**

| **Propriété**                                    | **Description**                                                                              |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| **Afficher les étiquettes de points de données** | **Activer/désactiver** l'affichage des étiquettes pour les points de données de votre série. |

***

## **Style**

| **Propriété**              | **Description**                                                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Police**                 | Affiche la **police et le style actuels** des étiquettes. Cliquez sur le bouton à côté de la zone de texte pour le modifier.                    |
| **Couleur de l'étiquette** | Sélectionnez la couleur du texte de l'étiquette. Les options incluent les **couleurs fixes, les dégradés, les textures et les motifs**.         |
| **Couleur d'arrière-plan** | Sélectionnez la **couleur d'arrière-plan** derrière le texte de l'étiquette. Prend en charge les couleurs unies, les dégradés, les motifs, etc. |

***

## **Position**

| **Propriété**                 | **Description**                                                                                                                                             |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Position**                  | Sélectionnez comment les étiquettes sont positionnées dans le graphique. Utilisez **Automatique** pour laisser le système décider de l'emplacement optimal. |
| **Intervalle des étiquettes** | Définissez l'intervalle (en pixels) entre deux étiquettes consécutives.                                                                                     |

***

## **Contenu**

| **Propriété**          | **Description**                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Contenu**            | Choisissez d'afficher uniquement les **étiquettes** ou les **étiquettes et les valeurs** ensemble.                        |
| **Format de valeur**   | Si des valeurs sont incluses, sélectionnez un **format** pour afficher ces valeurs (par exemple, devise, décimal).        |
| **Format d'étiquette** | Sélectionnez un **format** pour le texte de l'étiquette (par exemple, texte brut, mise en forme de chaîne personnalisée). |

***

## **Bordure**

| **Propriété**                          | **Description**                                                                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Afficher la bordure de l'étiquette** | **Activer/désactiver** une bordure autour des étiquettes.                                                                                  |
| **Largeur**                            | Définissez l'**épaisseur (en pixels)** de la bordure de l'étiquette.                                                                       |
| **Couleur de la bordure**              | Sélectionnez une couleur pour la bordure de l'étiquette. Prend en charge les **couleurs fixes, les dégradés, les textures et les motifs**. |

***

## **Remarques**

* Les étiquettes peuvent être entièrement personnalisées pour correspondre à vos **besoins en matière de design et d'image de marque**, notamment les **polices, les couleurs, les arrière-plans et les bordures**.
* L'**Intervalle des étiquettes** contrôle la **densité des étiquettes**, ce qui peut être utile pour les graphiques comportant de nombreux points de données.
* Si les **valeurs sont affichées**, les options de mise en forme garantissent que les données numériques sont présentées clairement (par exemple, en pourcentages, en devise).
* Le positionnement des étiquettes peut être laissé à l'**ajustement automatique**, garantissant que le graphique reste lisible sans réglage manuel.
