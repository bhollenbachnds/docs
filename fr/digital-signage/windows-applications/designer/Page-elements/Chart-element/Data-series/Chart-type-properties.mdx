Les **propriétés du type de graphique** dans le **Assistant de séries de données** définissent **la façon dont vos séries de données seront représentées visuellement** dans le graphique. Ces propriétés vous permettent de sélectionner le **type de graphique**, **nommer la série**, contrôler sa **visibilité**, et **l'affecter à un axe secondaire** si nécessaire.

***

## **Aperçu des propriétés**

| **Propriété**                             | **Description**                                                                                                                             |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Type de graphique**                     | Sélectionner le **type de graphique** pour afficher vos séries de données. Les exemples incluent **barres, courbes, secteurs, aires**, etc. |
|                                           | Lorsque vous choisissez un type, une **fenêtre d'aperçu** affiche un exemple visuel du graphique pour vous aider à décider.                 |
| **Série visible**                         | Activer ou désactiver cette option **activé/désactivé** pour afficher ou masquer la série de données dans le graphique final.               |
| **Nom de la série**                       | Saisir un **nom unique** pour identifier la série de données dans la **liste des séries** au sein de la configuration du graphique.         |
| **Titre de légende de la série**          | Ajouter un **titre descriptif** pour la série à afficher dans la **légende du graphique**.                                                  |
| **Ajouter la série à l'axe Y secondaire** | Affecter cette série à l'**axe Y secondaire**, utile pour comparer des séries de données avec des échelles différentes.                     |
|                                           | **Note:** Cette option n'est disponible que si le paramètre général du graphique **"Afficher l'axe Y secondaire"** est activé.              |

***

## **Notes clés**

* **Choisir le bon type de graphique** est crucial pour une visualisation des données claire et efficace.
* **Axe Y secondaire** aide à visualiser des ensembles de données ayant des plages de valeurs significativement différentes sur le même graphique.
* Vous pouvez gérer la **visibilité** des séries de manière dynamique, ce qui est utile lorsque vous souhaitez comparer uniquement certaines séries de données sans en supprimer d'autres.
* **Les titres de légende** facilitent la compréhension des graphiques pour les spectateurs, surtout lorsque plusieurs séries sont affichées.
