- title: Propriétés du fournisseur de données de la série de données
- description: Connectez une série de données de graphique à un fournisseur de
    données, sélectionnez les colonnes de données et d'étiquettes, et configurez
    les colonnes spéciales utilisées par les graphiques à bulles et boursiers.
---

Le **Propriétés du fournisseur de données** dans le **Assistant Série de données** définissent **comment la série de données se connecte à une source de données externe**, garantissant que votre graphique est alimenté par des **données en temps réel**.

***

## **Aperçu des propriétés**

| **Propriété**                              | **Description**                                                                                                                                                                                        |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Sélectionner un fournisseur de données** | Sélectionner un **fournisseur de données** (table, requête, procédure stockée, fichier XML, flux RSS, etc.) qui alimente la série de données.                                                          |
|                                            | Les fournisseurs de données sont définis **au niveau de la présentation** et sont disponibles pour tous les éléments. Vous pouvez créer un **nouveau fournisseur à la volée** via le bouton déroulant. |
| **Colonne de données**                     | Sélectionner la **colonne** du fournisseur de données qui contient les **valeurs de données principales** pour le graphique.                                                                           |
| **Colonne d'étiquette** (Facultatif)       | Sélectionner une **colonne** qui contient des **étiquettes** associées aux valeurs de données (par ex., noms de produits, dates).                                                                      |

***

## **Colonnes spéciales pour des types de graphiques spécifiques**

### **Colonnes du graphique à bulles**

Si **Graphique à bulles** est sélectionné comme type de graphique :

| **Colonne de bulles**          | **Description**                                                                                                                         |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Colonne de taille de bulle** | Sélectionner la colonne qui fournit la **taille de chaque bulle**, utilisée pour représenter une troisième dimension dans le graphique. |

***

### **Colonnes du graphique boursier**

Si **Graphique boursier** est sélectionné comme type de graphique :

| **Colonne boursière**   | **Description**                                          |
| ----------------------- | -------------------------------------------------------- |
| **Colonne Haute**       | Colonne contenant la **valeur boursière la plus haute**. |
| **Colonne Basse**       | Colonne contenant la **valeur boursière la plus basse**. |
| **Colonne d'ouverture** | Colonne contenant la **valeur boursière d'ouverture**.   |
| **Colonne de clôture**  | Colonne contenant la **valeur boursière de clôture**.    |

***

## **Points clés**

* **Fournisseurs de données** permettent une alimentation dynamique en données en temps réel pour des mises à jour en direct dans vos graphiques.
* La sélection de colonnes **lie des champs spécifiques** de vos données source au graphique pour la visualisation.
* Différents types de graphiques (par ex., Bulles, Boursier) nécessitent des **colonnes spécialisées** pour représenter correctement les données.
* Vous pouvez définir **de nouveaux fournisseurs de données directement** lors de la configuration de votre série de données pour plus de commodité.
