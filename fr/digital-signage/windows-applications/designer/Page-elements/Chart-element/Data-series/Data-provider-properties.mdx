Les **propriétés du Data Provider** dans le **Data Series Wizard** définissent **comment la série de données se connecte à une source de données externe**, garantissant que votre graphique est alimenté avec des **données en temps réel**.

***

## **Aperçu des propriétés**

| **Propriété**                | **Description**                                                                                                                                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Select Data Provider**     | Choisissez un **fournisseur de données** existant (table, requête, procédure stockée, fichier XML, flux RSS, etc.) qui alimente la série de données.                                                   |
|                              | Les fournisseurs de données sont définis **au niveau de la présentation** et sont disponibles pour tous les éléments. Vous pouvez créer un **nouveau fournisseur à la volée** via le bouton déroulant. |
| **Data Column**              | Sélectionnez la **colonne** du fournisseur de données qui contient les **valeurs de données principales** pour le graphique.                                                                           |
| **Label Column** (Optionnel) | Sélectionnez une **colonne** qui contient des **étiquettes** associées aux valeurs de données (par ex., noms de produits, dates).                                                                      |

***

## **Colonnes spéciales pour des types de graphiques spécifiques**

### **Colonnes du Bubble Chart**

Si **Bubble Chart** est sélectionné comme type de graphique :

| **Colonne Bubble**     | **Description**                                                                                                                         |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Bubble Size Column** | Sélectionnez la colonne qui fournit la **taille de chaque bulle**, utilisée pour représenter une troisième dimension dans le graphique. |

***

### **Colonnes du Stock Chart**

Si **Stock Chart** est sélectionné comme Type de graphique :

| **Colonne Stock**     | **Description**                                          |
| --------------------- | -------------------------------------------------------- |
| **Colonne Haute**     | Colonne contenant la **valeur boursière la plus haute**. |
| **Colonne Basse**     | Colonne contenant la **valeur boursière la plus basse**. |
| **Colonne Ouverture** | Colonne contenant la **valeur boursière d'ouverture**.   |
| **Colonne Clôture**   | Colonne contenant la **valeur boursière de clôture**.    |

***

## **Notes clés**

* **Fournisseurs de données** permettent une alimentation de données dynamique et en temps réel pour des mises à jour en direct dans vos graphiques.
* La sélection de colonnes **lie des champs spécifiques** de vos données source au graphique pour la visualisation.
* Différents types de graphiques (par ex., Bulle, Stock) nécessitent **des colonnes spécialisées** pour représenter correctement les données.
* Vous pouvez définir **de nouveaux fournisseurs de données directement** lors de la configuration de vos séries de données pour plus de commodité.
