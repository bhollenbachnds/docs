---
- title: Propriétés des labels d'axe
- description: Personnalisez les labels le long de chaque axe du graphique,
    notamment la police, la couleur, le mode de label automatique ou manuel,
    l'angle de rotation et l'intervalle entre les labels.
---

Ces propriétés définissent comment **labels** sont affichées le long de **X-axis, Y-axis, et Z-axis** d'un élément de graphique. Les labels aident les utilisateurs à comprendre ce que représente chaque axe et peuvent être entièrement personnalisées pour une clarté visuelle et une précision des données optimales.

***

## **Paramètres des labels**

| **Propriété**                 | **Description**                                                                                                                                    |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Police**                    | Spécifie la police et le style des labels d'axe. Cliquez sur le bouton situé à côté du champ de police pour ouvrir la boîte de dialogue de police. |
| **Couleur**                   | Définit la couleur des labels d'axe pour un meilleur contraste et une meilleure lisibilité.                                                        |
| **Mode de label automatique** | Détermine automatiquement le nombre de labels qui tiendront sur l'axe et ajuste leur placement de manière dynamique.                               |
| **Mode de label manuel**      | Définissez manuellement le nombre et le positionnement des labels pour un contrôle précis.                                                         |
| **Angle**                     | Définit l'angle de rotation (en degrés) des labels par rapport à l'axe. Utile pour adapter les textes longs.                                       |
| **Intervalle**                | Définit l'espace (en pixels) entre les labels consécutives en mode manuel.                                                                         |
| **Zones**                     | Lorsqu'il est activé, inclut des labels pour les valeurs minimale et maximale de l'axe.                                                            |
| **Valeur minimale de l'axe**  | Spécifie la valeur minimale de l'axe à laquelle une label doit être assignée.                                                                      |
| **Valeur maximale de l'axe**  | Spécifie la valeur maximale de l'axe à laquelle une label doit être assignée.                                                                      |

***

## **Intégration du fournisseur de données**

| **Propriété**                                               | **Description**                                                                                                                 |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Afficher le contenu du fournisseur de données sur l'axe** | Active ou désactive l'utilisation d'un fournisseur de données pour fournir les labels de manière dynamique.                     |
| **Fournisseur de données**                                  | Sélectionnez un fournisseur de données représentant une connexion à une source de données (par ex., base de données, XML, RSS). |
| **Colonne**                                                 | Sélectionnez la colonne dans le fournisseur de données sélectionné qui contient les valeurs des labels.                         |

> **Remarque** : Les fournisseurs de données sont définis au niveau de la **présentation** et sont disponibles pour une utilisation dans tous les éléments de votre présentation. Vous pouvez créer un nouveau fournisseur de données directement depuis cette fenêtre à l'aide du bouton adjacent. Consultez **Working with Data Providers** pour plus de détails.

***

## **Remarques**

* Toutes les propriétés décrites ci-dessus pour le **X-axis** sont également applicables au **Y-axis et Z-axis**.
* Lors de l'utilisation du **Mode de label automatique**, le système s'assure que les labels sont lisibles et bien espacées, en s'ajustant automatiquement en fonction de l'espace disponible.
* **Mode de label manuel** est idéal lorsqu'un contrôle précis sur les positions des labels est nécessaire, par exemple pour des intervalles fixes ou des catégories prédéfinies.
