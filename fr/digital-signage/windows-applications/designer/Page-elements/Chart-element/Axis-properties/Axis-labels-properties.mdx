Ces propriétés définissent comment **labels** sont affichés le long de **l'axe X, l'axe Y et l'axe Z** d'un élément de graphique. Les labels aident les utilisateurs à comprendre ce que représente chaque axe et peuvent être entièrement personnalisés pour une clarté visuelle et une précision des données optimales.

***

## **Paramètres des Labels**

| **Propriété**                | **Description**                                                                                                                                    |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Police**                   | Spécifie la police et le style des labels d'axe. Cliquez sur le bouton situé à côté du champ de police pour ouvrir la boîte de dialogue de police. |
| **Couleur**                  | Définit la couleur des labels d'axe pour un meilleur contraste et une meilleure lisibilité.                                                        |
| **Mode Label Automatique**   | Détermine automatiquement le nombre de labels qui tiendront sur l'axe et ajuste leur placement de manière dynamique.                               |
| **Mode Label Manuel**        | Définissez manuellement le nombre et le positionnement des labels pour un contrôle précis.                                                         |
| **Angle**                    | Définit l'angle de rotation (en degrés) des labels par rapport à l'axe. Utile pour adapter les textes longs.                                       |
| **Intervalle**               | Définit l'espace (en pixels) entre les labels consécutifs en mode manuel.                                                                          |
| **Zones**                    | Lorsqu'il est activé, inclut des labels pour les valeurs minimale et maximale de l'axe.                                                            |
| **Valeur Minimale de l'Axe** | Spécifie la valeur minimale de l'axe à laquelle un label doit être assigné.                                                                        |
| **Valeur Maximale de l'Axe** | Spécifie la valeur maximale de l'axe à laquelle un label doit être assigné.                                                                        |

***

## **Intégration du Fournisseur de Données**

| **Propriété**                                               | **Description**                                                                                                                 |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Afficher le Contenu du Fournisseur de Données sur l'Axe** | Active ou désactive l'utilisation d'un fournisseur de données pour fournir les labels de manière dynamique.                     |
| **Fournisseur de Données**                                  | Sélectionnez un fournisseur de données représentant une connexion à une source de données (par ex., base de données, XML, RSS). |
| **Colonne**                                                 | Choisissez la colonne dans le fournisseur de données sélectionné qui contient les valeurs des labels.                           |

> **Remarque**: Les fournisseurs de données sont définis au niveau de la **présentation** et sont disponibles pour une utilisation dans tous les éléments de votre présentation. Vous pouvez créer un nouveau fournisseur de données directement depuis cette fenêtre en utilisant le bouton adjacent. Consultez **Travailler avec les Fournisseurs de Données** pour plus de détails.

***

## **Remarques**

* Toutes les propriétés décrites ci-dessus pour l'**axe X** sont également applicables à l'**axe Y et à l'axe Z**.
* Lors de l'utilisation du **Mode Label Automatique**, le système s'assure que les labels sont lisibles et bien espacés, en s'ajustant automatiquement en fonction de l'espace disponible.
* **Mode Label Manuel** est idéal lorsqu'un contrôle précis sur les positions des labels est nécessaire, par exemple pour des intervalles fixes ou des catégories prédéfinies.
