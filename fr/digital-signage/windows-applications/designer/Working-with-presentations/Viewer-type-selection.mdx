Dans **PADS4 Designer**, vous pouvez sélectionner un **type de visionneuse spécifique** lors de la conception d'une présentation. Cela permet de s'assurer que vous n'utilisez que des éléments pris en charge par la visionneuse sélectionnée. Certains types de visionneuse peuvent **ne pas prendre en charge** certains éléments — la sélection d'un type de visionneuse **grisera** ces éléments non pris en charge pour éviter leur utilisation pendant le processus de conception.

***

## **Pourquoi sélectionner un type de visionneuse ?**

* **Éviter les erreurs de conception** en n'utilisant que des éléments pris en charge par la visionneuse.
* Assurez-vous que votre présentation **fonctionne correctement** sur la visionneuse cible sans problèmes de compatibilité.
* Améliorer **l'efficacité du flux de travail** en se concentrant uniquement sur les options disponibles.

***

## **Comment sélectionner un type de visionneuse**

1. **Cliquez sur l'onglet "Présentation"** dans la barre de ruban.

2. **Accédez à la section "Type de visionneuse".**

3. **Sélectionnez le type de visionneuse souhaité** dans la liste déroulante.
   * Exemples de types : Windows Viewer, HTML5 Viewer, Android Viewer, etc.

4. **Enregistrez votre présentation** :
   * Dans la **Content Library**, nommez votre présentation et cliquez sur **Enregistrer**.

***

## **Que se passe-t-il après la sélection ?**

* **Les éléments non pris en charge** pour le type de visionneuse sélectionné seront **grisés** dans la boîte à outils et les menus d'éléments.
* Vous **ne pourrez pas ajouter** ces éléments à votre présentation, évitant ainsi de futurs problèmes de lecture.
* Cela permet de s'assurer que votre présentation est **entièrement compatible** avec la visionneuse sur laquelle elle sera affichée.

***
