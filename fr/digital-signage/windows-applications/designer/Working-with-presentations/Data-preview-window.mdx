La **Fenêtre d'aperçu des données** en **mode Aperçu de la présentation** vous permet de **visualiser et vérifier** toutes les données récupérées depuis les **fournisseurs de données** utilisés dans votre présentation PADS4. Cela est particulièrement utile pour confirmer que les **connexions de données en direct** fonctionnent correctement et pour inspecter les données lors de la conception.

***

## **Ouverture de la fenêtre d'aperçu des données**

### Step-by-step:

1. **Démarrer** un **aperçu de la présentation** :
   * Accéder à **Vue** dans la barre de ruban.
   * Cliquez sur **Presentation** dans la **Preview** section.
   * La **fenêtre Presentation Preview** s'ouvrira et la présentation démarrera automatiquement.

2. Dans la **fenêtre Presentation Preview**, cliquez sur **Data Preview** dans la barre de ruban pour ouvrir la **fenêtre Data Preview**.

***

## **Aperçu de la fenêtre de prévisualisation des données**

### Ce que vous voyez :

* **Onglets pour chaque Data Provider** :\
  Chaque **Data Provider** utilisé dans la présentation aura son **propre onglet**. Cliquez sur les onglets pour basculer entre les Data Providers et afficher leurs données.

* **Données en direct** :\
  Vous voyez les **données réelles** renvoyées par chaque Data Provider, vous montrant ce qui sera affiché dans les éléments de votre présentation connectés à ces données.

***

## **Fonctions de la fenêtre de prévisualisation des données**

| **Fonction**   | **Description**                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Actualiser** | Recharge et met à jour les données pour **tous les Data Providers**. Cela vous permet de voir les données nouvellement récupérées en temps réel. |
| **Fermer**     | Ferme la fenêtre Data Preview.                                                                                                                   |

***

## **Cas d'utilisation de la prévisualisation des données**

* **Vérifier la connexion aux données**: Assurez-vous que les données provenant de sources externes (par ex., bases de données, services web, flux RSS) sont correctement récupérées.
* **Tester le contenu dynamique**: Vérifiez comment les données dynamiques apparaîtront dans les éléments de votre présentation.
* **Débogage**: Si des données sont manquantes ou incorrectes dans la présentation, utilisez cette fenêtre pour vérifier si la source de données renvoie les résultats attendus.
* **Mises à jour en direct**: Confirmez que les mises à jour de votre source de données sont reflétées lors de l'actualisation des données.
