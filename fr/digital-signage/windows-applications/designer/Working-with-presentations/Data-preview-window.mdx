La **fenêtre Data Preview** en **mode Presentation Preview** vous permet de **visualiser et vérifier** toutes les données récupérées depuis les **Data Providers** utilisés dans votre présentation PADS4. Cela est particulièrement utile pour confirmer que les **connexions de données en direct** fonctionnent correctement et pour inspecter les données lors de la conception.

***

## **Ouverture de la fenêtre Data Preview**

### Step-by-step:

1. **Démarrez** un **aperçu de présentation** :
   * Accédez à l'onglet **View** dans la barre de ruban.
   * Cliquez sur **Presentation** dans la section **Preview**.
   * La **fenêtre Presentation Preview** s'ouvrira et la présentation démarrera automatiquement.

2. Dans la **fenêtre Presentation Preview**, cliquez sur **Data Preview** dans la barre de ruban pour ouvrir la **fenêtre Data Preview**.

***

## **Aperçu de la fenêtre Data Preview**

### Ce que vous voyez :

* **Onglets pour chaque Data Provider** :\
  Chaque **Data Provider** utilisé dans la présentation aura son **propre onglet**. Cliquez sur les onglets pour basculer entre les Data Providers et afficher leurs données.

* **Données en direct** :\
  Vous voyez les **données réelles** renvoyées par chaque Data Provider, vous montrant ce qui sera affiché dans les éléments de votre présentation connectés à ces données.

***

## **Fonctions de la fenêtre Data Preview**

| **Fonction** | **Description**                                                                                                                                  |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Refresh**  | Recharge et met à jour les données pour **tous les Data Providers**. Cela vous permet de voir les données nouvellement récupérées en temps réel. |
| **Close**    | Ferme la fenêtre Data Preview.                                                                                                                   |

***

## **Cas d'utilisation de Data Preview**

* **Vérifier la connexion aux données** : Assurez-vous que les données provenant de sources externes (par exemple, bases de données, services web, flux RSS) sont correctement récupérées.
* **Tester le contenu dynamique** : Vérifiez comment les données dynamiques apparaîtront dans les éléments de votre présentation.
* **Débogage** : Si des données sont manquantes ou incorrectes dans la présentation, utilisez cette fenêtre pour vérifier si la source de données renvoie les résultats attendus.
* **Mises à jour en direct** : Confirmez que les mises à jour de votre source de données sont reflétées lors de l'actualisation des données.
