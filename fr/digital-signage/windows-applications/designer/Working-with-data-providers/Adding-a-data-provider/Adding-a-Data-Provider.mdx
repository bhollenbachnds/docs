Avant de connecter un **élément de présentation** à une **source de données en temps réel**, un **Fournisseur de données** doit être créé. Le **Assistant Fournisseur de données** simplifie ce processus en vous guidant à travers les étapes de configuration essentielles.

***

## **Étapes pour ajouter un fournisseur de données**

### **1. Ouvrir les paramètres du fournisseur de données**

* Accédez au **Menu Accueil**
* Cliquez sur **Fournisseurs de données**
* Cliquez sur **Ajouter…** pour démarrer l'**Assistant Fournisseur de données**

### **2. Suivre les étapes de l'assistant**

L'**Assistant Fournisseur de données** comprend les étapes suivantes :

#### **Choisir un type de fournisseur**

* Sélectionnez le **type de source** pour vos données en temps réel
* Les options incluent :
  * **Bases de données** (Microsoft SQL Server, MySQL, Oracle, etc.)
  * **Flux XML & RSS**
  * **Microsoft Excel**
  * **Fichiers texte & CSV**
  * **API Web & fichiers JSON**

#### **Paramètres généraux du fournisseur**

* Attribuez un **nom unique** au fournisseur
* Choisissez d'utiliser ou non le **PADS4 Data Server** pour la récupération en temps réel

#### **Paramètres de connexion du fournisseur**

* Entrez les paramètres de connexion spécifiques en fonction de la **source de données**
* Configurez les **identifiants d'authentification** (si requis)

#### **Réorganiser les données**

* Intervertissez les **lignes et colonnes** selon les besoins

#### **Ajout d'expressions régulières**

* Appliquez la **correspondance de modèles de texte** et les **remplacements de texte optionnels**

#### **Ajout de colonnes personnalisées**

* Définissez des **champs calculés** pour étendre le jeu de données

#### **Application de filtres & tri**

* Configurez des **conditions** pour affiner la **sélection des données**
* Définissez des **règles de tri**

#### **Paramètres avancés du fournisseur**

* Configurez des **sources de données de sauvegarde**
* Spécifiez les **options de récupération avancées**

***

## **Finalisation de la configuration du fournisseur de données**

* Cliquez sur **Terminer** pour finaliser la configuration
* Le Fournisseur de données est maintenant **disponible pour utilisation dans la présentation**

***

## **Notes supplémentaires**

* **Fournisseurs Data Vault** ne prennent pas en charge toutes les étapes de l'assistant (**seules les expressions, le tri et le filtrage sont disponibles**)
* **Aperçu** de votre Fournisseur de données pour **vérifier la récupération des données en temps réel**

### **Conseil**

Pour accélérer la configuration, cliquez sur **Terminer** après avoir complété les étapes **essentielles**.
