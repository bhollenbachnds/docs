Avant de connecter un **élément de présentation** à une **source de données en temps réel**, un **Data Provider** doit être créé. Le **Data Provider Wizard** simplifie ce processus en guidant les utilisateurs à travers les étapes de configuration essentielles.

***

## **Étapes pour ajouter un fournisseur de données**

### **1. Ouvrir les paramètres du fournisseur de données**

* Accédez au **Home Menu**
* Cliquez sur **Data Providers**
* Cliquez sur **Add…** pour démarrer le **Data Provider Wizard**

### **2. Suivre les étapes de l'assistant**

Le **Data Provider Wizard** comprend les étapes suivantes :

#### **Choisir un type de fournisseur**

* Sélectionnez le **type de source** pour vos données en temps réel
* Les options incluent :
  * **Bases de données** (Microsoft SQL Server, MySQL, Oracle, etc.)
  * **XML & RSS Feeds**
  * **Microsoft Excel**
  * **Fichiers texte & CSV**
  * **API web & fichiers JSON**

#### **Paramètres généraux du fournisseur**

* Attribuez un **nom unique** au fournisseur
* Choisissez si vous souhaitez utiliser **PADS4 Data Server** pour la récupération en temps réel

#### **Paramètres de connexion du fournisseur**

* Entrez les paramètres de connexion spécifiques en fonction de la **source de données**
* Configurez **informations d'identification** (si nécessaire)

#### **Réorganiser les données**

* Basculer **lignes et colonnes** selon les besoins

#### **Ajout d'expressions régulières**

* Appliquer **la correspondance de motifs de texte** et **des remplacements de texte optionnels**

#### **Ajout de colonnes personnalisées**

* Définir **des champs calculés** pour étendre le jeu de données

#### **Application de filtres et de tri**

* Configurer **des conditions** pour affiner **la sélection des données**
* Définir **des règles de tri**

#### **Paramètres avancés du fournisseur**

* Configurer **des sources de données de secours**
* Spécifier **des options de récupération avancées**

***

## **Finalisation de la configuration du fournisseur de données**

* Cliquer **Finish** pour terminer la configuration
* Le fournisseur de données est maintenant **disponible pour une utilisation dans la présentation**

***

## **Notes supplémentaires**

* **Data Vault Providers** ne prennent pas en charge toutes les étapes de l'assistant (**seules les expressions, le tri et le filtrage sont disponibles**)
* **Aperçu** de votre fournisseur de données pour **vérifier la récupération des données en temps réel**

### **Conseil**

Pour accélérer la configuration, cliquer sur **Finish** après avoir complété les étapes **essentielles**.
