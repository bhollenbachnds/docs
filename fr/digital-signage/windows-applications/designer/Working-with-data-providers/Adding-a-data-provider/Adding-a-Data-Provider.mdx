Avant de connecter un **élément de présentation** à un **source de données en temps réel**, un **Data Provider** doit être créé. Le **Data Provider Wizard** simplifie ce processus en guidant les utilisateurs à travers les étapes de configuration essentielles.

***

## **Étapes pour ajouter un fournisseur de données**

### **1. Ouvrir les paramètres du fournisseur de données**

* Accéder au **Home Menu**
* Cliquer sur **Data Providers**
* Cliquer sur **Add…** pour démarrer le **Data Provider Wizard**

### **2. Suivre les étapes de l'assistant**

Le **Data Provider Wizard** comprend les étapes suivantes :

#### **Choisir un type de fournisseur**

* Sélectionner le **type de source** pour vos données en temps réel
* Les options incluent :
  * **Bases de données** (Microsoft SQL Server, MySQL, Oracle, etc.)
  * **XML & RSS Feeds**
  * **Microsoft Excel**
  * **Fichiers texte & CSV**
  * **APIs web & fichiers JSON**

#### **Paramètres généraux du fournisseur**

* Attribuer un **nom unique** au fournisseur
* Choisir d'utiliser ou non le **PADS4 Data Server** pour la récupération en temps réel

#### **Paramètres de connexion du fournisseur**

* Saisir les paramètres de connexion spécifiques en fonction de la **source de données**
* Configurer les **identifiants d'authentification** (si nécessaire)

#### **Réorganiser les données**

* Permuter les **lignes et colonnes** selon les besoins

#### **Ajouter des expressions régulières**

* Appliquer la **correspondance de motifs de texte** et des **remplacements de texte optionnels**

#### **Ajouter des colonnes personnalisées**

* Définir des **champs calculés** pour étendre le jeu de données

#### **Appliquer des filtres & trier**

* Configurer des **conditions** pour affiner la **sélection des données**
* Définir des **règles de tri**

#### **Paramètres avancés du fournisseur**

* Configurer des **sources de données de sauvegarde**
* Spécifier les **options de récupération avancées**

***

## **Finaliser la configuration du fournisseur de données**

* Cliquer sur **Finish** pour terminer la configuration
* Le Data Provider est maintenant **disponible pour utilisation dans la présentation**

***

## **Notes supplémentaires**

* **Data Vault Providers** ne prennent pas en charge toutes les étapes de l'assistant (**seules les expressions, le tri et le filtrage sont disponibles**)
* **Aperçu** de votre Data Provider pour **vérifier la récupération des données en temps réel**

### **Conseil**

Pour accélérer la configuration, cliquer sur **Finish** après avoir complété les étapes **essentielles**.
