JSON (**JavaScript Object Notation**) est un format largement utilisé pour **stocker et échanger des données structurées**. Dans **PADS4**, les fichiers JSON peuvent être utilisés comme **sources de données** pour le contenu d'affichage dynamique en temps réel.

***

### **Étapes pour ajouter ou modifier une connexion de fichier JSON**

#### **1. Démarrer l'assistant de fournisseur de données**

* Ouvrez le **Assistant de fournisseur de données** en suivant les instructions dans **Ajouter un fournisseur de données** ou **Modifier un fournisseur de données**.
* Sélectionnez **Fichier JSON** comme type de fournisseur.

***

#### **2. Spécifier l'emplacement du fichier JSON**

* **Bibliothèque de contenu** → Sélectionnez cette option pour utiliser un fichier JSON stocké dans la **Bibliothèque de contenu PADS4**.
* **Nom de fichier** → Sélectionnez cette option pour utiliser un fichier JSON situé **en dehors de la bibliothèque de contenu**.
* Utilisez la fonction de navigation pour localiser et sélectionner le fichier JSON souhaité.

**Recommandation**:\
Si **vous n'utilisez pas de serveur de données PADS4**, il est préférable de stocker les fichiers JSON dans la **Bibliothèque de contenu PADS4**. Cela garantit une **synchronisation automatique** sur tous les ordinateurs connectés. Si un fichier JSON est **en dehors de la bibliothèque**, la distribution des fichiers doit être gérée manuellement.

***

#### **3. Configurer l'encodage du texte**

* Si le fichier JSON **nécessite un format d'encodage de texte spécifique**, sélectionnez l'option appropriée.

***

#### **4. Configurer le formatage des données**

* **Aplatir les données hiérarchiques** → Si la structure JSON contient plusieurs niveaux, cette option **aplatit les données imbriquées** dans un format tabulaire.
* **Inclure les noms de colonnes des niveaux parents** → Ajoute les noms des niveaux parents pour une **représentation hiérarchique plus claire**.
* **Créer des colonnes supplémentaires sans balises HTML** → Supprime les balises HTML des champs de texte et **les convertit en texte brut**.

Passez à l'étape suivante.

***

#### **5. Finalisation de la configuration du fichier JSON**

* Complétez la configuration du fournisseur de données.

***

## **Considérations importantes**

* **Utilisation du serveur de données PADS4**
  * Si un **serveur de données PADS4** est utilisé, assurez-vous que le fichier JSON **est accessible** depuis le **point de vue du serveur**.
  * Si **vous n'utilisez pas de serveur de données**, confirmez que **PADS4 Designer et les PADS4 Viewers** peuvent accéder à l'emplacement du fichier JSON spécifié.

* **Gestion des données JSON hiérarchiques**
  * Si la structure JSON contient plusieurs niveaux, l'activation de **Aplatir les données hiérarchiques** garantit une meilleure compatibilité.

En suivant ces étapes, **PADS4 peut intégrer et afficher de manière transparente les données basées sur JSON** dans les présentations d'affichage dynamique.
