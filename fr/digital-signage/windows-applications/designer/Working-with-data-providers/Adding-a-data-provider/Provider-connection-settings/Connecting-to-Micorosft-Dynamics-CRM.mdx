Le **type de fournisseur Microsoft Dynamics CRM** permet à **PADS4** de se connecter à Microsoft Dynamics CRM, spécifiquement la version **Dynamics 365 (online)**.

***

### **Étapes pour se connecter à Microsoft Dynamics CRM**

#### **1. Démarrer l'assistant de fournisseur de données**

* Ouvrir le **Data Provider Wizard** en suivant les instructions dans **Ajout d'un fournisseur de données** ou **Modification d'un fournisseur de données**.
* Sélectionner **Microsoft Dynamics CRM** comme **type de fournisseur**.

***

#### **2. Spécifier les paramètres de connexion**

* Saisir l'**URL complète** de votre **organisation Microsoft Dynamics CRM**.
* Cliquer sur **Authenticate** (si ce n'est pas déjà fait).
* Une fois authentifié, le champ **Authenticated As** affichera vos informations d'identification.

***

#### **3. Spécifier la région en ligne**

* Choisir la **région** où se trouve votre **serveur Microsoft Dynamics CRM**.
* Si vous n'êtes pas sûr, utilisez la fonction **Search** pour trouver la région correcte.

**Pour les serveurs proxy :**

* Si votre connexion passe par un **serveur proxy**, saisir les **paramètres d'authentification du serveur proxy**.

***

#### **4. Sélectionner l'organisation CRM**

* Choisir l'**organisation Microsoft Dynamics CRM** dans la liste des options disponibles.

***

#### **5. Sélectionner la vue de données**

* Choisir la **vue** qui contient les données dont vous avez besoin.
* Utiliser le bouton **Preview** pour voir un échantillon des données.
* Optionnellement, **filtrer la liste des vues** en saisissant une **sous-chaîne** pour affiner les résultats.

***

#### **6. Terminer la configuration**

* Cliquer sur **Next** pour continuer.
* Terminer la configuration en complétant le **Data Provider Wizard**.

***

### **Notes supplémentaires**

* **Seul Microsoft Dynamics 365 (online) est pris en charge.**
* Assurez-vous que votre **URL de l'organisation CRM** est correcte avant l'authentification.
* Si vous utilisez un **serveur proxy**, assurez-vous que les paramètres corrects sont appliqués.

Ce processus permet à **PADS4** de récupérer des **données en temps réel** depuis **Microsoft Dynamics CRM** et de les intégrer dans des présentations.
