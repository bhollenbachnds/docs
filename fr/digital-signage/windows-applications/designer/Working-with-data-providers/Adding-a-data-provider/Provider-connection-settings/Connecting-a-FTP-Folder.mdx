Le **fournisseur de dossier FTP** dans **PADS4** vous permet de vous connecter à un **serveur FTP distant** et d'accéder à ses fichiers pour les utiliser dans vos **présentations d'affichage dynamique**.

***

## **Étapes pour ajouter/modifier une connexion de dossier FTP dans PADS4**

### **1. Démarrer l'Assistant Fournisseur de Données**

* Ouvrir l'**Assistant Fournisseur de Données** en suivant les étapes dans **Ajouter un Fournisseur de Données** ou **Modifier un Fournisseur de Données**.
* Sélectionner **FTP Folder** comme **type de fournisseur**.

### **2. Spécifier le Serveur FTP et les Paramètres de Connexion**

* **Entrer l'URL FTP** (par ex., `ftp://yourserver.com/folder/`).
* **Authentification (si requise) :**
  * Entrer le **nom d'utilisateur** et le **mot de passe** si le serveur FTP requiert des identifiants de connexion.
* **Paramètres Proxy (si nécessaire) :**
  * Configurer un serveur proxy si requis pour l'accès à Internet.
* **Options de Sécurité :**
  * Activer **Use SSL** pour les connexions FTP sécurisées (**FTPS**).
  * Activer **Passive Mode** si le client doit utiliser un port supérieur à **1024** lors de la connexion au port **21**.

Cliquer sur **Next** pour continuer.

***

### **3. Configurer les Paramètres de Récupération des Dossiers et Fichiers**

* **Include Subfolders** si vous souhaitez récupérer des fichiers depuis les sous-répertoires.
* **Filtrage des Fichiers :**
  * Utiliser **Search Extension Restriction** pour filtrer les fichiers par type (par ex., `.jpg`, `.pdf`).
* **Options de Tri :**
  * Choisir les préférences de tri pour l'**ordre de récupération des fichiers**.

Cliquer sur **Next** pour continuer.

***

### **4. Terminer l'Assistant**

* Cliquer sur **Finish** pour finaliser la connexion FTP.
* Le **PADS4 Viewer** va maintenant récupérer les **fichiers** depuis le dossier FTP en temps réel.

***

## **Considérations Importantes**

* **Accès au PADS4 Data Server :**
  * Si vous utilisez un **PADS4 Data Server**, le dossier FTP **doit être accessible** depuis l'**emplacement du serveur**.
  * Si vous **n'utilisez pas de Data Server**, assurez-vous que chaque **PADS4 Designer et Viewer** dispose d'un **accès Internet** vers le **dossier FTP**.
* **Comportement du Tri :**
  * Les **options de tri** génériques dans les **dernières étapes** de l'assistant vont **remplacer** les paramètres de tri spécifiques au dossier.

En suivant ces étapes, vous pouvez **intégrer avec succès le contenu du dossier FTP** dans vos **présentations d'affichage dynamique PADS4**.
