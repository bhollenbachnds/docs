Le **fournisseur de dossier FTP** dans **PADS4** vous permet de vous connecter à un **serveur FTP distant** et d'accéder à ses fichiers pour les utiliser dans vos **présentations d'affichage dynamique**.

***

## **Étapes pour ajouter/modifier une connexion de dossier FTP dans PADS4**

### **1. Démarrer l'assistant de fournisseur de données**

* Ouvrez le **Data Provider Wizard** en suivant les étapes dans **Ajout d'un fournisseur de données** ou **Modification d'un fournisseur de données**.
* Sélectionnez **FTP Folder** comme **type de fournisseur**.

### **2. Spécifier le serveur FTP et les paramètres de connexion**

* **Entrez l'URL FTP** (par ex., `ftp://yourserver.com/folder/`).
* **Authentification (si requise) :**
  * Entrez le **nom d'utilisateur** et le **mot de passe** si le serveur FTP nécessite des identifiants de connexion.
* **Paramètres proxy (si nécessaire) :**
  * Configurez un serveur proxy si nécessaire pour l'accès à Internet.
* **Options de sécurité :**
  * Activez **Use SSL** pour les connexions FTP sécurisées (**FTPS**).
  * Activez **Passive Mode** si le client doit utiliser un port supérieur à **1024** lors de la connexion au port **21**.

Cliquez sur **Next** pour continuer.

***

### **3. Configurer les paramètres de dossier et de récupération de fichiers**

* **Include Subfolders** si vous souhaitez récupérer des fichiers depuis des sous-répertoires.
* **Filtrage de fichiers :**
  * Utilisez **Search Extension Restriction** pour filtrer les fichiers par type (par ex., `.jpg`, `.pdf`).
* **Options de tri :**
  * Sélectionnez les préférences de tri pour l'**ordre de récupération des fichiers**.

Cliquez sur **Next** pour continuer.

***

### **4. Terminer l'assistant**

* Cliquez sur **Finish** pour finaliser la connexion FTP.
* Le **PADS4 Viewer** va maintenant récupérer les **fichiers** depuis le dossier FTP en temps réel.

***

## **Considérations importantes**

* **Accès au PADS4 Data Server :**
  * Si vous utilisez un **PADS4 Data Server**, le dossier FTP **doit être accessible** depuis l'**emplacement du serveur**.
  * Si **not using a Data Server**, ensure that each **PADS4 Designer and Viewer** has **internet access** to the **FTP folder**.
* **Sorting Behavior:**
  * Generic **sorting options** in the **last steps** of the wizard will **override** folder-specific sorting settings.

By following these steps, you can **successfully integrate FTP folder content** into your **PADS4 digital signage presentations**.
