Le **Cognimatics feed provider** permet l'intégration avec les **Cognimatics devices** pour les **audience measurement data**, telles que le **people counting**, **queue monitoring**, et **demographics analysis**.

***

## **Étapes pour ajouter ou modifier un Cognimatics Data Provider**

### **1. Démarrer le Data Provider Wizard**

* Suivez les étapes dans **Adding a Data Provider** ou **Editing a Data Provider**.
* Choisissez **Cognimatics** comme type de fournisseur.

### **2. Configurer les paramètres de connexion Cognimatics**

* Entrez l'**HTTP Address (IP Address)** de l'**Cognimatics application**.
* Vous pouvez également spécifier une **manual URL** avec tous les paramètres.

### **3. Sélectionner la source active**

* Choisissez la **installed and active source** dans la liste.
* Seulement **une source** peut être active à la fois.
* La sélection d'une **inactive source** entraînera une **404 error** lors du test.

### **4. Sélectionner le type de données : Temps réel ou Période**

#### **Real-Time Data**

* Affiche le **current people count** entrant ou sortant d'un lieu.

#### **Period-Based Data**

* Récupère les **statistical results** pour une période spécifique :

| Period Option | Description                                |
| ------------- | ------------------------------------------ |
| **None**      | Aucune plage de temps n'est appliquée.     |
| **Today**     | Données pour **aujourd'hui** seulement.    |
| **Hier**      | Données pour **hier** seulement.           |
| **Manuel**    | Sélection de plage de dates personnalisée. |

***

## **Considérations importantes**

* **Assurez-vous que la source correcte est sélectionnée :**
  * Si une **source inactive** est sélectionnée, le bouton **Aperçu** renverra une erreur **404**.

* **Vérifiez l'accès réseau :**
  * Si vous utilisez **PADS4 Data Server**, assurez-vous que le **flux Cognimatics** est **accessible** depuis le **réseau du serveur**.
  * Si vous n'utilisez **pas** de **Data Server**, chaque **PADS4 Viewer** doit avoir un **accès direct** au flux Cognimatics.

* **Consulter la documentation Cognimatics :**
  * Pour **les descriptions détaillées des champs** et **les configurations des appareils**, référez-vous à **la documentation officielle de Cognimatics**.

***

## **Dépannage**

* **Aucune donnée n'apparaît ?**
  * Vérifiez que **l'adresse HTTP/IP** est correcte.
  * Assurez-vous que **l'appareil Cognimatics** est allumé et actif.
  * Vérifiez si **la bonne source** est sélectionnée.

* **Valeurs de données inattendues ?**
  * Confirmez que **la plage de temps sélectionnée** correspond aux données attendues.
  * Si vous utilisez le **Mode Temps Réel**, assurez-vous que le flux de données est en cours de mise à jour.

***

En configurant un **flux de données Cognimatics** dans **PADS4**, les entreprises peuvent **analyser le flux de clients, les temps d'attente et les données démographiques** en **temps réel**, optimisant ainsi leur **contenu d'affichage dynamique et leurs opérations**.
