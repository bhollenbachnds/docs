---
- title: Connexion d'un Microsoft Exchange Server
- description: Connectez PADS4 à un fournisseur de données Microsoft Exchange
    Server pour récupérer des données de calendrier, de boîte de réception, de
    contacts ou de dossiers publics pour des présentations en direct.
---

Le **Microsoft Exchange Server** fournisseur dans **PADS4** vous permet de vous connecter à **Microsoft Exchange Servers** (Office 2010 ou 2007 SP1) pour récupérer des **données de calendrier, de boîte de réception ou de contacts**.

***

### **Étapes pour ajouter ou modifier une connexion Microsoft Exchange Server**

#### **1. Démarrer l'Assistant Fournisseur de données**

* Ouvrir le **Data Provider Wizard** dans **PADS4**.
* Suivre les étapes pour **Ajouter un fournisseur de données** ou **Modifier un fournisseur de données**.
* Sélectionner **Microsoft Exchange Server** comme **type de fournisseur**.

***

#### **2. Configurer les paramètres de connexion**

* **Sélectionner la version de Microsoft Exchange Server**
  * Sélectionner la **version d'Exchange Server** appropriée parmi les options disponibles.
* **Sélectionner la configuration automatique ou manuelle**

  * **Automatique**:
    * Saisir l'**adresse e-mail** d'un **compte Exchange** valide.
  * **Manuel**:
    * Saisir l'**URL du serveur Exchange** pour établir une connexion.

  **Exemple d'URL :**

  ```
  https://YourSmallBusinessServer/EWX/Exchange.asmx
  ```
* **Saisir les identifiants de connexion**
  * Fournir un **nom d'utilisateur, un mot de passe et un domaine** d'un compte Exchange Server valide.
* **Accéder à la boîte aux lettres d'un autre utilisateur (facultatif)**
  * Saisir une **adresse e-mail** pour récupérer les données de la boîte aux lettres d'un autre utilisateur.
* **Emprunter l'identité d'un autre utilisateur (facultatif)**
  * Saisir une **adresse e-mail** pour emprunter l'identité d'un autre utilisateur.

Cliquer sur **Suivant** pour continuer.

***

#### **3. Sélectionner la source de données à laquelle se connecter**

* **Calendrier**
  * Récupère les données du calendrier.
  * Optionnellement, activer **Inclure le texte du message** pour récupérer les détails de l'événement.
  * *Note:* La récupération du corps du message **peut entraîner des problèmes de performances**.
* **Boîte de réception**
  * Récupère les e-mails de la **boîte de réception**.
  * Optionnellement, spécifier :
    * Un **(sous-)dossier** spécifique à partir duquel récupérer les e-mails.
    * **Inclure le texte du message** (pour le corps de l'e-mail).
* **Contacts**
  * Récupère la liste de contacts du compte Exchange.
* **Dossiers publics**
  * Accéder aux **dossiers publics** utilisés pour les informations partagées au sein d'une organisation.
  * *Note:* Les dossiers publics n'ont pas d'**adresse SMTP** et sont accessibles via l'**API EWS**.
* **Calendrier des ressources**
  * Récupère les **données de ressources de salles et de réunions**.
  * Spécifier **une ou plusieurs adresses e-mail** pour accéder à plusieurs calendriers de ressources.
  * Optionnellement, activer **Inclure le texte du message** pour récupérer les détails.
* **Disponibilité des utilisateurs**
  * Récupère le **statut libre/occupé** des utilisateurs.
  * Spécifier **une ou plusieurs adresses e-mail** pour obtenir des données de disponibilité fusionnées.

***

#### **4. Définir la plage de temps pour la récupération des données**

* **Aujourd'hui**
  * Récupère les données du **planning d'aujourd'hui**.
  * Optionnellement, appliquer un **décalage** en jours.
* **Maintenant**
  * Récupère les données à partir de la **date et heure actuelles**.
  * Optionnellement, spécifier un **décalage avant ou après** l'heure actuelle.
* **Date et heure**
  * Récupère les données pour une **période fixe**.
* **Prédéfini**
  * Sélectionner une période prédéfinie :
    * **Cette semaine**
    * **La semaine prochaine**
    * **Ce mois-ci**

**Remarque importante :**

* La récupération de données pour des **longues périodes** peut entraîner des **problèmes de performances** en raison de grandes quantités de données stockées.
* Utiliser des **filtres** ou **limiter le nombre de lignes** pour éviter une récupération excessive de données.

Cliquer sur **Suivant** pour continuer.

***

#### **5. Finaliser la configuration**

* Suivre les étapes restantes dans le **Data Provider Wizard**.
* Cliquer sur **Terminer** pour finaliser la configuration.

***

### **Notes supplémentaires**

* **Vous utilisez un PADS4 Data Server ?**
  * Assurez-vous que le **Exchange Server URL** est **accessible depuis le PADS4 Server**.
* **Vous n'utilisez pas de PADS4 Data Server ?**
  * Assurez-vous que **PADS4 Designer** (pour la prévisualisation) et tous les **PADS4 Viewers** peuvent accéder au Exchange Server.
* **Éviter les chargements de données volumineux**
  * Lors de la récupération de **longues périodes de données**, utilisez des filtres pour limiter l'utilisation de la mémoire.
