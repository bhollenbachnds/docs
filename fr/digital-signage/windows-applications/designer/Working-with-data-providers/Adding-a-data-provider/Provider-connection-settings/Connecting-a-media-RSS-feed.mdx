Media RSS (**Rich Site Summary**) étend le format standard de **flux web RSS** pour prendre en charge le contenu multimédia, tel que **des vidéos et des images**.

***

### **Étapes pour ajouter ou modifier une connexion de flux Media RSS**

#### **1. Démarrer le Data Provider Wizard**

* Ouvrir le **Data Provider Wizard** en suivant les instructions dans **Adding a Data Provider** ou **Editing a Data Provider**.
* Sélectionner **Media RSS Feed** comme type de fournisseur.

***

#### **2. Spécifier l'URL du flux Media RSS**

* Saisir l'**URL (URI)** du flux Media RSS.
* Si nécessaire, cliquer sur **Preview** pour vérifier la sortie du flux.

***

#### **3. Configurer l'authentification (si nécessaire)**

* Si le flux Media RSS **nécessite des identifiants de connexion**, activer **Authorization Required**.
* Saisir l'**User ID, Password, et (si nécessaire) un Domain**.

***

#### **4. Configurer le User-Agent (si nécessaire)**

* Certains serveurs peuvent nécessiter une **chaîne User-Agent spécifique** pour autoriser l'accès.
* Si nécessaire, saisir la **chaîne d'identification User-Agent** requise.

***

#### **5. Finaliser et enregistrer la connexion**

* Cliquer sur **Next** pour continuer.
* Terminer la configuration en complétant le **Data Provider Wizard**.

***

### **Considérations importantes**

* **Utilisation d'un PADS4 Data Server**
  * Si un **PADS4 Data Server** est utilisé, s'assurer que le **flux Media RSS est accessible** depuis le **point de vue du serveur**.
  * Si **aucun Data Server n'est utilisé**, confirmer que **PADS4 Designer et PADS4 Viewers** ont un accès direct au flux Media RSS via Internet.

En suivant ces étapes, PADS4 récupérera et affichera avec succès **le contenu multimédia d'un flux Media RSS**.
