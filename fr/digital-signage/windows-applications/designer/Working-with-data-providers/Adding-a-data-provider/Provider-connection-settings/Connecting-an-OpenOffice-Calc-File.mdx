Le **OpenOffice** provider dans **PADS4** vous permet de vous connecter à des **fichiers OpenOffice Calc (.ods)** pour récupérer et afficher des données de feuille de calcul.

***

### **Étapes pour ajouter ou modifier une connexion à un fichier OpenOffice**

#### **1. Démarrer le Data Provider Wizard**

* Ouvrir **PADS4** et accéder au **Data Provider Wizard**.
* Sélectionner **OpenOffice File** comme **type de provider**.
* Cliquer sur **Next** pour continuer.

#### **2. Spécifier l'emplacement du fichier**

* Choisir l'emplacement de stockage du fichier :
  * **Content Library** – Recommandé, car il **se synchronise automatiquement** sur tous les appareils connectés à PADS4.
  * **File Name** – Sélectionner un fichier OpenOffice en dehors de la content library *(vous devrez gérer la distribution manuellement)*.
* Cliquer sur **Browse** pour localiser le fichier, ou saisir manuellement le chemin complet.
* Cliquer sur **Next** pour continuer.

#### **3. Sélectionner la feuille**

* Sélectionner la **feuille spécifique** dans le fichier OpenOffice Calc.
* Cliquer sur **Preview** pour vérifier si les données sont correctement chargées.
* Cliquer sur **Next** pour continuer.

#### **4. Terminer la configuration**

* Vérifier les paramètres de connexion.
* Cliquer sur **Finish** pour enregistrer le data provider.

***

### **Notes importantes**

* **Considérations de performance** :
  * L'utilisation d'un **fichier OpenOffice externe** *(en dehors de la Content Library)* nécessite une **distribution manuelle des fichiers**.
  * Si le fichier OpenOffice est volumineux, s'assurer que **PADS4 dispose de suffisamment de ressources** pour le traitement.
* **Sécurité & Accessibilité** :
  * Si vous utilisez un **PADS4 Data Server**, le fichier **doit être accessible** depuis l'emplacement du serveur.
  * Sans PADS4 Data Server, s'assurer que **chaque PADS4 Viewer** peut localiser et accéder au fichier OpenOffice spécifié.
* **Utilisation hors ligne** :
  * Vous pouvez **télécharger** données provenant d'un **flux RSS** et les enregistrer en tant que **fichier OpenOffice Calc** pour un accès hors ligne.
  * Pour ce faire, ouvrez le **flux RSS dans un navigateur**, sélectionnez **Afficher la source**, et enregistrez-le en tant que **fichier .txt ou .csv** avant de l'importer dans OpenOffice.

***

Cette configuration garantit **un accès en temps réel ou planifié** aux **données OpenOffice Calc** au sein de **PADS4**, ce qui le rend utile pour **les présentations dynamiques, la visualisation de données et les rapports**.
