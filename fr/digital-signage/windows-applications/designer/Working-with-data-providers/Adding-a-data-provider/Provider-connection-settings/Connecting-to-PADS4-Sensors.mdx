Le fournisseur de données Capteurs PADS4 vous permet de récupérer toutes les informations liées aux caméras enregistrées sur le serveur PADS4. Utilisez le PADS4 CTRL Center pour ajouter des capteurs à PADS4.

### Étapes pour ajouter ou modifier un fournisseur de données de capteur

#### 1. Démarrer l'assistant de fournisseur de données

* Ouvrir le **Assistant de fournisseur de données** dans **PADS4**.
* Suivre les étapes pour **Ajouter un fournisseur de données** ou **Modifier un fournisseur de données**.
* Sélectionner **Capteurs PADS4** comme **type de fournisseur**.

***

#### 2. Configurer les paramètres d'informations du capteur

* **Sélectionner le type d'informations à récupérer :**
  * **Événements**: Données en temps réel fournies par le capteur.
  * **Incidents**: Notifications déclenchées lorsqu'une condition prédéfinie est remplie.
  * **Zones**: Données en temps réel sur le nombre de personnes dans une zone.
  * **Statistiques**: Informations statistiques sur les incidents et les zones.

***

#### 3. Configurer les options de récupération des données

* **Si Événements est sélectionné :**
  * Choisir le type d'événement spécifique à récupérer.
  * Toutes les caméras ne prennent pas en charge tous les types d'événements ; vérifier la compatibilité avec votre caméra.

* **Si Incidents est sélectionné :**
  * Définir un filtre pour récupérer les incidents des dernières **x** secondes.
  * Optionnellement, sélectionner une zone spécifique pour filtrer les incidents.

* **Si Zones est sélectionné :**
  * Récupérer les données d'occupation en temps réel pour une zone spécifiée.

* **Si Statistiques est sélectionné :**
  * Sélectionner le **type de vue** (jour, semaine ou mois).
  * Définir la **période** pour la récupération des données.

***

#### 4. Finaliser la configuration

* Compléter les étapes restantes dans le **Assistant de fournisseur de données**.
* Cliquer sur **Terminer** pour finaliser la configuration.

***

### Notes supplémentaires

* **Vérifier la compatibilité de la caméra**: Tous les capteurs ne prennent pas en charge toutes les fonctions. Consulter la page **Capteurs certifiés** pour plus de détails.
* **Utiliser des filtres**: La définition de filtres optimise la récupération des données et minimise la charge de données inutile.
* **Vérifier les autorisations d'accès**: Assurez-vous que les paramètres d'autorisation et de connectivité sont corrects pour récupérer les données des capteurs avec succès.
