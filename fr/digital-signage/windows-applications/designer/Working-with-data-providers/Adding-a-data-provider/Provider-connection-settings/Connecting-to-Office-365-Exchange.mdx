---
title: "Se connecter à Office 365 Microsoft Exchange"
description: "Connectez PADS4 à Exchange Online avec le fournisseur Office 365 Microsoft Exchange pour récupérer calendriers, boîte de réception et disponibilité."
---

Le fournisseur **Office 365 Microsoft Exchange** dans **PADS4** vous permet de vous connecter à **Exchange Online** (basé sur le cloud). Vous pouvez ainsi récupérer des données telles que **calendriers, messages de boîte de réception et disponibilité des utilisateurs**.

***

### **Étapes pour ajouter ou modifier une connexion Office 365 Microsoft Exchange**

#### **1. Démarrer l'Assistant Fournisseur de données**

* Ouvrez l'**Assistant Fournisseur de données** dans **PADS4**.
* Suivez les étapes pour **Ajouter un fournisseur de données** ou **Modifier un fournisseur de données**.
* Sélectionnez **Office 365 Microsoft Exchange** comme **type de fournisseur**.

***

#### **2. Configurer les paramètres de connexion**

* **Spécifier les paramètres de proxy (si nécessaire)**
  * Si votre organisation utilise un **serveur proxy**, saisissez les paramètres requis.
  * Contactez votre **administrateur système** pour plus de détails.

* **S'authentifier auprès de Microsoft Exchange**
  * Cliquez sur le bouton **Authentifier**.
  * **PADS4** ouvre une **page de connexion Microsoft**.
  * Connectez-vous avec vos **identifiants Exchange Online** et autorisez **PADS4** à accéder à votre environnement.
  * Une fois l'authentification réussie, le **statut** affiche **successful**.

* **Réauthentification**
  * Chaque fois que vous modifiez ce **fournisseur de données**, vous devez vous réauthentifier.

Cliquez sur **Next** pour continuer.

***

#### **3. Choisir la source de données à récupérer**

Sélectionnez le type de **données Exchange** à récupérer :

| **Option**            | **Description**                                                                                                                                      |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **My Calendar**       | Récupère les événements du calendrier de votre calendrier Exchange **personnel**.                                                                       |
| **Shared Calendar**   | Récupère les calendriers **partagés** en spécifiant des adresses e-mail. Utile pour les **salles de réunion ou événements de groupe**.                               |
| **User Availability** | Récupère le **statut libre/occupé** des utilisateurs spécifiés. Utile pour les **applications de planification**.                                        |
| **My Inbox**          | Récupère les **e-mails** de votre boîte de réception **personnelle**. Vous pouvez spécifier un dossier et choisir d'inclure les **sous-dossiers**.            |
| **Shared Inbox**      | Récupère les e-mails d'une boîte de réception **partagée** en spécifiant des adresses e-mail. Vous pouvez fusionner les données de plusieurs boîtes de réception. |

Cliquez sur **Next** pour continuer.

***

#### **4. Configurer les options de filtrage des données**

* **Include Message Text**
  * Cochez cette option pour **récupérer le corps de l'e-mail** avec les autres métadonnées.

* **Specify Date Range (From / Until)**
  * Utilisez une période **statique** ou **dynamique** pour filtrer les résultats.
  * Cette option réduit l'**utilisation de la mémoire** et **améliore les performances**.

**Note:**\
Si vous récupérez des données sur une **longue période**, l'**utilisation de la mémoire** peut être élevée. Utilisez des filtres ou définissez un **nombre maximal de lignes** pour éviter des charges de données excessives.

Cliquez sur **Next** pour continuer.

***

#### **5. Finaliser la configuration**

* Complétez les étapes restantes dans l'**Assistant Fournisseur de données**.
* Cliquez sur **Finish** pour finaliser la configuration.

***

### **Notes supplémentaires**

* Si l'**authentification échoue**, assurez-vous que votre **compte Microsoft 365** dispose des **permissions** nécessaires pour accéder à **Exchange Online**.
* Si des **ensembles de données volumineux** causent des problèmes de performance, **limitez la période ou le nombre de lignes récupérées**.
* Si vous utilisez un **serveur proxy**, assurez-vous que les **paramètres de proxy** sont correctement configurés.

Cette configuration permet à **PADS4** de récupérer et d'afficher en temps réel les **données Exchange** pour les **e-mails, calendriers et disponibilités**.
