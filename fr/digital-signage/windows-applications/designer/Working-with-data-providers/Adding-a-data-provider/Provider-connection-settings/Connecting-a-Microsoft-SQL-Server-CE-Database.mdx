Le **Microsoft SQL Server Compact Edition (CE)** fournisseur dans **PADS4** vous permet de vous connecter à un **fichier de base de données SQL Server CE** et de récupérer des données à utiliser dans vos présentations.

***

### **Étapes pour ajouter ou modifier une connexion Microsoft SQL Server CE**

#### **1. Démarrer l'assistant de fournisseur de données**

* Ouvrez **PADS4** et accédez à l'assistant **Data Provider Wizard**.
* Sélectionnez **Microsoft SQL Server CE** comme **type de fournisseur**.
* Cliquez sur **Next** pour continuer.

#### **2. Spécifier l'emplacement de la base de données et les paramètres d'accès**

* Sélectionnez l'une des options suivantes :
  * **Content Library** : Utilisez une **base de données SQL Server CE** stockée dans la **PADS4 Content Library** *(recommandé pour la synchronisation automatique)*.
  * **File Name** : Utilisez une **base de données SQL Server CE** stockée **en dehors de** la bibliothèque de contenu *(distribution manuelle des fichiers requise)*.

* Entrez le **chemin du fichier** ou utilisez le bouton **Browse** pour localiser le fichier.

* Si la base de données est **protégée par un mot de passe**, entrez le **mot de passe**.

* Cliquez sur **Next** pour continuer.

#### **3. Sélectionner la table ou la requête SQL**

* Le système détectera automatiquement les **tables disponibles** dans la base de données.

* Sélectionnez une table dans la **liste déroulante**.

* Alternatively, select **SQL Statement** and enter a **custom SQL query** to retrieve specific data.

* Click **Next** to continue.

#### **4. Complete the setup**

* **Review** the selected settings.
* Click **Finish** to save the data provider.

***

### **Important notes**

* **PADS4 Data Server Considerations**:
  * If using a **PADS4 Data Server**, ensure the **database file is accessible from the server**.
  * If **not** using a **PADS4 Data Server**, ensure **PADS4 Designer and Viewers** can access the **database file**.
* **File Storage Recommendations**:
  * Using the **PADS4 Content Library** ensures **automatic file synchronization**.
  * Storing the database **outside** the content library requires **manual file distribution**.
* **SQL Queries**:
  * Manually entered **SQL statements** should be optimized for **performance and efficiency**.

This setup allows **PADS4** to pull real-time data from a **SQL Server CE database**, integrating it seamlessly into digital signage, reports, or automation workflows.
