Le **Invue POD** provider dans **PADS4** vous permet de vous connecter à un **Invue Merchandising DIB (Device Interface Box)**, qui gère les **POD (Point of Display) security devices**. Cette configuration aide à intégrer les **merchandising security solutions** avec les **digital signage systems**.

***

## **Étapes pour ajouter/modifier une connexion Invue dans PADS4**

### **1. Démarrer le Data Provider Wizard**

* Ouvrez le **Data Provider Wizard** en suivant les étapes dans **Adding a Data Provider** ou **Editing a Data Provider**.
* Sélectionnez **Invue POD** comme **provider type**.

***

### **2. Configurer les paramètres de connexion Invue POD**

* **Sélectionner le port COM :**
  * Sélectionnez le **port COM** auquel le **DIB (Device Interface Box)** est connecté.
  * En cas de doute, vérifiez le **Windows Device Manager** pour trouver le bon **port série**.

Cliquez sur **Next** pour continuer.

***

### **3. Terminer la configuration**

* Cliquez sur **Finish** pour finaliser la connexion.
* Le **PADS4 Viewer** pourra désormais récupérer en temps réel les **Invue POD data**.

***

## **Considérations importantes**

### **Configuration du PADS4 Data Server**

* Si vous utilisez le **PADS4 Data Server**, assurez-vous que le **Invue DIB device est connecté** au **Data Server**.
* Si vous **n'utilisez pas de Data Server**, le **DIB device doit être connecté** au **Viewer PC** à la place.

### **Connectivité des appareils**

* Assurez-vous que le **DIB device** est correctement installé et reconnu par le système.
* Les **Invue software drivers** doivent être installés sur le **server ou Viewer PC**.

***

## **Cas d'utilisation**

* **Sécurité en commerce de détail :** Surveiller l'état de la **merchandise security**.
* **Engagement client :** Intégrer les **product interaction data** dans le **digital signage**.
* **Prévention des pertes :** Alerter le personnel si les **security conditions changent**.

En suivant ces étapes, **PADS4** intègre avec succès les **Invue POD devices** pour la **surveillance de sécurité en temps réel et l'analyse** dans les **environnements de commerce de détail et de merchandising**.
