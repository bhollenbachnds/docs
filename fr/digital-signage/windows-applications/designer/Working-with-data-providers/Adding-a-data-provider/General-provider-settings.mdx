À la **deuxième étape** de l'**Assistant Fournisseur de Données**, vous définissez un **nom unique** pour votre fournisseur de données et configurez les paramètres pour **la récupération de données en temps réel**.

***

## **Étapes pour configurer les paramètres généraux du fournisseur**

1. **Démarrer l'Assistant Fournisseur de Données**
   * Suivez les étapes dans **Ajout d'un Fournisseur de Données** ou **Modification d'un Fournisseur de Données**
2. **Entrer un Nom Unique pour le Fournisseur**
   * Attribuer un **Nom de Fournisseur** (doit être unique dans votre présentation)
   * Optionnellement, entrez une **Description**
3. **Décider d'utiliser ou non le Serveur de Données PADS4**
   * **Activer ou Désactiver** l'option :\
     **"Utiliser le Serveur de Données pour la récupération des Données"**
   * Si **activé**, les données en temps réel sont récupérées de manière centralisée via le **Serveur de Données PADS4**
   * Si **désactivé**, chaque **Visionneur PADS4** récupère les données **individuellement**
4. **Activer la mise en cache (Optionnel)**
   * **Utiliser le Cache de Conception** : Stocke les données de la source pour **l'aperçu en mode conception**
   * **Générer des Valeurs Exemples** : Crée **des valeurs de remplacement** si la source de données est indisponible
5. **Passer à l'Étape Suivante**

***

## **Utilisation du Serveur de Données PADS4**

Le **Serveur de Données PADS4** récupère et distribue **les données en temps réel** à tous les Visionneurs connectés.

### **Comparaison des méthodes de récupération de données**

| **Fonctionnalité**           | **Utilisation du Serveur de Données PADS4**            | **Récupération des Données Individuellement**                             |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------- |
| **Récupération des Données** | Requête unique pour tous les Visionneurs               | Chaque Visionneur récupère les données séparément                         |
| **Performance**              | Optimisée (réduit les requêtes de base de données)     | Plus de charge sur la source de données                                   |
| **Cas d'utilisation**        | Réseaux à grande échelle, sources de données lentes    | Requêtes spécifiques au Visionneur (ex. : filtrage par Nom de Visionneur) |
| **Support de Basculement**   | Bascule vers un Serveur PADS4 de secours si nécessaire | Aucune redondance intégrée                                                |

### **Quand activer le Serveur de Données PADS4**

✔ **Recommandé si :**

* **Plusieurs Visionneurs** ont besoin des **mêmes données** en même temps
* Votre **source de données est lente ou externe** (ex. : API, bases de données distantes)
* Vous souhaitez **réduire le trafic réseau et la charge de la base de données**

✘ **Non Recommandé si :**

* Chaque **Visionneur nécessite des données différentes** (ex. : filtré par emplacement)
* La **base de données optimise déjà les requêtes** pour plusieurs connexions

***

## **Options de mise en cache dans PADS4**

La mise en cache peut **améliorer les performances** et **permettre la conception hors ligne** lorsque les données en direct sont indisponibles.

| **Option de Mise en Cache**         | **Fonction**                                                                 |
| ----------------------------------- | ---------------------------------------------------------------------------- |
| **Utiliser le Cache de Conception** | Enregistre **jusqu'à 999 lignes** de données pour une utilisation hors ligne |
| **Générer des Valeurs Exemples**    | Remplace les données manquantes par **du texte de remplacement**             |
| **Idéal pour**                      | Concevoir des présentations **sans accès aux données en direct**             |

### **Exemple de cas d'utilisation**

Un **concepteur** a besoin de créer une **mise en page pilotée par les données** mais n'a pas **accès à la base de données**. En utilisant **données en cache**, ils peuvent toujours **concevoir et tester** la mise en page.

***

## **Considérations relatives au basculement et à la sauvegarde**

* Si le **PADS4 Data Server** tombe en panne, un **Backup PADS4 Server** (si configuré) prend le relais.
* Si **le Data Server est désactivé**, assurez-vous que **chaque Viewer** peut **accéder de manière indépendante** à la source de données.
