PADS4 Designer offre plusieurs façons de **naviguer entre les pages** de votre présentation, facilitant la révision et l'ajustement efficace du contenu.

***

## **Comment naviguer vers une page spécifique**

### Option 1 : Utiliser les boutons de navigation

* Accédez au menu **View**.
* Dans la **Go To** section, utilisez les boutons suivants :

| Bouton                              | Fonction                                                                                                                           |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Go to Master Page                   | Navigue vers la **page maître** de votre présentation. *(Remarque : Vous devez d'abord créer une page maître si aucune n'existe.)* |
| Go to First Page                    | Ouvre la **première page** de votre présentation.                                                                                  |
| Go to Previous Page                 | Passe à la **page précédente**.                                                                                                    |
| Go to Next Page                     | Passe à la **page suivante**.                                                                                                      |
| Aller à la dernière page            | Ouvre la **dernière page** de votre présentation.                                                                                  |
| Menu déroulant de sélection de page | Sélectionner et accéder à une **page spécifique** depuis la liste déroulante.                                                      |

***

### Option 2 : Utiliser la fenêtre Miniatures

* Cliquez directement sur la **miniature** de la page que vous souhaitez ouvrir.

***

### Option 3 : Utiliser les raccourcis clavier

| Touche du clavier   | Action                          |
| ------------------- | ------------------------------- |
| **Début**           | Aller à la **première page**.   |
| **Page précédente** | Aller à la **page précédente**. |
| **Page suivante**   | Aller à la **page suivante**.   |
| **Fin**             | Aller à la **dernière page**.   |

***

## **Conseil**

Utiliser les **miniatures** ou **raccourcis clavier** est un moyen rapide de naviguer tout en travaillant sur votre conception — idéal pour réviser de longues présentations.
