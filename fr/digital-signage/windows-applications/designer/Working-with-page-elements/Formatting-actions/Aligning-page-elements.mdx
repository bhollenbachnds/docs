**Éléments de page** dans une page PADS4 Designer peuvent être alignés **les uns par rapport aux autres** ou alignés **sur la grille** pour une mise en page précise et cohérente.

***

## Aligner les éléments de page les uns par rapport aux autres

1. **Sélectionner au moins deux éléments de page.**\
   (Voir *Sélectionner des éléments de page* pour des instructions détaillées.)

2. **Désigner un élément comme élément principal sélectionné** (la référence pour l'alignement).

3. Cliquer sur **Aligner** dans le menu **Éléments**.

4. Sélectionner l'une des options d'alignement suivantes :

| Élément de menu | Fonction                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Gauches**     | Aligne tous les éléments sélectionnés horizontalement sur le **bord gauche** de l'élément principal sélectionné.  |
| **Centres**     | Aligne tous les éléments sélectionnés horizontalement sur le **centre** de l'élément principal sélectionné.       |
| **Droites**     | Aligne tous les éléments sélectionnés horizontalement sur le **bord droit** de l'élément principal sélectionné.   |
| **Hauts**       | Aligne tous les éléments sélectionnés verticalement sur le **bord supérieur** de l'élément principal sélectionné. |
| **Milieux**     | Aligne tous les éléments sélectionnés verticalement sur le **milieu** de l'élément principal sélectionné.         |
| **Bas**         | Aligne tous les éléments sélectionnés verticalement sur le **bord inférieur** de l'élément principal sélectionné. |

***

## Aligner les éléments de page sur la grille

1. **Sélectionner** les éléments de page que vous souhaitez aligner sur la grille.

2. Cliquer sur **Aligner** dans le menu **Éléments**, puis sélectionner **Sur la grille**.

***

## Remarques

* Sélectionner **au moins deux éléments** pour activer les fonctions d'alignement les uns par rapport aux autres.
* Si **Aligner sur la grille** est déjà activé, l'utilisation de **Aligner sur la grille** n'aura **aucun effet supplémentaire**, car les éléments s'aligneront déjà sur les points de grille les plus proches lors de leur déplacement ou redimensionnement.
