Chaque élément de page possède un ensemble de **propriétés** qui déterminent son comportement et son apparence dans la page.

***

## Pour modifier les propriétés d'un seul élément de page

1. **Sélectionner** l'élément (par exemple, en cliquant dessus).
2. Cliquer sur **Propriétés de l'élément** dans le **menu Éléments**.
3. Ajuster un ou plusieurs paramètres dans la fenêtre des propriétés.
4. Cliquer sur **OK** pour enregistrer les modifications et revenir à votre présentation, ou cliquer sur **Appliquer** pour enregistrer les modifications sans fermer la fenêtre des propriétés.

***

## Pour modifier les propriétés de plusieurs éléments de page

1. **Sélectionner plusieurs éléments** (voir *Sélectionner plusieurs éléments de page*).
2. S'assurer que l'élément correct est marqué comme **élément principal sélectionné**.
3. Cliquer sur **Propriétés de l'élément** dans le **menu Éléments**.
4. Ajustez les propriétés dans la fenêtre. Notez que cette fenêtre affiche les propriétés de l' **élément sélectionné principal**.
5. Cliquez sur **OK** ou **Appliquer** pour appliquer les modifications à tous les éléments sélectionnés.

***

### Conseil

Modifier les propriétés de plusieurs éléments en une seule action **fait gagner du temps** et **réduit les erreurs**.

Si vous sélectionnez différents types d'éléments (comme du texte, des images, des vidéos), lorsque vous appliquez des modifications :

* Le système vérifie si chaque élément prend en charge la propriété.
* Si elle est prise en charge, la propriété est mise à jour.
* Si elle n'est pas prise en charge, cet élément est ignoré.

***

## Remarques

* Si l' **aperçu** option est activée dans la fenêtre des propriétés, une **fenêtre d'aperçu** apparaîtra pour afficher immédiatement l'effet de vos modifications.
* Si vous modifiez quelque chose accidentellement, utilisez **Annuler** dans le menu Accueil pour annuler les modifications.
* **Remarque** : Cliquer sur **OK** enregistre automatiquement les modifications. Vous **n'avez pas besoin de cliquer sur Appliquer** avant de cliquer sur OK — les deux actions ont le même effet lorsqu'elles sont combinées.
