Chaque élément de page possède un ensemble de **propriétés** qui déterminent son comportement et son apparence dans la page.

***

## Pour modifier les propriétés d'un seul élément de page

1. **Sélectionner** l'élément (par exemple, en cliquant dessus).
2. Cliquer **Element Properties** dans le **Elements menu**.
3. Ajuster un ou plusieurs paramètres dans la fenêtre des propriétés.
4. Cliquer **OK** pour enregistrer les modifications et revenir à votre présentation, ou cliquer **Apply** pour enregistrer les modifications sans fermer la fenêtre des propriétés.

***

## Pour modifier les propriétés de plusieurs éléments de page

1. **Sélectionner plusieurs éléments** (voir *Selecting multiple page elements*).
2. S'assurer que l'élément correct est marqué comme **primary selected item**.
3. Cliquer **Element Properties** dans le **Elements menu**.
4. Ajuster les propriétés dans la fenêtre. Notez que cette fenêtre affiche les propriétés du **primary selected item**.
5. Cliquer **OK** ou **Apply** pour appliquer les modifications à tous les éléments sélectionnés.

***

### Conseil

Modifier les propriétés de plusieurs éléments en une seule action **fait gagner du temps** et **réduit les erreurs**.

Si vous sélectionnez différents types d'éléments (comme du texte, des images, des vidéos), lorsque vous appliquez des modifications :

* Le système vérifie si chaque élément prend en charge la propriété.
* Si elle est prise en charge, la propriété est mise à jour.
* Si elle n'est pas prise en charge, cet élément est ignoré.

***

## Remarques

* Si l'option **show preview** est activée dans la fenêtre des propriétés, une **fenêtre d'aperçu** apparaîtra pour afficher immédiatement l'effet de vos modifications.
* Si vous modifiez accidentellement quelque chose, utilisez **Undo** dans le menu Home pour annuler les modifications.
* **Note** : Cliquer sur **OK** enregistre automatiquement les modifications. Vous **n'avez pas besoin de cliquer sur Apply** avant de cliquer sur OK — les deux actions ont le même effet lorsqu'elles sont combinées.
