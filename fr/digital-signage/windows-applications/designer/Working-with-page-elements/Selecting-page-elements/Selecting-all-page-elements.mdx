Tous les éléments de page sur la **page actuelle** peuvent être rapidement sélectionnés en une **seule opération**.

***

## Pour sélectionner tous les éléments de page sur la page actuelle

* Aller au **menu Éléments**.
* Cliquer sur **Tout sélectionner**.

***

Une fois sélectionnés, **tous les éléments** de la page peuvent être manipulés ensemble — notamment déplacés, redimensionnés, copiés ou mis en forme.
