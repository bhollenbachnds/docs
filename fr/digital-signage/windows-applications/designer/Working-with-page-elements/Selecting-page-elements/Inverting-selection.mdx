L'inversion de la sélection vous permet de **permuter rapidement** les éléments de page sélectionnés et non sélectionnés sur la **page actuelle**.\
Tous les **éléments sélectionnés** deviendront **non sélectionnés**, et tous les **éléments non sélectionnés** deviendront **sélectionnés**.

***

## Pour inverser la sélection sur la page actuelle

* Accédez au **Éléments** menu.
* Cliquez sur **Inverser la sélection**.

***

### Conseil

Si vous souhaitez sélectionner **presque tous** les éléments de page, il est souvent plus rapide de :

1. **Sélectionnez** uniquement les quelques éléments que vous **ne** voulez pas.
2. Puis utilisez **Inverser la sélection** pour sélectionner tout le reste en une seule étape.
