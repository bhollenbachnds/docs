Les éléments de page peuvent être déplacés **au sein de la même page**, **vers une autre page dans la même présentation**, ou **vers une autre présentation**.

***

## Déplacer des éléments de page au sein de la même page

1. **Sélectionnez** les éléments de page que vous souhaitez déplacer (voir *Sélectionner des éléments de page* pour plus de détails).
2. Déplacez le pointeur de la souris **sur l'un des éléments sélectionnés**, puis appuyez et maintenez le **bouton gauche de la souris**.
3. **Faites glisser** le pointeur de la souris vers la position souhaitée.
4. **Relâchez** le bouton de la souris pour placer les éléments.

### Tips:

* **Annulez** l'opération de déplacement à tout moment en appuyant sur **\[Esc]** sur votre clavier.
* Si **Verrouiller les éléments** dans le menu **Accueil** est actif, le déplacement des éléments de cette façon ne sera **pas possible**.
* Pour un **déplacement précis**, utilisez le clavier :
  * Maintenez **\[Ctrl]** et utilisez les **touches fléchées** pour déplacer les éléments.
  * Si **Aligner sur la grille** est activé, les éléments se déplacent d'**un point de grille** à la fois.
    &#x20;&#x20;
  * Si&#x20;
    &#x20; **Snap to Grid** est désactivé, les éléments se déplacent&#x20;
    &#x20; **d'un pixel** à la fois.
    &#x20;&#x20;
* Pour ajuster Snap to Grid, accédez à la fenêtre&#x20;
  &#x20; **Options**.
  &#x20;&#x20;

***

## Déplacer des éléments de page vers une autre page dans la même présentation

1. **Sélectionnez** les éléments à déplacer.
   &#x20;&#x20;
2. Cliquez sur&#x20;
   &#x20; **Couper** dans le&#x20;
   &#x20; **menu** Accueil.
   &#x20;&#x20;
3. Accédez à la page cible via le&#x20;
   &#x20; **menu** Affichage.
   &#x20;&#x20;
4. Cliquez sur&#x20;
   &#x20; **Coller** dans le&#x20;
   &#x20; **menu** Accueil.
   &#x20;&#x20;

* Les éléments seront collés à la&#x20;
  &#x20; **même position** que dans la page d'origine.
  &#x20;&#x20;

***

## Déplacer des éléments de page vers une autre présentation

1. **Sélectionnez** les éléments à déplacer.
   &#x20;&#x20;
2. Cliquez sur&#x20;
   &#x20; **Couper** dans le&#x20;
   &#x20; **menu** Accueil.
   &#x20;&#x20;
3. Ouvrez la présentation cible ou basculez vers son onglet.
4. Accédez à la page cible via le&#x20;
   &#x20; **menu** Affichage.
   &#x20;&#x20;
5. Cliquez sur&#x20;
   &#x20; **Coller** dans le&#x20;
   &#x20; **menu** Accueil.
   &#x20;&#x20;

* Les éléments seront insérés à la&#x20;
  &#x20; **même position** que dans la présentation d'origine.
  &#x20;&#x20;
* Si un élément est connecté à un&#x20;
  &#x20; **fournisseur de données**, ce fournisseur sera&#x20;
  &#x20; **copié dans la nouvelle présentation** (mais restera également dans l'original).
  &#x20;&#x20;

***

## Remarques

* Les éléments ne seront collés à la&#x20;
  &#x20; **position choisie que s'ils s'inscrivent dans les limites de la page**.
  &#x20;&#x20;
* S'ils ne s'y inscrivent pas, le système&#x20;
  &#x20; **ajustera automatiquement** la position pour s'assurer qu'ils sont visibles.
  &#x20;&#x20;
* Pour coller des éléments à une&#x20;
  &#x20; **position spécifique**,&#x20;
  &#x20; **faites un clic droit** sur cette position et sélectionnez&#x20;
  &#x20; **Coller** dans le menu contextuel. Les éléments y seront insérés si l'espace le permet.
  &#x20;&#x20;
* **Annuler** est disponible dans le&#x20;
  &#x20; **menu** Accueil si vous devez annuler des modifications.
  &#x20;&#x20;

***

## Conseil

Pour déplacer rapidement des éléments vers une autre page ou présentation :

* Utilisez&#x20;
  &#x20; **\[Ctrl] + X** pour couper.
  &#x20;&#x20;
* Utilisez&#x20;
  &#x20; **\[Ctrl] + V** pour coller.
  &#x20;&#x20;
