Après avoir sélectionné une catégorie d'informations dans le volet de navigation, les informations seront récupérées et les résultats seront affichés dans une fenêtre dans la **zone d'informations**. La façon dont les résultats sont affichés dans la fenêtre d'informations dépend de la catégorie choisie.

![EN System Management User Groupswindow Pn](/images/digital-signage/windows-applications/system-management/main-window/EN-SystemManagement-UserGroupswindow.png)

Pour la plupart des catégories, un certain nombre de fonctions contextuelles seront disponibles dans la barre de ruban. Les mêmes fonctions contextuelles peuvent également être appelées en faisant un clic droit sur la fenêtre d'informations.

Par défaut, l'application PADS4 utilise une fenêtre d'information par catégorie d'information. Cela signifie que lorsque vous passez à une autre catégorie d'information, une autre fenêtre s'ouvrira pour afficher les résultats. Si vous passez à une catégorie d'information qui possède déjà une fenêtre ouverte, cette fenêtre deviendra active et sera réutilisée pour afficher les résultats. Lorsque vous travaillez avec plusieurs serveurs, le système utilisera une fenêtre d'information par catégorie d'information et par connexion serveur. En option, vous pouvez ouvrir manuellement des fenêtres d'information supplémentaires comme décrit dans **Travailler avec plusieurs fenêtres**.

 

#### Actualisation des données

Les informations dans la fenêtre d'information reflètent toujours la situation réelle et sont automatiquement actualisées. Pour cette raison, il n'existe pas de fonction pour actualiser manuellement les informations.
