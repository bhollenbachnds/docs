Depuis la **fenêtre des destinations,** vous pouvez définir de nouveaux viewer groups, viewers, zone viewers, HTML viewers et desktop viewers.

Un viewer group est une unité logique composée d'autres destinations. Les membres d'un groupe peuvent être des viewers ou d'autres groupes. Les groupes peuvent être imbriqués sans aucune limitation et les viewers ou groupes peuvent être membres d'un nombre illimité de groupes.

Les groupes sont généralement utilisés pour organiser vos destinations dans une structure logique et pour les contrôler par groupe plutôt qu'individuellement par viewer.

 

#### Pour ajouter un nouveau viewer group

1. Sélectionnez **Destinations** dans le volet de navigation pour activer la fenêtre des destinations.
2. Cliquez sur **New Group** dans le **Home** menu.

   La fenêtre New Viewer Group apparaîtra.
3. Spécifiez les **Identification** paramètres dans l'onglet **General**.

   ![EN System Management Managing Destinations 01 Pn](/images/digital-signage/windows-applications/system-management/managing-destinations/EN-SystemManagement-Managing-Destinations-01.png)

   **Name**
   Un nom unique pour identifier le viewer group.

   **Description**
   Une chaîne descriptive pour fournir des informations supplémentaires sur le viewer group.
4. Spécifiez dans l'onglet **Member Of** à quel(s) viewer group(s) ce viewer group appartient en cochant les cases correspondantes.

   ![EN System Management Managing Destinations 02 Pn](/images/digital-signage/windows-applications/system-management/managing-destinations/EN-SystemManagement-Managing-Destinations-02.png)

   Utilisez éventuellement les options d'affichage, de tri et de filtrage dans la barre d'outils pour localiser vos destinations.
5. Spécifiez dans l'onglet **Members** quels viewers ou viewer groups appartiennent à ce viewer group en cochant les cases correspondantes.
   Lorsque vous sélectionnez un viewer group, tous les viewers qui font partie de ce groupe seront automatiquement inclus.

   ![EN System Management Managing Destinations 03 Pn](/images/digital-signage/windows-applications/system-management/managing-destinations/EN-SystemManagement-Managing-Destinations-03.png)

   Utilisez éventuellement les options d'affichage, de tri et de filtrage dans la barre d'outils pour localiser vos destinations.
6. Déterminez dans l'onglet **Permissions** quelles permissions doivent s'appliquer à ce viewer group.

   ![EN System Management Managing Destinations 04 Pn](/images/digital-signage/windows-applications/system-management/managing-destinations/EN-SystemManagement-Managing-Destinations-04.png)

   <Note>
     1. Avant de pouvoir attribuer une permission, vous devez d'abord la définir comme décrit dans **managing permissions**.
        Dans le cas des viewer groups, seules les permissions de contenu peuvent être attribuées. Les permissions de contenu sont utilisées pour filtrer le contenu téléchargé par un viewer.
   </Note>
7. Cliquez sur **OK** pour terminer la création du nouveau viewer group.
