---
- title: Zone d'informations
- description: Découvrez comment PADS4 Agent affiche les résultats d'une catégorie
    de serveur, de viewer ou de black box sélectionnée dans des fenêtres
    d'informations, et comment actualiser les données mises en cache.
---

Après avoir sélectionné une catégorie d'informations d'un serveur, d'un viewer ou d'une black box dans le [volet de navigation](https://pads4documentation.blob.core.windows.net/agent/Content/Main%20Window/navigation%20pane.htm), PADS4 Agent récupère les informations et affiche les résultats dans une fenêtre de la zone d'informations. La façon dont les résultats sont affichés dans la fenêtre d'informations dépend de la catégorie choisie.

![EN Agent Viewerconnections Pn](/images/digital-signage/windows-applications/agent/main-window/EN-Agent-Viewerconnections.png)

Pour la plupart des catégories, un certain nombre de fonctions contextuelles seront disponibles dans la barre de ruban. Les mêmes fonctions contextuelles peuvent également être appelées en faisant un clic droit sur la fenêtre d'informations.

Par défaut, l'application PADS4 utilise une seule fenêtre d'informations pour afficher tous les résultats. Cela signifie que lorsque vous passez à une autre catégorie d'informations, la même fenêtre sera réutilisée pour afficher les résultats. Vous pouvez éventuellement ouvrir manuellement des fenêtres d'informations supplémentaires comme décrit dans [Travailler avec plusieurs fenêtres](https://pads4documentation.blob.core.windows.net/agent/Content/Advanced%20features/Working%20with%20multiple%20windows.htm). Vous pouvez également utiliser les [options d'affichage](https://pads4documentation.blob.core.windows.net/agent/Content/Tools/Options/View%20options.htm) de l'application pour que le système ouvre automatiquement de nouvelles fenêtres d'informations.

 

#### **Actualisation des données**

La première fois que vous sélectionnez une certaine catégorie d'informations, les informations sont toujours récupérées depuis le serveur ou le viewer distant. Lorsque vous sélectionnez à nouveau la même catégorie d'informations dans le volet de navigation, la réponse du système dépend de la catégorie sélectionnée. Pour des raisons de performance, les catégories dont les informations ne changeront presque jamais afficheront les résultats précédents mis en cache localement. Les catégories avec des informations dynamiques récupéreront toujours leurs informations depuis le serveur ou le viewer distant. Si les informations sont récupérées depuis le serveur ou le viewer distant, vous verrez une nouvelle tâche apparaître dans la [fenêtre des tâches.](https://pads4documentation.blob.core.windows.net/agent/Content/Main%20Window/Tasks.htm) Si aucune nouvelle tâche n'apparaît dans la fenêtre des tâches, cela signifie que les informations sont récupérées depuis le cache local.

<Note>
  Pour forcer l'application PADS4 Agent à récupérer les informations demandées depuis le serveur ou le viewer connecté, vous devez cliquer sur **Actualiser** dans l'onglet **Accueil** de la barre de ruban ou utiliser la touche de raccourci F5.
</Note>

Pour certaines catégories d'informations (comme toutes les catégories de black box), la fonction **Actualiser** n'est pas disponible. Les informations de ces catégories sont toujours disponibles, il n'est donc pas nécessaire de les actualiser.
