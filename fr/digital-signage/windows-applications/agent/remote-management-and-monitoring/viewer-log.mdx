Grâce aux fonctions de journal du viewer, vous pouvez consulter les messages de journal de votre PADS4 (HTML5) Viewer ou du fichier boîte noire. Le journal du viewer d'un PADS4 Viewer peut être effacé ou enregistré dans un fichier, avec d'autres informations de boîte noire.

 

#### **Pour consulter les messages de journal d'un PADS4 (HTML5) Viewer**

1. Cliquez sur l'onglet **Viewer** dans le volet de navigation.

   ![EN Agent Navigationpane Viewertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Viewertab.png)
2. Sélectionnez un Viewer dans la liste des destinations disponibles.
3. Cliquez sur **Journal du viewer** dans la liste des catégories d'informations viewer disponibles.

Après cela, le système se connectera automatiquement au PADS4 Server connecté pour récupérer les informations demandées depuis le Viewer sélectionné et afficher les résultats dans la fenêtre du journal du viewer.

<Warning>
  L'application PADS4 ne pourra commencer à récupérer les informations du viewer demandées que lorsque vous aurez sélectionné <u>à la fois</u> un Viewer et une Catégorie dans le volet de navigation.
</Warning>

#### **Pour consulter les messages de journal d'un fichier boîte noire**

1. Assurez-vous que la boîte noire a été [ajoutée](https://pads4documentation.blob.core.windows.net/agent/Content/Main%20Window/Navigation%20pane.htm) à l'application.
2. Cliquez sur l'onglet **Black Box** dans le volet de navigation.

   ![EN Agent Navigationpane Blackboxtab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Blackboxtab.png)
3. Sélectionnez l'élément black box dans la liste des black boxes disponibles.
4. Cliquez sur **Viewer log** dans la liste des catégories d'informations black box disponibles.

Après cela, le système ouvrira automatiquement le fichier black box pour récupérer les informations demandées et affichera les résultats dans la fenêtre du viewer log.

 

#### **Fenêtre du viewer log**

La fenêtre du viewer log affiche tous les messages de journal générés par l'application PADS4 Viewer ou le PADS4 Controller. Lorsque vous rencontrez un problème avec un PADS4 Viewer, le Viewer log est généralement le point de départ pour trouver la cause de votre problème.

![EN Agent Viewerlog Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Viewerlog.png)

Optionnellement, vous pouvez utiliser les boutons bascule en bas de la fenêtre du viewer log pour filtrer les messages affichés. Par exemple, lorsque vous souhaitez uniquement voir les avertissements et les messages d'erreur.\
Le bouton ci-dessous à droite copie l'élément sélectionné dans le **presse-papiers**. Une autre façon est d'utiliser le bouton droit de la souris sur l'élément et de sélectionner copier dans le presse-papiers dans le menu.

**Niveau**\
Une icône indiquant si l'élément journalisé est un message d'information, un avertissement ou une erreur.

**Horodatage**\
Date et heure auxquelles l'élément a été journalisé.

**Source**\
Nom du processus qui a journalisé l'élément. Si le processus est PADS4 Viewer, le nom du viewer qui identifie le PADS4 Viewer est indiqué.

**Message**\
Le message réel qui est journalisé.

 

#### **Effacement du viewer log**

En effaçant le Viewer log, vous pouvez redémarrer le processus de journalisation de votre PADS4 Viewer. Pour effacer le Viewer log :

1. Cliquez sur **Clear Log** dans le **Home** menu.

   ![EN Agent Ribbon Clear Log Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Ribbon-ClearLog.png)
2. Cliquez sur **Yes** pour confirmer que vous souhaitez effacer le Viewer log.

Après cela, tous les messages de journal seront supprimés du viewer log sur le PC PADS4 Viewer.

 

#### **Sauvegarde du Viewer log (HTML5)**

Pour sauvegarder le Viewer log afin de le consulter hors ligne ultérieurement, vous pouvez le sauvegarder avec d'autres informations de [black box](https://pads4documentation.blob.core.windows.net/agent/Content/Main%20Window/Navigation%20pane.htm) de votre Viewer. Pour sauvegarder le viewer log :

1. Cliquez sur **Save Black Box** dans le **Home** menu.
2. Entrez un **Nom de fichier** et cliquez sur **Save** pour sauvegarder les informations.

Après cela, le fichier black box sera sauvegardé sur votre ordinateur.

<Tip>
  Chaque PADS4 Viewer crée automatiquement une soi-disant black box dans laquelle des informations précieuses sur PADS4 sont stockées. Cela inclut des informations système et divers journaux. Lorsque vous rencontrez un problème avec un PADS4 (HTML5) Viewer, la black box est la source d'information idéale pour analyser la situation et retracer le problème. Ainsi, lorsque vous contactez le support pour un problème avec un PADS4 (HTML5) Viewer, il est conseillé d'envoyer toujours le fichier black box.
</Tip>
