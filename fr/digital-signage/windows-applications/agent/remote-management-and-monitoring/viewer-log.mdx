Avec les fonctions de journal du viewer, vous pouvez consulter les messages du journal de votre PADS4 (HTML5) Viewer ou du fichier boîte noire. Le journal du viewer d'un PADS4 Viewer peut être effacé ou enregistré dans un fichier, avec d'autres informations de la boîte noire.

 

#### **Pour afficher les messages du journal d'un PADS4 (HTML5) Viewer**

1. Cliquez sur l'onglet **Viewer** dans le volet de navigation.

   ![EN Agent Navigationpane Viewertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Viewertab.png)
2. Sélectionnez un Viewer dans la liste des destinations disponibles.
3. Cliquez sur **Journal du viewer** dans la liste des catégories d'informations du viewer disponibles.

Après cela, le système se connectera automatiquement au PADS4 Server connecté pour récupérer les informations demandées auprès du Viewer sélectionné et afficher les résultats dans la fenêtre du journal du viewer.

<Warning>
  L'application PADS4 ne pourra commencer à récupérer les informations du viewer demandées que lorsque vous aurez sélectionné <u>à la fois</u> un Viewer et une Catégorie dans le volet de navigation.
</Warning>

#### **Pour afficher les messages du journal d'un fichier boîte noire**

1. Assurez-vous que la boîte noire a été [ajoutée](https://pads4documentation.blob.core.windows.net/agent/Content/Main%20Window/Navigation%20pane.htm) à l'application.
2. Cliquez sur l'onglet **Boîte noire** dans le volet de navigation.

   ![EN Agent Navigationpane Blackboxtab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Blackboxtab.png)
3. Sélectionnez l'élément boîte noire dans la liste des boîtes noires disponibles.
4. Cliquez sur **Journal du viewer** dans la liste des catégories d'informations de la boîte noire disponibles.

Après cela, le système ouvrira automatiquement le fichier boîte noire pour récupérer les informations demandées et afficher les résultats dans la fenêtre du journal du viewer.

 

#### **Fenêtre du journal du viewer**

La fenêtre du journal du viewer affiche tous les messages du journal générés par l'application PADS4 Viewer ou PADS4 Controller. Lorsque vous rencontrez un problème avec un PADS4 Viewer, le journal du Viewer est généralement le point de départ pour trouver la cause de votre problème.

![EN Agent Viewerlog Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Viewerlog.png)

Optionnellement, vous pouvez utiliser les boutons bascule en bas de la fenêtre du journal du viewer pour filtrer les messages affichés. Par exemple, lorsque vous souhaitez uniquement voir les avertissements et les messages d'erreur.\
Le bouton ci-dessous à droite copie l'élément sélectionné dans le **presse-papiers**. Une autre façon est d'utiliser le bouton droit de la souris au-dessus de l'élément et de sélectionner copier dans le presse-papiers dans le menu.

**Niveau**\
Une icône indiquant si l'élément journalisé est un message d'information, un avertissement ou une erreur.

**Horodatage**\
Date et heure auxquelles l'élément a été journalisé.

**Source**\
Nom du processus qui a journalisé l'élément. Si le processus est PADS4 Viewer, le nom du viewer qui identifie le PADS4 Viewer est indiqué.

**Message**\
Le message réel qui est journalisé.

 

#### **Effacement du journal du viewer**

En effaçant le journal du Viewer, vous pouvez redémarrer le processus de journalisation de votre PADS4 Viewer. Pour effacer le journal du Viewer :

1. Cliquez sur **Effacer le journal** sur le **Accueil** menu.

   ![EN Agent Ribbon Clear Log Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Ribbon-ClearLog.png)
2. Cliquez sur **Oui** pour confirmer que vous souhaitez effacer le journal du Viewer.

Après cela, tous les messages du journal seront supprimés du journal du viewer sur le PC PADS4 Viewer.

 

#### **Enregistrement du journal du (HTML5) Viewer**

Pour enregistrer le journal du Viewer afin de le consulter hors ligne ultérieurement, vous pouvez l'enregistrer avec d'autres informations de la [boîte noire](https://pads4documentation.blob.core.windows.net/agent/Content/Main%20Window/Navigation%20pane.htm) de votre Viewer. Pour enregistrer le journal du viewer :

1. Cliquez sur **Enregistrer la boîte noire** sur le **Accueil** menu.
2. Entrez un **Nom de fichier** et cliquez sur **Enregistrer** pour enregistrer les informations.

Après cela, le fichier boîte noire sera enregistré sur votre ordinateur.

<Tip>
  Chaque PADS4 Viewer crée automatiquement une soi-disant boîte noire dans laquelle des informations précieuses sur PADS4 sont stockées. Cela inclut des informations système et divers journaux. Lorsque vous rencontrez un problème avec un PADS4 (HTML5) Viewer, la boîte noire est la source d'information idéale pour analyser la situation et localiser le problème. Ainsi, lorsque vous contactez le support pour un problème avec un PADS4 (HTML5) Viewer, il est conseillé d'envoyer toujours le fichier boîte noire.
</Tip>
