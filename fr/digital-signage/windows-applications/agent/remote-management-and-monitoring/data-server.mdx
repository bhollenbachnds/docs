Grâce aux fonctions du serveur de données, vous pouvez inspecter les paramètres du fournisseur de données et les données en temps réel fournies par votre PADS4 (Sub)Server.

 

#### **Pour récupérer les informations du serveur de données de votre PADS4 (Sub) Server**

1. Cliquez sur l'onglet **Serveur** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Serveur de données** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupérera automatiquement les informations demandées auprès du PADS4 Server connecté et affichera les résultats dans la fenêtre Serveur de données. Si votre installation PADS4 comprend des sous-serveurs, vous devez d'abord sélectionner un serveur avant de choisir la catégorie d'informations.

 

#### **Fenêtre Serveur de données**

La fenêtre Serveur de données affiche les fournisseurs de données et les fournisseurs de coffre de données en cours d'utilisation. Cela vous permet de vérifier les paramètres, les performances et les données en temps réel fournies par chaque fournisseur de données individuel.

![EN Agent Dataserver 1196x712 Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Dataserver_1196x712.png)

**Fournisseurs de données**

* Tous les fournisseurs de données définis actuellement utilisés par un ou plusieurs PADS4 Viewers.
* Tous les fournisseurs de coffre de données définis actuellement actifs sur le PADS4 (Sub) Server sélectionné. L'icône de cadenas devant l'icône du type de fournisseur de données indique qu'il s'agit d'un fournisseur de coffre de données.

#### **Fournisseurs de coffre de données**

De plus amples informations sur l'utilisation des fournisseurs de coffre de données sont disponibles dans la documentation de gestion du système PADS4.\
Les fournisseurs de coffre de données vous permettent de spécifier des fournisseurs de données définis par le système, qui ne sont pas modifiables par les utilisateurs de Designer, et de chiffrer les données.

Si vous survolez un élément de la liste, une info-bulle contenant des informations détaillées s'affichera.

En sélectionnant l'un des fournisseurs listés, PADS4 affichera dans la zone de droite (Fournisseur de données) des informations détaillées, et en bas, les données réelles.

**Fournisseur de données (droite)**\
Consultez les horodatages, les détails de performance et les paramètres de configuration du fournisseur sélectionné. Les paramètres de configuration sont en lecture seule. Pour modifier les paramètres de configuration d'un fournisseur de données, vous devez ajuster le fournisseur de données dans votre présentation avec l'application PADS4 Designer ou en utilisant l'application de gestion du système lorsque le fournisseur est un fournisseur de coffre de données.

**Résultats du fournisseur de données (bas)**\
Les données en temps réel sont fournies par le fournisseur de données sélectionné. Ce sont les données que le serveur de données PADS4 distribue à tous les PADS4 Viewers connectés.

 

<Tip>
  Si votre fournisseur de données utilise le serveur de données PADS4 pour collecter et fournir des données en temps réel, vous pouvez utiliser une combinaison des [Fournisseurs de données](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Data%20Providers.htm) fenêtre et la fenêtre Data Server pour vérifier la livraison des données en temps réel. Dans la fenêtre Data Server, vous pouvez vérifier si les données en temps réel sont correctement collectées par PADS4 Data Server. Dans la fenêtre Data Providers, vous pouvez vérifier si les données collectées sont correctement transmises à votre PADS4 Viewer par le Data Server.
</Tip>

<Info>
  Les informations sur les Viewers connectés à un Data Vault Provider ne sont pas disponibles. Seuls les Viewers ayant une connexion Data Provider à un Data Server sont visibles.\
  \
  Si vous vous connectez à un PADS4 Server version 4.7 ou inférieure, l'interface graphique affichera l'ancienne disposition de fenêtre.
</Info>
