Avec les fonctions du serveur de données, vous pouvez inspecter les paramètres du fournisseur de données et les données en temps réel fournies par votre PADS4 (Sub)Server.

 

#### **Pour récupérer les informations du serveur de données de votre PADS4 (Sub) Server**

1. Cliquez sur le **Server** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Data Server** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupère automatiquement les informations demandées depuis le PADS4 Server connecté et affiche les résultats dans la fenêtre Data Server. Si votre installation PADS4 comprend des sous-serveurs, vous devez d'abord sélectionner un serveur avant de choisir la catégorie d'informations.

 

#### **Fenêtre Data Server**

La fenêtre Data Server affiche les Data Providers et Data Vault Providers en cours d'utilisation. Cela vous permet de vérifier les paramètres, les performances et les données en temps réel fournies par chaque Data Provider individuel.

![EN Agent Dataserver 1196x712 Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Dataserver_1196x712.png)

**Data Providers**

* Tous les Data Providers définis actuellement utilisés par un ou plusieurs PADS4 Viewers.
* Tous les Data Vault Providers définis actuellement actifs sur le PADS4 (Sub) Server sélectionné. L'icône de cadenas devant l'icône du type de Data Provider indique qu'il s'agit d'un Data Vault Provider.

#### **Data Vault Providers**

Vous pouvez trouver plus d'informations sur l'utilisation des Data Vault Providers dans la documentation PADS4 System Management.\
Les Data Vault Providers vous permettent de spécifier des Data Providers définis par le système, qui ne sont pas modifiables par les utilisateurs Designer, et de chiffrer les données.

Si vous survolez un élément de la liste, une info-bulle contenant des informations détaillées apparaît.

Lorsque vous sélectionnez l'un des Providers listés, PADS4 affiche des informations détaillées dans la zone de droite (Data Provider) et les données réelles en bas.

**Data Provider (droite)**\
Consultez les horodatages de lecture, les détails de performance et les paramètres de configuration du Provider sélectionné. Les paramètres de configuration sont en lecture seule. Pour modifier les paramètres de configuration d'un Data Provider, vous devez ajuster le Data Provider dans votre présentation avec l'application PADS4 Designer. Lorsque le Provider est un Data Vault Provider, utilisez plutôt l'application System Management.

**Résultats du Data Provider (bas)**\
Les données en temps réel sont fournies par le Data Provider sélectionné. Ce sont les données que le PADS4 Data Server distribue à tous les PADS4 Viewers connectés.

 

<Tip>
  Si votre Data Provider utilise PADS4 Data Server pour collecter et fournir des données en temps réel, vous pouvez vérifier la livraison des données en temps réel. Pour ce faire, utilisez une combinaison de la fenêtre [Data Providers](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Data%20Providers.htm) et de la fenêtre Data Server. Dans la fenêtre Data Server, vous pouvez vérifier si les données en temps réel sont correctement collectées par le PADS4 Data Server. Dans la fenêtre Data Providers, vous pouvez vérifier si les données collectées sont correctement transmises à votre PADS4 Viewer par le Data Server.
</Tip>

<Info>
  Les informations sur les Viewers connectés à un Data Vault Provider ne sont pas disponibles. Seuls les Viewers ayant une connexion Data Provider à un Data Server sont visibles.\
  \
  Si vous vous connectez à un PADS4 Server version 4.7 ou inférieure, l'interface graphique affichera l'ancienne disposition de fenêtre.
</Info>
