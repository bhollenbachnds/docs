Avec les fonctions du Serveur de Données, vous pouvez inspecter les paramètres du Fournisseur de Données et les données en temps réel fournies par votre PADS4 (Sous-)Serveur.

 

#### **Pour récupérer les informations du Serveur de Données de votre PADS4 (Sous-)Serveur**

1. Cliquez sur l'onglet **Serveur** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Serveur de Données** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupérera automatiquement les informations demandées depuis le PADS4 Server connecté et affichera les résultats dans la fenêtre Serveur de Données. Si votre installation PADS4 comprend des sous-serveurs, vous devez d'abord sélectionner un serveur avant de sélectionner la catégorie d'informations.

 

#### **Fenêtre Serveur de Données**

La fenêtre Serveur de Données affiche les Fournisseurs de Données et les Fournisseurs de Coffre de Données en cours d'utilisation. Cela vous permet de vérifier les paramètres, les performances et les données en temps réel fournies par chaque Fournisseur de Données individuel.

![EN Agent Dataserver 1196x712 Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Dataserver_1196x712.png)

**Fournisseurs de Données**

* Tous les Fournisseurs de Données définis actuellement utilisés par un ou plusieurs PADS4 Viewers.
* Tous les Fournisseurs de Coffre de Données définis actuellement actifs sur le PADS4 (Sous-)Serveur sélectionné. L'icône de cadenas devant l'icône du type de Fournisseur de Données indique qu'il s'agit d'un Fournisseur de Coffre de Données.

#### **Fournisseurs de Coffre de Données**

Plus d'informations sur l'utilisation des Fournisseurs de Coffre de Données sont disponibles dans la documentation de Gestion du Système PADS4.\
Les fournisseurs de Data Vault permettent de spécifier des fournisseurs de données définis par le système, qui ne sont pas modifiables par les utilisateurs Designer, et de chiffrer les données.

Si vous survolez l'élément dans la liste, une info-bulle contenant des informations détaillées s'affichera.

En sélectionnant l'un des fournisseurs répertoriés, PADS4 affichera dans la zone de droite (Data Provider) des informations détaillées, et en bas, les données réelles.

**Data Provider (droite)**\
Consultez les horodatages, les détails de performance et les paramètres de configuration du fournisseur sélectionné. Les paramètres de configuration sont en lecture seule. Pour modifier les paramètres de configuration d'un Data Provider, vous devez ajuster le Data Provider dans votre présentation avec l'application PADS4 Designer ou en utilisant l'application System Management lorsque le fournisseur est un Data Vault Provider.

**Résultats du Data Provider (bas)**\
Les données en temps réel sont fournies par le Data Provider sélectionné. Ce sont les données que PADS4 Data Server distribue à tous les PADS4 Viewers connectés.

 

<Tip>
  Si votre Data Provider utilise PADS4 Data Server pour collecter et fournir des données en temps réel, vous pouvez utiliser une combinaison de la [Data Providers](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Data%20Providers.htm) fenêtre et de la fenêtre Data Server pour vérifier la livraison des données en temps réel. Dans la fenêtre Data Server, vous pouvez vérifier si les données en temps réel sont correctement collectées par PADS4 Data Server. Dans la fenêtre Data Providers, vous pouvez vérifier si les données collectées sont correctement transmises à votre PADS4 Viewer par le Data Server.
</Tip>

<Info>
  Les informations sur les Viewers connectés à un Data Vault Provider ne sont pas disponibles. Seuls les Viewers disposant d'une connexion Data Provider à un Data Server sont visibles.\
  \
  Si vous vous connectez à un PADS4 Server version 4.7 ou inférieure, l'interface graphique affichera l'ancienne disposition de fenêtre.
</Info>
