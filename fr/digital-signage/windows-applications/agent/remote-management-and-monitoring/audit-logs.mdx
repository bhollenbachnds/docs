Grâce aux fonctions de journal de piste d'audit, vous pouvez consulter les journaux d'audit stockés sur votre PADS4 Server.

Grâce aux journaux d'audit, vous pouvez, par exemple, identifier le comportement de connexion/déconnexion des utilisateurs. De plus, il est possible de savoir quel utilisateur a planifié une certaine présentation ou modifié certains paramètres. Si un utilisateur tente d'utiliser une application non autorisée, cette activité inappropriée est enregistrée dans la piste d'audit.

 

#### Pour consulter les journaux d'audit stockés sur votre PADS4 Server

1. Cliquez sur l'onglet **Serveur** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Journaux d'audit** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupérera automatiquement les informations demandées depuis le PADS4 Server connecté et affichera les résultats dans la fenêtre du journal d'audit. Par défaut, la période sélectionnée correspond au mois en cours à partir du 1er.

<Warning>
  Par défaut, les journaux d'audit sont désactivés. Utilisez l'application de gestion du système pour modifier les paramètres du serveur afin de permettre l'enregistrement des journaux d'audit.
</Warning>

 

#### Fenêtre des journaux d'audit

La fenêtre Journaux d'audit affiche les entrées de journal d'audit qui ont été stockées sur votre PADS4 Server.

![EN Agent Audit Window Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-AuditWindow.png)

Dans la fenêtre des journaux d'audit de votre PADS4 Server, vous pouvez consulter toutes les entrées de journal qui ont été enregistrées sur votre PADS4 Server.

Vous pouvez spécifier la **période**. Vous pouvez également **filtrer les données** en cliquant sur l'icône de filtre dans l'en-tête de colonne. Cliquez sur **Exporter la vue** pour exporter les données, y compris les filtres définis.

 

**Horodatage**\
Date et heure auxquelles l'action a été enregistrée.

**Nom d'utilisateur**\
Quel utilisateur a effectué cette action.

**Application**\
Quelle application a été utilisée par cet utilisateur.

**Description**\
Une description qui décrit l'action effectuée par l'utilisateur. ("Updated Schedule x", "Updated Server Settings", "Created new Schedule y")

**Détails**\
Lorsque les modifications (mise à jour) affectent un ou plusieurs changements de propriété (par exemple "Priority to High" ou "StartDate to 01/01/2017"), ceux-ci seront enregistrés dans la colonne des détails.\
Chaque paire Propriété et nouvelle valeur est séparée par un saut de ligne.

**Usertype**\
Utilisateur PADS ou LDAP provenant d'Active Directory.

**Displayname**\
Nom d'utilisateur saisi dans l'application de gestion du système pour identifier un utilisateur ou récupéré par LDAP.

**EventType**\
Type d'action effectuée.

| Logon   | L'utilisateur tente de se connecter                                                |
| :------ | :--------------------------------------------------------------------------------- |
| Logoff  | L'utilisateur tente de se déconnecter                                              |
| Create  | L'utilisateur crée une entrée (l'entrée est spécifique à l'action effectuée)       |
| Update  | L'utilisateur met à jour une entrée (l'entrée est spécifique à l'action effectuée) |
| Delete  | L'utilisateur supprime une entrée (l'entrée est spécifique à l'action effectuée)   |
| Execute | L'utilisateur exécute une tâche Agent                                              |

**IPAddress**\
Adresse IP depuis laquelle l'utilisateur a démarré l'application.\
La colonne contient \[local] lorsque l'application s'exécute sur le même ordinateur que le serveur PADS4.

**Computername**\
Nom de l'ordinateur sur lequel l'application s'exécute.

**HistoricalID**\
L'ID interne peut être utilisé pour regrouper les actions basées sur la même destination afin de les analyser (par exemple, modifier un planning).

**Servername**\
Sur quel serveur cette action a-t-elle été effectuée.

 

#### Période

Spécifiez la période à partir de laquelle les données doivent être récupérées. Si aucune donnée n'est disponible, un message s'affichera.

 

#### Exportation des informations des journaux d'audit

Pour traiter les informations des journaux d'audit dans une application externe (comme Microsoft Excel), vous pouvez les exporter dans différents formats. Cela inclut XML et le format Microsoft Excel.

Pour exporter les informations des journaux d'audit :

1. Cliquez sur **Export** dans le menu **Home**.
2. Saisissez la **Start** et la **End** de la période pour laquelle vous souhaitez exporter les informations de preuve de diffusion.

   ![EN Agent Audit Export Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-AuditExport.png)
3. Sélectionnez le type de sortie, **XML** ou **Excel**.
4. Cliquez sur **Browse** pour spécifier le **File Name** du fichier dans lequel vous souhaitez enregistrer les résultats de l'exportation.
5. Dans la boîte de dialogue Enregistrer qui apparaît, spécifiez le nom du fichier et sélectionnez le format de fichier dans lequel vous souhaitez que les informations soient enregistrées, puis cliquez sur **Save**.
6. Cliquez sur **Export** pour commencer à enregistrer toutes les informations de preuve de diffusion pour la période spécifiée dans le fichier spécifié.

 

#### Quelles informations utilisateur sont enregistrées ?

* Tentatives de connexion / déconnexion pour chaque application PADS4
* Actions CRUD (Create/Read/Update/Delete) du Scheduler pour la planification des présentations dans l'application PADS4 Scheduler\
  Les mises à jour sont enregistrées en détail. (niveau propriété, quelles sont les modifications entre l'ancienne et la nouvelle situation)
* Actions CRUD (Create/Read/Update/Delete) du Messenger pour la planification des présentations dans l'application PADS4 Messenger\
  Les mises à jour sont enregistrées en détail. (niveau propriété, quelles sont les modifications entre l'ancienne et la nouvelle situation)
* Récupération des informations serveur par l'Agent dans le PADS4 Agent\
  Viewer Connections, User Connections, Scheduled Tasks, Monitoring & Alerts, Synchronization Queue, Content Library, Data Server, PADS4 Software, System Info, Processes, Services, Windows logs, Viewer Variables, Television channels.
* Récupération des informations Viewer par l'Agent dans le PADS4 Agent\
  Screenshot, Viewer log, Memory usage, Content library, Synchronization log, Scheduled presentations, Data providers, Viewer settings, PADS4 software, Add-Ons, Scheduled tasks, Monitoring & alerts, System info, Processes, Services, Windows logs, Fonts, Proof of play, television.
* Actions de connexion Viewer de l'Agent (serveur) : **restart/reboot/shutdown/wake-on-lan**
* Actions de connexion utilisateur de l'Agent (serveur) : **close connection**
* Actions de tâche planifiée de l'Agent (serveur) : **New/Edit/Duplicate/Delete/Enable/Disable**
* Actions Monitoring & Alert de l'Agent (serveur) : **Add/Edit/Duplicate/Delete/Enable/Disable/Pending/Resolved**
* Action logicielle PADS4 de l'Agent (serveur) : **Update**
* Actions Processus de l'Agent (serveur) : **Start/Stop/Restart**
* Actions Services de l'Agent (serveur) : **Start/Pause/Restart**
* Actions journaux Windows de l'Agent (serveur) : **Clear log**
* Actions journal d'audit de l'Agent (serveur) : **Export**
* Actions preuve de diffusion de l'Agent (serveur) : **Export**
* Actions variables Viewer de l'Agent (serveur) : **Edit/Reset/Duplicate**
* Actions chaînes de télévision de l'Agent (serveur) : **Add/Edit/Delete/Merge**
* Actions journal Viewer de l'Agent (viewer) : **Clear log/Save blackbox**
* Actions utilisation mémoire de l'Agent (viewer) : **Clear log/Save blackbox** 
* Actions journal de synchronisation de l'Agent (viewer) : **Clear log/Save blackbox**
* Actions paramètres Viewer de l'Agent (viewer) : **Edit**
* Actions logicielles PADS4 de l'Agent (viewer) : **Update**
* Actions Add-Ons de l'Agent (viewer) : **Installation Wizard**
* Actions Processus de l'Agent (viewer) : **Start/Restart/Stop**
* Actions Services de l'Agent (viewer) : **Start/Pause/Restart**
* Actions journaux Windows de l'Agent (viewer) : **Clear log**
* Actions Polices de l'Agent (viewer) : **Install/Install from file/Uninstall**
* Actions Télévision de l'Agent (viewer) : **Auto channel scan/copy to destinations/create channel name**
* Actions de gestion du système - Destinations : **Ajouter/Modifier/Supprimer/Réactivation du Viewer**
* Actions de gestion du système - Utilisateurs : **Ajouter/Modifier/Supprimer/Réinitialiser le mot de passe**
* Actions de gestion du système - Groupes d'utilisateurs : **Nouveau/Modifier/Supprimer**
* Actions de gestion du système - Permissions : **Nouveau/Modifier/Supprimer**
* Actions de gestion du système - Priorités : **Ajouter/Modifier/Supprimer/Augmenter le niveau/Diminuer le niveau**
* Gestion du système - Catégories de contenu : **Nouveau/Modifier/Supprimer**
* Actions de gestion du système - Serveurs : **Nouveau sous-serveur/Nouveau serveur de sauvegarde/Modifier/Supprimer**
* Actions de gestion du système - Licences : **Attribuer une licence/Assistant de retrait de licence**

* Actions de gestion du système - Variables du Viewer : **Ajouter/Modifier/Supprimer**
* Content Organizer : actions sur les dossiers et fichiers de contenu : **Ajouter/Modifier/Supprimer/Déplacer**

 

<Tip>
  Lors de l'exportation, vous recevrez deux colonnes supplémentaires EventTypeID et ApplicationID qui contiennent la valeur numérique de EventType et Application.\

  Utilisateur, Période, Date de génération et éventuellement le filtre utilisé sur la grille.
</Tip>
