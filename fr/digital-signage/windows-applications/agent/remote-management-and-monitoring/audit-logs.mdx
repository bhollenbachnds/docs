Grâce aux fonctions de journal de piste d'audit, vous pouvez consulter les journaux d'audit stockés sur votre serveur PADS4.

Avec les journaux d'audit, vous pouvez, par exemple, identifier le comportement de connexion/déconnexion des utilisateurs. De plus, il est possible de savoir quel utilisateur a planifié une certaine présentation ou modifié certains paramètres. Si un utilisateur tente d'utiliser une application non autorisée, cette activité inappropriée est enregistrée dans la piste d'audit.

 

#### Pour consulter les journaux d'audit stockés sur votre serveur PADS4

1. Cliquez sur **Server** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Audit Logs** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupérera automatiquement les informations demandées depuis le serveur PADS4 connecté et affichera les résultats dans la fenêtre du journal d'audit. Par défaut, la période du mois en cours à partir du 1er est sélectionnée.

<Warning>
  Par défaut, les journaux d'audit sont désactivés. Utilisez l'application System Management pour modifier les paramètres du serveur afin de permettre l'enregistrement des journaux d'audit.
</Warning>

 

#### Fenêtre des journaux d'audit

La fenêtre Audit Logs affiche les entrées du journal d'audit qui ont été stockées sur votre serveur PADS4.

![EN Agent Audit Window Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-AuditWindow.png)

Dans la fenêtre des journaux d'audit de votre serveur PADS4, vous pouvez consulter toutes les entrées de journal qui ont été enregistrées sur votre serveur PADS4.

Vous pouvez spécifier la **période**. Vous pouvez également **filtrer les données** en cliquant sur l'icône de filtre dans l'en-tête de colonne. Cliquez sur **Export View** pour exporter les données, y compris les filtres définis.

 

**Timestamp**\
Date et heure auxquelles l'action a été enregistrée.

**Username**\
Quel utilisateur a effectué cette action.

**Application**\
Quelle application a été utilisée par cet utilisateur.

**Description**\
Une description qui décrit l'action effectuée par l'utilisateur. ("Updated Schedule x", "Updated Server Settings", "Created new Schedule y")

**Détails**\
Lorsque les modifications (mise à jour) affectent un ou plusieurs changements de propriété (par exemple "Priority to High" ou "StartDate to 01/01/2017"), ceux-ci seront enregistrés dans la colonne des détails.\
Chaque paire Propriété et nouvelle valeur est séparée par un saut de ligne.

**Usertype**\
Utilisateur PADS ou LDAP depuis Active Directory.

**Displayname**\
Nom d'utilisateur saisi dans l'application System Management pour identifier un utilisateur ou récupéré par LDAP.

**EventType**\
Type d'action effectuée.

| Logon   | L'utilisateur tente de se connecter                                                |
| :------ | :--------------------------------------------------------------------------------- |
| Logoff  | L'utilisateur tente de se déconnecter                                              |
| Create  | L'utilisateur crée une entrée (l'entrée est spécifique à l'action effectuée)       |
| Update  | L'utilisateur met à jour une entrée (l'entrée est spécifique à l'action effectuée) |
| Delete  | L'utilisateur supprime une entrée (l'entrée est spécifique à l'action effectuée)   |
| Execute | L'utilisateur exécute une tâche Agent                                              |

**IPAddress**\
Adresse IP depuis laquelle l'utilisateur a démarré l'application.\
La colonne contient \[local] lorsque l'application s'exécute sur le même ordinateur que le serveur PADS4.

**Computername**\
Nom de l'ordinateur sur lequel l'application s'exécute.

**HistoricalID**\
L'ID interne peut être utilisé pour regrouper afin que les actions basées sur la même destination puissent être examinées (par exemple, modifier un planning).

**Servername**\
Sur quel serveur cette action a-t-elle été effectuée.

 

#### Période

Spécifiez la période à partir de laquelle les données doivent être récupérées. Lorsqu'aucune donnée n'est disponible, un message s'affichera.

 

#### Exportation des informations des journaux d'audit

Pour traiter les informations des journaux d'audit dans une application externe (comme Microsoft Excel), vous pouvez les exporter dans différents formats. Cela inclut XML et le format Microsoft Excel.

Pour exporter les informations des journaux d'audit :

1. Cliquez sur **Export** dans le menu **Home**.
2. Saisissez le **Début** et la **Fin** de la période pour laquelle vous souhaitez exporter les informations de preuve de diffusion.

   ![EN Agent Audit Export Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-AuditExport.png)
3. Sélectionnez le type de sortie, **XML** ou **Excel**.
4. Cliquez sur **Browse** pour spécifier le **Nom du fichier** du fichier dans lequel vous souhaitez enregistrer les résultats de l'exportation.
5. Dans la boîte de dialogue Enregistrer qui apparaît, spécifiez le nom du fichier et sélectionnez le format de fichier dans lequel vous souhaitez enregistrer les informations, puis cliquez sur **Enregistrer**.
6. Cliquez sur **Exporter** pour commencer à enregistrer toutes les informations de preuve de diffusion pour la période spécifiée dans le fichier spécifié.

 

#### Quelles informations utilisateur sont enregistrées ?

* Tentatives de connexion / déconnexion pour chaque application PADS4
* Actions CRUD (Créer/Lire/Mettre à jour/Supprimer) du Scheduler pour la planification des présentations dans l'application PADS4 Scheduler\
  Les mises à jour sont enregistrées en détail. (niveau propriété, quelles sont les modifications entre l'ancienne et la nouvelle situation)
* Actions CRUD (Créer/Lire/Mettre à jour/Supprimer) du Messenger pour la planification des présentations dans l'application PADS4 Messenger\
  Les mises à jour sont enregistrées en détail. (niveau propriété, quelles sont les modifications entre l'ancienne et la nouvelle situation)
* Récupération des informations du serveur par l'Agent dans le PADS4 Agent\
  Connexions des viewers, Connexions utilisateurs, Tâches planifiées, Surveillance et alertes, File de synchronisation, Bibliothèque de contenu, Serveur de données, Logiciel PADS4, Informations système, Processus, Services, Journaux Windows, Variables du viewer, Chaînes de télévision.
* Récupération des informations du viewer par l'Agent dans le PADS4 Agent\
  Capture d'écran, Journal du viewer, Utilisation de la mémoire, Bibliothèque de contenu, Journal de synchronisation, Présentations planifiées, Fournisseurs de données, Paramètres du viewer, Logiciel PADS4, Add-Ons, Tâches planifiées, Surveillance et alertes, Informations système, Processus, Services, Journaux Windows, Polices, Preuve de diffusion, Télévision.

* Actions de tâches planifiées Agent (serveur) : **Nouveau/Modifier/Dupliquer/Supprimer/Activer/Désactiver**
* Actions de surveillance et alertes Agent (serveur) : **Ajouter/Modifier/Dupliquer/Supprimer/Activer/Désactiver/En attente/Résolu**
* Action logiciel PADS4 Agent (serveur) : **Mettre à jour**
* Actions de processus Agent (serveur) : **Démarrer/Arrêter/Redémarrer**
* Actions de services Agent (serveur) : **Démarrer/Mettre en pause/Redémarrer**
* Actions de journaux Windows Agent (serveur) : **Effacer le journal**
* Actions de journal d'audit Agent (serveur) : **Exporter**
* Actions de preuve de diffusion Agent (serveur) : **Exporter**
* Actions de variables du viewer Agent (serveur) : **Modifier/Réinitialiser/Dupliquer**
* Actions de chaînes de télévision Agent (serveur) : **Ajouter/Modifier/Supprimer/Fusionner**
* Actions de journal du viewer Agent (viewer) : **Effacer le journal/Enregistrer la boîte noire**
* Actions d'utilisation de la mémoire Agent (viewer) :**Effacer le journal/Enregistrer la boîte noire** 
* Actions de journal de synchronisation Agent (viewer) : **Effacer le journal/Enregistrer la boîte noire**
* Actions de paramètres du viewer Agent (viewer) : **Modifier**
* Actions logiciel PADS4 Agent (viewer) : **Mettre à jour**
* Actions Add-Ons Agent (viewer) : **Assistant d'installation**
* Actions de processus Agent (viewer) : **Démarrer/Redémarrer/Arrêter**
* Actions de services Agent (viewer) : **Démarrer/Mettre en pause/Redémarrer**
* Actions de journaux Windows Agent (viewer) : **Effacer le journal**
* Actions de polices Agent (viewer) : **Installer/Installer depuis un fichier/Désinstaller**
* Actions de télévision Agent (viewer) : **Balayage automatique des chaînes/copier vers les destinations/créer un nom de chaîne**
* Actions de destinations de gestion du système : **Ajouter/Modifier/Supprimer/Réactivation du viewer**
