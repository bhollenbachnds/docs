Avec les fonctions du journal de piste d'audit, vous pouvez consulter les journaux d'audit stockés sur votre PADS4 Server.

Avec les journaux d'audit, vous pouvez, par exemple, identifier le comportement de connexion/déconnexion des utilisateurs. De plus, il est possible de savoir quel utilisateur a planifié une certaine présentation, ou modifié certains paramètres. Si un utilisateur tente d'utiliser une application non autorisée, cette activité inappropriée est enregistrée dans la piste d'audit.

 

#### Pour consulter les journaux d'audit stockés sur votre PADS4 Server

1. Cliquez sur l'onglet **Serveur** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Journaux d'audit** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupérera automatiquement les informations demandées depuis le PADS4 Server connecté et affichera les résultats dans la fenêtre du journal d'audit. Par défaut, la période du mois en cours à partir du 1er est sélectionnée.

<Warning>
  Par défaut, les journaux d'audit sont désactivés. Utilisez l'application System Management pour modifier les paramètres du serveur afin de permettre l'enregistrement des journaux d'audit.
</Warning>

 

#### Fenêtre des journaux d'audit

La fenêtre des journaux d'audit affiche les entrées de journal d'audit qui ont été stockées sur votre PADS4 Server.

![EN Agent Audit Window Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-AuditWindow.png)

Dans la fenêtre des journaux d'audit de votre PADS4 Server, vous pouvez consulter toutes les entrées de journal qui ont été enregistrées sur votre PADS4 Server.

Vous pouvez spécifier la **période**. Vous pouvez également **filtrer les données** en cliquant sur l'icône de filtre dans l'en-tête de colonne. Cliquez sur **Exporter la vue** pour exporter les données, y compris les filtres définis.

 

**Horodatage**\
Date et heure à laquelle l'action a été enregistrée.

**Nom d'utilisateur**\
Quel utilisateur a effectué cette action.

**Application**\
Quelle application a été utilisée par cet utilisateur.

**Description**\
Une description qui décrit l'action effectuée par l'utilisateur. ("Planification x mise à jour", "Paramètres du serveur mis à jour", "Nouvelle planification y créée")

**Détails**\
Lorsque les modifications (mise à jour) affectent un ou plusieurs changements de propriété (exemple "Priorité à Haute", ou "DateDébut au 01/01/2017"), ceux-ci seront enregistrés dans la colonne des détails.\
Chaque paire Propriété et nouvelle valeur est séparée par un saut de ligne.

**Type d'utilisateur**\
Utilisateur PADS ou LDAP depuis Active Directory.

**Nom d'affichage**\
Nom d'utilisateur saisi dans l'application System Management pour identifier un utilisateur ou récupéré par LDAP.

**TypeÉvénement**\
Type d'action effectuée.

| Connexion     | L'utilisateur tente de se connecter                                                |
| :------------ | :--------------------------------------------------------------------------------- |
| Déconnexion   | L'utilisateur tente de se déconnecter                                              |
| Créer         | L'utilisateur crée une entrée (l'entrée est spécifique à l'action effectuée)       |
| Mettre à jour | L'utilisateur met à jour une entrée (l'entrée est spécifique à l'action effectuée) |
| Supprimer     | L'utilisateur supprime une entrée (l'entrée est spécifique à l'action effectuée)   |
| Exécuter      | L'utilisateur exécute une tâche Agent                                              |

**AdresseIP**\
Adresse IP depuis laquelle l'utilisateur a démarré l'application.\
La colonne contient \[local] lorsque l'application s'exécute sur le même ordinateur que le PADS4 Server.

**Nom de l'ordinateur**\
Nom de l'ordinateur sur lequel l'application s'exécute.

**IDHistorique**\
L'ID interne peut être utilisé pour regrouper afin que les actions basées sur la même destination puissent être examinées (par exemple, modifier une planification).

**Nom du serveur**\
Sur quel serveur cette action a-t-elle été effectuée.

 

#### Période

Spécifiez la période à partir de laquelle les données doivent être récupérées. Lorsqu'aucune donnée n'est disponible, un message sera affiché.

 

#### Exportation des informations des journaux d'audit

Pour traiter les informations des journaux d'audit dans une application externe (comme Microsoft Excel), vous pouvez les exporter dans différents formats. Cela inclut XML et le format Microsoft Excel.

Pour exporter les informations des journaux d'audit :

1. Cliquez sur **Exporter** dans le menu **Accueil**.
2. Entrez le **Début** et la **Fin** de la période pour laquelle vous souhaitez exporter les informations de preuve de diffusion.

   ![EN Agent Audit Export Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-AuditExport.png)
3. Sélectionnez le type de sortie, **XML** ou **Excel**.
4. Cliquez sur **Parcourir** pour spécifier le **Nom du fichier** du fichier dans lequel vous souhaitez enregistrer les résultats de l'exportation.
5. Dans la boîte de dialogue Enregistrer qui apparaît, spécifiez le nom du fichier et sélectionnez le format de fichier dans lequel vous souhaitez que les informations soient enregistrées, puis cliquez sur **Enregistrer**.
6. Cliquez sur **Exporter** pour commencer à enregistrer toutes les informations de preuve de diffusion pour la période spécifiée dans le fichier spécifié.

 

#### Quelles informations utilisateur sont enregistrées ?

* Tentatives de connexion / déconnexion pour chaque application PADS4
* Actions CRUD (Créer/Lire/Mettre à jour/Supprimer) du Scheduler pour la planification des présentations dans l'application PADS4 Scheduler\
  Les mises à jour sont enregistrées en détail. (niveau des propriétés, quelles sont les modifications entre l'ancienne et la nouvelle situation)
* Actions CRUD (Créer/Lire/Mettre à jour/Supprimer) du Messenger pour la planification des présentations dans l'application PADS4 Messenger\
  Les mises à jour sont enregistrées en détail. (niveau des propriétés, quelles sont les modifications entre l'ancienne et la nouvelle situation)
* Récupération des informations du serveur par l'Agent dans le PADS4 Agent\
  Connexions des viewers, Connexions des utilisateurs, Tâches planifiées, Surveillance et alertes, File de synchronisation, Bibliothèque de contenu, Serveur de données, Logiciel PADS4, Informations système, Processus, Services, Journaux Windows, Variables du viewer, Chaînes de télévision.
* Récupération des informations du viewer par l'Agent dans le PADS4 Agent\
  Capture d'écran, Journal du viewer, Utilisation de la mémoire, Bibliothèque de contenu, Journal de synchronisation, Présentations planifiées, Fournisseurs de données, Paramètres du viewer, Logiciel PADS4, Add-Ons, Tâches planifiées, Surveillance et alertes, Informations système, Processus, Services, Journaux Windows, Polices, Preuve de diffusion, Télévision.
* Actions de connexion du viewer Agent (serveur) : **redémarrer/redémarrer le système/arrêter/wake-on-lan**
* Actions de connexion utilisateur Agent (serveur) : **fermer la connexion**
* Actions de tâche planifiée Agent (serveur) : **Nouveau/Modifier/Dupliquer/Supprimer/Activer/Désactiver**
* Actions de surveillance et d'alerte Agent (serveur) : **Ajouter/Modifier/Dupliquer/Supprimer/Activer/Désactiver/En attente/Résolu**
* Action du logiciel PADS4 Agent (serveur) : **Mettre à jour**
* Actions de processus Agent (serveur) : **Démarrer/Arrêter/Redémarrer**
* Actions de services Agent (serveur) : **Démarrer/Mettre en pause/Redémarrer**
* Actions des journaux Windows Agent (serveur) : **Effacer le journal**
* Actions du journal d'audit Agent (serveur) : **Exporter**
* Actions de preuve de diffusion Agent (serveur) : **Exporter**
* Actions de variables du viewer Agent (serveur) : **Modifier/Réinitialiser/Dupliquer**
* Actions de chaînes de télévision Agent (serveur) : **Ajouter/Modifier/Supprimer/Fusionner**
* Actions du journal du viewer Agent (viewer) : **Effacer le journal/Enregistrer la boîte noire**
* Actions d'utilisation de la mémoire Agent (viewer) :**Effacer le journal/Enregistrer la boîte noire** 
* Actions du journal de synchronisation Agent (viewer) : **Effacer le journal/Enregistrer la boîte noire**
* Actions des paramètres du viewer Agent (viewer) : **Modifier**
* Actions du logiciel PADS4 Agent (viewer) : **Mettre à jour**
* Actions des Add-Ons Agent (viewer) : **Assistant d'installation**
* Actions de processus Agent (viewer) : **Démarrer/Redémarrer/Arrêter**
* Actions de services Agent (viewer) : **Démarrer/Mettre en pause/Redémarrer**
* Actions des journaux Windows Agent (viewer) : **Effacer le journal**
* Actions des polices Agent (viewer) : **Installer/Installer depuis un fichier/Désinstaller**
* Actions de télévision Agent (viewer) : **Balayage automatique des chaînes/copier vers les destinations/créer un nom de chaîne**
* Actions des destinations de gestion du système : **Ajouter/Modifier/Supprimer/Réactivation du viewer**
