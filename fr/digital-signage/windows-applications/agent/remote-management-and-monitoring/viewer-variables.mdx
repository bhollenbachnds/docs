Grâce aux fonctions de variables Viewer, vous pouvez consulter et modifier les variables Viewer actuellement disponibles dans le système PADS4.

 

#### **Pour consulter les informations sur les variables Viewer stockées sur votre serveur PADS4**

1. Cliquez sur l'onglet **Server** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Viewer variables** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupère automatiquement les informations demandées depuis le serveur PADS4 connecté et affiche les résultats dans la fenêtre Viewer variables.

 

#### **Fenêtre Viewer variables**

La fenêtre Viewer variables affiche toutes les entrées qui ont été stockées sur votre serveur PADS4.\
Les variables Viewer sont créées à l'aide de l'application PADS4 System Management.

 

**Edit**\
Modifiez la valeur d'une variable Viewer. Cliquez sur le bouton **Edit** dans la barre de ruban.

![En Agent Viewervariablesdocedit Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/en_agent_viewervariablesdocedit.png)

\
Cliquez sur la colonne Valeur de la variable Viewer que vous souhaitez modifier manuellement.

**Reset**\
Cliquez sur le bouton Reset dans la barre de ruban pour réinitialiser les valeurs à la valeur par défaut pour ce Viewer.

 

**Duplicate**\
Cliquez sur le bouton **Duplicate** dans la barre de ruban pour dupliquer cette valeur vers un ou plusieurs Viewers.\
Il vous sera demandé de spécifier les destinations.\
\
Cela vous permet de définir la valeur pour plusieurs viewers simultanément.

 

**Export**\
Exportez toutes les variables viewer vers Microsoft Excel. Lorsque vous souhaitez dupliquer des variables viewer vers un autre système PADS4, ou lorsque vous souhaitez modifier les valeurs des variables viewer dans Excel, ce qui permet des actions de copier/coller plus avancées, l'export crée une feuille Excel avec toutes les variables viewer. Seules les cellules modifiables sont déverrouillées.

 

**Import**\
Importez des variables viewer depuis Microsoft Excel.

Lors de l'importation, une fenêtre d'aperçu s'affiche montrant les résultats après l'import. Il existe deux options d'importation. L'une est un remplacement où toutes les variables viewer sont remplacées, et l'autre est une fusion où les variables viewer existantes sont mises à jour et les nouvelles variables viewer sont ajoutées.

* Il est possible d'importer de nouvelles variables viewer dans le document Excel
* Il n'est pas possible d'importer de nouveaux noms de viewers dans le document Excel
* Les cellules non modifiables sont verrouillées
* Utilisez le modèle de document Excel issu de l'export
* Les documents Excel ne correspondant pas au modèle seront ignorés

 

<Warning>
  L'ajout/la suppression de variables Viewer s'effectue avec l'application PADS4 System Management.
</Warning>
