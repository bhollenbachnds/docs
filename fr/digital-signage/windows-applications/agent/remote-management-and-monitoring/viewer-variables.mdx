Grâce aux fonctions de variables Viewer, vous pouvez afficher et modifier les variables Viewer actuellement disponibles dans le système PADS4.

 

#### **Pour afficher les informations sur les variables Viewer stockées sur votre serveur PADS4**

1. Cliquez sur l'onglet **Server** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Viewer variables** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupère automatiquement les informations demandées depuis le serveur PADS4 connecté et affiche les résultats dans la fenêtre Viewer variables.

 

#### **Fenêtre Viewer variables**

La fenêtre Viewer variables affiche toutes les entrées qui ont été stockées sur votre serveur PADS4.\
Les Viewer variables sont créées à l'aide de l'application PADS4 System Management.

 

**Edit**\
Modifiez la valeur d'une Viewer variable. Cliquez sur le bouton **Edit** dans la barre de ruban.

![En Agent Viewervariablesdocedit Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/en_agent_viewervariablesdocedit.png)

\
Cliquez sur la colonne Valeur de la Viewer variable que vous souhaitez modifier manuellement.

**Réinitialiser**\
Cliquez sur le bouton Réinitialiser dans la barre de ruban pour rétablir les valeurs par défaut de ce Viewer.

 

**Dupliquer**\
Cliquez sur le **Dupliquer** bouton dans la barre de ruban pour dupliquer cette valeur vers un ou plusieurs Viewers.\
Il vous sera demandé de spécifier les destinations.\
\
Cela vous permet de définir la valeur pour plusieurs viewers en même temps.

 

**Exporter**\
Exportez toutes les variables du viewer vers Microsoft Excel. Lorsque vous souhaitez dupliquer des variables de viewer vers un autre système PADS4, ou lorsque vous souhaitez modifier les valeurs des variables de viewer dans Excel, ce qui permet des actions de copier/coller plus avancées, l'exportation crée une feuille Excel avec toutes les variables du viewer. Seules les cellules modifiables sont déverrouillées.

 

**Importer**\
Importez des variables de viewer depuis Microsoft Excel.

Lors de l'importation, une fenêtre d'aperçu s'affiche montrant les résultats après l'importation. Il existe deux options d'importation. L'une est un remplacement où toutes les variables du viewer sont remplacées, et l'autre est une fusion où les variables du viewer existantes sont mises à jour et les nouvelles variables du viewer sont ajoutées.

* Il est possible d'importer de nouvelles variables de viewer dans le document Excel
* Il n'est pas possible d'importer de nouveaux noms de viewer dans le document Excel
* Les cellules non modifiables sont verrouillées
* Utilisez le modèle de document Excel issu de l'exportation
* Les documents Excel qui ne correspondent pas au modèle seront ignorés

 

<Warning>
  L'ajout/la suppression de variables de viewer s'effectue avec l'application PADS4 System Management.
</Warning>
