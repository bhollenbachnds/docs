Avec les fonctions de variables Viewer, vous pouvez afficher et modifier les variables Viewer actuellement disponibles dans le système PADS4.

 

#### **Pour afficher les informations sur les variables Viewer stockées sur votre serveur PADS4**

1. Cliquez sur l'onglet **Serveur** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Variables Viewer** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupérera automatiquement les informations demandées depuis le serveur PADS4 connecté et affichera les résultats dans la fenêtre des variables Viewer.

 

#### **Fenêtre des variables Viewer**

La fenêtre des variables Viewer affiche toutes les entrées qui ont été stockées sur votre serveur PADS4.\
Les variables Viewer sont créées à l'aide de l'application PADS4 System Management.

 

**Modifier**\
Modifier la valeur d'une variable Viewer. Cliquez sur le bouton **Modifier** dans la barre de ruban.

![En Agent Viewervariablesdocedit Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/en_agent_viewervariablesdocedit.png)

\
Cliquez sur la colonne Valeur pour la variable Viewer que vous souhaitez modifier manuellement.

**Réinitialiser**\
Cliquez sur le bouton Réinitialiser dans la barre de ruban pour rétablir les valeurs par défaut pour ce Viewer.

 

**Dupliquer**\
Cliquez sur le bouton **Dupliquer** dans la barre de ruban pour dupliquer cette valeur vers un ou plusieurs Viewers.\
Il vous sera demandé de spécifier les destinations.\
\
Cela vous permet de définir la valeur pour plusieurs Viewers en même temps.

 

**Exporter**\
Exporter toutes les variables Viewer vers Microsoft Excel. Lorsque vous souhaitez dupliquer des variables Viewer vers un autre système PADS4, ou lorsque vous souhaitez modifier les valeurs des variables Viewer dans Excel, ce qui permet des actions de copier/coller plus avancées, l'exportation crée une feuille Excel avec toutes les variables Viewer. Seules les cellules modifiables sont déverrouillées.

 

**Importer**\
Importer des variables Viewer depuis Microsoft Excel.

Lors de l'importation, une fenêtre d'aperçu s'affiche montrant les résultats après l'importation. Il existe deux options d'importation. L'une est un remplacement où toutes les variables Viewer sont remplacées, et l'autre est une fusion où les variables Viewer existantes sont mises à jour et de nouvelles variables Viewer sont ajoutées.

* Il est possible d'importer de nouvelles variables Viewer dans le document Excel
* Il n'est pas possible d'importer de nouveaux noms de Viewer dans le document Excel
* Les cellules non modifiables sont verrouillées
* Utiliser le modèle de document Excel issu de l'exportation
* Les documents Excel ne correspondant pas au modèle seront ignorés

 

<Warning>
  L'ajout/la suppression de variables Viewer s'effectue avec l'application PADS4 System Management.
</Warning>
