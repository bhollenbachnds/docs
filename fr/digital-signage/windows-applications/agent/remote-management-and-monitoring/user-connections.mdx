- title: Connexions utilisateur
- description: Consultez les applications PADS4 auxquelles chaque utilisateur est
    connecté et depuis combien de temps, et forcez la fermeture d'une connexion
    sur une ou toutes les applications depuis PADS4 Agent.
---

Avec les fonctions de connexion utilisateur, vous pouvez vérifier à distance pour tous les utilisateurs du système PADS4 dans quelles applications ils sont connectés et éventuellement forcer la fermeture d'une connexion sur une ou toutes les applications.

 

#### **Pour vérifier l'état de connexion de vos utilisateurs PADS4**

1. Cliquez sur l'onglet **Serveur** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Connexions utilisateur** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupérera automatiquement les informations demandées depuis le serveur PADS4 connecté et affichera les résultats dans la fenêtre des connexions utilisateur. Si votre installation PADS4 comprend des sous-serveurs, la fenêtre des connexions utilisateur affichera toujours les résultats globaux de l'ensemble de votre installation PADS4, quel que soit le serveur que vous avez sélectionné.

 

#### **Fenêtre des connexions utilisateur**

Dans la fenêtre des connexions utilisateur, vous pouvez voir en un coup d'œil quel utilisateur est connecté à quelle application PADS4 et depuis combien de temps.

![EN Agent Userconnections Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Userconnections.png)

* La première colonne affiche les utilisateurs, les colonnes suivantes contiennent les applications PADS4. Les durées affichées indiquent depuis combien de temps l'utilisateur est connecté à une certaine application. Si vous survolez la durée avec le curseur de la souris, une fenêtre contextuelle avec des informations plus détaillées s'affiche.
* Si vous souhaitez (forcer) la fermeture d'une connexion, sélectionnez la cellule avec la durée que vous souhaitez fermer en cliquant sur la durée et sélectionnez l'option **Fermer la connexion** dans la barre de ruban en haut dans le groupe Gérer.
* Si vous souhaitez fermer (forcer la fermeture de) toutes les connexions, sélectionnez la cellule Utilisateur que vous souhaitez fermer en cliquant sur le nom d'utilisateur et sélectionnez le **Close Connection** option dans la barre de ruban en haut dans le groupe Gérer.
* Si vous souhaitez afficher uniquement les utilisateurs ayant 1 connexion ouverte ou plus, sélectionnez l'option **Connected** dans le groupe Afficher de la barre de ruban.
