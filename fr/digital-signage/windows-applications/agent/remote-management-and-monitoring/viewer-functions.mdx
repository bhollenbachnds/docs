Avec les fonctions de visualisation de PADS4 Agent, vous pouvez récupérer toutes sortes d'informations de chaque Viewer de votre PADS4 Server connecté et effectuer des ajustements à distance.

Pour accéder aux fonctions de visualisation, vous devez [sélectionner une catégorie d'informations de Viewer](https://pads4documentation.blob.core.windows.net/agent/Content/Main%20Window/Navigation%20pane.htm) dans le volet de navigation de la fenêtre principale.

 

#### **Aperçu des fonctions de Viewer**

| **Fonction**                                                                                                                                                                     | **Description**                                                                                                                           |
| :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------- |
| [Screenshot](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Screenshot.htm)                                               | Pour récupérer une capture d'écran de la situation actuelle sur votre PADS4 Viewer.                                                       |
| [Viewer log](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Viewer%20log.htm)                                             | Pour afficher les messages du journal de votre PADS4 Viewer.                                                                              |
| [Memory usage](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Memory%20usage.htm)                                         | Pour analyser l'utilisation de la mémoire des processus PADS4 sur votre PADS4 Viewer ou l'ensemble de votre système PADS4 Viewer.         |
| [Content library](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Content%20library.htm)                                   | Pour parcourir la bibliothèque de contenu de votre PADS4 Viewer.                                                                          |
| [Synchronization log](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Synchronization%20log.htm)                           | Pour afficher les messages du journal du processus de synchronisation de contenu sur votre PADS4 Viewer.                                  |
| [Scheduled presentations](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Scheduled%20presentations.htm)                   | Pour obtenir un aperçu des présentations PADS4 qui ont été planifiées pour votre PADS4 Viewer.                                            |
| [Data providers](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Data%20Providers.htm)                                     | Pour inspecter les paramètres du Data Provider et les données en temps réel transmises à votre PADS4 Viewer.                              |
| [Viewer settings](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Viewer%20settings.htm)                                   | Pour afficher ou modifier les paramètres du programme de votre PADS4 Viewer.                                                              |
| [PADS software](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/PADS%20software.htm)                                       | Pour récupérer les informations de version des fichiers PADS4 sur votre PADS4 Viewer et pour mettre à jour le logiciel PADS4.             |

| [Scheduled tasks](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Scheduled%20tasks.htm)                                   | Pour afficher les tâches planifiées de votre PADS4 Viewer.                                                                                |
| [Monitoring & alerts](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Monitoring%20&%20alerts/Monitoring%20&%20alerts.htm) | Pour afficher les alertes de votre PADS4 Viewer.                                                                                          |
| [System info](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/System%20info.htm)                                           | Pour récupérer des informations système détaillées de votre PADS4 Viewer.                                                                 |
| [Processes](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Processes.htm)                                                 | Pour afficher les processus en cours d'exécution sur votre PADS4 Viewer.<br />Les processus peuvent être démarrés, redémarrés ou arrêtés. |
| [Services](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Services.htm)                                                   | Pour afficher les services Windows sur votre PADS4 Viewer.<br />Les services peuvent être démarrés, mis en pause ou redémarrés.           |

| [Fonts](https://pads4documentation.blob.core.windows.net/agent/Content/Remote%20management%20and%20monitoring/Fonts.htm)                                                         | Pour récupérer des informations sur les polices installées sur votre PADS4 Viewer et pour installer des polices supplémentaires.          |
