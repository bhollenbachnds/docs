PADS dispose de fonctionnalités intégrées pour synchroniser automatiquement les fichiers de contenu entre votre PADS4 Server et tous ses clients connectés. Grâce aux fonctions de file d'attente de synchronisation, vous pouvez vérifier à distance l'état réel du processus de synchronisation du contenu sur votre PADS4 Server. Vous pouvez voir les détails de progression des clients qui téléchargent actuellement des fichiers de contenu (upload/download) ainsi que les clients en attente de synchronisation.

 

#### **Pour vérifier la file d'attente de synchronisation de votre PADS4 Server**

1. Cliquez sur l'onglet **Server** dans le volet de navigation.

   ![EN Agent Navigationpane Servertab Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Navigationpane-Servertab.png)
2. Cliquez sur **Synchronization Queue** dans la liste des catégories d'informations serveur disponibles.

Après cela, le système récupère automatiquement les informations demandées depuis le PADS4 Server connecté et affiche les résultats dans la fenêtre de file d'attente de synchronisation. Si votre installation PADS4 comprend des sous-serveurs, vous devez d'abord sélectionner un serveur avant de choisir la catégorie d'informations.

 

#### **Fenêtre de file d'attente de synchronisation**

Si vous avez activé la synchronisation du contenu pour votre installation PADS4, la fenêtre de file d'attente de synchronisation affiche en un coup d'œil l'état réel du processus de synchronisation du contenu. Si aucune information n'est affichée dans la fenêtre de file d'attente de synchronisation, cela signifie que les bibliothèques de contenu sur tous les PC de votre installation sont à jour ou que la synchronisation du contenu n'a pas été activée.

![EN Agent Synchronization Queue Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-SynchronizationQueue.png)

<Tip>
  Seuls les clients en cours de synchronisation ou en attente de synchronisation sont inclus dans la vue d'ensemble. Dès qu'un client a été entièrement synchronisé, il est retiré de la liste.
</Tip>

**Application**\
\
L'application cliente qui synchronise ou attend d'être synchronisée. Les clients possibles sont : PADS4 Viewer, PADS4 Designer, PADS4 Scheduler, PADS4 Content Library et PADS4 Sub server.

**Identification**\
\
Le nom unique permettant d'identifier l'application cliente au sein du système PADS4. Pour les PADS4 Viewers, il s'agit du nom du Viewer ; pour les sous-serveurs, du nom du Server ; et pour les autres applications, le nom d'utilisateur de l'utilisateur connecté est affiché.

**Statut**\
Le statut indique si l'application cliente est en cours de synchronisation ou en attente de synchronisation.

**Statut Depuis**\
\
L'horodatage du moment depuis lequel l'application cliente a atteint le statut actuel. Cela donne une bonne indication sur les performances du processus de synchronisation pour ce client.

**Progression Totale**\
Affiche la progression de la synchronisation du contenu pour ce client en pourcentage. Cette valeur en pourcentage est basée sur le nombre de fichiers qui ont été synchronisés par rapport au nombre total de fichiers devant être synchronisés.

**Modifications Totales**\
\
Le nombre total d'éléments devant être synchronisés. Une modification peut être l'ajout d'un nouveau fichier, le renommage d'un fichier ou le remplacement d'un fichier.

**Direction**\
Indique si le fichier en cours de synchronisation concerne un téléversement vers le PADS4 Server ou un téléchargement depuis le PADS4 Server.

**Fichier**\
Le fichier de la bibliothèque de contenu en cours de synchronisation.

**Progression du fichier**\
La progression du processus de synchronisation pour le fichier actuel.

 

#### **Actualisation**

Par défaut, les informations dans la fenêtre de file d'attente de synchronisation ne sont pas automatiquement actualisées. Pour obtenir les dernières informations, vous devez cliquer sur **Actualiser** dans le **Accueil** menu ou appuyer sur la touche de fonction F5.

Optionnellement, vous pouvez faire en sorte que les informations soient automatiquement actualisées :

1. Cochez **Actualisation Automatique** dans le **Accueil** menu.

   ![EN Agent Ribbon Synchronization Queue Pn](/images/digital-signage/windows-applications/agent/remote-management-and-monitoring/EN-Agent-Ribbon-SynchronizationQueue.png)
2. Sélectionnez la fréquence d'actualisation des informations.

Après cela, les informations dans la fenêtre de file d'attente de synchronisation seront automatiquement actualisées avec la fréquence spécifiée.

<Warning>
  Lorsque vous activez l'actualisation automatique, vous devez savoir que cela générera une quantité significative de trafic réseau supplémentaire. Par conséquent, cela peut ralentir le processus de synchronisation du contenu lui-même. Il est donc recommandé de n'utiliser les fonctions d'actualisation automatique que pendant une courte période.
</Warning>
