**PADS4 Agent** est l'application destinée aux utilisateurs finaux pour gérer et surveiller à distance votre système PADS4. Elle fournit des outils pour la santé du système, les diagnostics, les alertes et le contrôle opérationnel.

***

## Comment Lancer PADS4 Agent

Vous pouvez démarrer l'application PADS4 Agent de l'une des façons suivantes :

### Méthode 1 : Utilisation du Menu Démarrer

1. Cliquez sur le bouton **Démarrer** dans la barre des tâches Windows.
2. Accédez à **Tous les Programmes** > **PADS4**.
3. Cliquez sur **Agent**.

### Méthode 2 : Utilisation de l'Explorateur Windows

1. Ouvrez **l'Explorateur Windows**.
2. Accédez au dossier où les fichiers du programme **PADS4 Agent** sont installés.
3. Double-cliquez `PADSAgent.exe` pour lancer l'application.

***

## Configuration et paramétrage initiaux

> **Note:**\
> Si tous les paramètres de configuration sont corrects, l'application se connectera automatiquement au **PADS4 Server** au démarrage.

Si c'est la **première fois que vous lancez** l'application ou si les **paramètres de connexion sont incorrects**, la **PADS4 Connection Management** fenêtre apparaîtra. Cela vous permet de configurer manuellement ou de corriger les paramètres de connexion au serveur pour démarrer l'application avec succès.
