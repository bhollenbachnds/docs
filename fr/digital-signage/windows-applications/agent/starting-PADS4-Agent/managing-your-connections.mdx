# **Gérer vos connexions**

Pour pouvoir vous connecter à votre serveur PADS4, vous devez d'abord configurer votre connexion. Une connexion décrit généralement comment se connecter et ouvrir une session sur votre serveur PADS4. Vous gérez les connexions dans la fenêtre Connexions au serveur PADS4. Dans la plupart des situations, vous n'aurez qu'un seul serveur PADS4, mais vous pouvez également [vous connecter à plusieurs serveurs PADS4](/fr/digital-signage/windows-applications/agent/advanced-features/connecting-to-multiple-servers).

Les connexions que vous définissez dans la fenêtre PADS4 Server Connections sont partagées par toutes les applications PADS4 installées sur votre ordinateur.

 

#### **Pour afficher vos connexions**

1. Cliquez sur **Manage** dans la **Connections** section de l'onglet **Home** dans la barre de ruban.

   ![EN Agent Manageconnections 01 Pn](/images/digital-signage/windows-applications/agent/starting-PADS4-Agent/EN-Agent-Manageconnections-01.png)

   Cela ouvre automatiquement la fenêtre PADS4 Server Connections, où vous pouvez afficher vos connexions.

 

#### **Fenêtre PADS Server Connections**

La fenêtre PADS4 Server Connections affiche la liste de toutes les connexions définies sur votre ordinateur avec leur statut actuel.

![EN Agent Manageconnections 02 Pn](/images/digital-signage/windows-applications/agent/starting-PADS4-Agent/EN-Agent-Manageconnections-02.png)

Vous pouvez utiliser la fenêtre Connections pour vous connecter ou vous déconnecter manuellement d'un PADS4 Server. Si une connexion n'est pas encore établie, vous pouvez la sélectionner et cliquer sur **Connect** pour établir manuellement une connexion. Pour vous déconnecter, cliquez simplement sur **Disconnect**.

<Tip>
  Travailler avec plusieurs connexions et se connecter et se déconnecter manuellement peut être particulièrement utile lorsque vous devez assurer la maintenance de plusieurs installations PADS4. Un exemple est celui d'une agence de création développant du contenu pour plusieurs clients utilisant PADS4.
</Tip>

 

#### **Pour ajouter une nouvelle connexion**

1. Cliquez sur **Add...**.

   ![EN Agent Manageconnections Add Pn](/images/digital-signage/windows-applications/agent/starting-PADS4-Agent/EN-Agent-Manageconnections-add.png)
2. Renseignez les paramètres dans l'onglet **Connection**.

   ![EN Agent Manageconnections Details Pn](/images/digital-signage/windows-applications/agent/starting-PADS4-Agent/EN-Agent-Manageconnections-details.png)

   **Connection Name**\
   Un nom unique qui sera utilisé pour identifier votre connexion. Le nom que vous saisissez ici sera utilisé partout dans l'interface graphique pour désigner votre connexion.

   **Application Startup**\
   Choisissez si vous souhaitez que votre système se connecte automatiquement à votre PADS4 Server au démarrage de votre application PADS4.

   **Server Connection**\
   \
   Indiquez l'emplacement de votre PADS4 Server. Les options possibles sont :

   <Note>
     Un PADS4 Server ne peut être détecté automatiquement que si le processus PADS4 Server est en cours d'exécution et que le port UDP numéro 3702 n'est pas bloqué par un pare-feu sur le PC serveur ou ailleurs dans le réseau. La détection automatique fonctionne uniquement sur un réseau local (LAN).
   </Note>

   | **Option de connexion** | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
   | :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
   | Automatic               | Votre système PADS4 détectera automatiquement l'emplacement de votre PADS4 Server. Si vous n'avez qu'un seul PADS4 Server dans votre réseau, il peut s'agir de la meilleure option. Si votre PADS4 Server est déplacé vers un autre emplacement dans votre réseau ou reçoit une adresse réseau différente, le système effectuera automatiquement les ajustements nécessaires. Si vous avez plusieurs PADS4 Servers (comme un serveur de sauvegarde) en cours d'exécution dans votre réseau, vous ne pouvez pas utiliser cette option. Il n'y a aucune garantie que le système détectera le bon serveur.                                                                                                                                                 |
   | This Computer           | Votre PADS4 Server est censé fonctionner sur le même ordinateur que votre application. Si vous avez installé à la fois PADS4 Server et votre application PADS4 sur le même ordinateur, il s'agit de l'option recommandée. Elle garantit que le système continuera à fonctionner même si le nom de votre ordinateur change. Elle maintient également la communication en local, ce qui est beaucoup plus rapide. Enfin, elle évite que votre système passe par le réseau pour accéder à votre PADS4 Server et risque d'être bloqué par un pare-feu.                                                                                                                                                                                                      |
   | Other                   | Utilisez cette option si aucune des options ci-dessus n'est applicable. Avec cette option, vous pouvez spécifier manuellement l'adresse réseau de votre **PADS4 Server**. Vous pouvez saisir un nom d'ordinateur, une adresse IP ou un nom DNS. Vous pouvez également cliquer sur **Search...** pour rechercher automatiquement les PADS4 Servers existants dans votre réseau. En cliquant sur **Show Advanced Options** vous avez la possibilité de spécifier un **numéro de port** alternatif pour communiquer avec votre PADS4 Server. Le numéro de port que vous saisissez ici doit correspondre au numéro de port de votre PADS4 Server. Vous spécifiez ce numéro de port dans les paramètres du serveur de l'application PADS4 System Management. |

   **Paramètres Http**\
   Lorsqu'il est défini sur automatique, PADS4 identifie la connexion au serveur et configure les paramètres http en fonction des paramètres de connexion par défaut. Cela peut être ajusté en le définissant sur **manual** et en spécifiant un chemin d'hôte et un port.\
   \
   PADS4 utilise 2 protocoles réseau. Les connexions web sont utilisées dans PADS4 Agent (Proof of Play et journal d'audit) et PADS4 Desktop Viewer (synchronisation). Dans certaines situations, la connexion au serveur est établie via un routeur ou un proxy utilisant la redirection de port. Dans ce cas, vous devrez peut-être spécifier un chemin d'hôte/port différent pour vous connecter au PADS4 Server.
3. Spécifiez les paramètres de connexion dans l'onglet **Credentials**.

   ![EN Agent Logon Properties Creds Pn](/images/digital-signage/windows-applications/agent/starting-PADS4-Agent/EN-Agent-LogonProperties-creds.png)

   **Credentials**\
   Ici vous pouvez spécifier le **User Name** et/ou le **Password** que vous souhaitez utiliser pour vous connecter à votre PADS4 Server lorsqu'une connexion est établie. Si vous ne spécifiez qu'un nom d'utilisateur, vous serez invité à saisir le mot de passe lors de la connexion. Si vous sélectionnez **Automatic Login**, le système tentera de se connecter automatiquement à votre PADS4 Server lors de la connexion. Si la connexion échoue, vous serez invité à saisir le nom d'utilisateur et le mot de passe corrects.

   <Tip>
     1. Souvent, l'option **Automatic Login** est utilisée en combinaison avec l'option **Automatically start this connection** dans l'onglet **Connection**. De cette façon, votre application se connectera et se connectera automatiquement à votre PADS4 Server au démarrage de votre application PADS4.
   </Tip>

   **Domain**\
   Si votre PC PADS4 Server héberge plusieurs PADS4 Servers, vous avez ici la possibilité de spécifier manuellement le **Domain** qui correspond à votre système PADS4. Vous pouvez également avoir besoin de domaines lorsque vous avez plusieurs connexions à différents PADS4 Servers. Dans ce cas, les domaines vous permettent de garder ces connexions séparées sur votre PC client. Dans toutes les autres situations, sélectionnez l'option **Automatic**.
4. Ajustez éventuellement les paramètres de synchronisation dans l'onglet **Synchronization**.

   ![Agent Manageconnection Sync Pn](/images/digital-signage/windows-applications/agent/starting-PADS4-Agent/Agent-manageconnection-sync.png)

   \
   **Activation de la synchronisation de la bibliothèque de contenu**\
   Spécifiez la méthode à utiliser pour la synchronisation.\
   **Automatic** synchronisera lorsque des modifications sont détectées, **Manual** attendra que vous cliquiez sur un bouton de synchronisation immédiate et **never** ne synchronisera pas. Lorsque les trois options sont désactivées, l'utilisation de la synchronisation n'est pas autorisée. Par exemple, lorsque le serveur et le Designer sont sur le même PC, la synchronisation n'est pas nécessaire car ils utilisent le même environnement.\
   \
   **Dossier de stockage de la bibliothèque de contenu PADS4**\
   Spécifiez l'emplacement où le contenu doit être stocké si l'emplacement généré automatiquement n'est pas possible.

   * **Domaine**\
     Si votre PC serveur PADS4 héberge plusieurs serveurs PADS4, vous avez ici la possibilité de spécifier manuellement le **Domaine** qui correspond à votre système PADS4. Vous pouvez également avoir besoin de domaines lorsque vous avez plusieurs connexions à différents serveurs PADS4. Dans ce cas, les domaines vous permettent de garder ces connexions séparées sur votre PC client. Dans toutes les autres situations, sélectionnez l'option **Automatique**.
   * Cliquez sur **OK** pour enregistrer vos paramètres.

 

#### **Pour modifier une connexion**

Avant de pouvoir commencer à modifier une connexion, vous devez d'abord vous assurer que la connexion est déconnectée. Il n'est pas possible d'apporter des modifications à une connexion actuellement en cours d'utilisation.

1. Cliquez sur la connexion dans la fenêtre des connexions au serveur PADS4 pour la sélectionner.
2. Cliquez sur **Modifier...** pour ouvrir la fenêtre des propriétés de connexion.

   ![EN Agent Manageconnections Edit Pn](/images/digital-signage/windows-applications/agent/starting-PADS4-Agent/EN-Agent-Manageconnections-edit.png)
3. Effectuez les ajustements requis (voir la description ci-dessus).
4. Cliquez sur **OK** pour enregistrer vos paramètres.

 

#### **Pour supprimer une connexion**

1. Cliquez sur la connexion dans la fenêtre des connexions au serveur PADS4 pour la sélectionner.
2. Cliquez sur **Supprimer** pour supprimer la connexion.

Après cela, votre connexion sera définitivement supprimée pour toutes les applications PADS4 sur votre ordinateur.
