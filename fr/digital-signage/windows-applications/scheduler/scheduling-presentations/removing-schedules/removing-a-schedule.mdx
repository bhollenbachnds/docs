Vous pouvez **supprimer manuellement** tout type de présentation planifiée — qu'il s'agisse d'un planning **Simple**, **Playlist**, ou **Avancé** — directement depuis la **Vue Calendrier** ou la **Vue Tableau**.

***

## Comment supprimer un planning

### Steps:

1. Dans la **vue arborescente des destinations** (panneau gauche), sélectionnez le **Viewer** ou le **Viewer Group** où le planning a été créé.

2. Dans la vue **Calendrier** ou **Tableau**, **cliquez** pour sélectionner la présentation planifiée que vous souhaitez supprimer.

3. Accédez à l'onglet **Accueil** dans la barre de ruban.

4. Dans le groupe **Presse-papiers**, cliquez sur **Supprimer**.

***

### Méthodes de suppression alternatives

Vous pouvez également supprimer un planning en utilisant l'une des méthodes suivantes :

* Cliquez sur le bouton **Supprimer** dans le groupe **Gérer le planning** du **Accueil** onglet.
* **Clic droit** sur le planning et sélectionnez **Supprimer** dans le menu contextuel.
* Appuyez sur la touche **Suppr** de votre clavier après avoir sélectionné le planning.

***

### Invite de confirmation

Un message de confirmation apparaîtra :

> "Êtes-vous sûr de vouloir supprimer ce planning ?"

* Cliquez sur **Oui** pour supprimer définitivement le planning.
* Cliquez sur **Non** pour annuler l'action.

Une fois confirmé, le planning sera supprimé de la vue et ne sera plus actif pour la ou les destination(s) sélectionnée(s).
