Vous pouvez **supprimer manuellement** tout type de présentation planifiée — qu'il s'agisse d'un planning **Simple**, **Playlist**, ou **Advanced** — directement depuis la **Calendar View** ou la **Table View**.

***

## Comment supprimer un planning

### Steps:

1. Dans le **Destinations tree view** (panneau gauche), sélectionnez le **Viewer** ou **Viewer Group** où le planning a été créé.

2. Dans le **Calendar** ou **Table** vue, **cliquez** pour sélectionner la présentation planifiée que vous souhaitez supprimer.

3. Accédez à l'onglet **Home** dans la barre de ruban.

4. Dans le **Clipboard** groupe, cliquez sur **Delete**.

***

### Méthodes de suppression alternatives

Vous pouvez également supprimer un planning en utilisant l'une des méthodes suivantes :

* Cliquez sur le bouton **Delete** dans le **Manage Schedule** groupe de l'onglet **Home**.
* **Clic droit** sur le planning et sélectionnez **Delete** dans le menu contextuel.
* Appuyez sur la touche **Del** de votre clavier après avoir sélectionné le planning.

***

### Invite de confirmation

Un message de confirmation apparaîtra :

> "Êtes-vous sûr de vouloir supprimer ce planning ?"

* Cliquez sur **Yes** pour supprimer définitivement le planning.
* Cliquez sur **No** pour annuler l'action.

Une fois confirmé, le planning sera supprimé de la vue et ne sera plus actif pour la ou les destinations sélectionnées.
