Vous pouvez **supprimer manuellement** tout type de présentation planifiée—qu'il s'agisse d'une planification **Simple**, **Playlist**, ou **Avancée**—directement depuis la **Vue Calendrier** ou **Vue Tableau**.

***

## Comment supprimer une planification

### Steps:

1. Dans la **arborescence des destinations** (panneau gauche), sélectionnez le **Viewer** ou **Groupe de Viewers** où la planification a été créée.

2. Dans la **Calendrier** ou **Tableau** vue, **cliquez** pour sélectionner la présentation planifiée que vous souhaitez supprimer.

3. Accédez à l'onglet **Accueil** dans la barre de ruban.

4. Dans le **Presse-papiers** groupe, cliquez sur **Supprimer**.

***

### Méthodes de suppression alternatives

Vous pouvez également supprimer une planification en utilisant l'une des méthodes suivantes :

* Cliquez sur le **Supprimer** bouton dans le **Manage Schedule** groupe de l'onglet **Home**.
* **Clic droit** sur le planning et sélectionnez **Supprimer** dans le menu contextuel.
* Appuyez sur la touche **Suppr** de votre clavier après avoir sélectionné le planning.

***

### Invite de confirmation

Un message de confirmation apparaîtra :

> "Êtes-vous sûr de vouloir supprimer ce planning ?"

* Cliquez sur **Oui** pour supprimer définitivement le planning.
* Cliquez sur **Non** pour annuler l'action.

Une fois confirmé, le planning sera supprimé de la vue et ne sera plus actif pour la ou les destinations sélectionnées.
