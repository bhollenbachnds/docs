PADS4 Scheduler vous permet de supprimer des **planifications récurrentes** de deux manières distinctes :

* **Supprimer une occurrence** – Supprime uniquement une seule instance de la planification récurrente.
* **Supprimer la série** – Supprime la **définition de récurrence entière** et toutes les occurrences associées.

> **Distinction importante**
>
> * **Remove Recurrence** : Supprime le modèle de récurrence et convertit l'occurrence sélectionnée en **planification autonome**. Toutes les autres occurrences sont supprimées.
> * **Delete Series** : Supprime la **planification récurrente entière**, y compris les paramètres de récurrence **et toutes les occurrences**.

***

## Pour supprimer un calendrier récurrent

### Steps:

1. Dans le **arborescence Destinations**, sélectionnez le **Viewer** ou **Viewer Group** où le calendrier récurrent a été créé.

2. Dans le **Calendar** ou **Table** vue, **sélectionnez le calendrier récurrent** que vous souhaitez modifier.

3. Dans le **Home** onglet de la barre de ruban, sous le groupe **Clipboard**, cliquez sur le bouton **Delete**.

4. Une boîte de dialogue apparaîtra vous demandant de choisir entre :
   * **Delete Occurrence**
   * **Delete Series**

5. Cliquez sur **OK** pour confirmer l'action sélectionnée.

***

## Méthodes alternatives

### Utilisation du menu contextuel

1. **Clic droit** sur le calendrier récurrent.

2. Survolez l'option **Delete** dans le menu contextuel.
   * Choisissez **Occurrence** pour supprimer une seule instance.
   * Choisissez **Series** pour supprimer toutes les occurrences et la règle de récurrence.

3. Vous pouvez également survoler **Recurrence**, puis sélectionner **Remove** pour supprimer la récurrence et conserver uniquement l'instance sélectionnée en tant que **planification unique, non récurrente**.

***

### Utilisation de la barre de ruban

1. Accédez à l'onglet **Home**.
2. Dans le **Manage Schedule** group:
   * Cliquez sur **Remove Recurrence** pour supprimer le modèle mais conserver l'occurrence sélectionnée en tant que planification ponctuelle.
   * Ou cliquez sur la **flèche** à côté de **Delete** et sélectionnez :
     * **Delete Occurrence**
     * **Delete Series**

***

Cette flexibilité vous permet de contrôler comment et quand les calendriers récurrents sont modifiés ou supprimés — partiellement ou entièrement.
