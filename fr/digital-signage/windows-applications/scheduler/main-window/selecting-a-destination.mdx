Avant de visualiser ou de gérer les présentations planifiées, vous devez d'abord **sélectionner une Destination**. Dans PADS4, une *Destination* désigne un **Viewer** (un dispositif d'affichage dynamique) ou un **Viewer Group** (un ensemble de Viewers). Ces dispositifs sont gérés de manière centralisée par le système PADS4.

PADS4 Scheduler offre plusieurs façons de sélectionner une Destination, selon vos préférences ou votre configuration.

***

## Sélectionner une Destination depuis la vue arborescente

1. Dans la **fenêtre principale**, localisez la **vue arborescente des Destinations** dans le panneau de gauche.
2. Cliquez sur un **Viewer** ou un **Viewer Group** pour le sélectionner.
   * Utilisez les symboles de flèche pour développer les éléments groupés si nécessaire.
3. Une fois sélectionnée, les vues de planification à droite se mettront automatiquement à jour pour refléter la Destination choisie.

> **Note:** La vue arborescente est généralement remplie automatiquement avec les Viewers définis dans votre système PADS4. Si votre compte utilisateur dispose d'autorisations limitées, seuls les Viewers auxquels vous êtes autorisé à accéder apparaîtront.

***

## Utiliser la vue alphabétique

Par défaut, les Destinations sont affichées dans une **Vue par catégorie**. Vous pouvez basculer vers la **Vue alphabétique** pour faciliter la recherche ou le défilement.

1. Déplacez votre curseur vers la **zone des Destinations** dans le panneau de gauche.
2. Cliquez sur le bouton **Vue alphabétique**.
3. Les Destinations seront désormais listées par ordre alphabétique.

***

## Utiliser la fonction de recherche

Le **bouton Rechercher** vous permet de trouver des Destinations par nom.

1. Cliquez sur le bouton **Rechercher** à côté du bouton Vue alphabétique.
2. Entrez votre **texte de recherche**.
3. Cliquez sur le **bouton flèche droite** pour trouver la première correspondance.
4. Cliquez à nouveau sur la flèche pour parcourir plusieurs résultats.

> La fonction Recherche correspond à n'importe quelle partie du nom de la Destination, pas seulement au début.

***

## Utilisation de l'option Filtre

Le filtrage permet de réduire la liste des Destinations visibles selon vos critères.

> **Important:** Le filtrage est uniquement disponible en **Vue Alphabétique**.

1. Passez en **Vue Alphabétique** si elle n'est pas déjà active.
2. Cliquez sur le **Filtre** bouton.
3. Entrez votre **texte de filtre**.
   * Les résultats se mettent à jour en temps réel au fur et à mesure que vous tapez.
4. Pour affiner les résultats par type :
   * Cliquez sur le **menu de sélection du type de Viewer**.
   * Choisissez **Viewers uniquement** ou **Toutes les Destinations**.

### Effacement du Filtre :

* Cliquez sur le **Effacer le Filtre** bouton pour réinitialiser la liste et afficher à nouveau toutes les Destinations.

***

## Utilisation conjointe de la Recherche et du Filtre

Vous pouvez combiner **Recherche** et **Filtre** pour affiner davantage votre liste de Destinations.

1. Cliquez sur le **Recherche** bouton.
2. Cliquez sur le **Filtre** bouton.
3. Entrez vos termes de recherche ou de filtre.
4. Naviguez dans les résultats selon vos besoins.

***

## Sélection d'une Destination via la barre de ruban

Les Destinations peuvent également être sélectionnées à l'aide de l'onglet **Vue** dans la barre de ruban.

1. Dans le **Vue** groupe d'onglets, cliquez sur **Sélectionner la Destination**.
2. La **Rechercher une Destination** fenêtre s'affiche.
   * Cela inclut les vues Catégorisée et Alphabétique.
   * Les fonctions Recherche et Filtre sont également disponibles ici.
3. Sélectionnez la Destination souhaitée.
4. Cliquez sur **OK** pour confirmer.

La Destination sélectionnée sera désormais active dans la fenêtre principale.
