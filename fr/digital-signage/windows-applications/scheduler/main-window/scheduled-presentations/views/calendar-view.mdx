La **Vue Calendrier** est la **vue par défaut** de PADS4 Scheduler et s'affiche automatiquement au lancement de l'application. Elle fournit un aperçu visuel, basé sur un calendrier, de toutes les présentations planifiées pour la destination et la ou les dates sélectionnées.

Cette vue est idéale pour planifier, examiner et modifier les planifications de contenu avec une perspective orientée vers le temps.

***

## Accéder à la vue Calendrier

Pour passer à la vue Calendrier :

1. Accédez à l'onglet **Affichage** dans la barre de ruban.
2. Dans la section **Vue des planifications**, cliquez sur **Calendrier**.

L'affichage se mettra à jour pour présenter les présentations dans une disposition de calendrier traditionnelle.

***

## Modes de calendrier

PADS4 Scheduler prend en charge plusieurs **modes de calendrier**, vous permettant de personnaliser l'affichage des planifications en fonction de vos besoins de planification :

* **Vue Jour** : Affiche la planification d'une seule journée, décomposée par heure.
* **Vue Semaine de travail** : Affiche du lundi au vendredi, idéale pour la planification professionnelle.
* **Vue Semaine** : Affiche une semaine complète de sept jours.
* **Vue Mois** : Présente un aperçu d'un mois complet pour une planification plus large.
* **Vue Chronologie** : Affiche les planifications dans un format horizontal de type Gantt, particulièrement utile pour gérer le contenu qui se chevauche sur de longues périodes.

Pour changer le mode de calendrier :

1. Dans l'onglet **Affichage**, dans la section **Vue Calendrier**, cliquez sur votre mode préféré :
   * **Jour**
   * **Semaine de travail**
   * **Semaine**
   * **Mois**
   * **Chronologie**

Le mode sélectionné mettra immédiatement à jour l'affichage dans la zone des planifications.
