La **Vue Calendrier** est la **vue par défaut** dans PADS4 Scheduler et s'affiche automatiquement au lancement de l'application. Elle offre une vue d'ensemble visuelle, basée sur un calendrier, de toutes les présentations planifiées pour la destination et la ou les dates sélectionnées.

Cette vue est idéale pour planifier, examiner et modifier les plannings de contenu avec une perspective temporelle.

***

## Accéder à la vue Calendrier

Pour passer à la vue Calendrier :

1. Accédez à l'onglet **Affichage** dans la barre de ruban.
2. Dans la section **Vue des plannings**, cliquez sur **Calendrier**.

L'affichage se mettra à jour pour présenter les présentations dans une mise en page de calendrier traditionnelle.

***

## Modes de calendrier

PADS4 Scheduler prend en charge plusieurs **modes de calendrier**, vous permettant de personnaliser l'affichage des plannings en fonction de vos besoins de planification :

* **Vue Jour** : Affiche le planning d'une seule journée, décomposé par heure.
* **Vue Semaine de travail** : Affiche du lundi au vendredi, idéal pour la planification professionnelle.
* **Vue Semaine** : Affiche une semaine complète de sept jours.
* **Vue Mois** : Présente une vue d'ensemble du mois complet pour une planification plus large.
* **Vue Chronologie**: Affiche les plannings dans un format horizontal de type Gantt, particulièrement utile pour gérer du contenu qui se chevauche sur de longues périodes.

Pour changer le mode Calendrier :

1. Dans l'**View** onglet, dans la section **Calendar View** , cliquez sur votre mode préféré :
   * **Day**
   * **Work Week**
   * **Week**
   * **Month**
   * **Timeline**

Le mode sélectionné mettra immédiatement à jour l'affichage dans la zone des plannings.
