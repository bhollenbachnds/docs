La **vue Tableau** affiche toutes les présentations planifiées sous forme d'enregistrements structurés dans un format tabulaire. Cette vue est particulièrement utile pour consulter rapidement des données de planification détaillées et comparer plusieurs entrées.

***

## Accès à la vue Tableau

Pour passer à la vue Tableau :

1. Accédez à l'onglet **View** dans la barre de ruban.
2. Dans la section **Schedules View**, cliquez sur **Table**.

Les horaires pour la destination et la/les date(s) sélectionnée(s) apparaîtront désormais dans un **tableau**, affichant des détails tels que :

* Nom de la présentation
* Heure de début et de fin
* Durée
* Destination assignée
* Propriétés supplémentaires (telles que les intervalles de répétition ou la priorité)
