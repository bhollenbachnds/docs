La **section Connection Properties** vous permet de configurer et de gérer les connexions entre PADS4 Scheduler et votre PADS4 Server. Cela inclut les méthodes de connexion, les identifiants de connexion, les paramètres de synchronisation et les options HTTP.

***

## Ouverture de la fenêtre PADS4 Server Connections

Pour gérer les connexions au serveur :

1. Accédez à l'onglet **Home** dans la barre de ruban.
2. Dans la section **Connections**, cliquez sur le bouton **Manage**.\
   Cela ouvre la fenêtre **PADS4 Server Connections**.

***

## Gestion des connexions

Depuis la fenêtre PADS4 Server Connections, vous pouvez :

* **Add...** une nouvelle connexion PADS4 Server
* **Edit...** une connexion existante
* **Remove...** une connexion dont vous n'avez plus besoin

***

## Ajout ou modification d'une connexion au serveur

Que vous créiez une nouvelle connexion ou que vous en modifiiez une existante, la fenêtre de configuration est la même.

### Paramètres de l'onglet Connection

#### **Nom de la connexion (Connection name)**

Un nom unique utilisé pour identifier cette connexion au serveur dans l'interface Scheduler.

#### **Option de démarrage de l'application (Application startup option)**

Choisissez si vous souhaitez **vous connecter automatiquement** à ce serveur au démarrage de PADS4 Scheduler.

#### **Types de connexion au serveur**

| Option            | Description                                                                                                                                                              |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Automatic**     | Détecte automatiquement le serveur. Recommandé uniquement lorsqu'un seul PADS4 Server existe sur votre réseau local (LAN). Nécessite que le port UDP 3702 soit ouvert.   |
| **This Computer** | Suppose que PADS4 Server s'exécute sur la même machine que le Scheduler. Préférable pour les configurations locales.                                                     |
| **Other**         | Spécifiez manuellement le nom d'hôte, l'adresse IP ou l'entrée DNS du serveur. Vous pouvez également cliquer sur **Search...** pour détecter les serveurs sur le réseau. |

> **Options avancées (Advanced Options)**: Vous pouvez définir un numéro de port personnalisé si le serveur utilise des ports non standard. Le numéro de port doit correspondre à la configuration dans **PADS4 System Management**.

***

### Paramètres HTTP

PADS4 Scheduler utilise ces paramètres pour la communication web, comme la journalisation des audits ou la synchronisation.

* **Automatique**: Paramètres par défaut basés sur la configuration du serveur.
* **Manuel**: Spécifiez un **Chemin d'hôte** et **Port** personnalisés, utile lors de l'utilisation de routeurs, de proxies ou de la redirection de ports.

***

### Onglet Identifiants

Spécifiez les informations de connexion pour votre connexion au serveur.

* **Nom d'utilisateur**: Le nom d'utilisateur pour l'authentification au serveur.
* **Mot de passe**: (Facultatif) Mot de passe enregistré. Si vous le laissez vide, PADS4 Scheduler vous le demandera.
* **Connexion automatique**: Tente automatiquement de se connecter lors de la connexion. En cas d'échec, PADS4 Scheduler vous demande vos identifiants.

> **Tip:** Combinez **Connexion automatique** avec **Démarrer automatiquement cette connexion** pour vous connecter de manière transparente lors du lancement de l'application.

***

### Onglet Synchronisation

Contrôlez la façon dont le contenu de présentation est synchronisé entre le Scheduler et le Serveur.

* **Activation de la synchronisation**:
  * **Automatique**: Synchronise lors d'un changement
  * **Manuel**: Synchronise uniquement lorsque vous le démarrez
  * **Jamais**: Désactive la synchronisation

> Si le serveur et le Scheduler se trouvent sur la même machine, la synchronisation peut ne pas être nécessaire.

* **Dossier de stockage de la bibliothèque de contenu PADS4**:\
  Définissez un dossier local pour le stockage du contenu si l'emplacement par défaut ne convient pas.

* **Domaine**:\
  Utilisez ce champ si le serveur héberge plusieurs domaines PADS4, ou si vous gérez plusieurs connexions serveur et devez les garder séparées. Sinon, choisissez **Automatique**.

***

### Enregistrement de la configuration

Cliquez sur **OK** pour enregistrer vos paramètres de connexion et revenir à la fenêtre principale de l'application.
