Avec Userful, vous pouvez enrichir PADS4 CMS avec la plateforme de réseau visuel de Userful. Cette approche riche en fonctionnalités et facile à utiliser pour déployer des affichages numériques et des murs vidéo vous aide à réduire les coûts d'exploitation et à mettre en œuvre rapidement de nouvelles initiatives pour atteindre les objectifs de votre organisation.

Pour en savoir plus sur Userful, rendez-vous sur le site web de Userful : [https://www.userful.com/](https://www.userful.com/)

Activez le curseur dans le coin supérieur droit sur « ON » et renseignez les informations suivantes :

### Informations de connexion

Fournissez les informations suivantes pour vous connecter à votre compte Userful :

Userful API : *Fournissez le lien depuis votre connexion Userful.*

Username: *Par exemple : [user@pads4.com](mailto:user@pads4.com)*

Password: *Votre mot de passe*
