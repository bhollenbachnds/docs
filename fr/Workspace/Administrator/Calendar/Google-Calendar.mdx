Ce paragraphe est destiné à la configuration du service Google Calendar lors de l'utilisation de PADS4 CMS incluant le module Workspace. Les étapes suivantes vous montreront comment générer un fichier JSON de configuration ainsi que le compte Google Workspace.

 

**Configuration du compte de service**

Le compte de service est le compte Google Workspace qui sera utilisé par PADS4 CMS pour :

• Récupérer une liste de salles

• Gérer les réservations

Il est donc nécessaire d'effectuer les étapes suivantes :

Depuis le site d'administration Google Workspace : [<u>https://console.developers.google.com/cloud-resource-manager</u>](https://console.developers.google.com/cloud-resource-manager)

* Créer un projet pour l'application PADS4 CMS
* Sélectionner le projet après sa création dans la console pour activer les APIs

Les APIs à activer sont :

• Google Calendar

• Admin SDK

* Créer un compte de service avec la configuration suivante

* Créer une clé privée pour le compte de service

* Attention, le fichier est à télécharger en json et sera réutilisé lors de la configuration de PADS4 CMS

* Autoriser les actions nécessaires pour PADS4 CMS pour le compte de service

Récupérer le numéro d'identification du compte de service.

Ensuite, rendez-vous sur la console d'administration : [https://admin.google.com](https://admin.google.com) dans l'onglet "Sécurité" et "Gérer l'accès au client API"

Ajoutez ensuite votre identifiant et les URLs suivantes :

[https://www.googleapis.com/auth/admin.directory.resource.calendar](https://www.googleapis.com/auth/admin.directory.resource.calendar)

[https://www.googleapis.com/auth/admin.directory.resource.calendar.readonly](https://www.googleapis.com/auth/admin.directory.resource.calendar.readonly)

[https://www.googleapis.com/auth/calendar](https://www.googleapis.com/auth/calendar)

Créer et configurer des ressources dans la console d'administration : [https://admin.google.com](https://admin.google.com)

Allez dans "Applications" puis "GSuite".

Sélectionnez ensuite l'application "Calendar".

#### Activer Google Calendar dans PADS4 CMS

Une fois cette étape terminée, retournez dans la section administrateur de PADS4 CMS et accédez aux Plugins.<br /><br />Sélectionnez l'option Calendar<br /><br />Activez le curseur en haut à droite sur "<u>ON</u>" et renseignez les informations suivantes :<br /><br />Sélectionnez l'option Google Calendar sous Type d'authentification.

Clé du compte de service : *Téléversez votre fichier JSON ici*.

Nom d'utilisateur\_ : renseignez votre adresse e-mail\_

Désactiver les notifications de réservation : *Sélectionnez si vous souhaitez désactiver les notifications oui/non.*

Enregistrez les options et vérifiez si la connexion est valide en important des salles dans le module Workspace.
