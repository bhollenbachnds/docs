---
- title: "Active Directory "
---

<Warning>
  Depuis **PADS4 version 2025.2**, ce plugin est géré depuis la section **Credentials** dans PADS4 CTRL Center, offrant un système de gestion des utilisateurs cohérent au sein d'un environnement unique.
</Warning>

Utilisez ce plugin pour connecter un **serveur Active Directory (LDAP)** à votre environnement PADS4.

![LDAP CMS 1 0](/images/modules/workspace/workspace-cms-admin/LDAP-CMS-1.0.png)

* Entrez votre **serveur LDAP**, **nom d'utilisateur** et **mot de passe** pour établir une connexion sécurisée.
  <Info>
    L'adresse du serveur LDAP doit avoir le format suivant : **LDAP://**\<servername>
  </Info>
* Une fois connecté, vous pouvez importer des utilisateurs depuis Active Directory directement via l'onglet **Utilisateurs** dans chaque module.
