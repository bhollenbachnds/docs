Solstice est une plateforme de collaboration en réunion basée sur logiciel et activée dans le cloud, optimisée pour les équipes locales et distantes. Elle permet à plusieurs utilisateurs simultanés de partager du contenu sans fil sur l'écran de la salle et relie de manière transparente les sites distants à l'aide de n'importe quel service de vidéoconférence majeur. Avec Solstice dans vos espaces de réunion, vous bénéficiez des gains de productivité de la collaboration sans fil combinés à la puissance d'une vidéoconférence entièrement intégrée. Pour plus d'informations, visitez le site web de Mersive : [https://www.mersive.com/](https://www.mersive.com/)

Avant de commencer, obtenez les clés requises depuis la base de connaissances Mersive.<br />

Activez le curseur dans le coin supérieur droit sur « ON » et renseignez les informations suivantes :

#### Informations de connexion

Mersive SDS API : *Renseignez le lien ici*

Password: *Renseignez le mot de passe pour le lien SDS API ici*

URL PADS4 : *Entrez votre URL localhost ici*

Lorsque ces informations sont correctes, cliquez sur le bouton **Enregistrer**. Pour vérifier la connexion, assurez-vous que la connexion est valide dans votre environnement Mersive.
