Le Mappedin Web SDK vous permet de restituer les cartes de votre lieu, conçues à l'aide de Mappedin CMS, dans une page HTML sur le frontend de votre application web. Le SDK est un package JavaScript, construit en JavaScript pur. Pour en savoir plus sur MappedIn, veuillez consulter la documentation développeur ici.

Vous devrez acquérir certaines clés avant de procéder à l'implémentation, alors assurez-vous d'avoir parcouru leur base de connaissances : [https://developer.mappedin.com/](https://developer.mappedin.com/)<br />

Activez le curseur dans le coin supérieur droit sur « ON » et renseignez les informations suivantes

#### Informations de connexion

Clé publique : *Ajoutez la clé publique de l'API MappedIn*

Clé privée : *Ajoutez la clé privée de l'API MappedIn*

Venue: *Renseignez votre type de lieu*

Type d'espace de travail :  *Renseignez votre type d'espace de travail.*
