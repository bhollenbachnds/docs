Le Mappedin Web SDK vous permet de rendre les cartes de votre lieu, conçues à l'aide de Mappedin CMS, dans une page HTML sur le frontend de votre application web. Le SDK est un package JavaScript, construit en JavaScript pur. Pour en savoir plus sur MappedIn, veuillez consulter la documentation développeur ici.

Vous devrez acquérir certaines clés avant de procéder à l'implémentation, alors assurez-vous d'avoir parcouru leur Base de connaissances : [https://developer.mappedin.com/](https://developer.mappedin.com/)<br />
