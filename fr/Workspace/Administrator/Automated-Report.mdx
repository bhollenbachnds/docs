- title: Rapports automatisés
- description: Générez automatiquement des rapports PADS4 CMS pour les
    administrateurs et les parties prenantes en définissant les adresses e-mail,
    le type d'export, la granularité et la fréquence des rapports.
---

Dans les modules PADS4 CMS, vous pouvez générer automatiquement des rapports pour vos administrateurs ou d'autres parties prenantes dans certains délais.

Note: You need to configure your SMTP server to be able to send out automated reports.

Activez le curseur dans le coin supérieur droit sur « ON » et renseignez les informations suivantes :

#### Configuration

**E-mail addresses***: Ajoutez des adresses e-mail ici. Vous pouvez ajouter plusieurs utilisateurs*.

**Export type**: *Choisissez un ou plusieurs type(s) de fichier à exporter. PDF (.pdf), Excel (.xlsx), ou les deux.*

**Granularity**: *Sélectionnez la portée de votre rapport*. *Choisissez parmi : All buildings / By location / Per building*

**Frequency**: Sélectionnez la fréquence des rapports automatisés. Choisissez parmi : Weekly / Monthly / Quarterly / Bi-annually / Annually

Une fois que vous avez sélectionné toutes ces propriétés, cliquez sur le bouton **Save**. Cela activera l'envoi des rapports automatisés à partir du moment où vous avez enregistré.
