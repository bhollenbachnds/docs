---
- title: Rapports automatisés
---

Dans les modules CMS de PADS4, vous pouvez générer automatiquement des rapports pour vos administrateurs ou d'autres parties prenantes dans certains délais.

Note: You need to configure your SMTP server to be able to send out automated reports.

Activez le curseur dans le coin supérieur droit sur « ON » et renseignez les informations suivantes

#### Configuration

**Adresses e-mail***&#x20;: Ajoutez des adresses e-mail ici. Vous pouvez ajouter plusieurs utilisateurs*.

**Type d'exportation** : *Choisissez un ou plusieurs types de fichiers à exporter. PDF (.pdf), Excel (.xlsx), ou les deux.*

**Granularité** : *Sélectionnez la portée de votre rapport*. *Choisissez parmi : Tous les bâtiments / Par emplacement / Par bâtiment*

**Fréquence** : Sélectionnez la fréquence des rapports automatisés. Choisissez parmi : Hebdomadaire / Mensuel / Trimestriel / Semestriel / Annuel

Une fois que vous avez sélectionné toutes ces propriétés, appuyez sur le bouton Enregistrer. Cela activera l'envoi des rapports automatisés à partir du moment où vous avez enregistré.
