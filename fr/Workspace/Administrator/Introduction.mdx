---
- title: Calendrier
---

PADS Workspace est un module permettant de trouver et de réserver des salles ou d'autres espaces via une interface de calendrier intuitive. Il peut fonctionner comme une solution de réservation d'entreprise autonome : les utilisateurs ouvrent simplement l'URL Workspace configurée et se connectent avec un compte autorisé.

Workspace peut également compléter les outils de réservation et les environnements de calendrier existants au sein de votre organisation.

PADS Workspace s'intègre avec les plateformes suivantes :

* Microsoft Graph
* Microsoft Office 365
* Microsoft Exchange Server
* Google Calendar
* iPorta
