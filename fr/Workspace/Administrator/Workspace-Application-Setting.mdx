- description: Configurez les paramètres globaux par défaut de PADS4 Workspace
    pour les notifications et rappels, les réunions en ligne Microsoft Teams
    automatiques, la visibilité du nom de l'organisateur et la confidentialité.
---

### Paramètres de notification par défaut

Ce paramètre configure les préférences de notification globales dans PADS4 Workspace, où vous pouvez activer ou désactiver les notifications, définir les délais et activer les rappels pour les participants aux réunions.

![Workspace Defaults](/images/modules/workspace-cms-admin/WorkspaceDefaults.png)

### Paramètre de création d'événement

Activez par défaut les réunions en ligne Microsoft Teams automatiques. Disponible uniquement pour les salles intégrées à Exchange.

### Paramètres de confidentialité

Ce paramètre configure les options de confidentialité globales pour les réservations dans PADS4 Workspace, permettant de contrôler la visibilité du nom de l'organisateur et d'activer la fonctionnalité « Rechercher un collègue ».
