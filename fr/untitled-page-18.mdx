## Aperçu

Magasin de credentials chiffré pour l'accès aux sources de données. Gère les enregistrements d'applications (Canva, fournisseurs OAuth), les mappages de credentials par utilisateur et les credentials génériques utilisés par les connecteurs de données et les intégrations.

| Champ                                 | Valeur                                                                       |
| ------------------------------------- | ---------------------------------------------------------------------------- |
| Swagger UI                            | `https://<your-server>/rdx/NDS.Services.Credentials/swagger/index.html`      |
| Spécification OpenAPI                 | `https://<your-server>/rdx/NDS.Services.Credentials/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.Credentials`                         |
| Nombre total de points de terminaison | 40                                                                           |

***

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin de service indiqué ci-dessus.
