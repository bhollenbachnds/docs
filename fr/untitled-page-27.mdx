## Aperçu

Gère les clés de licence PADS4, les droits aux fonctionnalités et l'allocation des sièges de viewer. Valide l'état de la licence et applique les indicateurs de fonctionnalités en fonction du niveau de licence actif.

| Champ                                 | Valeur                                                                   |
| ------------------------------------- | ------------------------------------------------------------------------ |
| Swagger UI                            | `https://<your-server>/rdx/NDS.Services.License/swagger/index.html`      |
| Spécification OpenAPI                 | `https://<your-server>/rdx/NDS.Services.License/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.License`                         |
| Nombre total de points de terminaison | 30                                                                       |

***

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin de service indiqué ci-dessus.
