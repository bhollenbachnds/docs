- title: Mise à niveau depuis une version antérieure à 2025.2
---

Pour mettre à niveau vers PADS4 2025.2, votre version actuelle doit être au moins 2022.3, ce qui signifie que PADS4 2022.3 doit être installé et en cours d'exécution au préalable.

Les versions 2022.2 ou antérieures ne se mettront pas à jour automatiquement vers 2025.2 ; une mise à niveau intermédiaire vers 2022.3 est requise.

<Warning>
  Comptes utilisateurs et mise à jour de sécurité

  À partir de la version 2025.1, les utilisateurs par défaut User1 et Administrator ont été supprimés pour renforcer la sécurité. Lors de la configuration, vous devez créer un nouveau compte utilisateur. Cet utilisateur est créé par l'utilisateur Root, dont le mot de passe est défini pendant le processus d'installation.
</Warning>

### **Notes de version**

Les notes de version de PADS4 2025.2 sont disponibles \[[ici](https://www.netdisplaysystems.com/downloads/ForwardLinks/PADS4relnotes.pdf)]

## Gestion des utilisateurs et migration

La gestion des utilisateurs pour PADS4 Workspace et PADS4 CMS 1.0 a été migrée vers PADS4 CTRL Center, permettant à tous les utilisateurs d'être gérés depuis un emplacement unique et centralisé.

Cette migration inclut tous les utilisateurs, licences et rôles attribués de PADS4 Workspace et CMS 1.0, qui sont automatiquement transférés vers PADS4 CTRL Center lors de l'installation. Après l'installation, vous pouvez examiner le processus de migration en vous connectant au portail web avec votre compte Root et en accédant à Migration.

Dans cette section, vous trouverez un aperçu de toutes les étapes de migration. En sélectionnant un élément, vous pouvez afficher des informations détaillées dans Détails de l'exécution de la migration ou ouvrir le Rapport de statut de migration pour un résumé complet.

## Mise à jour de l'URL de réponse Azure Single Sign-on

<Warning>
  Cette modification doit être appliquée avant la mise à jour vers 2025.2. Elle peut également être appliquée à tout moment avant la migration, car cela n'affectera pas l'installation actuelle.
</Warning>

À partir de la version PADS4 **2025.2**, l'URL de réponse attendue sur le fournisseur d'identité externe change pour prendre en charge l'utilisation multi-domaines.

Pour que le SSO PADS4 continue de fonctionner comme avant, vous devez ajouter une URL de réponse spécifique au domaine à l'application Azure Enterprise existante utilisée pour PADS4.

Suivez ces étapes :

1. Accédez à [https://entra.microsoft.com](https://entra.microsoft.com)
2. Sélectionnez **Entra ID**.
3. Ouvrez Applications d'entreprise → Toutes les applications.
4. Recherchez et sélectionnez l'application que vous avez créée pour PADS4.
5. Dans le menu Gérer à gauche, sélectionnez Authentification unique.
6. Sur la page Authentification unique, dans la section Configuration SAML de base, cliquez sur Modifier.
7. Dans le panneau Configuration SAML de base, sous URL de réponse (URL du service consommateur d'assertion), cliquez sur Ajouter une URL de réponse.
8. Dans la nouvelle ligne, entrez l'URL de réponse liée au domaine dans la première colonne, par exemple :<br /><br />https\://\[PADS4Server]/rdx/nds.services.authentication.integration/api/v1/**pads**/Saml2/Acs<br />
   <Frame>
     ![Entra ID Basic SAML Configuration Reply URL](/images/install-pads4/EntraID_Basic_SAML_Configuration_Reply-URL.png "Entra ID Basic SAML Configuration Reply URL")
   </Frame>
9. Dans cet exemple, **pads** est le segment de domaine ajouté à l'URL de réponse existante. Si votre domaine est différent du domaine par défaut `pads` domaine, remplacez `pads` dans l'URL par votre propre valeur de domaine.
10. Cliquez sur Enregistrer en haut du panneau pour appliquer les modifications.

## Rôles Viewer

Une fois la migration terminée, il est possible qu'aucun viewer ne soit affiché lorsque vous vous connectez, même si toutes les licences sont disponibles. Cela est dû à l'introduction de trois nouveaux rôles pour gérer l'accès aux viewers.

<Warning>
  Pour afficher ou modifier les paramètres des viewers, vous devez avoir l'un des rôles viewer attribué à votre compte utilisateur. Pour plus d'informations, consultez Utilisateurs et rôles dans PADS4 CTRL Center → Administrateur → Gestion des utilisateurs.
</Warning>

## Fonctionnalités obsolètes

Les composants suivants ont été marqués comme obsolètes et ne sont plus inclus dans l'installation :

* Élément TV – Remplacé par l'élément Streaming.
* Flash – Prise en charge entièrement abandonnée en raison d'une technologie dépassée.
* PADS4 License Wizard – Remplacé par le système de licences web disponible via le portail PADS4.
