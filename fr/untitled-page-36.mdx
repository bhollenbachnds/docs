## Aperçu

Gère les entrées de capteurs et les déclencheurs pour le contenu PADS4 interactif. Prend en charge les capteurs de mouvement, les lecteurs RFID, les scanners QR et les périphériques d'entrée personnalisés qui déclenchent des changements de contenu ou des flux interactifs.

| Champ                                 | Valeur                                                                  |
| ------------------------------------- | ----------------------------------------------------------------------- |
| Swagger UI                            | `https://<your-server>/rdx/NDS.Services.Sensor/swagger/index.html`      |
| OpenAPI spec                          | `https://<your-server>/rdx/NDS.Services.Sensor/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.Sensor`                         |
| Nombre total de points de terminaison | 31                                                                      |

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin de service indiqué ci-dessus.
