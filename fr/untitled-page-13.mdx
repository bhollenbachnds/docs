## Aperçu

Gère tous les flux d'authentification pour PADS4 : fournisseurs d'identité, SSO, MFA, mappage des revendications, authentification externe, groupes, rôles, permissions et gestion des jetons de session. Il s'agit de la passerelle de sécurité centrale pour toute l'authentification des utilisateurs et des services.

| Champ           | Valeur                                                                          |
| --------------- | ------------------------------------------------------------------------------- |
| Swagger UI      | `https://<your-server>/rdx/NDS.Services.Authentication/swagger/index.html`      |
| OpenAPI spec    | `https://<your-server>/rdx/NDS.Services.Authentication/swagger/v1/swagger.json` |
| Base URL        | `https://<your-server>/rdx/NDS.Services.Authentication`                         |
| Total endpoints | 76                                                                              |

## Authentification

Tous les endpoints utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin du service indiqué ci-dessus.
