#### Aperçu du fil d'actualités

Ici, vous pouvez configurer un message de bienvenue et un ticker de fil d'actualités pour vos utilisateurs sur le tableau de bord. Cela peut être utile pour envoyer certaines mises à jour à vos utilisateurs PADS4 CMS.

#### Message de bienvenue

Ici, vous pouvez ajouter une image de bienvenue et un message dans le coin supérieur gauche du tableau de bord.

• Ajoutez une image (image d'entreprise de marque ou tout ce que vous pouvez imaginer).<br />• Ajoutez un message texte à afficher pour les utilisateurs lorsqu'ils se connectent à PADS4 CMS.

Lorsque vous avez terminé d'ajouter une image et un message, cliquez sur le bouton Enregistrer à droite.

#### Messages du fil d'actualités

Voici un aperçu des différents messages du fil d'actualités. Vous pouvez créer plusieurs messages, qui s'afficheront sous forme de ticker dans le coin supérieur droit du tableau de bord utilisateur PADS4 CMS.

**Afficher X entrées**: afficher 10/25/50/100 messages.<br />**Rechercher**: utilisez des mots-clés pour rechercher certains messages.

Cliquez sur le bouton 'ajouter un message' pour ajouter un message ticker au fil d'actualités.

• Ajoutez un message texte à afficher pour les utilisateurs lorsqu'ils se connectent à PADS4 CMS.<br />• Ajoutez une image (image d'entreprise de marque ou tout ce que vous pouvez imaginer).

Lorsque vous êtes satisfait de vos messages, vous pouvez cliquer sur le bouton Enregistrer à droite. Vous pouvez toujours consulter les messages séparés et cliquer sur l'icône crayon pour modifier/supprimer les messages.
