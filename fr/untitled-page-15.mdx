## Aperçu

Le service de gestion de contenu gère les messages, listes de lecture et modèles PADS4. Prend en charge le CRUD complet pour les messages CMS, la génération de miniatures, la planification et la gestion des listes de lecture. Service principal pour tous les flux de travail de création de contenu.

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` avec le chemin de service indiqué ci-dessus.
