## Aperçu

Le moteur de planification PADS4. Gère les tranches horaires, les affectations de playlists aux créneaux temporels, les exceptions de planification et le calendrier du contenu diffusé sur quels écrans et à quels moments.

| Champ                                 | Valeur                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------- |
| Swagger UI                            | `https://<your-server>/rdx/nds.services.schedule/swagger/index.html`      |
| OpenAPI spec                          | `https://<your-server>/rdx/nds.services.schedule/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/nds.services.schedule`                         |
| Nombre total de points de terminaison | 33                                                                        |

***

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacer `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin de service indiqué ci-dessus.
