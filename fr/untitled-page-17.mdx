## Aperçu

Gère la bibliothèque multimédia PADS4 : téléchargement de fichiers, intégration de designs Canva, polices, traitement d'images et métadonnées des ressources. Gère le stockage des fichiers, les déclencheurs de conversion de format et la gestion des versions de contenu pour tous les actifs multimédias.

| Champ                                 | Valeur                                                                   |
| ------------------------------------- | ------------------------------------------------------------------------ |
| Swagger UI                            | `https://<your-server>/rdx/NDS.Services.Content/swagger/index.html`      |
| OpenAPI spec                          | `https://<your-server>/rdx/NDS.Services.Content/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.Content`                         |
| Nombre total de points de terminaison | 44                                                                       |

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin du service indiqué ci-dessus.
