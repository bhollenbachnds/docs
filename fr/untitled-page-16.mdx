## Aperçu

Stocke et récupère des paires clé-valeur de configuration à l'échelle du système et au niveau du domaine. Utilisé par d'autres services pour lire les paramètres d'exécution, les indicateurs de fonctionnalités et la configuration spécifique au déploiement.

| Champ                                 | Valeur                                                                         |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| Swagger UI                            | `https://<your-server>/rdx/NDS.Services.Configuration/swagger/index.html`      |
| OpenAPI spec                          | `https://<your-server>/rdx/NDS.Services.Configuration/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.Configuration`                         |
| Nombre total de points de terminaison | 22                                                                             |

***

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin du service indiqué ci-dessus.
