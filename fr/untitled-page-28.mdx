## Aperçu

Infrastructure interne de messagerie pub/sub pour les microservices PADS4. Gère les files d'attente de messages, les abonnements et le routage des événements entre les services. N'est généralement pas appelée directement par des clients externes.

| Champ                                 | Valeur                                                                     |
| ------------------------------------- | -------------------------------------------------------------------------- |
| Swagger UI                            | `https://<your-server>/rdx/NDS.Services.Messaging/swagger/index.html`      |
| Spécification OpenAPI                 | `https://<your-server>/rdx/NDS.Services.Messaging/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/NDS.Services.Messaging`                         |
| Nombre total de points de terminaison | 17                                                                         |

***

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin du service indiqué ci-dessus.
