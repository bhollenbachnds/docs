## Aperçu

Gère la distribution des e-mails sortants pour PADS4 : configuration SMTP, modèles d'e-mails et envoi d'e-mails transactionnels tels que les invitations d'utilisateurs, les alertes et les notifications.

| Champ                                 | Valeur                                                                 |
| ------------------------------------- | ---------------------------------------------------------------------- |
| Swagger UI                            | `https://<your-server>/rdx/nds.services.email/swagger/index.html`      |
| OpenAPI spec                          | `https://<your-server>/rdx/nds.services.email/swagger/v1/swagger.json` |
| URL de base                           | `https://<your-server>/rdx/nds.services.email`                         |
| Nombre total de points de terminaison | 17                                                                     |

***

## Authentification

Tous les points de terminaison utilisent le cookie de session PADS4 standard. Obtenez-le une fois et réutilisez-le :

```bash
# Log in and save the session cookie
curl -c cookies.txt -X POST 'https://<your-server>/api/v1/Account/Logon' \
  -H 'Content-Type: application/json' \
  -d '{"UserName": "admin", "Password": "yourpassword", "Domain": "yourdomain"}'

# Use the cookie on all subsequent requests
curl -b cookies.txt -X GET 'https://<your-server>/rdx/<ServiceName>/...'
```

> Remplacez `https://<your-server>` par l'adresse de votre serveur PADS4 et `<ServiceName>` par le chemin de service indiqué ci-dessus.
