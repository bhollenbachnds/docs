---
- title: Stratégies de groupe Microsoft Windows
- description: Utilisez les stratégies de groupe Microsoft Windows pour gérer de
    manière centralisée les paramètres du PADS4 Desktop Viewer pour les
    utilisateurs et les groupes d'utilisateurs de votre organisation.
---

De nombreuses organisations utilisent les stratégies de groupe Microsoft pour gérer de manière centralisée les paramètres de leurs utilisateurs. Avec les stratégies de groupe Microsoft, vous pouvez gérer de manière centralisée les paramètres du Desktop Viewer.

PADS4 a mis en œuvre des stratégies de groupe pour l'application Desktop Viewer. Celles-ci vous permettent de spécifier les paramètres depuis un emplacement central et de les transmettre à un ou plusieurs utilisateurs ou groupes d'utilisateurs. La fenêtre d'options du Desktop Viewer détecte automatiquement les stratégies que vous avez définies et désactive ces options dans l'interface utilisateur. De cette façon, vous pouvez transmettre un ensemble de paramètres prédéfinis aux utilisateurs tout en leur permettant de modifier certains paramètres localement.

Les paramètres transmis sont stockés dans le registre sous :

HKEY\_CURRENT\_USER\SOFTWARE\Policies\Net Display Systems\PADS4

Les « paramètres normaux » sont stockés dans le registre sous :

HKEY\_CURRENT\_USER\SOFTWARE\Net Display Systems\PADS4

## Configurer les stratégies de groupe pour les Desktop Viewers PADS4

### Installer le serveur PADS4

Commencez par installer le serveur PADS4 (ou d'autres composants, mais les fichiers de stratégie sont installés avec l'installation du serveur).

### Installer le fichier de modèle de stratégie de groupe

Copiez PADS4.admx depuis C:\Program Files\Net Display Systems\PADS4\PolicyDefinitions vers le répertoire de définitions de stratégies de domaine sur le serveur de domaine (généralement : \FQDN\SYSVOL\FQDN\Policies\PolicyDefinitions)

### Installer le fichier de traduction de stratégie

Copiez PADS4.adml depuis C:\Program Files\Net Display Systems\PADS4\PolicyDefinitions vers le répertoire de langue des définitions de stratégies de domaine sur le serveur de domaine (généralement : \FQDN\SYSVOL\<FQDN>\Policies\PolicyDefinitions\en-US)

### Configurer les stratégies dans la console de gestion des stratégies de groupe (GPMC)

Ouvrez l'application Console de gestion des stratégies de groupe, puis ouvrez l'Éditeur de stratégie de groupe.

Sélectionnez Configuration utilisateur / Stratégies / Modèles d'administration : Définition de stratégie / Net Display Systems / PADS4 / Desktop Viewer

</Note>
