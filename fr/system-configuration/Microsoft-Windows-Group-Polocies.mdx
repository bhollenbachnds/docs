---
- title: Stratégies de groupe Microsoft Windows
- description: Utilisez les stratégies de groupe Microsoft Windows pour gérer de
    manière centralisée les paramètres du PADS4 Desktop Viewer pour les
    utilisateurs et les groupes d'utilisateurs de votre organisation.
---

De nombreuses organisations utilisent les stratégies de groupe Microsoft pour gérer de manière centralisée les paramètres des utilisateurs. Avec les stratégies de groupe de Microsoft, vous pouvez gérer de manière centralisée les paramètres du Desktop Viewer.

PADS4 a implémenté des stratégies de groupe pour l'application Desktop Viewer. Celles-ci vous permettent de spécifier les paramètres depuis un emplacement central et de les transmettre à un ou plusieurs utilisateurs ou groupes d'utilisateurs. La fenêtre des options du Desktop Viewer détecte automatiquement les stratégies que vous définissez et désactive ces options dans l'interface utilisateur. De cette façon, il est possible de transmettre un ensemble de paramètres prédéfinis aux utilisateurs, tout en leur donnant la possibilité de modifier certains paramètres localement.

Les paramètres transmis sont stockés dans le registre sous :

HKEY\_CURRENT\_USER\SOFTWARE\Policies\Net Display Systems\PADS4

Les « paramètres normaux » sont stockés dans le registre sous :

HKEY\_CURRENT\_USER\SOFTWARE\Net Display Systems\PADS4

Pour configurer l'utilisation des stratégies de groupe pour les PADS4 Desktop Viewers - Installation de PADS4 Server

Installez d'abord PADS4 Server (ou d'autres composants, mais les fichiers de stratégie sont installés avec l'installation du serveur).

Installer le fichier de modèle de stratégie de groupe

Copiez PADS4.admx depuis C:\Program Files\Net Display Systems\PADS4\PolicyDefinitions vers le répertoire des définitions de stratégie de domaine sur le serveur de domaine (généralement : \FQDN\SYSVOL\FQDN\Policies\PolicyDefinitions)

Fichier de traduction de stratégie

Copiez PADS4.adml depuis C:\Program Files\Net Display Systems\PADS4\PolicyDefinitions vers le répertoire de langue des définitions de stratégie de domaine sur le serveur de domaine (généralement : \FQDN\SYSVOL\<FQDN>\Policies\PolicyDefinitions\en-US)

Console de gestion des stratégies de groupe Microsoft (GPMC)

Ouvrez l'application Console de gestion des stratégies de groupe, puis ouvrez l'Éditeur de stratégie de groupe.

Sélectionnez Configuration utilisateur / Stratégies / Modèles d'administration : Définition de stratégie / Net Display Systems / PADS4 / Desktop Viewer

REMARQUE

Cela vous permet de spécifier les paramètres depuis un emplacement central et de les transmettre aux utilisateurs. Les utilisateurs ne peuvent pas remplacer ces paramètres via la fenêtre des options. Les options que vous définissez/transmettez sont désactivées dans la fenêtre des options du Desktop Viewer.
