L'onglet **Room User Profiles** permet aux administrateurs de créer et de gérer des profils utilisateur définissant les niveaux d'accès et les permissions au sein du système.

## Ajout d'un Room User Profile

Pour créer un nouveau Room User Profile, cliquez sur le bouton **Add Room User Profile**.

### Informations générales

Lors de la création d'un nouveau profil, fournissez les informations suivantes :

* **Nom**<br />Le nom du profil.
* **Description**<br />Une brève description de l'objectif du profil ou du groupe d'utilisateurs concerné.
* **Télétravail**<br />Activez cette option si les utilisateurs assignés à ce profil travaillent principalement depuis leur domicile.
* **Empêcher la réservation de salle**<br />Activez cette option pour permettre aux utilisateurs de consulter les salles sans pouvoir les réserver.

### Onglet Salles

Spécifiez les salles que les utilisateurs de ce profil sont autorisés à **consulter** et/ou **réserver**.

## Gestion des Room User Profiles

* **Modifier un profil**<br />Pour apporter des modifications à un profil existant, sélectionnez l'option **modifier** et mettez à jour les champs nécessaires.
* **Supprimer un profil**<br />Pour supprimer un profil, sélectionnez l'option **modifier** et choisissez **supprimer**.
