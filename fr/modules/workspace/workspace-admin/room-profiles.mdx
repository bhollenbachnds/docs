---
- title: Profils de salles
---

L'onglet **Room Profiles** vous permet de définir des paramètres de configuration réutilisables et des règles opérationnelles pour les salles. En attribuant le même profil à plusieurs salles, vous pouvez simplifier la configuration des salles et maintenir un comportement cohérent.

## Aperçu

Lorsque vous ouvrez **Room Profiles**, le tableau de bord affiche deux profils par défaut :

* **Salles réservables**
* **Salles non réservables**

Ces profils standard sont fournis par PADS4 Workspace. Vous pouvez également créer des profils de salle personnalisés pour répondre aux besoins de votre organisation.

Par défaut, les utilisateurs peuvent consulter et réserver toutes les salles disponibles. Pour limiter l'accès à des salles spécifiques, configurez les autorisations de salle applicables dans le profil utilisateur.

## Général

* **Name:** Saisissez un nom pour le profil de salle.
* **Description:** Saisissez une description du profil et de son utilisation prévue.
* **Utiliser un système de réservation externe :** Permet aux salles assignées à ce profil d'être réservées via un système de réservation externe, tel que Microsoft Outlook.
* **Est un profil de bureau partagé :** Sélectionnez cette option lorsque le profil est utilisé pour des bureaux partagés ou des espaces de travail partagés.
* **Est attribué par défaut à un utilisateur :** Sélectionnez cette option lorsque l'espace de travail est normalement attribué à un utilisateur spécifique.
* **Inactive:** Sélectionnez cette option pour désactiver le profil. Décochez l'option pour rendre le profil à nouveau disponible.
* **Limiter la capacité :** Sélectionnez cette option pour ne rendre disponible qu'une partie de la capacité de la salle. Indiquez le pourcentage de capacité disponible pour les réservations.
* **Activer le nettoyage :** Empêche les salles assignées à ce profil d'être réservées pendant 30 minutes après la fin d'une réunion.

### App Booking

Les **App Booking** paramètres contrôlent si les salles assignées à ce profil peuvent être réservées via l'application PADS4 Workspace.

* **Type de réservation :** Sélectionnez **Calendrier** pour les réservations via le plug-in Outlook, ou **Impulse** pour les réservations directes depuis un écran.
* **Utiliser l'authentification :** Active ou désactive l'authentification des utilisateurs dans l'application Workspace.
* **Utiliser l'enregistrement :** Active ou désactive l'enregistrement pour les réservations dans l'application Workspace.
* **Enregistrement anonyme :** Permet aux utilisateurs de s'enregistrer sans authentification.
* **Heure d'enregistrement :** Spécifie le délai dont disposent les utilisateurs pour s'enregistrer avant qu'une réservation non confirmée soit supprimée.
* **Heure d'enregistrement avant la réunion :** Spécifie combien de temps avant la réunion les utilisateurs peuvent s'enregistrer.
* **Planning journalier :** Définit les jours et les horaires pendant lesquels la réservation via l'application est disponible. Sélectionnez les jours disponibles et configurez les heures de début et de fin.

### Occupancy Sensor Booking

The **Occupancy Sensor Booking** Les paramètres permettent des réservations de salles automatiques basées sur les données d'un capteur d'occupation. Lorsque le capteur détecte une présence dans l'espace de travail, il peut créer automatiquement une réservation.

* **Désactiver la réservation automatique :** Empêche la réservation automatique lorsqu'une présence est détectée. Les réservations par capteur peuvent toujours être supprimées manuellement, et les réunions non confirmées sont supprimées automatiquement.
* **Durée de présence avant le début :** Spécifie le nombre de minutes pendant lesquelles une présence doit être détectée avant qu'une réservation soit créée.
* **Période de réservation :** Spécifie la durée, en minutes, de la réservation créée après la détection d'une présence.
* **Planning de la pause déjeuner :** Définit l'heure de début et de fin de la pause déjeuner.
* **Durée sans présence avant libération :** Spécifie le nombre de minutes sans présence détectée avant que la salle soit libérée automatiquement.

## Additional Service

Utilisez **Additional Service** pour proposer des services optionnels lors d'une réservation, tels que la commande de nourriture ou de boissons.

## Extended Property

**Extended Property** peut être utilisé pour définir des caractéristiques supplémentaires de la salle, telles que des chaises confortables.

## Licence

* **Utiliser cet espace dans le plug-in Outlook :** Rend les salles assignées à ce profil disponibles dans le plug-in Outlook.
* **Rendre le QR code disponible pour cet espace :** Génère un QR code pour l'espace. Les utilisateurs peuvent scanner le code pour ouvrir l'application Workspace, s'authentifier avec leur compte de domaine et réserver la salle.
