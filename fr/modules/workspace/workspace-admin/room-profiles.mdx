L'**Profils de salle** vous permet de définir des règles opérationnelles pour les salles. Chaque profil définit des paramètres de comportement qui peuvent être réutilisés dans plusieurs salles, simplifiant la configuration et garantissant la cohérence.

## Création d'un profil de salle

Pour créer un nouveau profil de salle, cliquez sur le **Créer un profil de salle** bouton.

### Onglet Général

Dans l'onglet Général, renseignez les informations suivantes :

* **Nom**<br />Nom du profil de salle.
* **Description**<br />Une brève explication de l'objectif du profil.
* **Utiliser un système de réservation externe**<br />Active l'intégration avec des systèmes externes tels que Microsoft Outlook.
* **Est un profil de bureau partagé**<br />Utilisez cette option pour les profils destinés aux bureaux partagés.
* **Est attribué par défaut à un utilisateur**<br />Indique si ce bureau est normalement attribué à un utilisateur spécifique.
* **Inactif**<br />Marque le profil comme non réservable (par exemple, temporairement indisponible).
* **Limiter la capacité**<br />Utilisé dans les scénarios de bureau partagé pour restreindre le nombre de places disponibles.
* **Activer le nettoyage**<br />Ajoute un délai tampon de nettoyage après une réservation. Pendant cette période, la salle ne peut pas être réservée.
* **Réservation via l'application**<br />Active les réservations via l'application web PADS4 ou les panneaux de salle physiques.
* **Réservation par capteur**<br />Active la réservation basée sur des capteurs d'occupation (par exemple, réservation automatique lorsqu'une présence est détectée).

### Onglets supplémentaires

* **Service supplémentaire**<br />Attribuez des services supplémentaires tels que la restauration ou la configuration audiovisuelle aux salles utilisant ce profil.
* **Approbation**<br />Exiger l'approbation d'un utilisateur désigné avant qu'une réservation soit finalisée.
* **Propriété étendue**<br />Ajoutez des caractéristiques personnalisées de la salle telles que l'accessibilité en fauteuil roulant ou des notes sur l'équipement.
* **Licence**<br />Activez cette salle pour qu'elle apparaisse dans le complément Outlook ou attribuez-lui un code QR pour l'accès des utilisateurs.
