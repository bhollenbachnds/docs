L'**Room Users** permet aux administrateurs de créer ou d'importer des utilisateurs qui auront accès à l'**PADS4 Workspace User Interface**.

## Ajout d'un utilisateur de salle

Pour ajouter un nouvel utilisateur, cliquez sur le bouton **Add Room User**.

### Création manuelle d'utilisateur

Pour ajouter manuellement un utilisateur, sélectionnez **Add a Room User** et remplissez les champs requis.

### Informations générales

* **Login**<br />Le nom d'utilisateur du compte.
* **Mot de passe / Confirmer le mot de passe**<br />Requis pour sécuriser le compte.
* **Profil**<br />Attribuez l'utilisateur à un profil d'utilisateur de salle spécifique.
* **E-mail**<br />Adresse e-mail de l'utilisateur.
* **Nom / Prénom**<br />Le nom de famille et le prénom de l'utilisateur.
* **Numéro NFC**<br />Le cas échéant, entrez l'identifiant NFC de l'utilisateur (utilisé pour les enregistrements en salle via NFC).
* **Télétravail**<br />Activez cette option si l'utilisateur travaille principalement depuis chez lui.
* **Empêcher la réservation de salle**<br />Si cette option est sélectionnée, l'utilisateur pourra consulter les salles mais pas les réserver.

### Accès aux salles

Spécifiez les salles auxquelles cet utilisateur peut **voir** et/ou **réserver** dans l'interface PADS4 Workspace.

### Délégation

Assignez les utilisateurs qui doivent approuver les réservations de salles effectuées par cet utilisateur, si nécessaire.
