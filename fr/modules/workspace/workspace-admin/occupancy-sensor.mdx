- title: Capteurs d'occupation
---

#### Gateways

Dans cette section, les informations réseau des capteurs d'occupation connectés sont répertoriées.

**Name** : Nom du capteur d'occupation.

**MAC address** : L'adresse MAC du capteur d'occupation

**IP address** : L'adresse IP ou réseau du capteur d'occupation.

#### Sensors

Dans cette section, les capteurs connectés sont répertoriés

**ID** : L'identifiant du capteur

**Name** : Le nom du capteur

**Type** : Indique le type de capteur

**Connected to** : Indique à quelle passerelle le capteur est connecté.

**Linked to room** : Indique à quelles salles le capteur est lié.

#### LED's

Utilisé pour indiquer si une salle ou un espace de travail est réservé (vert = disponible / rouge = indisponible)

**Name** : Nom de la LED

**MAC Address** : Adresse MAC de la LED

**IP Address** : Adresse IP / Adresse réseau de la LED

**Last Activity** : Indique quand la LED a été déclenchée pour la dernière fois.

**Linked To** : Indique à quelles salles la LED est liée.
