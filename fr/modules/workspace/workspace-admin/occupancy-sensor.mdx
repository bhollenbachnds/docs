- title: Capteurs d'occupation
---

#### Passerelles

Dans cette section sont répertoriées les informations réseau des capteurs d'occupation connectés.

**Nom** : Nom du capteur d'occupation.

**Adresse MAC** : L'adresse MAC du capteur d'occupation

**Adresse IP** : L'adresse IP ou réseau du capteur d'occupation.

#### Capteurs

Dans cette section sont répertoriés les capteurs connectés

**ID** : L'ID du capteur

**Nom** : Le nom du capteur

**Type** : Indique le type de capteur

**Connecté à** : Indique à quelle passerelle le capteur est connecté.

**Lié à la salle** : Indique à quelles salles le capteur est lié.

#### LED

Utilisé pour indiquer si une salle ou un espace de travail est réservé (vert = disponible / rouge = indisponible)

**Nom** : Nom de la LED

**Adresse MAC** : Adresse MAC de la LED

**Adresse IP** : Adresse IP / Adresse réseau de la LED

**Dernière activité** : Indique quand la LED a été déclenchée pour la dernière fois.

**Lié à** : Indique à quelles salles la LED est liée.
