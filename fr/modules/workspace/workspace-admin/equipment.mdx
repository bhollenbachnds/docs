L'**Equipment** onglet permet aux administrateurs de définir des équipements pouvant être associés à des salles dans le **PADS4 Workspace Module**. Cela aide les utilisateurs finaux à comprendre quels outils ou appareils sont disponibles dans chaque espace.

## Ajout d'équipement

Pour ajouter un nouvel équipement :

1. Cliquez sur le bouton **Add Equipment**.
2. Dans la **Create Equipment** fenêtre, renseignez les informations suivantes :
   * **Nom**<br />Saisissez le nom de l'équipement (par ex., Projecteur, Tableau blanc, Système de vidéoconférence).
   * **Image**<br />Téléchargez une image qui représentera visuellement l'équipement dans l'interface utilisateur.

{/* TODO: missing image — original placeholder referenced /mnt/data/image.png with alt: "Create Equipment Screen" */}

3. Cliquez sur **Save** pour finaliser le processus.

Une fois ajouté, l'équipement peut être assigné à des salles individuelles via le panneau de configuration des salles.
