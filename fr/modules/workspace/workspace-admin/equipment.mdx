L'**Équipement** onglet permet aux administrateurs de définir des éléments d'équipement pouvant être associés à des salles dans le **PADS4 Workspace Module**. Cela aide les utilisateurs finaux à comprendre quels outils ou appareils sont disponibles dans chaque espace.

## Ajout d'équipement

Pour ajouter un nouvel équipement :

1. Cliquez sur le bouton **Ajouter un équipement**.

2. Dans la fenêtre **Créer un équipement**, renseignez les informations suivantes :

   * **Nom**\
     Saisissez le nom de l'équipement (par ex., Projecteur, Tableau blanc, Système de vidéoconférence).

   * **Image**\
     Téléchargez une image qui représentera visuellement l'équipement dans l'interface utilisateur.

{/* TODO: missing image — original placeholder referenced /mnt/data/image.png with alt: "Create Equipment Screen" */}

3. Cliquez sur **Enregistrer** pour terminer le processus.

Une fois ajouté, l'équipement peut être attribué à des salles individuelles via le panneau de configuration des salles.
