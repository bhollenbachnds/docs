- title: Équipement
---

Le **Equipment** onglet permet aux administrateurs de définir des équipements pouvant être associés aux salles dans le **PADS4 Workspace Module**. Cela aide les utilisateurs finaux à comprendre quels outils ou appareils sont disponibles dans chaque espace.

## Ajouter un équipement

Pour ajouter un nouvel équipement :

1. Cliquez sur le **Add Equipment** bouton.
2. Dans la **Create Equipment** fenêtre, renseignez les détails suivants :
   * **Nom**<br />Saisissez le nom de l'équipement (par ex., Projecteur, Tableau blanc, Système de vidéoconférence).
   * **Image**<br />Téléchargez une image qui représentera visuellement l'équipement dans l'interface utilisateur.

{/* TODO: missing image — original placeholder referenced /mnt/data/image.png with alt: "Create Equipment Screen" */}

3. Cliquez sur **Save** pour terminer le processus.

Une fois ajouté, l'équipement peut être attribué à des salles individuelles via le panneau de configuration de la salle.
