L'onglet **Capteurs d'occupation** permet aux administrateurs de visualiser et de gérer toutes les passerelles, tous les capteurs et tous les dispositifs LED connectés utilisés dans le **Module PADS4 Workspace**.

## Passerelles

Affiche toutes les **passerelles de capteurs** connectées ainsi que leur statut de connexion et les détails d'activité.

## Capteurs

Affiche tous les **capteurs d'occupation** connectés et permet aux administrateurs de les affecter à des salles spécifiques dans le système.

## LEDs

Répertorie tous les **dispositifs LED** gérés par le Module PADS4 Workspace, généralement utilisés pour signaler le statut ou la disponibilité d'une salle.
