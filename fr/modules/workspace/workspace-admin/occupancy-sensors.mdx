L'onglet **Capteurs d'occupation** permet aux administrateurs de visualiser et de gérer toutes les passerelles, tous les capteurs et tous les appareils LED connectés utilisés dans le **module PADS4 Workspace**.

## Passerelles

Affiche toutes les **passerelles de capteurs** connectées ainsi que leur état de connexion et les détails d'activité.

## Capteurs

Affiche tous les **capteurs d'occupation** connectés et permet aux administrateurs de les affecter à des salles spécifiques dans le système.

## LEDs

Répertorie tous les **appareils LED** gérés par le module PADS4 Workspace, généralement utilisés pour signaler l'état ou la disponibilité des salles.
