L'onglet **Occupancy Sensors** permet aux administrateurs d'afficher et de gérer toutes les passerelles, capteurs et dispositifs LED connectés utilisés dans le **module PADS4 Workspace**.

## Passerelles

Affiche toutes les **passerelles de capteurs** connectées ainsi que leur statut de connexion et les détails d'activité.

## Capteurs

Affiche tous les **capteurs de présence** connectés et permet aux administrateurs de les affecter à des salles spécifiques dans le système.

## LEDs

Répertorie tous les **dispositifs LED** géré par le module PADS4 Workspace, généralement utilisé pour signaler le statut ou la disponibilité d'une salle.
