Le **Extended Property** tab permet aux administrateurs de créer des attributs personnalisés pour les salles et les espaces, tels que **l'accessibilité en fauteuil roulant**, **les types de sièges**, ou d'autres caractéristiques spécialisées de la salle.

## Ajouter une propriété étendue

Pour ajouter une nouvelle propriété, cliquez sur le bouton **Add Extended Property**.

### Champs obligatoires

Lors de la création d'une propriété, fournissez les informations suivantes :

* **Name**<br />Le nom de la propriété étendue (ex. : Wheelchair Accessible, U-Shaped Seating).
* **Type**<br />Définit où la propriété s'applique :
  * **Default** – Pour les salles et les espaces de travail.
  * **Common Areas** – Pour les restaurants, les halls d'entrée ou autres espaces partagés.
* **Value**<br />La valeur ou caractéristique spécifique de la propriété (ex. : "Yes" pour l'accessibilité, "10 chairs" pour les sièges).
* **Add to All Room Profiles**<br />Activez cette option si la propriété doit être disponible dans tous les profils de salle du système.
