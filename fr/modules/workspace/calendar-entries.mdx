Chaque type d'entrée dans Mon calendrier possède sa propre icône et couleur. Utilisez cette page pour trouver la bonne icône et comprendre ce que vous voyez dans votre calendrier.

## Icônes et couleurs

| Entrée                                    | Icône pour la démarrer                                    | Couleur dans le calendrier       |
| ----------------------------------------- | --------------------------------------------------------- | -------------------------------- |
| Réservation de salle                      | Le **+** bouton dans le coin inférieur droit              | Vert                             |
| Réservation en attente d'approbation      | Le **+** bouton, comme pour une réservation de salle      | Vert (affiché comme En attente.) |
| Demande de réservation                    | Demande de réservation dans votre calendrier              | Jaune                            |
| Réservation d'espace commun               | L'icône violette, après avoir sélectionné le **+** bouton | Violet                           |
| Réservation d'espace de travail de groupe | L'icône verte dans le coin inférieur droit                | Vert                             |
| Déclaration de télétravail                | L'icône bleue dans le coin inférieur droit                | Bleu                             |
| Absence                                   | L'icône rouge, après avoir sélectionné le **+** bouton    | Rouge                            |
