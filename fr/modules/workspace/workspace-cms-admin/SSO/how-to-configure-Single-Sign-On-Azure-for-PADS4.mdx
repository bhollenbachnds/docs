Suivez ce processus pour configurer votre installation PADS4 CMS afin d'utiliser Azure SSO.

<Warning>
  À partir de PADS4 2025.2, cette fonctionnalité fait partie de PADS4 CTRL Center. Pour plus d'informations, consultez CTRL Center > Administration > Identity.
</Warning>

## Paramètres Azure

Configurez l'instance Azure pour permettre aux utilisateurs de votre organisation d'accéder à l'application CMS PADS4 (Legacy). Pour activer cette fonctionnalité, suivez les étapes de ce document.

## Étape 1 : Accédez à votre page "Azure portal" et connectez-vous en tant qu'administrateur

[https://portal.azure.com/](https://portal.azure.com/)

## Étape 2 : Sélectionnez l'option "Microsoft Entra ID"

![Microsoft Entra ID](/images/MicrosftentraID.png)

## Étape 3 : Dans le panneau de gauche, sélectionnez "Enterprise Applications"

![Enterprise Applications Pn](/images/EnterpriseApplications.png)

## Important

<Warning>
  Si vous **<u>ne</u>** souhaitez pas utiliser un Application Proxy sur votre application sur site, continuez avec l'étape 4 ci-dessous et ignorez les étapes 7 et 8.

  Si vous **<u>souhaitez</u>** utiliser un Application Proxy pour votre application sur site, passez à l'étape 7 et ignorez les étapes 4, 5 et 6.
</Warning>

## Étape 4 : Sélectionnez l'option "+ New application" en haut de l'écran

![Step4+newapplication Pn](/images/step4+newapplication.png)

## Étape 5 : Sélectionnez "Create your own application"

![Step5 Pn](/images/step5.png)

## Étape 6 : Remplissez les informations demandées dans le formulaire et sélectionnez Create

![Step6 Pn](/images/step6.png)

<Warning>
  Ignorez cette étape (7) si vous n'utilisez pas un Application Proxy.
</Warning>

## Étape 7 : Créez un groupe de connecteurs / connecteur de proxy d'application

Sélectionnez la **Manage Application Proxy Connectors** **section**.

![Step7 Pn](/images/step7.png)

1. Dans le menu Application Proxy, sélectionnez + Download Connector Service
2. Acceptez les conditions et téléchargez le fichier **<u>AADApplicationProxyConnectorInstaller.exe</u>** sur le PC serveur.
3. Exécutez le programme d'installation et assurez-vous de valider vos informations d'identification d'administrateur Azure lors de la configuration.

   ![Step8 Pn](/images/step8.png)
4. Une fois l'installation terminée, sélectionnez la section **+New Connector** Group
5. Créez un nom par défaut pour votre connexion. Par exemple : **SSO Connector**
6. Sélectionnez votre machine serveur dans la liste des connecteurs
7. Sélectionnez la région où se trouve votre machine.

   ![Step9 Pn](/images/step9.png)
8. Enregistrez votre nouvelle connexion ici.
9. Retournez à la section Enterprise Applications et sélectionnez **"Add your own on-premises application"**

## Créez une application sur site dans Azure

1. Sélectionnez **Add an on-premises application**

   ![Step10 Pn](/images/step10.png)

<Warning>
  Ignorez cette étape (8) si vous n'utilisez pas un Application Proxy.
</Warning>

## Étape 8 : Remplissez les informations demandées dans le formulaire et sélectionnez Create

![Addyouownonpromiseapp Pn](/images/Addyouownonpromiseapp.png)

### Exemple

Name: PADS4 CMS

URL interne : URL de l'installation PADS4 CMS ([https://servername](https://servername))

Pre-authentication: Azure Active Directory

Connector Group : SSO Connector (par défaut). <u>Il s'agit du groupe de connecteurs que vous venez de configurer</u>

Sélectionnez ensuite **Add**.

## Étape 9 : Accédez à l'application nouvellement créée

1. Accédez à l'application nouvellement créée en sélectionnant **"Enterprise Applications"** et utilisez **la barre de recherche** pour trouver votre application. **Sélectionnez-la** puis accédez à "Users and Groups" :

![Userandgroups Pn](/images/userandgroups.png)

2. Ajoutez les utilisateurs et les groupes qui auront accès à l'application en sélectionnant l'option **"Add user/group"**.

![Robinsso Pn](/images/robinsso.png)

3. Sélectionnez l'option **"None Selected"** pour accéder aux groupes et aux utilisateurs :

![Add Pn](/images/add.png)

4. Utilisez la barre de recherche pour rechercher un utilisateur ou un groupe. Sélectionnez **"select"** et **"assign"** une fois terminé.

![Add2 Pn](/images/add2.png)

<Warning>
  Nous vous recommandons vivement de créer un groupe d'utilisateurs PADS4 CMS avec Windows Server AD comme source.
</Warning>

## Étape 10 : Configurer l'authentification unique (SSO)

Sélectionnez **"Single sign-on option"** dans le volet de gauche, puis **"SAML"**.

![10 Pn](/images/10.png)

## Étape 11 : Sélectionnez "Edit" dans la section "Basic SAML Configuration"

![Image23 Pn](/images/Image23.png)

Sélectionnez "Add identifier" et **"Add Reply URL"**, et fournissez les valeurs comme indiqué dans l'exemple ci-dessous :

![Image24 Pn](/images/Image24.png)

## Exemple

**Identifier** : URL PADS4 CMS locale avec /Saml2 **(ex :** [https://robin.pads365.com/crystal/domain/Saml2](https://robin.pads365.com/crystal/domain/Saml2))

Si vous utilisez un port réseau unique, incluez-le dans la chaîne ci-dessus.

E.g.: [https://robin.pads365.com:444/crystal/domain/Saml2](https://robin.pads365.com:444/crystal/domain/Saml2)

**Assurez-vous** de spécifier votre domaine PADS4 à "domain" dans l'URL.

![Image25 Pn](/images/Image25.png)

Si vous utilisez le nom de domaine par défaut, ce sera : [https://robin.pads365.com/crystal/pads/Saml2](https://robin.pads365.com/crystal/pads/Saml2)

Reply URL : URL PADS4 CMS locale avec /Saml2/Acs **(ex :**[**https://robin.pads365.com/crystal/domain/Saml2/Acs**](https://robin.pads365.com/crystal/domain/Saml2/Acs))

Si vous utilisez un port réseau unique, incluez-le dans la chaîne ci-dessus.

E.g.: [https://robin.pads365.com:444/crystal/domain/Saml2/Acs](https://robin.pads365.com:444/crystal/domain/Saml2/Acs)

**Assurez-vous** de spécifier votre domaine PADS4 à "domain" dans l'URL.

![Image26 Pn](/images/Image26.png)

Si vous utilisez le nom de domaine par défaut, ce sera :

[https://robin.pads365.com/crystal/pads/Saml2/Acs](https://robin.pads365.com/crystal/pads/Saml2/Acs)

<Info>
  **Remark:** Si vous avez configuré le SSO sur une version antérieure à 2023.1, le nom de domaine n'était pas requis dans l'URL lors de l'utilisation d'un seul domaine. À partir de la version 2023.1, le nom de domaine est requis dans l'URL pour les configurations à un seul domaine et à plusieurs domaines.

  Par conséquent, lors de la mise à jour d'une version antérieure à 2023.1 avec le SSO configuré vers la dernière version, assurez-vous d'ajouter le domaine à la fois à l'Identifier et à la Reply URL.

  **Assurez-vous d'"Enregistrer" ces configurations.**
</Info>

# Informations requises pour la configuration SSO dans PADS4 CMS

## Pour configurer le SSO dans PADS4 CMS, vous avez besoin des éléments suivants

Certificat du serveur de fédération

Identifiant du service de fédération

URL SSO SAML

URL des métadonnées

URL de la partie de confiance

ID de groupe du groupe d'utilisateurs que vous avez assigné à l'application.

## 1. Obtenez le "Certificat du serveur de fédération"

Dans votre application, sélectionnez **"Single sign-on"** dans le volet gauche.

Faites défiler jusqu'à l'en-tête **"SAML Certificates"**.

Sélectionnez l'option **"Download"** en regard de l'option "Certificate (Raw)".

![Image32 Pn](/images/Image32.png)

## 2. Obtenir le "Federation Service Identifier"

Dans votre application, sélectionnez **"Single sign-on"** dans le volet gauche.

Faites défiler jusqu'à l'en-tête **"Set up your\_application\_name"**.

Sélectionnez l'option **"Copy"** en regard de l'option **"Azure AD Identifier"**.

![Image33 Pn](/images/Image33.png)

## 3. Obtenir le "SAML SSO URL"

Dans votre application, sélectionnez **"Single sign-on"** dans le volet gauche.

Faites défiler jusqu'à l'en-tête **"Set up your\_application\_name"**.

Sélectionnez l'option **"Copy"** en regard de l'option **"Login URL"**.

![Image34 Pn](/images/Image34.png)

## 4. Obtenir le "Metadata URL"

Dans votre application, sélectionnez **"Single sign-on"** dans le volet gauche.

Faites défiler jusqu'à l'en-tête **"SAML Certificates"**.

Sélectionnez l'option **"Copy"** en regard de l'option **"App Federation Metadata URL"**.

![Image35 Pn](/images/Image35.png)

## 5. Obtenir le "URL of the Relying party"

Dans votre application, sélectionnez **"Single sign-on"** dans le volet gauche.

Faites défiler jusqu'à l'en-tête **"Basic SAML Configuration"**.

Copiez la chaîne en regard de l'option **"Identifier (Entity ID)"**.

![Image36 Pn](/images/Image36.png)

## 6. Obtenir le "Group ID" du groupe que vous avez assigné à votre application

<Info>
  Pour **chaque groupe d'utilisateurs ajouté pour utiliser l'application PADS4 CMS, vous avez besoin d'une table de correspondance pour ajouter les groupes à l'interface. Fournissez aux installateurs les identifiants de groupe (Group IDs) et les noms des groupes depuis Azure afin de garantir que les utilisateurs peuvent se connecter.**
</Info>

Sélectionnez **"home"** sur portal.azure.com et sélectionnez **"Microsoft Entra ID"**.

Accédez à **"Groups"** dans le volet gauche.

Recherchez le groupe que vous avez assigné dans votre application et copiez le **"Object Id"**.

![Image37 Pn](/images/Image37.png)

## 7. Configurer le SSO dans PADS4 CMS

Maintenant que vous avez rassemblé toutes les informations ci-dessus, vous pouvez configurer PADS4 CMS pour utiliser le SSO.
