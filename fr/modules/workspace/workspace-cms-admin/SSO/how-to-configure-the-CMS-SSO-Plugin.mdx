<Warning>
  De **PADS4 2025.2 et versions ultérieures**, cette fonctionnalité fait partie de PADS4 CTRL Center. Pour plus d'informations, voir CTRL Center > Administration > Identity.
</Warning>

Ce manuel ne peut être suivi que si vous avez configuré SSO dans votre environnement Azure / Entra ID.

Maintenant que vous avez rassemblé toutes les informations requises, vous pouvez configurer PADS4 CMS pour utiliser SSO.

## Important

Pour que SSO fonctionne correctement, vous devez configurer PADS4 pour utiliser HTTPS. Pour ce faire, suivez ce guide en utilisant un certificat SSL.

## Étape 1 : Accédez à votre instance PADS4 CMS dans un navigateur

Connectez-vous avec un compte Administrateur et sélectionnez "CMS Admin".

![CM Sadmin Pn](/images/CMSadmin.png)

## Étape 2 : Sélectionnez "Plugins" dans le volet gauche, puis "Single Sign-on (SSO)"

Activez le plugin en **haut à droite**. À côté de **"Type"**, sélectionnez l'option **"Azure AD"** dans la liste déroulante.

![Plugin Type Azure AD Pn](/images/Pluging-Type-AzureAD.png)

## Étape 3 : Insérez les informations obtenues dans la section précédente

| Connu dans Azure Active Directory | Connu dans PADS4                           |
| --------------------------------- | ------------------------------------------ |
| Azure AD Identifier               | Federation Service Identifier              |
| URL of Relying Party              | URL of Relying party                       |
| SAML SSO URL                      | SAML SSO URL                               |
| App Federation Metadata           | Federation Metadata URL                    |
| Certificate (Raw)                 | Certificat du serveur de fédération (.cer) |
| Object ID                         | Active directory group ID                  |

### Important

La chaîne copiée pour le **"URL of the relying party"** dans la configuration SSO du CMS ne doit pas contenir **"/Saml"** tel que copié depuis Azure, mais uniquement **"/crystal/pads"**.

Ici, "pads" est le domaine par défaut. Par exemple, le lien copié depuis Azure ressemble à ceci :

[https://robin.pads365.com/crystal/pads/Saml2](https://robin.pads365.com/crystal/pads/Saml2)

Cependant, il devrait plutôt ressembler à ceci :

[https://robin.pads365.com/crystal/pads](https://robin.pads365.com/crystal/pads)
