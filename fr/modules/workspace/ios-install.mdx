Installez l'application une seule fois sur votre appareil Apple. Après l'installation, connectez-la à l'environnement PADS4 Workspace de votre organisation.

## Avant de commencer

* Connectez-vous sur votre appareil avec un Apple ID.
* Vérifiez que votre appareil dispose d'une connexion Internet ou d'une connexion à votre réseau local, via Wi-Fi ou données mobiles.
* Assurez-vous de disposer d'un compte : un compte PADS4 ou un compte SSO. Voir [Se connecter à l'application mobile](/modules/workspace/mobile-sign-in).

## Installer l'application

<Steps>
  <Step title="Ouvrir l'App Store">
    Sur votre appareil, ouvrez l'**App Store**.
  </Step>

  <Step title="Rechercher l'application">
    Rechercher `PADS4 Workspace`.
  </Step>

  <Step title="Installer l'application">
    Sélectionnez l'application, puis appuyez sur **Télécharger**.
  </Step>
</Steps>
