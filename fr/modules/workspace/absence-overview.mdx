Si un bureau ou un bureau vous est attribué, personne d'autre ne l'utilise pendant votre absence. Vous pouvez le libérer pour les jours où vous n'êtes pas là. Par exemple, signalez votre absence pendant les congés ou les vacances. Vos collègues peuvent alors réserver l'espace, et votre organisation utilise mieux ses espaces.

## Fonctionnement de l'absence

* L'absence s'applique à un bureau ou un bureau qui vous est *attribué*. Si vous n'avez pas d'espace attribué, vous n'avez pas besoin de signaler une absence.
* Vous signalez une absence pour un jour ou pour une période. Vous pouvez sélectionner plusieurs jours à la fois.
* Une absence apparaît en rouge dans votre calendrier. Les administrateurs peuvent la voir.
* Pendant votre absence, votre espace est libre pour que d'autres personnes puissent le réserver.

<Note>
  L'absence est différente du télétravail. Le télétravail signifie que vous travaillez depuis un autre endroit et conservez votre place. Voir [Télétravail dans PADS4 Workspace](/fr/modules/workspace/remote-work).
</Note>

## Qui attribue un espace à un utilisateur

Votre administrateur vous attribue un bureau ou un bureau. Dans un profil de salle, le paramètre **Is default assigned to user** marque les espaces qui sont normalement attribués à une seule personne. Voir [Profils de salle](/fr/modules/workspace/workspace-admin/room-profiles).
