Si un bureau ou une salle vous est attribué(e), personne d'autre ne l'utilise pendant votre absence. Vous pouvez le/la libérer pour les jours où vous n'êtes pas là. Par exemple, signalez votre absence pendant les congés ou les arrêts. Vos collègues peuvent alors réserver l'espace, et votre organisation utilise mieux ses espaces.

## Fonctionnement de l'absence

* L'absence s'applique à un bureau ou une salle qui vous est *attribué(e)*. Si vous n'avez pas d'espace attribué, vous n'avez pas besoin de signaler une absence.
* Vous signalez une absence pour un jour ou pour une période. Vous pouvez sélectionner plusieurs jours à la fois.
* Une absence apparaît en rouge dans votre calendrier. Les administrateurs peuvent la voir.
* Pendant votre absence, votre espace est libre pour que d'autres personnes puissent le réserver.

<Note>
  L'absence est différente du télétravail. Le télétravail signifie que vous travaillez depuis un autre endroit et conservez votre place. Voir [Télétravail dans PADS4 Workspace](/modules/workspace/remote-work-overview).
</Note>

## Qui attribue un espace à un utilisateur

Votre administrateur vous attribue un bureau ou une salle. Dans un profil de salle, le paramètre **Est attribué par défaut à l'utilisateur** identifie les espaces normalement attribués à une seule personne. Voir [Profils de salle](/fr/modules/workspace/workspace-admin/room-profiles).
