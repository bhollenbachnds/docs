Lorsque vous avez terminé d'utiliser PADS4 Workspace, déconnectez-vous pour sécuriser votre compte. Cela est particulièrement important sur les appareils partagés ou publics.

***

### **Comment se déconnecter**

1. Cliquez sur votre **icône utilisateur** située dans le **coin supérieur droit** de l'écran.
2. Sélectionnez **Se déconnecter** dans le menu déroulant.

Vous serez déconnecté de l'application de manière sécurisée et redirigé vers l'écran de connexion.
