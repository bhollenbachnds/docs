Lorsque vous avez fini d'utiliser PADS4 Workspace, il est important de vous déconnecter — en particulier sur les appareils partagés ou publics — afin de garantir la sécurité de votre compte.

***

### **Comment se déconnecter**

1. Cliquez sur votre **icône utilisateur** située dans le **coin supérieur droit** de l'écran.
2. Sélectionnez **Se déconnecter** dans le menu déroulant.

Vous serez déconnecté(e) de l'application de manière sécurisée et redirigé(e) vers l'écran de connexion.
