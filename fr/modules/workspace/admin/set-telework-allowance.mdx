Définissez le nombre de jours pendant lesquels un utilisateur peut travailler à distance. Les utilisateurs déclarent leurs jours de travail à distance dans l'application web Workspace, et PADS4 Workspace les décompte de cette allocation. L'interface d'administration appelle le travail à distance **Télétravail**.

## Avant de commencer

* Créez l'utilisateur de salle. Voir [Utilisateurs](/fr/modules/workspace/workspace-admin/users).
* Décidez si vous définissez le travail à distance pour un seul utilisateur ou pour un groupe d'utilisateurs avec un profil d'utilisateur de salle.

## Activer le télétravail

Choisissez le niveau qui convient à votre organisation.

| Niveau      | Où                                 | Paramètre       | Utiliser pour                                                            |
| ----------- | ---------------------------------- | --------------- | ------------------------------------------------------------------------ |
| Utilisateur | **Room Users** > l'utilisateur     | **Télétravail** | Un utilisateur qui travaille depuis un site distant.                     |
| Profil      | **Room User Profiles** > le profil | **Télétravail** | Un groupe d'utilisateurs qui travaillent principalement depuis chez eux. |

## Définir l'allocation pour un utilisateur

<Steps>
  <Step title="Ouvrir l'utilisateur">
    Dans l'interface d'administration, accédez à **Room Users**, puis ouvrez l'utilisateur.
  </Step>

  <Step title="Ouvrir l'onglet Télétravail">
    Sélectionnez l'onglet **Télétravail**.
  </Step>

  <Step title="Définir le nombre maximum de jours">
    Entrez le nombre maximum de jours pendant lesquels l'utilisateur peut travailler depuis chez lui ou depuis un autre lieu distant.
  </Step>

  <Step title="Ajouter des périodes de planification">
    (Facultatif) Créez un planning pour une période spécifique. Pour chaque période, entrez la date de début, la date de fin et le nombre de jours de télétravail autorisés.
  </Step>

  <Step title="Enregistrer l'utilisateur">
    Enregistrez vos modifications.
  </Step>
</Steps>

## Vérifier l'allocation

Demandez à l'utilisateur d'ouvrir l'outil de travail à distance dans l'application web Workspace. Les jours de travail à distance restants sont affichés en bas à gauche. Voir [Déclarer le travail à distance](/fr/modules/workspace/workspace-web-application/declaring-remote-work).
