- description: Activez la fonctionnalité Rechercher un collègue dans les

    puissent voir où leurs collègues sont planifiés pour travailler.
---

La recherche de collègues permet aux utilisateurs de voir où leurs collègues sont planifiés pour travailler. La fonctionnalité est désactivée jusqu'à ce que vous l'activiez dans les paramètres de confidentialité de PADS4 Workspace.

## Avant de commencer

La recherche de collègues affiche les réservations des utilisateurs à d'autres utilisateurs. Vérifiez que cela est conforme aux règles de confidentialité de votre organisation avant de l'activer.

## Activer la recherche de collègues

<Steps>
  <Step title="Ouvrir les paramètres de l'application">
    Dans l'interface d'administration, ouvrez les paramètres de l'application Workspace.
  </Step>

  <Step title="Ouvrir les paramètres de confidentialité">
    Accédez aux paramètres de confidentialité. Ces paramètres s'appliquent à toutes les réservations dans PADS4 Workspace.
  </Step>

  <Step title="Activer la fonctionnalité">
    Activez **Rechercher un collègue**.
  </Step>

  <Step title="Enregistrer les paramètres">
    Enregistrez vos modifications.
  </Step>
</Steps>

Les mêmes paramètres de confidentialité contrôlent si le nom de l'organisateur est visible pour les réservations.

## Vérifier le paramètre

Demandez à un utilisateur de vérifier que **Rechercher des collègues** est dans le menu principal de PADS4 Workspace. Voir [Rechercher des collègues](/fr/modules/workspace/search-for-colleagues).
