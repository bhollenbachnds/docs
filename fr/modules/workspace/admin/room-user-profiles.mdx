Un *profil d'utilisateur de salle* définit les niveaux d'accès et les autorisations pour un groupe d'utilisateurs de salle. Attribuez le même profil à chaque utilisateur du groupe, plutôt que de définir les mêmes options pour chaque utilisateur. Vous gérez les profils dans l'onglet **Profils d'utilisateurs de salle**.

Par défaut, un utilisateur de salle peut consulter et réserver toutes les salles disponibles. Un profil peut limiter cela à des salles sélectionnées, ou permettre aux utilisateurs de consulter les salles sans les réserver.

## Paramètres du profil

| Paramètre                            | Description                                                                                             |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| **Nom**                              | Le nom du profil.                                                                                       |
| **Description**                      | Une brève description de l'objectif du profil, ou du groupe d'utilisateurs auquel il est destiné.       |
| **Télétravail**                      | Activez cette option si les utilisateurs avec ce profil travaillent principalement depuis chez eux.     |
| **Empêcher la réservation de salle** | Activez cette option pour permettre aux utilisateurs de consulter les salles, mais pas de les réserver. |

### Onglet Salles

Dans l'onglet **Salles**, choisissez les salles que les utilisateurs avec ce profil peuvent **consulter** et celles qu'ils peuvent **réserver**.

## Quand utiliser un profil

Utilisez un profil lorsque de nombreux utilisateurs ont besoin du même accès. Par exemple, créez un profil pour les utilisateurs d'un bâtiment, et un autre pour les utilisateurs qui ont uniquement besoin de consulter les salles. Utilisez les paramètres d'un seul utilisateur pour les exceptions. Voir [Paramètres des utilisateurs de salle](/fr/modules/workspace/admin/room-user-settings).
