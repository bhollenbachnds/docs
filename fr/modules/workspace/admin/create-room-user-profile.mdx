Créez un profil pour donner à un groupe d'utilisateurs de salle le même accès aux salles.

## Avant de commencer

Identifiez les salles que le groupe peut consulter et celles qu'il peut réserver. Voir [Profils d'utilisateurs de salle](/fr/modules/workspace/workspace-admin/room-user-profile).

## Créer un profil

<Steps>
  <Step title="Ouvrir les profils d'utilisateurs de salle">
    Dans l'interface d'administration Workspace, accédez à **Profils d'utilisateurs de salle**.
  </Step>

  <Step title="Ajouter le profil">
    Sélectionnez **Ajouter un profil d'utilisateur de salle**.
  </Step>

  <Step title="Saisir les informations générales">
    Saisissez un **Nom** et une **Description**. Activez **Télétravail** si les utilisateurs travaillent principalement depuis chez eux. Activez **Empêcher la réservation de salle** si les utilisateurs peuvent consulter les salles mais pas les réserver.
  </Step>

  <Step title="Choisir les salles">
    Dans l'onglet **Salles**, choisissez les salles que les utilisateurs peuvent consulter et celles qu'ils peuvent réserver.
  </Step>

  <Step title="Enregistrer le profil">
    Enregistrez le profil.
  </Step>
</Steps>

{/* SCREENSHOT: Workspace admin interface > Room User Profiles, the form to add a profile with the Rooms tab. */}

Attribuez le profil à un utilisateur dans le champ **Profil** lorsque vous [ajoutez un utilisateur de salle](/fr/modules/workspace/admin/add-user).

## Modifier un profil

1. Dans **Profils d'utilisateurs de salle**, sélectionnez l'option de modification pour le profil.
2. Modifiez les champs dont vous avez besoin.
3. Enregistrez vos modifications.

## Supprimer un profil

1. Dans **Profils d'utilisateurs de salle**, sélectionnez l'option de modification pour le profil.
2. Sélectionnez **Supprimer**.
