L'application mobile PADS4 Workspace apporte PADS4 Workspace sur votre téléphone ou tablette. Utilisez-la pour trouver et réserver un espace, consulter vos réservations et recevoir des notifications lorsque vous n'êtes pas à votre bureau.

## Ce que vous pouvez faire

* **Rechercher et réserver des espaces** : Trouvez une salle ou un bureau disponible et réservez-le.
* **Consulter vos réservations** : Voyez ce que vous avez réservé.
* **Recevoir des notifications** : Soyez notifié de vos réservations.

Pour les options de réservation, l'application mobile fonctionne comme PADS4 Workspace dans le navigateur. Voir [Utiliser l'application mobile](/modules/workspace/mobile-use).

## Ce dont vous avez besoin

| Exigence                | Description                                                                                          |
| ----------------------- | ---------------------------------------------------------------------------------------------------- |
| **Appareil**            | Un téléphone ou une tablette avec Apple iOS ou Android.                                              |
| **Compte de boutique**  | Un Apple ID sur iOS, ou un compte Google sur Android, pour télécharger l'application.                |
| **Compte de connexion** | Un compte PADS4, ou un compte d'authentification unique (SSO) de votre organisation.                 |
| **Connexion**           | Une connexion Internet ou une connexion à votre réseau local, via Wi-Fi ou données mobiles.          |
| **Adresse du serveur**  | L'adresse du serveur PADS4 Workspace de votre organisation. Votre administrateur vous la communique. |
