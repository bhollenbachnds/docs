Configurez les approbations et les demandes de réservation afin que les utilisateurs puissent suivre les processus dans [Approbations et demandes de réservation](/fr/modules/workspace/booking-workflows). Vous configurez trois éléments : l'approbation pour une salle, les demandes de réservation pour les utilisateurs, et les gestionnaires pour les salles.

## Activer l'approbation pour une salle

<Steps>
  <Step title="Ouvrir la salle">
    Dans l'interface d'administration, accédez à **Rooms**, puis ouvrez la salle.
  </Step>

  <Step title="Activer l'approbation">
    Dans l'onglet **Approval**, spécifiez que les réservations pour cette salle nécessitent une approbation.
  </Step>

  <Step title="Enregistrer la salle">
    Enregistrez vos modifications.
  </Step>
</Steps>

## Autoriser les demandes de réservation pour un utilisateur

1. Accédez à **Room Users**, puis ouvrez l'utilisateur.
2. Activez **Booking request enabled**. L'utilisateur peut alors envoyer des demandes de réservation à son gestionnaire.
3. Enregistrez l'utilisateur.

## Accorder à un utilisateur les droits de gestionnaire

Les gestionnaires peuvent modifier les réunions dans les salles qu'ils gèrent.

1. Accédez à **Room Users**, puis ouvrez l'utilisateur.
2. Activez **Enable bookings overview**. L'onglet **Manager** apparaît à côté de l'onglet **Delegation**.
3. Dans l'onglet **Manager**, sélectionnez les salles que l'utilisateur gère.
4. Enregistrez l'utilisateur.
