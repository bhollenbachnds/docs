## Aperçu des formulaires

Si vous avez créé un formulaire, vous serez redirigé vers le tableau de bord des formulaires dans la section Catégorie. Cela affichera votre formulaire avec les propriétés suivantes :

Les onglets de gauche et les catégories codées par couleur afficheront toutes les catégories disponibles et configurées dans votre environnement PADS4 CMS. Vous pouvez facilement basculer entre les catégories ici.

Au centre, vous trouverez un aperçu de vos formulaires créés.

• Capture d'écran : La capture d'écran qui a été configurée dans le formulaire comme référence.<br />• Nom du formulaire : Le nom du formulaire est affiché ici<br />• État : Ceci affiche l'état actuel du formulaire. Lors de la création, le paramètre par défaut est actif. Vous pouvez activer/désactiver cette option ici dans le tableau de bord.

* Cliquer sur l'option Sélectionner vous permettra d'accéder au tableau de bord des messages.<br />- Cliquer sur l'icône crayon vous permettra de modifier, dupliquer ou supprimer le formulaire.

#### Messages

Lorsque vous sélectionnez l'option Sélectionner sur votre formulaire, vous serez dirigé vers le tableau de bord des messages. Ici, vous pouvez voir tous les messages que les utilisateurs ont créés dans votre environnement PADS4 CMS Digital Signage. Lors de la première utilisation, il sera vide. Vous verrez les formulaires configurés avec un codage couleur sur le côté gauche.

Au centre, vous trouverez un aperçu de vos messages créés :

• Étiquette : Nom que vous avez fourni.<br />• Nom de la propriété : Nom que le champ a fourni.<br />• Date de début : La date de début du message<br />• Date de fin : La date de fin du message<br />• État : indique si le message est activement planifié (passé/actuel/futur).<br />• Statut : indique l'état actif/inactif du message<br />• Auteur : indique quel utilisateur a créé le message

Si vous sélectionnez l'icône crayon, vous pouvez :

* Prévisualiser le message sur la présentation (si vous avez activé la Prévisualisation dans le formulaire)<br />- Modifier le message<br />- Dupliquer le message<br />- Supprimer le message

#### Ajouter un message

En sélectionnant Ajouter un message ou l'icône + dans le coin supérieur droit, vous pouvez ajouter un message. Ce message est défini par le formulaire qui a été configuré par l'Administrateur ou l'Utilisateur (profil). Il est construit de la manière suivante :

**Diffusion**: par défaut, le message sera planifié pour 1 journée de travail complète (24 heures) au moment de la création. Vous pouvez modifier la récurrence en sélectionnant l'icône de calendrier jaune à droite. Vous pouvez modifier la date/heure de début et sélectionner une date/heure définie ou sélectionner l'option "Pas de date de fin". Cela permettra au message d'être toujours actuel.

En cliquant sur l'icône de flèche circulaire, vous activerez plus d'options de récurrence :

**Type de planification**:<br />\*\*\* Quotidien. Vous pouvez sélectionner si le message est affiché par jour, ou chaque jour de la semaine.<br />\*\*\* Hebdomadaire : vous pouvez sélectionner quel jour de la semaine les messages sont affichés et/ou en semaines alternées.

**Un jour**: personnalisez l'heure de début et de fin pour chaque jour.

Lorsque vous avez sélectionné votre préférence, cliquez sur le bouton Enregistrer pour revenir au message.

**Formulaire**: le message affichera les sections/champs qui ont été configurés dans le formulaire pour que l'utilisateur puisse créer/configurer.

**Écrans**: sélectionnez les groupes/écrans sur lesquels ce message sera affiché.

Lorsque vous avez configuré votre planning de diffusion, le formulaire/message et sélectionné les Écrans, cliquez sur l'icône d'enregistrement pour revenir au tableau de bord des messages.

#### Ordre des messages

Sous les messages, vous pouvez créer un ordre personnalisé des messages. Passez simplement votre souris sur la colonne de gauche du message, et une icône à six points apparaîtra. Faites ensuite glisser et déposez votre message à la position souhaitée.

Vous pouvez confirmer la position par message en regardant la colonne Ordre à droite.

Note: if you want to select other ways of sorting the data of the messages in your presentation, please setup the filter/sort data section of PADS4 CMS Dataprovider in the Designer.
