Les formulaires sont des modèles utilisés pour définir la mise en page et la structure des messages d'affichage dynamique. Ils déterminent où le contenu apparaît sur l'écran et comment il est formaté. Considérez un formulaire comme un cadre de conception que vous pouvez réutiliser dans différents messages.

### Créer un nouveau formulaire

Pour créer un formulaire :

1. **Accédez à la section 'Forms'**<br />Sélectionnez la **Catégorie** à laquelle vous souhaitez que le formulaire appartienne dans le menu de navigation.
2. **Cliquez sur Add a Form**<br />Cela ouvrira l'interface de l'éditeur de formulaires.
3. **Définir les paramètres du formulaire** :
   * **Nom**: Attribuez un nom qui reflète son objectif (par ex., "Welcome Layout" ou "News Bar").
   * **Résolution/Taille**: Sélectionnez la résolution d'écran appropriée (par ex., 1920x1080 pour la full HD).
   * **Orientation**: Sélectionnez **Portrait** ou **Paysage** selon la configuration de votre écran.
4. **Concevoir la mise en page du masque** :<br />Utilisez les outils de l'éditeur pour ajouter et positionner des zones de contenu telles que :
   * **Blocs de texte**
   * **Zones d'image**
   * **Zones vidéo**
   * **Bandeaux défilants**
   * **Champs de données dynamiques (par ex., date, météo, RSS)**
5. **Enregistrer votre masque**<br />Une fois la mise en page définie, enregistrez le masque afin qu'il puisse être réutilisé lors de la création de messages.

### Gérer les masques existants

* **Modifier**: Ouvrez n'importe quel masque pour mettre à jour sa mise en page ou ajuster les champs.
* **Dupliquer**: Créez une copie d'un masque existant pour des modifications rapides.
* **Supprimer**: Supprimez les masques inutilisés (notez que les masques utilisés par des messages peuvent être verrouillés contre la suppression).

Les masques vous permettent de maintenir une identité visuelle cohérente tout en offrant aux utilisateurs la flexibilité de mettre à jour le contenu des messages dans une structure prédéfinie.
