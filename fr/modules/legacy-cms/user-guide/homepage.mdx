#### Tableau de bord

Bienvenue sur le tableau de bord de PADS4 CMS 1.0. La section affichage dynamique de PADS4 CMS 1.0 permet aux utilisateurs de télécharger du contenu, de créer des messages et de planifier ce contenu sur certaines présentations et écrans PADS4. Après avoir configuré votre section Administrateur avec les utilisateurs, vous pouvez commencer par configurer vos premiers formulaires, messages et bien plus encore.

Voici un aperçu de ce que vous pouvez voir sur le tableau de bord lorsque vous vous connectez pour la première fois avec votre compte Administrateur :

• Un message de bienvenue en haut à gauche.<br />• Un exemple de texte de fil d'actualités défilant en haut à droite.<br />• Un module de messages diffusés qui présente vos messages planifiés actuels/passés.<br />• Un module Mon historique qui présente vos messages créés précédemment.

Sur le côté gauche, vous trouverez les onglets suivants :

• **Home** : Ceci vous amènera à l'écran d'accueil / tableau de bord de la section CMS.<br />• **Category** : Ici, vous pouvez configurer des formulaires/catégories/messages pour les utilisateurs de PADS4 CMS.<br />• **Broadcast** : Ici, vous pouvez consulter vos messages actuellement diffusés et leur planification.<br />• **History** : Ici, vous pouvez consulter l'historique des messages créés.<br />• **Screens** : Ici, vous pouvez configurer et gérer tous vos écrans PADS4 CMS.\*<br />• **Newsfeed** : Ici, vous pouvez configurer un message pour vos utilisateurs dans PADS4 CMS.

Important: Screens do not sync automatically with your PADS4 installation (Viewers setup in System Management, CTRL Center or Agent). You have to manually configure and setup the screens with the same name (no special characters) inside PADS4 CMS - Digital Signage - Screens to implement the functionality correctly.
