Les catégories dans PADS4 CMS Designer sont utilisées pour organiser les modèles et les messages. Elles permettent de maintenir un environnement structuré, notamment lors de la gestion du contenu entre plusieurs départements, emplacements ou cas d'utilisation.

## Créer une nouvelle catégorie

Pour créer une nouvelle catégorie :

* Accédez à la section **Nouveau message** dans le menu de navigation principal.

![Cms1](/images/digital-signage/cms/cms1.png)

* Cliquez sur le bouton **Créer une nouvelle catégorie**.

<img src="/images/digital-signage/cms/cms-new-category.png" alt="Cms New Category" style={{ width:"41%" }} />

* Dans le formulaire qui apparaît, saisissez les informations suivantes :
  * **Nom de la catégorie** : Le nom qui identifie cette catégorie.
  * **Description** *(facultatif)* : Une brève explication de l'objet de cette catégorie.
* Sélectionnez le viewer avec lequel ce modèle peut être utilisé.

<img src="/images/digital-signage/cms/cms-new-category2.png" alt="Cms New Category2" style={{ width:"44%" }} />

* Cliquez sur **Créer** pour créer la catégorie.

Après avoir créé la catégorie, elle apparaît dans la liste. Vous pouvez l'utiliser pour organiser les modèles et les messages. Les catégories peuvent également aider à définir les autorisations des utilisateurs et à simplifier la création de messages en regroupant le contenu associé.

![Create A Template1](/images/digital-signage/cms/create-a-template1.png)
