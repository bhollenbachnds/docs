Les catégories dans PADS4 CMS Designer sont utilisées pour organiser les templates et les messages. Elles permettent de maintenir un environnement structuré, notamment lors de la gestion de contenu entre plusieurs départements, emplacements ou cas d'utilisation.

## Créer une nouvelle catégorie

Pour créer une nouvelle catégorie :

* Accédez à la **New message** dans le menu de navigation principal.

![Cms1](/images/digital-signage/cms/cms1.png)

* Cliquez sur **Create a new category** bouton.

<img src="/images/digital-signage/cms/cms-new-category.png" alt="Cms New Category" style={{ width:"41%" }} />

* Dans le formulaire qui apparaît, saisissez les informations suivantes :
  * **Category Name** : Le nom qui identifie cette catégorie.
  * **Description** *(facultatif)* : Une brève explication de l'objet de cette catégorie.
* Sélectionnez le viewer avec lequel ce template peut être utilisé.

<img src="/images/digital-signage/cms/cms-new-category2.png" alt="Cms New Category2" style={{ width:"44%" }} />

* Cliquez sur **Create** pour créer la catégorie.

Une fois la catégorie créée, elle apparaît dans la liste. Vous pouvez l'utiliser pour organiser les templates et les messages. Les catégories peuvent également aider à définir les permissions des utilisateurs et à simplifier la création de messages en regroupant les contenus associés.

![Create A Template1](/images/digital-signage/cms/create-a-template1.png)
