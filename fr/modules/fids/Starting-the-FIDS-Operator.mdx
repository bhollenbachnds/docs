---
- title: Démarrage de FIDS Operator
---

Pour commencer à utiliser **PADS4FIDS Operator**, vous devez y accéder via votre navigateur web en utilisant l'URL correcte et vous connecter avec votre compte PADS4.

## Connexion à PADS4FIDS Operator

Dans la barre d'adresse de votre navigateur, entrez l'URL suivante :

```text
https://<Server Name>/
```

Remplacez `<Server Name>` par le **nom d'hôte** ou l'**adresse IP** du serveur sur lequel PADS4FIDS est installé.

## Connexion

Une fois l'URL correcte saisie, la page de **Connexion** s'affichera.

1. Entrez votre **Nom d'utilisateur** et votre **Mot de passe**.
2. Cliquez sur **Connexion** pour accéder à l'application.

> Si vous cliquez sur **"Impossible d'accéder à votre compte"**, une page d'aide s'ouvrira dans une fenêtre séparée pour vous aider à résoudre les problèmes de connexion.

Après une connexion réussie, l'interface principale de **PADS4FIDS Operator** se lancera.

## Dépannage

### Pas d'identifiants ?

Si vous ne disposez pas d'identifiants de connexion :

* Contactez votre administrateur.
* Assurez-vous qu'une **licence PADS4FIDS Operator** a été attribuée à votre compte via l'application **PADS4 System Management**.

### Page Introuvable ?

Si vous recevez une erreur **"Page Introuvable"** error:

* Vérifiez que l'installation de PADS4FIDS est complète et en cours d'exécution sur le serveur spécifié.
* Vérifiez les fautes de frappe dans l'URL ou un numéro de port incorrect.
