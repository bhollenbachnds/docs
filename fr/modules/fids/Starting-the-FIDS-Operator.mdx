Pour commencer à utiliser le **PADS4FIDS Operator**, vous devez y accéder via votre navigateur web en utilisant l'URL correcte et vous connecter avec votre compte PADS4.

## Connexion au PADS4FIDS Operator

Dans la barre d'adresse de votre navigateur, saisissez l'URL suivante :

```text
https://<Server Name>/
```

Remplacez `<Server Name>` par le **nom d'hôte** ou l'**adresse IP** du serveur sur lequel PADS4FIDS est installé.

## Connexion

Une fois l'URL correcte saisie, la **Sign In** page apparaîtra.

1. Entrez votre **Nom d'utilisateur** et **Mot de passe**.
2. Cliquez sur **Sign In** pour accéder à l'application.

> Si vous cliquez sur **"Can't access your account"**, une page d'aide s'ouvrira dans une fenêtre séparée pour vous aider à résoudre les problèmes de connexion.

Après une connexion réussie, le **PADS4FIDS Operator** interface principale se lancera.

## Dépannage

### Pas d'identifiants ?

Si vous n'avez pas d'identifiants de connexion :

* Contactez votre administrateur.
* Assurez-vous qu'une **licence PADS4FIDS Operator** a été attribuée à votre compte à l'aide de l'application **PADS4 System Management**.

### Page introuvable ?

Si vous recevez un **"Page Not Found"** error:

* Vérifiez que l'installation de PADS4FIDS est complète et en cours d'exécution sur le serveur spécifié.
* Vérifiez les fautes de frappe dans l'URL ou le numéro de port incorrect.
