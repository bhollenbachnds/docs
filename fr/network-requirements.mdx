- title: Exigences réseau et pare-feu pour PADS4
- description: Référence des ports TCP, UDP et HTTP utilisés par les composants
    serveur et client PADS4, incluant le port par défaut 7237 et les règles de
    pare-feu entrantes ou sortantes requises.
---

Cette page explique quels ports réseau PADS4 utilise. Les numéros de port répertoriés sont les paramètres par défaut. Vous pouvez ajuster certains ports.

La communication réseau entre les composants du système PADS4 utilise TCP/IP. PADS4 utilise un port pour communiquer. Le port par défaut est 7237.

Si vous utilisez un pare-feu sur le PADS4 Server, ouvrez un ou plusieurs des numéros de port répertoriés ci-dessous afin que PADS4 puisse communiquer sur le réseau.

Du côté client, il n'est pas nécessaire d'ouvrir des numéros de port dans le pare-feu.

## Ports du PADS4 Server utilisés avec les connexions externes

| Port         | Protocole | Règles de pare-feu | Description                                                                                    |
| ------------ | --------- | ------------------ | ---------------------------------------------------------------------------------------------- |
| 7237         | TCP       | Entrant            | Port par défaut utilisé pour la communication PADS4                                            |
| 3702         | UDP       | Entrant            | Requis pour la fonction de recherche du serveur PADS4 (fonctionnalité de découverte du réseau) |
| 4525 ou 443  | HTTP      | Sortant            | Activation en ligne (un seul port doit être disponible)                                        |
| 80 et/ou 443 | HTTP      | Entrant / Sortant  | Mises à jour logicielles et réplication lors de l'utilisation de plusieurs serveurs            |
| 7            | UDP       | Sortant            | Fonction Wake On LAN (port WOL standard)                                                       |
| 9            | UDP       | Sortant            | Fonction Wake On LAN (port WOL standard)                                                       |
| 123          | UDP       | Entrant / Sortant  | Requis pour NTP (Network Time Protocol pour la synchronisation de l'heure du Viewer)           |

## Ports locaux du PADS4 Server

*PADS4 utilise ces ports uniquement en local.*

| Port  | Protocole | Description                                                   |
| ----- | --------- | ------------------------------------------------------------- |
| 15672 | HTTP      | Utilisé par RabbitMQ pour la connexion API HTTP               |
| 15671 | HTTP      | Utilisé par RabbitMQ https pour la connexion API HTTP via TLS |
| 5672  | TCP       | Utilisé par RabbitMQ AMQP                                     |
| 5671  | TCP       | Utilisé par RabbitMQ AMQP via TLS                             |

## Ports du PADS4 Viewer

| Port | Protocole | Règles de pare-feu | Description                                                                                    |
| ---- | --------- | ------------------ | ---------------------------------------------------------------------------------------------- |
| 7237 | TCP       | Sortant            | Port par défaut utilisé pour la communication PADS4                                            |
| 3702 | UDP       | Sortant            | Requis pour la fonction de recherche du serveur PADS4 (fonctionnalité de découverte du réseau) |
| 7    | UDP       | Entrant            | Fonction Wake On LAN (port WOL standard)                                                       |
| 9    | UDP       | Entrant            | Fonction Wake On LAN (port WOL standard)                                                       |
| 123  | UDP       | Entrant / Sortant  | Requis pour NTP (Network Time Protocol pour la synchronisation de l'heure du Viewer)           |

## Ports du PADS4 HTML5 Viewer

Port 80 et/ou 443 (HTTP)

### Remarque

<Note>
  PADS4 dispose de fonctionnalités intégrées pour détecter automatiquement un PADS4 Server sur votre réseau. Cependant, PADS4 ne peut détecter automatiquement un PADS4 Server que si aucun pare-feu sur le PC serveur ou ailleurs dans le réseau ne bloque le port UDP 3702.
</Note>

<Note>
  La version 2021.3 introduit un nouveau mécanisme qui réplique dans les deux sens. Les modifications sur le serveur Sub/Backup sont synchronisées avec le serveur principal et les modifications du serveur principal sont synchronisées avec les serveurs Sub/Backup.
</Note>
