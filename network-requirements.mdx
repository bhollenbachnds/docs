This page lists the network ports that PADS4 uses. The port numbers are the default settings. You can change some of them. 

Components of the PADS4 system communicate over TCP/IP. PADS4 uses one port for this communication. The default port is 7237.

If you use a firewall on the PADS4 Server, open the ports that you need from the tables on this page. On the client side, you don't need to open any ports in the firewall.

## PADS4 Server ports for external connections

| Port | Protocol | Firewall rule | Description |
| --- | --- | --- | --- |
| 7237 | TCP | Inbound | Default port for PADS4 communication. |
| 3702 | UDP | Inbound | Needed to search for a PADS4 Server on the network (network discovery). |
| 4525 or 443 | HTTP | Outbound | Online activation. Only one of the two ports must be available. |
| 443 / 80 | HTTPS<br />or HTTP | Inbound and outbound | Software updates, and replication when you use more than one server. |
| 7 | UDP | Outbound | Wake on LAN (standard Wake on LAN port). |
| 9 | UDP | Outbound | Wake on LAN (standard Wake on LAN port). |
| 123 | UDP | Inbound and outbound | Network Time Protocol (NTP), for Viewer time synchronization. |

<Info>
  From PADS4 2021.3, replication works in both directions. PADS4 synchronizes changes on the Sub Server or Backup Server with the Main Server. It also synchronizes changes on the Main Server with the Sub Servers and Backup Servers.
</Info>

## PADS4 Windows Viewer ports

| Port | Protocol | Firewall rule | Description |
| --- | --- | --- | --- |
| 7237 | TCP | Outbound | Default port for PADS4 communication. |
| 3702 | UDP | Outbound | Needed to search for a PADS4 Server on the network (network discovery). |
| 7 | UDP | Inbound | Wake on LAN (standard Wake on LAN port). |
| 9 | UDP | Inbound | Wake on LAN (standard Wake on LAN port). |
| 123 | UDP | Inbound and outbound | Network Time Protocol (NTP), for Viewer time synchronization. |

## Automatic detection of PADS4 Server

<Note>
  PADS4 can detect a PADS4 Server on your network automatically. This works only if no firewall on the server computer, or elsewhere on the network, blocks UDP port 3702.
</Note>
