To activate your **PADS4 product**, follow the steps below using the provided **PADS4 license key.**

## Step 1: Open PADS4 CTRL Center

- After installing **PADS4**, browse to the **PADS4 Web Portal.**

<Tip>
  If you re-activate a PADS4 installation that is already in use, you don't need to use the su\\root user. Any user with the **System Management \+ License Management** license can re-activate the installation by going to **Licenses** in the left-hand menu.
</Tip>

- Log in with the **su\\root** user.
- At the top of the screen, select the "**pads**" domain.

![Root Domain](/images/install-pads4/activating-pads4/root-domain.png)

- **Licenses** now appears in the left-hand menu.

<img
  src="/images/install-pads4/activating-pads4/root-licenses.png"
  alt="Root Licenses"
  title="Root Licenses"
  style={{ width:"100%" }}
/>

- Select **Licenses**, then select **Activate**.

![Root License2](/images/install-pads4/activating-pads4/root-license2.png)

- If an internet connection is unavailable, PADS4 displays an **offline activation** method.
  - Follow the instructions provided on-screen.
  - After receiving the **License File**, select **Upload License File**, then select the file.
  - Complete the activation process by following the wizard.

Once activation is complete, your **PADS4 installation is ready for use.**
