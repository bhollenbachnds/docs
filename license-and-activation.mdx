---
title: "License & activation"
description: "Activate the plugin's own license online or with an offline activation file, read the license status card, and remove a license to move it elsewhere."
---

**License** (`/license`, administrator only) manages _this plugin's own_ activation. This is separate from PADS4's own application licensing.

### Status card

Shows current state (Active / Expired / Not activated), licensee, license key, activation mode (Online or Offline file), activation date, expiry (or "Never (perpetual)"), and days remaining. It also shows the last time it was checked online and this installation's unique **Installation ID**. The ID has a one-click copy button, and you need it for offline activation requests.

### Activating

- **Online**: paste the license key you were issued and click **Activate**. Requires this server to reach the license server directly.
- **Offline** (no internet access from this server): copy the Installation ID from the status card. Request an activation file from NDS using that ID plus your license key (you can do this from any machine with internet access). Then use **Upload activation file…** to select the `.lic` file you received. The app validates the file client-side for a sane size before upload.

### Removing a license

Once active, a **Remove license…** option appears (behind a confirmation step, since it immediately stops the application from being usable until re-activated). Use this when moving a license to a different installation.

The plugin periodically re-validates an active license in the background. If that check fails, a warning appears on this page describing the problem without necessarily deactivating the app immediately (grace behavior depends on the license terms).
